## 审查重点

1. 空但已选择的较高字段仍必须使用对应结构权限；空值不得被降级丢弃。
2. 非空值权限须按实际内容判定，非空倒计时不得缺少 intermediate；direct-only 不得被无关撤权清空。
3. 暂存时捕获的权限 epoch 不得在撤权恢复、换号或迟到异步后复活。
4. 未选列、重复表头、错误详情和预览不得泄露未选单元格；Wire 重试不得重新投影或变体。
5. CSV 与完整 JSON 各自 65536 字节边界、窄屏高级区及操作可达性均须真实测试。
