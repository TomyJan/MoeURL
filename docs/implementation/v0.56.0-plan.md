## 审查重点

1. 指定短码不得因唯一冲突变成随机，软删除和跨域名同样占用；一行失败整批无副作用。
2. 撤权重放和全部空短码仍需四列全部权限，未知重试不得跨账号或接口。
3. 归一化重复和随机抢占稍后指定短码不得造成顺序相关结果。
4. 四协议回执键共享，原始大小写／空白／标签顺序摘要保留，旧三协议字节不变。
5. 严格 JSON／surrogate、文件与完整请求各 65536 字节、迟到异步不覆盖新草稿。
