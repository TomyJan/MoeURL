# v0.1.1 验收清单

> 未执行的项目不得标记为完成。

## API 与权限

- [ ] 个人概览 API 只返回当前用户拥有且未删除短链的聚合结果。
- [ ] API 使用 `short_link:read_own`，管理员个人概览不泄露全站数据。
- [ ] 总数、启用数、总访问量和今日访问量口径正确。
- [ ] 无数据返回零值，权限不足和基础设施错误符合既有响应约定。

## 控制台

- [ ] `/console` 展示真实概览数据，不展示伪造数据。
- [ ] 最近 5 条短链按创建时间倒序展示，并可进入短链管理和访问分析。
- [ ] 指标与最近短链具备独立加载和错误状态。
- [ ] 空数据、移动端和中英文文案完整。
- [ ] 概览导航不再标记为规划中，旧概览占位配置已删除。

## 发布验证

- [ ] `go test ./...` 通过。
- [ ] `go vet ./...` 通过。
- [ ] 后端覆盖率门禁为 100%。
- [ ] `cd web && pnpm lint`、`pnpm typecheck`、`pnpm test`、`pnpm test:coverage`、`pnpm build` 通过。
- [ ] `git diff --check` 通过。
