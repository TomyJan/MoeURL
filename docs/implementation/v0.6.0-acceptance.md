# v0.6.0 验收清单

状态：尚未验收。以下项目必须由实际命令和环境证据支持后才能勾选。

> 未执行的项目不得标记为完成。

## 配置与初始化安全

- [ ] production 缺少、空白或少于 32 字符的 `MOEURL_SETUP_TOKEN` 时应用拒绝启动，development 可省略。
- [ ] 初始化状态只返回 `initialized` 和 `setupTokenRequired`，不返回 Token 内容。
- [ ] setup 先校验普通输入和已初始化状态，再校验 Token；正确 Token 只能完成一次初始化。
- [ ] Token 不写入数据库、日志或响应，前端在成功和失败后清除局部值与 mutation variables。

## HTTP 与健康检查

- [ ] HTTP Server 配置 5 秒 Header、15 秒读取、30 秒写入、60 秒空闲超时和 1 MiB Header 上限。
- [ ] 合法请求 ID 被透传，非法值被替换；响应、请求日志、panic 和 readiness 错误使用同一 ID。
- [ ] panic 返回 HTTP `500`、`code=900000`，客户端看不到 panic 值、stack 或内部错误。
- [ ] 安全响应头与当前前端产物兼容，应用明文响应不发送 HSTS。
- [ ] 非读取请求体上限为 1 MiB，超限请求不能继续进入业务 Handler。
- [ ] `/api/v1/health/live` 不访问数据库或 Current User；readiness 和兼容 `/health` 在数据库失败时返回 HTTP `503`。
- [ ] 数据库启动 Ping 失败时应用不监听端口且已创建的 Pool 被关闭。

## 生命周期与后台任务

- [ ] `SIGINT` 和 `SIGTERM` 停止新请求并等待在途请求，正常关闭不把 `http.ErrServerClosed` 记录为故障。
- [ ] HTTP drain、Session 清理、短链授权清理和 Pool 关闭遵循固定顺序，任一步失败不跳过后续资源释放。
- [ ] 统一关闭期限为 15 秒；超时记录失败并产生非零退出语义。
- [ ] Shutdown 支持重复调用、nil 任务和部分初始化，不 panic、不重复关闭资源。

## 登录与 Session

- [ ] `00011` Up、Down 和再次 Up 通过；Down 只丢失登录失败临时状态，不修改用户、Session 或短链数据。
- [ ] 登录失败表只存用户名摘要和计数状态，不存额外明文用户名。
- [ ] 未知用户名、无密码和错误密码均执行一次 Argon2id 校验并返回相同凭据错误。
- [ ] 用户名摘要只裁剪首尾空白并保持大小写敏感语义。
- [ ] 15 分钟内第 10 次失败触发 15 分钟阻断，窗口边界、并发请求和多 Service 实例结果一致。
- [ ] 成功登录清理失败状态；禁用账号保留既有错误语义且不创建 Session。
- [ ] Session 清理每轮最多删除 500 条过期或撤销记录，保留有效记录；错误不阻断在线请求，取消后任务退出。

## 前端与回归

- [ ] Setup 页面仅在 `setupTokenRequired=true` 时显示密码型 Token 输入，桌面和移动布局可操作且无溢出。
- [ ] production 初始化 E2E 覆盖缺失、错误和正确 Token，响应、页面和报告不泄露 Token。
- [ ] v0.2.0 至 v0.5.0 真实入口 E2E、权限即时生效、密码和三种跳转模式均无回退。

## Compose、备份与恢复

- [ ] 缺少数据库密码时 `docker compose config` 失败；`.env.example` 不包含可用于生产的弱密码。
- [ ] PostgreSQL 不映射宿主端口，App 默认只绑定 `127.0.0.1`。
- [ ] App 以非 root 运行，并启用只读根文件系统、`tmpfs /tmp`、init、healthcheck 和重启策略。
- [ ] 外部 TLS 反向代理负责 HTTPS、HSTS、可信转发头和登录、初始化、公开解锁的来源级限流。
- [ ] 空卷 Compose 可以迁移到 v11、readiness 正常、完成首次初始化并在 App 重启后保留数据。
- [ ] 逻辑备份在隔离数据库或 Compose project 恢复，`goose_db_version`、内置用户组、管理员登录和样例短链通过验证。
- [ ] smoke、恢复和清理命令只作用于明确的隔离 project，结束后容器、网络、卷和临时文件均已清理。
