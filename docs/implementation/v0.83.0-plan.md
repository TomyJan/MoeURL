# v0.83.0 CSV 自定义列映射计划

> **面向 AI 代理的工作者：** 必需子技能 executing-plans 内联执行、TDD；仅版末一次 fresh 最强独立整分支终审，不派 builder／实现代理或复审。自主授权已覆盖常规提问及正常交付。

**目标：** 显式手选 CSV 网址列和可选标题列，安全接入原批量创建。

**架构：** 共用原严格扫描器；新映射投影复用 targets／titles schema，hook 私有暂存，独立小组件显示列选择。

**技术栈：** 现有 Vue、TypeScript、Vuetify、vue-i18n、Vitest、Playwright，无新依赖。

**规格：** [范围](../product/scope-v0.83.0.md)、[设计](../specs/2026-11-15-v0.83.0-csv-column-mapping-design.md)。

## 全局约束

- 基线 `8540be11408bebd61cbd5872bf1125475a6aa8f3`，分支 `feat/v0.83.0-csv-column-mapping`；已交付产品0.82.0，产品实现后0.83.0。
- 严格 UTF-8／65536 字节／1–8 列／1–20 条数据；首条表头，目标列必选，标题可选且不得同列。两个入口独立，其他列明确忽略。
- 不改 API／DB／权限／依赖／八份模板；不查 CI，不碰 PR240／266／267、18080 或日常 DB，不发布部署。
- 活动4GiB／双.tmp12GiB／Docker可回收6GiB，先预算串行，用完精确清理；原9条裁决、失败和3组Minor冻结保留。

## 审查重点

1. 标准扫描抽出后，EOF第22条、晚于坏表头的语法错误及旧失败对象不能改变；Task1具名字面量旧回归。
2. CSV有恶意头、重复名、空名、未选秘密或HTML时，列索引仍唯一、纯文本有界，未选字段不进payload；Task1 parser／真实组件与Task2 HTTP断言。
3. 暂存取消、非法选择和新文件读取失败不得抹原手工或结构化草稿；Task1确定性hook／组件验证。
4. 元数据撤权恢复、换号和旧finally不能复活暂存或解锁新读取；Task1权限epoch／race具名测试。
5. 有暂存不能预览旧草稿，unknown不得改列或文件；Task1同UUIDpayload测试和Task2实际targets／titles分发验证。
