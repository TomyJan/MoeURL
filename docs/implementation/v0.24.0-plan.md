# v0.24.0 匿名访问记录导出实现计划

> **面向 AI 代理的工作者：** 使用 subagent-driven-development 逐任务实现、测试、提交并独立审查。

**目标：** 个人与管理单链访问记录可按实际应用的日期和过滤条件下载完整、有界的匿名 CSV。

**架构：** 复用 insights 的只读 repeatable-read 授权／时间快照，新增带双重字节预算的单次 SQLC 查询和独立导出权限；前端在原记录面板接入共享下载控件，不扩展通用导出框架。

**技术栈：** 既有 Go／Chi／SQLC 1.30.0／Goose／PostgreSQL、Vue／Vuetify／TanStack Query／zod，无新依赖。

**规格：** [范围](../product/scope-v0.24.0.md)、[设计](../specs/2026-10-26-v0.24.0-visit-record-export-design.md)。独立建造者检查已完成，没有剩下重要的问题。

## 全局约束

- 新增 `GET /api/v1/short-link/visits/export` 和 `GET /api/v1/admin/short-link/visits/export`。
- 输入仅 id、days 或 startDate／endDate、deviceType、countryCode；规范非零 UUID、默认 7 天、7／30／90、最多 90 个 UTC 日；拒绝 cursor、pageSize、重复／未知／显式空参数。
- 新可配置 `short_link:export_visits`，叠加 read_visits 与个人 read_own／owner，或 admin:access／read_all；user／admin 默认和 standard 拥有，guest／basic／restricted 不拥有。
- 同一 5 秒只读 repeatable-read 快照重新检查有效账号、当前数据库组权限、时间和未删除链接；不新增事件、采集、审计或数据修改。
- 最多 1000 行，候选元数据最多 1001；原始可变长文本与最终 CSV 各限 8 MiB，超限整体拒绝、不拉取超预算文本、不返回部分文件。
- 成功 `{fileName,contentType,content}`；MIME `text/csv;charset=utf-8`，文件名 `moeurl-visits-{id}-{startDate}-{endDate}.csv`，BOM／CRLF／固定机器字段／公式中和。表头逐字取设计第 4 节。
- 业务码 100001、120001、200104、200120，基础设施 HTTP 500／900000；响应 no-store，日志只有安全类别／类型和 request_id。
- 保持原业务／前端 100% 阈值，不扩大排除，生成文件只经标准入口；不改日常 18080、日常数据库或 web/dist。

## 审查重点

- 下载不能将当前页误认为完整范围；SQL 必须先过滤再 limit，1001 条时拒绝，不悄悄导出前 1000 条。
- PostgreSQL text 可以来自历史异常大字段；读取预算在返回文本前应用，CSV 转义和多字节不能突破最终预算。
- 页面草稿与已应用过滤不同、查询刷新失败、日期跨 UTC 午夜时，禁止下载错误或缓存范围。
- 过滤／身份在一个 tick 内变更又恢复、同账号重新登录或卸载重建时，迟到结果不能下载；父级同步递增轮次不能只靠子组件观察字符串。
- 当前有效拒绝触发的授权读取独立于发起按钮的挂载生命周期：清空权限卸载父级记录区后，仍可按身份轮次与持续到读取结束的 cache 写入代次恢复有效读授权；较新写入（含相同空数组）不得被覆盖。导出 UI 结果仍严格抑制。
- 真实 ConsoleShell 的自动权限重定向与该 pending 协调：保持拒绝和数据卸载，仅暂缓当前有效授权重读期间的权限跳转；读取失败／确认无权／较新 cache 写入恢复正常跳转，主动离开不自动返回。使用真实 Shell、AnalyticsPage、Router 和 QueryClient 回归，不能仅测试独立页面。
- 已加载实际日期不受浏览器今天二次否定；前端保留日历／顺序／90 天校验，未来日由服务端 UTC 日期校验，补 UTC 边界时钟落后的实际请求／下载回归。
- 权限迁移回滚不得撤销迁移前或后独立授予的权限；导出本身不得改访问量、业务记录或产生伪审计。
