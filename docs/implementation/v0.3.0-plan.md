# v0.3.0 实施计划

## 版本目标

v0.3.0 实现受保护短链访问闭环。范围和数据契约以 [产品范围](../product/scope-v0.3.0.md) 与 [功能设计](../specs/2026-08-04-v0.3.0-protected-link-access-design.md) 为准，工程执行细节见 [详细实现计划](v0.3.0-detailed-plan.md)。

## 实施顺序

1. 文档、权限常量和迁移设计。
2. SQLC 查询与数据库集成测试。
3. 短链创建/编辑密码配置。
4. 公开解锁、失败窗口和短期授权。
5. 前端设置、密码页和 i18n。
6. E2E、覆盖率、生产构建和验收记录。

## 原子边界

每个工程切片先写失败测试，再实现最小代码，验证通过后本地提交。提交是默认行为；`push`、合并、`pull`、创建或切换分支/worktree 以及其他远程 Git 操作必须用户明确授权。

## 生产验收

生产构建遵循既有基线：允许已记录的大分块警告，但禁止新增警告、扩大受影响分块范围或提高既有阈值。后端和前端业务覆盖率继续保持 100%。
