# v0.4.0 验收清单

> 未执行的项目不得标记为完成。

## 数据库与权限

- [x] `00008` 扩展跳转模式约束并追加权限，`00009` 独立验证约束；migration 可升级和回滚。
- [x] 既有 direct/intermediate 数据保持不变，回滚时 confirmation 安全降级为 direct。
- [x] `user`/`admin` 拥有 `short_link:use_confirmation`，`guest` 不拥有，既有自定义权限不被回滚误删。
- [x] 生产短链 Service 从数据库读取当前用户组权限，运行中撤销 confirmation 后，创建、个人更新和管理员更新均不能绕过后端。
- [x] SQLC 生成代码与查询一致，无手工漂移。

## API 与访问行为

- [x] 有权限用户可创建和编辑 confirmation，无权限用户不能绕过后端；切回 direct 不要求高级模式权限。
- [x] 公开预览显式返回 `redirectMode`，只包含短码、目标主机名、模式、倒计时和过期时间。
- [x] 无密码 confirmation 从真实短链入口进入确认页，不自动跳转；主动继续后返回目标 `302`。
- [x] 受密码保护 confirmation 解锁后进入确认状态，不直接跳转或启动倒计时。
- [x] Continue 重新检查禁用、软删除、过期、模式和密码授权；无密码 direct 不能借 continue 绕过入口。
- [x] Continue 基础设施错误回流公共访问页并重新读取安全预览，direct/intermediate/confirmation 均等待手动重试，不形成自动跳转循环。
- [x] confirmation 进入和点击不增加访问量，最终目标 `302` 成功写出后只记录一次访问。

## 页面与 E2E

- [x] 创建和设置表单按权限组合显示模式选项，倒计时只在 intermediate 下显示。
- [x] 我的短链和全站短链列表正确显示确认页标签。
- [x] 确认页覆盖加载、继续失败、返回首页和密码后确认状态，不渲染完整目标 URL。
- [x] 确认页展示短码、目标主机名和可选过期时间；失去高级模式权限后仍可切回 direct。
- [x] 桌面 `1280 x 720` 和移动 `390 x 800` 视口无重叠或横向溢出。
