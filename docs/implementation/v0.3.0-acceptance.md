# v0.3.0 验收清单

> 未执行的项目不得标记为完成。

## 数据库与权限

- [x] migration 可升级和回滚，既有短链默认未设置密码。
- [x] `user`/`admin` 拥有 `short_link:set_password`，`guest` 不拥有。
- [ ] SQLC 生成代码与查询一致，无手工漂移。

## API 与访问安全

- [x] 有权限用户可设置、修改和清除密码，无权限用户无法绕过校验。
- [x] 数据库只保存 Argon2id 哈希和授权令牌哈希。
- [x] 五次失败后限流，成功后清零；授权有效期 15 分钟。
- [x] 密码变更后旧授权失效。
- [x] 无授权、禁用、软删除和过期短链不跳转、不增加访问量。
- [x] 只有最终目标 `302` 成功写出后记录一次 `redirect_response_sent`。

## 页面与 E2E

- [x] 创建和设置表单按权限正确展示密码控件。
- [x] 公共密码页错误、限流、成功解锁和中间页状态完整。
- [ ] 桌面和移动视口无重叠、横向溢出或目标 URL 泄露。
