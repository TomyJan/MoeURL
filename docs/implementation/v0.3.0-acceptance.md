# v0.3.0 验收清单

> 未执行的项目不得标记为完成。

## 数据库与权限

- [x] `00006` 以 `NOT VALID` 添加密码失败次数约束，`00007` 独立完成验证；migration 可升级和回滚，既有短链默认未设置密码。
- [x] `user`/`admin` 拥有 `short_link:set_password`，`guest` 不拥有。
- [x] SQLC 生成代码与查询一致，无手工漂移。

## API 与访问安全

- [x] 有权限用户可设置、修改和清除密码；后端按当前用户实际权限判断，无权限用户不能借助内置组默认值绕过校验。
- [x] 数据库只保存 Argon2id 哈希和授权令牌哈希。
- [x] 同一短链在 15 分钟内连续失败 5 次后限流 15 分钟，成功后清零；授权有效期为 15 分钟。
- [x] 修改或清除密码后，现有授权立即失效。
- [x] 无授权、禁用、软删除和过期短链不跳转、不增加访问量。
- [x] 只有最终目标 `302` 成功写出后记录一次 `redirect_response_sent`。

## 页面与 E2E

- [x] 创建和设置表单按权限正确展示密码控件，创建请求 pending 时高级控件不可编辑。
- [x] 公开预览拒绝缺失或非布尔值的 `requiresPassword`，开发服务器只代理预览和继续数据路由。
- [x] 公共密码页错误、限流、成功解锁和中间页状态完整；E2E 通过真实 UI 覆盖密码创建、留空保留、修改和清除。
- [x] 桌面和移动视口无重叠、横向溢出或目标 URL 泄露。
