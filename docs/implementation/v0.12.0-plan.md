文件：`internal/shortlink/{model,slug,service,handler}.go`、对应测试、`internal/permission/`、`queries/domain.sql`、生成的 `internal/db/sqlc/`；新增 `migrations/00017_custom_slug_permission.sql` 及迁移测试，生成权限 fixture。

- [x] 先写格式、保留字、权限、并发冲突、软删除占用和权限撤销测试，运行 `go test ./internal/shortlink ./internal/db ./internal/permission`，确认新增行为失败。
- [x] 扩展 `CreateInput.CustomSlug *string`，实现原始 ASCII 校验与小写规范化：`Team2026` 成为 `team2026`，`ab`、空字符串、`team-docs`、` team ` 和 Unicode 相似字拒绝；`LOGIN` 返回保留字错误。
- [x] 创建事务授权查询加入可选自定义权限检查；指定值遇 slug 约束冲突立即失败，随机模式保留重试。只将 slug 唯一约束映射为短码冲突。
- [x] 权限迁移使用现有 UPDATE 编辑追踪模式，覆盖 Up／Down／Up、后续授予保留及短码保留。
- [x] 执行锁定 SQLC 版本与权限 fixture 生成，各重复生成比较；定向测试和覆盖率通过后提交后端切片。标准 SQLC 入口网络失败后的同版本离线入口见验收记录。

有效请求与错误契约：

```json
{"targetUrl":"https://example.com/docs","customSlug":"TeamDocs2026"}
```

期望 `slug=teamdocs2026`；同值第二次提交返回 `200101`，`LOGIN` 返回 `200102`，非法格式返回 `100001`，缺能力返回 `120001`。省略 `customSlug` 继续随机创建。并发提交同值仅一次成功，不泄露已有记录信息。
