# 标准列表与页脚链接调整

## 设计

沿用雾蓝石墨主题，将短链、用户和最近短链改为 Vuetify `v-table`：明确表头、紧凑分隔行、状态标签及行尾操作。现有服务端筛选和分页继续生效，不增加只针对当前页的排序或第二套分页。宽表在自身容器内滚动，长地址省略，操作按钮保持可访问。

域名和 OIDC 提供商属于主从编辑器的选择列表，使用 Vuetify `v-list` / `v-list-item`，保留编辑草稿、切换确认、并发冲突与删除快照行为。用户组保持现有标准 Tabs，不改权限流程。

页脚的 `Powered by MoeURL` 是普通文字，仅 `V` 开头的静态构建版本为源码链接；始终显示署名的策略不变。
