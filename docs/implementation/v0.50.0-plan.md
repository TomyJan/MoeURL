## 审查重点（Review Focus）

1. 草稿 A→B→A、旧预览晚到或排队确认：必须重新真实预览，不得用旧备注版本确认新正文。
2. 后项不可见／版本冲突、审计拒写：全批零业务写入，不泄露旧正文或失败目标。
3. 同值 no-op 与并发单条编辑：仍核双版本；只推进真实变化项备注版本，不碰主版本。
4. ABA 登录／撤权恢复／旧 finally：不能清新锁、刷新新身份缓存或发布旧提示。
5. 未知写结果和畸形成功：无自动重试，实际重新预览后仍要再次确认；私密输入不进 URL／storage／CSV／日志。
