**架构：** 共享弹窗在 PNG 成功后启动独立 SVG Promise，复用 generation 守卫，编码 data URL 下载；不注入 XML、不新增产品请求。

**技术栈：** 现有 Vue、TypeScript、Vuetify、qrcode、Vitest、Playwright；不安装依赖。

**规格：** [范围](../product/scope-v0.57.0.md)、[设计](../specs/2026-11-11-v0.57.0-qr-svg-design.md)。

## 审查重点

1. SVG 延迟或失败仍能立即使用 PNG，不把 SVG 错误误报为 PNG 错误。
2. 迟到的成功、失败和 finally 不发布旧制品、不关闭新 loading。
3. slug-only、URL-only、关闭／重开、卸载均隔离，并恢复 classic。
4. 长 URL 和类 XML 文本只进入 QR 载荷，不截断、不成为页面或文件可执行节点。
5. 手机第三个动作可见、键盘可达，SVG 和 PNG 属于同一当前公开链接及颜色。
