# v0.83.1 纯网址批量请求预算实现计划

> **面向 AI 代理的工作者：** 使用 executing-plans 内联逐任务实现。持续自主授权覆盖常规确认、安装与集成菜单；本版不安装依赖，只在最终派一次最强全新整分支审查。

**目标：** 旧手工／标准单列 CSV 在预览或替换草稿前满足原完整请求预算。

**架构：** 在共同 targets schema 增加固定 36 字节 UUID 的 JSON UTF-8 预算，消费方复用，不改 hook 或 API。

**技术栈：** 现有 Vue、Zod、Vitest、Playwright、隔离 Docker。

**规格：** [设计](../specs/2026-11-16-v0.83.1-targets-wire-budget-design.md)及[范围](../product/scope-v0.83.1.md)。

## 全局约束

- 完整请求不大于 65536 字节；1–20 条唯一 ASCII HTTP(S) 网址，每条至多 2048 字节；UUID 36 个 ASCII 字符。文件仍最多 65536 字节，不能互相代替。
- 原字面值、顺序、手工 ASCII trim、八种协议、权限／身份／重试、模板及服务端全部保持。
- 不查 CI、不碰 PR240／266／267、18080 或日常 DB，不发布部署、不 force、不删分支或 worktree。
- 活动 4 GiB／双根 12 GiB／Docker 可回收缓存 6 GiB，大操作预算后串行，用完精确清理并留恢复证据。

## 审查重点

1. 文件在 65536 内但 JSON 超额时必须拒绝；Task1 反斜杠与原引号 fixture，Task2 实际 HTTP 边界。
2. 恰好 65536 可提交，多一字节拒绝；Task1 schema／manual／parser／API 字面 fixture，不以生产 helper 算期望。
3. 标准拒绝不得先替换原手工或 titles 草稿；Task1 真实 hook 两种原草稿及后续精确提交，Task2 从界面验证。
4. 手工拒绝不得生成 UUID／snapshot；合法预览与 unknown 重试仍同 UUID／payload；Task1 hook 和旧重试回归。
5. 共同 schema 收紧不得改变七种结构化协议、CSV 结构错误顺序或映射权限；Task1 全套与八模板／诊断／映射旧回归，Task2 原产品功能可用。
