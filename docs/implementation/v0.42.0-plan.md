## 审查重点（Review Focus）

1. CurrentGrant：预检后撤权／禁用／改组／删除，SQL快照不泄露标签；自定义组按权限放行，不硬编码admin组。
2. ScopeIsolation：管理员本人API仍只看自己；own/admin缓存、失效及A→B→A隔离，旧响应不能跨域显示。
3. PendingInvalidation：首次无数据pending及两次连续失效，旧成功／失败和离线重连不能恢复旧计数。
4. CountAndInput：重复数组／软删／转移／50与51、C排序、Unicode及百分号等字面输入，必须正确且有界。
5. ParentInteraction：排队旧点击、批量／导出／设置冲突不能绕过父守卫；手机和桌面控件不交叠。
