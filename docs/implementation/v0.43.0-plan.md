## 审查重点（Review Focus）

1. CurrentAuthorization：当前账号／组／owner及转移竞争，失权身份不得读备注或写入，header不能冒身份。
2. AtomicVersion：两写唯一赢家、陈旧同值仍冲突、no-op不审计、审计失败零提交且旧字段保留。
3. ScalarAndFraming：1000/1001、emoji／组合／BOM／CRLF／孤立CR／Cc／畸形UTF8／loneUTF16、重复字段和body边界两端一致。
4. AsyncRetirement：A→B→A、权限与打开代际的load/save迟到成功／失败／finally、dirty与unknown显式恢复。
5. PrivacyAndInteraction：公开/CSV/主列表无备注、转移明示、queued菜单不能绕过互斥、双视口长文键盘与几何。
