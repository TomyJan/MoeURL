# v0.1.1 实施计划

## 1. 目标

v0.1.1 将控制台概览从信息架构占位页升级为当前用户的真实工作台，不扩展为系统级管理仪表盘。

## 3. 阶段

1. 同步产品范围、控制台概览设计、技术基线和验收边界。
2. 以 SQLC 提供当前用户的短链与访问量聚合查询。
3. 提供受 `short_link:read_own` 保护的个人概览 API。
4. 交付真实控制台概览页、最近短链、导航状态和双语文案。
5. 运行后端与前端质量门禁，记录完整验收结果。

## 4. 技术要求

- 继续使用 Go、Chi、SQLC、PostgreSQL、Vue 3、Vuetify 4 与 TanStack Query。
- 不新增 schema 或 migration；通过现有 `short_link` 和 `short_link_event` 聚合。
- 概览聚合在数据库中一次完成，不通过前端分页数据推算总访问量。
- 最近短链复用 `GET /api/v1/short-link/list?page=1&pageSize=5`，不扩展概览 API 返回列表。
- 页面保持控制台工作台密度，不使用营销式英雄区或伪造图表。

## 5. 验收重点

- 当前用户、管理员个人视角和权限不足边界正确。
- 禁用、软删除和非成功事件的统计口径正确。
- 指标与最近短链可以独立加载和独立失败，不互相遮蔽可用内容。
- 空数据和移动端布局可用，导航不再显示规划中标识。
