## 审查重点

1. 无标题权限的双列空标题也不能绕过：Task1 当前 DB 撤权／回执测试，Task2 导入及 cache 撤权测试。
2. 跨旧新端点同 UUID 不得重复创建：Task1 双向 conflict 和并发，核 links/audit/receipt。
3. CSV 导入后不能因 textarea 编辑或 preview 丢标题：Task2 可见结构化草稿、精确 payload。
4. 账号／文件／草稿变化的迟到读取不得覆盖或解锁：Task2 barriers 覆盖 success/error/finally。
5. unknown 重试必须同模式／UUID／完整内容：Task2 transport failure 后精确二次 payload，Task3 实际网络场景。
