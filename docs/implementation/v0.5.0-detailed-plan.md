# v0.5.0 用户组权限管理详细实现计划

状态：功能实现已于 2026-08-20 完成；Node.js `26.x` CI 门禁和版本验收待验证，实际证据见 [v0.5.0 验收清单](v0.5.0-acceptance.md)。

> **面向 AI 代理的工作者：** 必需子技能：使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans` 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法跟踪进度。

**目标：** 在现有数据库动态权限 Resolver 之上，展示三个内置用户组，为 `user`、`admin` 交付权限目录、预设、并发安全写入和真实控制台管理页面，并保持 `guest` 只读。

**架构：** `internal/permission` 负责权限目录、分类和固定保护规则；新的 `internal/usergroup` 负责管理员授权、SQLC 读写、规范化和业务错误；前端使用 TanStack Query 管理服务端状态，以独立草稿编辑权限，并在保存后刷新用户组和 `auth/me`。v0.5.0 不增加 schema 或跨请求权限缓存。

**语言基线：** Go 最低版本为 1.25+，`go.mod` 当前声明为 1.25.7。

**构建环境：** `Dockerfile` 当前使用稳定镜像 `golang:1.27.0`。

**技术栈：** Chi、SQLC 1.30.0、PostgreSQL、Vue 3、TypeScript、Vuetify 4、TanStack Query、Zod、Vitest、Playwright。

- [x] **步骤 6：实现 SQLC 查询并生成代码**

```sql
-- name: ListBuiltinUserGroups :many
select id, key, name, description, permissions, builtin, created_at, updated_at
from user_group
where builtin = true and key in ('guest', 'user', 'admin')
order by case key when 'guest' then 1 when 'user' then 2 when 'admin' then 3 end;

-- name: UpdateBuiltinUserGroupPermissions :one
update user_group
set permissions = $2,
    updated_at = greatest(clock_timestamp(), updated_at + interval '1 microsecond')
where key = $1 and key in ('user', 'admin') and builtin = true and updated_at = $3
returning id, key, name, description, permissions, builtin, created_at, updated_at;
```

使用仓库锁定的 SQLC `1.30.0` 生成代码，不手工编辑 `internal/db/sqlc`。
