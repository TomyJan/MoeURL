# v0.13.0 个人密码修改实施计划

> 使用子代理驱动开发逐切片实现，先规格审查、再质量审查；不等待常规人工确认。基线 `17e1f766`，分支 `feat/v0.13.0-password-change`。

**目标：** 已登录本地账号可以证明当前密码并安全更新，全部旧 Session 撤销，重新登录闭环可重复验证。

**架构：** 同一 Auth Service 实现独立 PasswordPort，共享既有数据库失败窗口和两层槽位。前端密码区域独立于昵称编辑，无 schema 和权限变更。

**技术栈：** Go、Chi、SQLC 1.30.0、PostgreSQL、Vue、Vuetify、TanStack Query、vee-validate、zod、Vitest、Playwright。
