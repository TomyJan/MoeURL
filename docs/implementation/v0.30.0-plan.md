## 审查重点（Review Focus）

1. 批次中同时含缺失、builtin、自身、陈旧账号，改变 HTTP items 顺序仍应同类错误且其他账号／Session／审计零变化；Task1 `TestBatchChangeGroupErrorPriority`。
2. A 批量降 B、B 同时降 A，或 actor 等账号／组锁时被撤权，必须串行后按当前 DB 拒绝旧 actor，不出现两个管理员都被降权；Task1 `TestBatchChangeGroupCrossAdmin`／`TestBatchChangeGroupWaitingAuthorization`。
3. 成功 commit 后列表刷新失败，不能将批量成功显示成失败，也不能拿旧版本马上再次写入；Task2 `UserMembership.batch.test.ts` 的 readback barrier 真实 HTTP 回归。
4. 同一账号 logout→login 新 epoch，旧批量／列表迟到结果不能关闭新确认、发 Toast 或解锁新请求；Task2 `UserMembership.batch.races.test.ts`。
5. 第二账号写／撤销／审计失败，第一账号的变更也必须回滚；请求断连后不能自动重放潜在已提交操作；Task1 `TestBatchChangeGroupRollback`，Task2 普通故障快照回归。
