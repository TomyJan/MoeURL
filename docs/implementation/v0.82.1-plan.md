## 审查重点

1. 账号成功创建但 newContext 失败：服务端账号必须 disabled，原初始化错误保留。
2. 场景与删除／禁用／close 同时失败：原对象及顺序完整，后续实际资源释放继续。
3. undefined 等假值拒绝：依然失败；无用户时不得凭空禁用或读取无 context 的短链。
4. 一个短链删除失败不能跳过其余短链及账号；列出失败也仍禁用和 close。
5. spec 必须使用被测生命周期，原六场景全部 wire／草稿／纯文本／手机操作保持，旧产品与新测试归属分开。
