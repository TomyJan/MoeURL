# v0.38.0 有界批量创建实现计划

> **面向 AI 代理：** 使用 executing-plans 内联实施。长期持续自主授权覆盖普通确认，不派 builder 或逐任务审查者；仅最终一次 fresh 最强 supported 整分支审查。

**目标：** 个人列表最多 20 条目标网址整批创建，明确重试不重复。

**架构：** 独立 BatchCreate 单事务复用当前权限、域名与短链审计，永久轻量幂等回执；前端独立输入预览与 mutation，不循环单条 Create。

**技术栈：** Go、Chi、SQLC 1.30、Goose、PG、Vue 3、Vuetify 4、TanStack Query、zod、Vitest、Playwright；无新依赖。

**规格：** [设计](../specs/2026-11-01-v0.38.0-bulk-create-design.md)、[范围](../product/scope-v0.38.0.md)。

## 审查重点（Review Focus）

1. 已提交但响应丢失／并发同key：只创建一次，原数量与审计不增加（Task1 ReplayConcurrent，Task2 UnknownResult）。
2. 创建第二条或审计失败：第一条、审计和回执必须全部回滚，不能部分成功（Task1 AtomicFailure）。
3. 旧账号／组快照、域名撤权与异步晚到：按真实当前身份拒绝，旧结果不可污染新账号（Task1 CurrentAuthority，Task2 IdentityGeneration）。
4. 21条、超长、重复、私网、JSON歧义与Unicode：零写入且日志不泄露目标或body（Task1 InputBoundary，Task2 PreviewBoundary）。
5. 未知结果后关闭／刷新、手机长网址与键盘：不静默换key重试、如实提示恢复限制、无横溢（Task2 RecoveryWarning，Task3 BrowserFlow）。
