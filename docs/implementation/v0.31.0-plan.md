> 使用 executing-plans 内联执行；每任务使用标准 task-start／task-done 和独立 owned 账本。不派实现者，不重复常规审批。用户路径规则优先，规格为[范围](../product/scope-v0.31.0.md)与[设计](../specs/2026-10-28-v0.31.0-oidc-provider-templates-design.md)。

**目标：** 仅创建阶段提供本地手动／Google模板，明确应用和安全清草稿，既有 OIDC 契约不变。

**架构：** `features/oidc-provider-template/template.ts` 构造无秘密字段快照；`OIDCProviderTemplatePicker.vue` 管选择；真实父页管理完整 draft 替换和确认生命期。复用现有 API、QueryClient、Vuetify 和 i18n，不增依赖／schema／权限。

- 源码只在 C: 现有隔离 worktree；证据为 D:/Dev/TomyJan/MoeURL/.tmp/v031-evidence 与本计划 owned leaf，不碰日常 18080／DB／dist／其他计划或未知 Docker。
- host Node 固定 nvm/v26.3.0、pnpm11.5，仅 web、无额外 `--`、绝对隔离产物；Go 显式 GOTOOLCHAIN=go1.26.10，默认／Docker／CI 分别归属。不重装未变依赖／降 100／扩排除／改既有断言或超时。
- 共享类型 `ProviderTemplateID = 'manual' | 'google'`；`ProviderTemplateFields = {key:string;displayName:string;issuerUrl:string;enabled:boolean}`。`buildProviderTemplate(id): ProviderTemplateFields` 纯函数；picker props `disabled:boolean`，emits `apply(fields)`、`change()`。每次返回新的非秘密字段快照，不使用共享可变对象。

- commit 显式 `-c commit.gpgsign=false`，逐文件暂存；同名 push/upstream；gh 只使用规定 GCM wrapper，无 token 输出、force、绕保护或删旧 branch/worktree。无 tag/release/正式部署。

## 审查重点（Review Focus）

1. 旧 Secret-only 或空格草稿应用是否先确认，取消是否逐字段无损，确认是否清全部三类凭据／域名，不能跨提供商混合。
2. Google issuer 与禁用默认是否精确，手动重置是否恢复原默认；模板是否说明首次供应的已验证邮箱要求，且不暗示未证明兼容的 Entra 预设。
3. 确认打开后切换 provider／取消创建／开始 mutation 的迟到 apply 是否拒绝，模板选择是否可能隐式 submit。
4. 真实七字段 HTTP 请求与 mutation cache 是否多出 template／Secret 副本；既有编辑的 Secret preserve 与版本冲突是否保持。
5. 1280×720 和 390×800 的模板选择、覆盖提示及动作是否可达，键盘／窄屏无裁剪；本地 IdP 成功不能冒外部互通。
