# v0.85.0 导出所选短链 CSV 实现计划

> **面向 AI 代理的工作者：** 使用 executing-plans 内联实施；步骤以复选框跟踪，只在最终派一名全新上下文 gpt-6.1-sol high 审查者，不派 builder。

**目标：** 为本人和管理员提供当前页所选 1–100 条的服务端管理 CSV，完整授权、零部分成功。

**架构：** 独立严格 POST／Service 入口，共用原单 SELECT 和 CSV writer；前端严格 entity、独立生命周期 hook／按钮及两个父页互斥锁。

**技术栈：** 既有 Go、Chi、SQLC1.30、PostgreSQL、Vue3、Vuetify4、TanStack Query、Vitest／Playwright；无依赖、权限或 migration 新增。

**规格：** [范围](../product/scope-v0.85.0.md)、[设计](../specs/2026-11-16-v0.85.0-selected-csv-export-design.md)。

## 全局约束
