## ROOT 自检与下一步

协议、存储、授权、审计、公共竞态、管理轮次、布局和完整交付均有具名覆盖；无新实现或执行结果，不能勾验收。ROOT复核独立资源和现有appearance服务模式一致，但URL包含路径与自托管内网，不复用Origin或短链私网限制。共享URL语料是下一任务建立的测试源，不是生成物；前端消费同源，避免各写一套期望。

新body严格decoder的重复键与Unicode边界需要单独小函数及负向测试；不得只依赖DisallowUnknownFields冒重复键拒绝。public失败回空和后台pending保最近成功是不同状态，必须分别测。保存后从public coordinator发布只用服务端规范值。

B04/F01 还必须拒绝字段名错误大小写；B06/F01 增 IPv4-mapped IPv6 整类拒绝。八例 Node 内置 WHATWG URL 诊断只是设计旁证，不代 Go／浏览器或产品测试；协议／实现仍未验证。

当前 host 已安装前端组合落后 master manifest 的限制仍有效；设计不允许用错误组合称新版本门禁通过。正式计划已选择 owned Linux 容器中的当前 frozen 依赖源码副本，安装只在隔离目录／卷内；实际镜像、运行时、安装与门禁仍待执行，新候选／master 各自 CI 另行证明。
