# v0.2.0 验收清单

> 未执行的项目不得标记为完成。

## 数据库与兼容性

- [x] migration 可以为既有短链增加默认直接跳转配置，且可以完整回滚。
- [x] 既有 `user`、`admin` 权限数据完成升级，`guest` 不获得新增权限。
- [x] SQLC 生成代码与 migration 一致，工作区没有手工漂移的生成文件。

## API 与权限

- [x] 创建和更新接口支持跳转模式、倒计时与显式过期配置。
- [x] 无中间页或过期权限的用户不能通过 API 绕过校验。
- [x] 个人更新与管理员更新继续遵守所有权和全站权限边界。
- [x] 只更新状态时不会覆盖目标 URL、跳转模式、倒计时或过期时间。
- [x] 公开预览只返回目标主机名和页面所需字段，不暴露完整目标 URL。

## 公共访问与统计

- [x] 直接模式保持原有目标 `302` 行为。
- [x] 中间页模式先进入 `/go/{slug}`，不在该步骤增加访问量。
- [x] `/go/{slug}/continue` 重新检查状态、删除和过期时间。
- [x] 过期短链被拦截且不记录 `redirect_response_sent`。
- [x] 只有最终目标跳转响应成功写出后才记录一次成功访问。

## 页面与交互

- [x] 创建组件在折叠高级设置中提供权限允许的中间页与过期选项。
- [x] 我的短链和全站短链展示模式、过期信息并可编辑访问配置。
- [x] 中间页覆盖加载、倒计时、立即前往、返回首页和失败状态。
- [x] 二维码可生成、预览和下载，编码内容等于短链 URL。
- [x] 中英文文案完整，桌面端和移动端没有重叠、溢出或空白图片。
