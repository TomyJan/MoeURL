## 审查重点（Review Focus）

1. 缺字段与非法已提供字段不能混淆；用户不应导入被静默修正的表格。Task1 的空 tags、坏行宽和字面值测试保护。
2. 省列不能绕过原权限，撤权恢复不能复活旧文件。Task1 权限／ABA 与 Task2 真实低权限操作保护。
3. CSV 较小而补齐 wire JSON 超限时保留旧草稿。Task1 两精确边界与 hook 无副作用保护。
4. 缺方式不能根据秒数或偏好推断，未知结果重试不能换协议。Task1 默认／依赖拒绝及 frozen HTTP、Task2 真实持久化保护。
5. 前端便利不应导致后端／模板漂移，清理不应损坏原证据或共享资源。完整输入 hash、模板守恒与精确 cleanup 收据保护。
