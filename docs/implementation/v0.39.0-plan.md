## 审查重点（Review Focus）

1. 锁等待中禁用、改组或撤销增强权限，旧会话不得保存增强值（Task1 CurrentAuthority）。
2. 同版本并发、纳秒不舍入、首次null重放，只有正确CAS成功且无部分写（Task1 ExactCAS）。
3. 相同账号重登、离线恢复及same-tick切换，旧mutation真正发送前必须失效（Task2 StaleSend）。
4. 个人默认已知但域名读取失败、个人null或撤权，优先级与显式手动不能被错误屏障覆盖（Task2 DefaultPriority）。
5. 后台读取、冲突重载及旧success／error／finally晚到，不能覆盖新草稿或污染新身份（Task2 DraftOwnership，Task3 BrowserFlow）。
