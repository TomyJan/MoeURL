## 审查重点（Review Focus）

1. 同时间 tie 跨越第 20／21 项时，两条 SQL 都必须有唯一次级键。
2. 更大的 UUID 属于更早时间时，不得压过较新记录；UUID不是创建顺序。
3. 普通 GET 与私密 POST 都保持本人／全站、软删和筛选交集，不泄露备注。
4. CSV保持全量已匹配集合和原17列，不能借本轮把导出改成当前页。
5. 不变数据确定排序不等于并发跨请求快照；无依据索引／事务／API扩张属于范围错误。
