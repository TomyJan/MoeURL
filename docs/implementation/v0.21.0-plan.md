# v0.21.0 短链清单导出实施计划

> 面向 AI 代理的工作者：使用 subagent-driven-development 按任务执行；用户已授权独立设计、开发和审查，不在任务间请求确认。

**目标：** 个人与管理员按当前列表筛选安全导出最多 1000 条短链。

**架构：** 单 SELECT 同时校验当前授权与读取一致清单，服务端生成受限 CSV 下载描述；Vue 列表按钮固定筛选和身份轮次，复用下载工具。

**技术栈：** 现有 Go、SQLC、PostgreSQL、Vue、Vuetify、TanStack Query、Vitest 和 Playwright，不增加依赖。

**规格：** [短链清单导出设计](../specs/2026-10-24-v0.21.0-link-list-export-design.md)；范围见 [scope](../product/scope-v0.21.0.md)。

## 全局约束

- `short_link:export` 叠加对应读取权限，guest 始终拒绝；一条 SELECT 快照重查账号、组权限和归属。
- 最多 1000 条，原始可变长文本累计读取与最终 CSV UTF-8 各有独立 8 MiB 预算，5 秒查询超时，超限 `200118`，不截断；同语句先检查元数据预算再投影正文。固定表头／文件名／MIME 逐字使用规格。
- 只使用 GET／POST、统一 envelope 和 no-store，不含秘密或原始访问记录。
- 迁移和生成物遵循标准入口；业务／前端门禁 100%，不扩大排除。
- 用真实隔离数据库与 Compose；日常预览和数据库不修改。本任务仅本地原子提交，不沿用上个 PR 的推送／合并授权。

## 审查重点

1. 导出开始前禁用、撤权或转移，SQL 必须按当前状态拒绝或排除，不能信任入口快照。
2. 无结果与无权限不能混淆；1001 条不能静默导出前 1000 条。
3. 当前默认域名变化不能重写旧短链 URL；个人文件不能含其他账号记录。
4. 筛选防抖、列表重取或身份切换期间，不保存旧上下文的文件。
5. 恶意标题／标签／用户名与引号、换行、Unicode 空白不能变成电子表格公式或破坏 CSV。
