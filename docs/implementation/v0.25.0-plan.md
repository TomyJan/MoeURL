# v0.25.0 操作审计 CSV 导出实现计划

> **面向 AI 代理的工作者：** 使用 subagent-driven-development 逐任务实现、测试、提交并独立审查。用户已授权全自主连续交付，无需设计或执行方式确认。

**目标：** 管理员在现有审计页下载当前完整筛选结果的有界 CSV，保持授权、隐私、保留及异步生命周期边界。

**架构：** 复用 insights.read 与现有审计筛选，独立 ExportAudit 端口；SQL 先检查候选元数据及文本预算，文件再限额；前端复用当前身份／授权恢复及 downloadCsv。

**技术栈：** 既有 Go／Chi／SQLC 1.30.0／Goose／PostgreSQL，Vue／Vuetify／TanStack Query／zod，无新依赖。

**规格：** [范围](../product/scope-v0.25.0.md)、[设计](../specs/2026-10-27-v0.25.0-audit-export-design.md)。独立建造者检查没有剩下重要的问题。

## 全局约束

- 新增 `GET /api/v1/admin/audit/export`；只接收 days 或 startDate／endDate、actorId、resourceType、action；默认 7 天、预设 7／30／90、最多 90 个 UTC 日，拒绝分页／未知／重复／空／非法参数。
- `audit:export` 属于 administration，与现有 `audit:read` 一致为受保护的管理员权限。只添加至 admin baseline，user／guest 和 restricted／basic／standard 不添加。
- 同时要求 `admin:access`、`audit:read`、`audit:export`，5 秒只读 repeatable-read 当前账号／数据库授权／UTC／180 天保留快照，不新建采集、审计或业务写入。
- 最多 1000 行、候选 1001；原始文本（含 changed_fields 完整 JSON）与最终 CSV 各限 8 MiB；超限整份拒绝，禁止先拉大文本或只导前 1000。
- 成功 JSON `{fileName,contentType,content}`，MIME `text/csv;charset=utf-8`，文件名 `moeurl-audit-{startDate}-{endDate}.csv`；固定表头逐字取规格第 4 节，bigint／UTC 精度不丢失、changed_fields 为单个 JSON 单元格。
- 错误 100001／120001／100002，基础设施 HTTP 500／900000，所有响应 no-store，保持现有安全日志；访问导出的 200120 不变。
- 使用标准 CSV、BOM／CRLF、Unicode 空白及公式中和；严格前端下载描述、账号／上下文隔离、未应用全部三种草稿不可导出；只使用服务端已加载实际日期，不依赖浏览器 today。
- 原业务与前端 100% 阈值、原排除范围不降低／扩大；生成文件只走标准入口；所有命令、实际环境／输入／SHA／制品／退出码分别留证。pnpm 参数不额外 `--`，输出必须指向本版独立绝对证据目录。
- 不改主检出、日常 18080／数据库／web/dist。PR 前 CI 与实际 CodeRabbit 都要完成；用户要求合并后 CI 后台跟进，不阻塞下一轮，真实失败优先修复。

## 审查重点

- 保留截止时间与整个文件授权必须处于同一快照，过期记录、较新写入或既有撤权不能混进同一文件（任务 1 的受控事务测试）。
- changed_fields 可为空数组，异常大量空元素仍占 JSON 预算；bigint／Unicode／CSV 转义不能损失或绕过上限（任务 1 的真实数据库和编码边界测试）。
- 草稿或分页先改变再返回同值仍使旧请求失效，不能只比较序列化字符串（任务 2 的同步轮次回归）。
- 拒绝清空授权时父页／按钮可能卸载，当前身份恢复应继续，旧身份／较新 cache 写入必须抑制旧回填（任务 2 的真实 Shell 回归）。
- E2E 预期不能由实测退化数据自我确认；固定产生操作及分类数量，只有数据库 ID／时间从记录取得（任务 3 的真实业务 fixture）。
