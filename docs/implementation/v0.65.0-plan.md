# v0.65.0 本人每日创建用量实施计划

> **面向 AI 代理的工作者：** 使用 executing-plans 内联执行，不派 builder；最后仅一次 fresh 最强整分支独立终审。持续无人值守授权覆盖常规设计／执行确认。

**目标：** 在控制台提供本人当天创建用量的可靠只读快照。
**架构：** 独立 UsagePort／handler／SQLC 查询，单个 readonly RR 事务；独立严格 entity／身份 epoch query／概览卡片。
**技术栈：** 既有 Go、Chi、SQLC、PostgreSQL、Vue、Vuetify、TanStack Query、zod、i18n。
**规格：** [范围](../product/scope-v0.65.0.md)、[设计](../specs/2026-11-12-v0.65.0-own-create-usage-design.md)。基线 `0ff18e2a1f6dd74ae432c192c4b8c3730192138a`，分支 `feat/v0.65.0-own-create-quota`。

## 全局约束与文件

不改 Consume、管理员 Port／CAS、迁移、依赖或固定前端路由。新增 `internal/createquota/usage{,_handler}.go` 及测试；修改 quota SQL 查询和标准生成物、router/app、Go 覆盖目标。前端新增 `web/src/entities/account-daily-create-quota/usage.ts`、`usage.test.ts` 和 `web/src/features/account-daily-create-quota/OwnDailyCreateUsageCard{.vue,.test.ts}`，概览仅插入卡片，i18n 和版本同步。E2E 在独立 `web/e2e/own-create-usage.spec.ts`。本版五文档、六入口及前版完成状态同步，原证据不改。

GET `/api/v1/account/daily-create-usage` 四字段／used 字符串／UTC 日期；只读不建行不审计。五秒超时，当前 DB 授权，不硬编码 admin。无自动轮询／重试／禁创建。4／12／6 GiB 预算，盘点／生成／清理串行，不查 CI、不碰指定 PR 和日常资源、不安装、不发布部署。

## 审查重点（Review Focus）

1. Cookie 已换人而旧页仍发读请求：header 不匹配拒绝；Task1 HTTP＋Task2 身份 race 核准。
2. int64 大计量精度或有限额减法溢出：used 字符串、BigInt 比较；Task1 大整数／超额及 Task2 严格解码测试。
3. 历史日被读取重置或未来／负值被当 0：Task1 真实 PG 前后状态及坏行测试，不写任何行。
4. 旧请求晚到、撤权后缓存闪回或刷新失败显示旧数字：Task2 受控 success/error／epoch／撤权／卸载 DOM 核准。
5. UTC 日与用户时区混淆或快照变成创建授权：Task3 实际 UTC 文案、真实创建后主动刷新及耗尽仍可进创建验证。
