# v0.48.0 列表每页条数实施计划

> 面向 AI 代理的工作者：使用 executing-plans 内联执行；末段唯一 fresh 最强 supported 独立整分支终审，不派 builder 或逐任务实现者。基线为已验 master `5ed2939c6de3f75e3cb46dac37fcb6ffa06ad74f`，普通设计及 Git 集成选择按无人值守授权自主决定。

**目标：** 本人和全站短链列表可选择每页 20／50／100 条，保持权限、私密筛选和单页批量操作边界。

**架构：** 两个页面各自持有挂载内的页大小，沿用现有列表查询及单调代际；共享分页组件只展示受控值并发出事件。页大小追加至查询 key 末尾，所有请求只读取捕获的 key；CSV 继续导出全部匹配集合。

**技术栈：** 既有 Vue 3、Vuetify 4、TypeScript、TanStack Query、vue-i18n、Vitest 和 Playwright。不新增依赖。

**规格：** [设计](../specs/2026-11-04-v0.48.0-list-page-size-design.md)、[范围](../product/scope-v0.48.0.md)。

## 全局约束

- 仅允许 number 类型的 20、50、100；默认 20，不持久化至 URL、账号或浏览器存储。
- 改变页大小回第 1 页，清选择并退休旧查询／备注上下文；同值事件没有额外请求。
- 身份或有效读权限变化恢复默认 20；普通筛选保留当前大小，仅回第 1 页。
- 请求 key 原槽 0–9 保持，末尾新增 size。queryFn 不从可变 ref 取请求大小。
- 实时授权和编辑／写入／导出／批量创建锁同时守卫 queued 事件；普通读取 pending 时允许换大小。
- 不改变 API、数据库、索引、权限、排序、CSV 列或导出范围，不实现跨页全选、跳页或快照。
- v0.47.0 的真实审查、候选及 master CI 和归档已完成；本版仍必须取得自身完整交付证据。

## 审查重点

1. 20→50→20 和同账号重挂载时，旧响应不能恢复旧集合；用两个受控 deferred 响应核顺序。
2. 同 tick 撤权／打开编辑窗口后排队的 size 事件必须无操作；测试从保留的控件 emit 入口发出。
3. 私密 POST 的响应 meta 必须匹配请求的 size；fixture 不得硬编码 20 或把解析失败冒产品 RED。
4. 当前 size 的成功 total 才能证明最后一页；pending、失败或退休响应不能触发错误收敛。
5. 换 size 必须清除本页选择；CSV 始终导出全部匹配集合，不含 page 或 pageSize。

## 任务 1：有界页大小与真实页面行为

**Interfaces：** 产生 `SHORT_LINK_PAGE_SIZES = [20, 50, 100] as const`、`DEFAULT_SHORT_LINK_PAGE_SIZE = 20`、`ShortLinkPageSize` 及 `isShortLinkPageSize(value: unknown): value is ShortLinkPageSize`。分页组件新增必传 `pageSize: ShortLinkPageSize`，事件 `size: [value: unknown]`；页面 `changePageSize(value: unknown): void` 负责授权与业务守卫。

- [x] 先在 LinkPagination 的既有真实页面挂载补 `changesPageSizeAndRetiresSelection`，本人／全站各一：61 条 fixture，默认 20，点击 50 后请求 page=1/pageSize=50、显示 50 行且原选择为空；第二页只剩 11 行；100 档显示 61 行且 next 禁用。先运行 `pnpm exec vitest run src/pages/LinkPagination.test.ts`，确认因缺少真实条数控件而失败，不能用新模块导入失败作 RED。
- [x] fixture 读取实际 GET pageSize 并切片，完整 envelope 返回同值 meta；私密 POST 同样读取 body 的 pageSize。仅新 size 控件局部 stub 将受支持 option 转为 number，其余全局 VSelect stub 保持；非法事件通过保存的 emit 回调发出。
- [x] 新建有界常量及 guard，组件接收 pageSize，所有 `/ 20` 和 `* 20` 改为显式 size。v-select 使用 number items、受控 model，标签键 `pagination.pageSize` 为中文“每页条数”／英文“Rows per page”，选项只显示数字，隐藏辅助详情与 compact 密度；布局沿用 flex-wrap，选择框独立 class 保证手机可换行。
- [x] 两页面增加 `ref<ShortLinkPageSize>(DEFAULT_SHORT_LINK_PAGE_SIZE)`，追加 key 槽 10 并在 queryFn 捕获 `requestPageSize`。batch.filters 和 note.reset 观察 size，size 变化推进 listRevision，即使 page 原本就是 1。独立身份／读授权重置 size，普通筛选不改 size。页数收敛 watch 增加 size，统一用当前值计算。
- [x] `changePageSize` 拒绝无权限、paginationBlocked、非法值和同值；其余写入 size 并回 page1。不能加 query.isFetching 拒绝条件。原 next 守卫仍要求当前成功且 idle 的响应，用当前 size 计算边界。
- [x] 补具名测试 `rejectsUnsupportedAndSameSize`（字符串、null、NaN、分数、0、负数、21、200）、`preservesSizeForFilters`、`resetsSizeForIdentityAndReadGrant`、`usesSizeForPrivatePost`。每项本人／全站参数化，保留既有默认20测试。
- [x] 补 `retiresLateSizeABA`、`remountDefaultsWithoutRetiredRows`、`blocksQueuedSizeForLiveLocks`、`doesNotClampOnPendingOrError`、`clampsSuccessfulTotalUsingCurrentSize`、`retryKeepsCurrentSize`、`exportsAllMatchesFromSecondPage`。旧请求只能 resolve 到旧 key；失败用新 Response，不复用已消费 body。
- [x] 执行两个定向文件及相关通用页面回归，核实际结果及完整原日志。检查 lint／types、翻译键和完整 diff 后提交原子功能切片。
