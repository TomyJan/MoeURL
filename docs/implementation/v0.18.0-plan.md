# v0.18.0 全站统计、访问明细与操作审计实现计划

交付状态（2026-10-23）：功能已通过 PR #208 合并为 `0f01a2e5`，尚未正式发布。下文保留原分支实施过程；当前状态和各候选验证证据见 [验收记录](v0.18.0-acceptance.md)。

> **面向 AI 代理的工作者：** 使用 subagent-driven-development 逐任务实现，每个任务完成规格与质量审查；全分支最终审查后交付。任务中的步骤使用复选框跟踪。

**目标：** 一次交付管理员全站仪表盘、权限控制的匿名访问记录和关键业务变更的原子审计闭环。

**架构：** `internal/insights` 提供有界只读统计／日志查询，SQLC 承载真实查询。现有成功跳转事件只扩展浏览器／系统类别；新增事务局部审计上下文与白名单触发器，关键服务写入必须绑定真实 actor。Vue 使用既有 Shell、日期筛选、Chart.js 和 Vuetify 表格。

**技术栈：** Go 1.26.8+（验证使用安全补丁工具链）、Chi、SQLC 1.30.0、Goose、PostgreSQL 18；Vue 3、Vuetify 4、TanStack Query、Node.js 26、pnpm。

**规格：** [产品范围](../product/scope-v0.18.0.md)、[完整设计](../specs/2026-10-22-v0.18.0-analytics-audit-design.md)。基线 `722b2ce0`，分支 `feat/v0.18.0-analytics-audit`；原主检出不参与实现。

## 全局约束

- API 只用 GET／POST 与现有 envelope；无效输入 100001、无权限 120001、链接不存在 200104、未知基础设施错误 HTTP 500／900000；NoStore。
- 权限为 `statistics:read_all`、`audit:read`（admin 保护）和 `short_link:read_visits`（user／admin、standard），不按组名绕过授权。
- 日期默认近 7 天，days 仅 7／30／90，或成对自定义 UTC 日；含结束日、最多 90 天，不允许未来／反向／混合／重复／显式空参数。
- 明细和审计 pageSize 默认 25、范围 1–100；cursor 最大 512 字节，为严格 base64url JSON，按 `(created_at,id)` 唯一倒序，读取 pageSize+1，不做 offset／count。
- `deviceType` 过滤为 desktop／mobile／tablet／bot／other／unknown；countryCode 为两位大写 ASCII 或 unknown；空参数不是 unknown。
- 浏览器类别仅 chrome／edge／firefox／safari／opera／samsung／bot／other；系统类别仅 windows／macos／ios／android／linux／chromeos／other；无法识别为 null，不含版本／原始 UA。机器人浏览器归 bot。
- 不持久化原始 IP、完整 UA／Referer、密码／哈希／Token／Secret／subject／email、请求体、完整目标地址或配置值；审计只保留 ID、动作与字段名。
- 访问统计只含 redirect_response_sent，失败或条件阻断不计入；原访问事件长期统计保留与写入时机不变，新审计保留 180 天。
- SQLC 与权限 fixture 只通过锁定生成入口更新；保持完整 Go／前端业务覆盖率 100%，不扩大排除或添加镜像测试。
- 本地验证使用隔离数据库／容器、18086／19006 等空闲任务端口与独立构建；不覆盖原主检出的 web/dist、18080 预览或日常数据库。

## 审查重点

1. 权限撤销、用户停用／换组、退出换号或迟到请求，不能继续显示原有私有记录；任务 1、3 覆盖服务／页面。
2. 多条记录具有相同时间、翻页期间有新增或游标恶意构造，不能重复、越权或无限读取；任务 1、2、3 覆盖。
3. 审计写入失败不能留下成功业务或部分批量变更；任务 2 以数据库故障注入覆盖全部关键写入类别。
4. 自助改密失败计数必须提交，成功凭据／会话撤销与审计原子；域名相同授权集合不能产生伪变更；任务 2 专项覆盖。
5. 实际页面出现旧事件无新字段、空区间、已删除热门资源、未知操作者、长文本或网络失败，必须有正确且不泄露数据的状态；任务 1、2、3 覆盖。

## 文件职责与接口

任务 1 创建 `internal/insights/{model,query,service,dashboard,visits,handler}.go` 及相邻真实数据库／HTTP 测试，`queries/insights.sql`、`migrations/00020_insights.sql`。修改 `queries/event.sql`、event.Event／DBRecorder、shortlink analytics／redirect handler、permission 常量／catalog、HTTP／app 接线与 SQLC 输出；新增文件纳入 Go 业务覆盖率目标。对应 migration／目录测试及生成 fixture 同任务同步。

任务 2 创建 `internal/db/audit.go`、`internal/insights/{audit,audit_handler,audit_cleanup}.go` 及测试，`queries/audit.sql`、`migrations/00021_audit.sql`；增强 `internal/db/tx.go`，接入 shortlink／user／auth 密码／usergroup／domain／system／OIDC 关键服务写入及 app 生命周期。域名差量授权 SQL 与测试属于任务 2。所有新审计业务 Go 文件和 db/audit.go 纳入覆盖率，非空审计回滚保护写入迁移测试。

任务 3 创建 `web/src/entities/insights/{api,model}.ts`、`features/visit-records/VisitRecordsPanel.vue`、`pages/AdminDashboardPage.vue`、`pages/AdminAuditPage.vue` 与相邻测试；调整 AnalyticsPage、ConsoleShell、router、permission/i18n。新增 `web/e2e/v0.18.0-insights-audit.spec.ts`，更新当前 package version、技术基线、规格及验收记录。必要样式及现有 API schema 的扩展在同一切片完成。

公开 Go 接口固定为 `NewService(pool *pgxpool.Pool, permissions permission.Resolver) *Service`；`Dashboard(context.Context, auth.CurrentUser, RangeInput) (DashboardResult,error)`、`Visits(context.Context, auth.CurrentUser, VisitInput) (VisitResult,error)`、`AdminVisits(...)` 和任务 2 的 `Audit(context.Context, auth.CurrentUser, AuditInput) (AuditResult,error)`。Dashboard／Visits 的 `Port` 与独立 `AuditPort` 分开，避免第二个任务迫使旧 handler stubs 实现新接口。HTTP Dependencies 分别增加 Insights 与 Audit，app 共用一个 service。

`RangeInput` 为 Days／StartDate／EndDate string；`VisitInput` 增加 ID／Cursor／DeviceType／CountryCode string 和 PageSize int32；`AuditInput` 增加 ActorID／ResourceType／Action／Cursor string 和 PageSize int32。响应字段、日期和列表结构逐字按设计第 2、3、6 节；bigint audit ID／cursor ID 使用字符串。前端按实际后端 schema 实现，不猜字段。

事务 API 为 `WithAuditTx(ctx context.Context,pool *pgxpool.Pool,actorID string,fn func(pgx.Tx)error)error`、`WithAuditActor(ctx context.Context,actorID string)context.Context`、`SetAuditContext(ctx context.Context,tx pgx.Tx,actorID string)error`。具体辅助函数可由实现者决定，但不改变已有业务原子性与错误语义。
