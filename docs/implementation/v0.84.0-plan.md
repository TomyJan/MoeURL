> **面向 AI 代理的工作者：** 使用 executing-plans 内联执行，各步骤以复选框跟踪；最后只用一名 gpt-6.1-sol 独立整分支审查者。

**目标：** 把当前页所选标题和公开短链复制为安全的 Markdown 项目清单。

**架构：** 扩展现有复制 hook 的可选格式，保原选择、缓存、身份及所有权守卫；两个真实父页复用同一锁，不改管理清单 CSV。

**规格：** [范围](../product/scope-v0.84.0.md)、[设计](../specs/2026-11-16-v0.84.0-selected-markdown-design.md)。

## 审查重点（Review Focus）

1. 标题中的方括号、反斜杠、HTML／实体和目的地址特殊符号不能生成额外链接或内容；Task1 字面量格式及拒绝回归。
2. 空、重复、未知、越界或未授权选择必须整体拒绝，不能取交集或读其他页；Task1 真实 cache 边界。
3. 只读账号可复制，但不得读取目标网址／备注或扩大 CSV／写权限；Task1 两真实父页及 Task2 真实只读用户。
4. 三个入口竞争、身份／选择同 tick 切回和旧 finally 不能污染新操作；Task1 受控 Promise 与真实生命周期。
5. 新按钮在中英桌面／320px 可见、键盘可达，真实 Clipboard 与受控拒绝不混写；Task2 单轮浏览器及原图。
