# v0.10.0 短链最大访问次数闭环验收清单

状态：设计提交 `197623e` 已完成；功能、完整本地门禁、目标 CI 和生产发布验收均待执行。

## 功能验收

- [ ] 有权限用户可以创建有限额短链，默认创建仍为无限额。
- [ ] 无权限用户不能设置或修改限额，但可以省略该字段编辑其他允许配置。
- [ ] 修改已有上限保留已用次数；降低上限可以立即耗尽；提高上限恢复访问。
- [ ] 清除限额归零当前额度周期，再次启用从 0 开始。
- [ ] direct 只在最终外部跳转消耗额度。
- [ ] intermediate 和 confirmation 打开页面不消耗，Continue 才消耗。
- [ ] 密码失败、密码限流、禁用、过期、域名不匹配和软删除不消耗额度。
- [ ] 达到上限后公开页面展示统一耗尽状态，不泄露目标 URL 或额度数值。
- [ ] 两个并发请求争抢最后一个名额时最多一个返回最终跳转。
- [ ] 无限额短链不执行同步额度更新。

## 数据与回滚

- [ ] migration Up、Down、再次 Up 通过。
- [ ] 既有短链升级后保持无限额，历史统计不回填额度用量。
- [ ] 权限只追加到需要的内置用户组，保留迁移后的人工权限修改。
- [ ] 数据库检查约束拒绝非法上限、负数和无限额非零用量。
- [ ] SQLC 生成两次零漂移。

## 前端验收

- [ ] 创建面板和设置对话框覆盖权限、边界校验、耗尽提示和清除周期提示。
- [ ] 个人和管理员列表只对有限额短链显示额度状态。
- [ ] 访问统计和额度用量使用不同字段及文案。
- [ ] 中英文、浅色/深色和桌面/移动布局通过自动化或人工检查。
- [ ] mutation 失败保留草稿，pending 和权限不确定状态禁止重复提交。
