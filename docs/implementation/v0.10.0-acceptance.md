# v0.10.0 短链最大访问次数闭环验收清单

## 功能验收

- [x] 有权限用户可以创建有限额短链，默认创建仍为无限额。
- [x] 无权限用户不能设置或修改限额，但可以省略该字段编辑其他允许配置。
- [x] 修改已有上限保留已用次数；降低上限可以立即耗尽；提高上限恢复访问。
- [x] 清除限额归零当前额度周期，再次启用从 0 开始。
- [x] direct 只在最终外部跳转消耗额度。
- [x] intermediate 和 confirmation 打开页面不消耗，Continue 才消耗。
- [ ] 密码失败、密码限流、禁用、过期、域名不匹配和软删除不消耗额度。
- [ ] 达到上限后公开页面展示统一耗尽状态，不泄露目标 URL 或额度数值。
- [x] 两个并发请求争抢最后一个名额时最多一个返回最终跳转。
- [x] 无限额短链不执行同步额度更新。
- [x] 最终跳转响应正文明确写失败时不记录统计事件，也不归还已签发额度。
