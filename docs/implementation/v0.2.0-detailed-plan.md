# v0.2.0 短链访问体验与生命周期实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。
>
> 本计划默认在验证通过后执行本地原子提交；`push`、合并及其他 Git 或远程集成操作仅在用户明确授权后执行。

**目标：** 在保持既有直接跳转兼容性的前提下，交付中间页跳转、可选过期时间、访问配置编辑和二维码，并让统计、覆盖率、构建与 E2E 达到发布门禁。

**架构：** `short_link` 通过 Goose 增加访问配置，短链 Service 负责权限和输入校验，Redirect Service 将初次打开、公开预览和最终继续拆成明确动作。Vue 侧复用短链实体 API，在创建组件和共享设置对话框中维护配置；公共中间页只读取目标主机名和倒计时，最终目标跳转仍由 Go 服务完成；二维码在浏览器中即时生成。

**技术栈：** Go 1.25、Chi、SQLC、Goose、PostgreSQL、Vue 3、TypeScript、Vuetify 4、TanStack Query、vee-validate、zod、vue-i18n、qrcode、Vitest、Playwright。

- [x] **步骤 3：实现 migration 和权限常量**

创建 migration：

```sql
-- +goose Up
-- +goose StatementBegin
alter table short_link
    add column redirect_mode text not null default 'direct',
    add column intermediate_delay_seconds smallint not null default 5,
    add column expires_at timestamptz;

alter table short_link
    add constraint short_link_redirect_mode_check
        check (redirect_mode in ('direct', 'intermediate')) not valid,
    add constraint short_link_intermediate_delay_check
        check (intermediate_delay_seconds between 3 and 10) not valid;

update user_group
set permissions = permissions
        || case
            when permissions ? 'short_link:use_intermediate' then '[]'::jsonb
            else '["short_link:use_intermediate"]'::jsonb
        end
        || case
            when permissions ? 'short_link:set_expiration' then '[]'::jsonb
            else '["short_link:set_expiration"]'::jsonb
        end,
    updated_at = now()
where key in ('user', 'admin');
-- +goose StatementEnd

-- +goose Down
-- +goose StatementBegin
update user_group
set permissions = (permissions - 'short_link:use_intermediate') - 'short_link:set_expiration',
    updated_at = now()
where key in ('user', 'admin');

alter table short_link
    drop constraint if exists short_link_intermediate_delay_check,
    drop constraint if exists short_link_redirect_mode_check,
    drop column if exists expires_at,
    drop column if exists intermediate_delay_seconds,
    drop column if exists redirect_mode;
-- +goose StatementEnd
```

创建 `00005_validate_short_link_experience.sql`，让历史行扫描运行在单独的 migration 事务中：

```sql

-- +goose StatementBegin
alter table short_link validate constraint short_link_redirect_mode_check;
alter table short_link validate constraint short_link_intermediate_delay_check;
-- +goose StatementEnd

-- +goose Down
select 1;
```

在 `permission.go` 定义两个常量并加入 `UserPermissions`、`AdminPermissions`；`system.Setup` 将通过现有数组自动写入新实例。

建立 3 组行为断言：

```go
result, err := service.Open(ctx, "abc123")

preview, err := service.Preview(ctx, "abc123")
```

- [x] **步骤 3：实现 Redirect Service 三动作**

定义端口：

```go
type RedirectPort interface {
    Open(context.Context, string) (OpenResult, error)
    Preview(context.Context, string) (PreviewResult, error)
    Continue(context.Context, string) (RedirectResult, error)
}
```

`Open` 记录打开和条件检查；直接模式可在准备写出目标 `302` 前记录 `redirect_initiated` 作为非统计审计，中间页入口不记录该事件；`Preview` 不写访问事件且只返回目标主机名；`Continue` 重新查询并检查状态、删除和过期后可记录准备跳转审计，最终目标响应成功写出后由 Handler 记录一次 `redirect_response_sent`。

```ts
  () => [props.open, props.url] as const,
  async ([open, url]) => {
    dataUrl.value = ''
    generationError.value = false
    if (!open || !url) return
    try {
      dataUrl.value = await QRCode.toDataURL(url, { width: 320, margin: 2, errorCorrectionLevel: 'M' })
    } catch {
      generationError.value = true
    }
  },
  { immediate: true },
)
```
