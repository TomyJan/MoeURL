# v0.78.0 复制本页短链实现计划

> **面向 AI 代理的工作者：** 使用 executing-plans 内联执行；最后仅一次 fresh 最强独立整分支审查，不派 builder 或任务实现代理。

**目标：** 安全复制当前页 1–100 个公开短链地址，不扩数据读取范围。

**架构：** 两个父页共享 hook 与展示按钮，读取现有 QueryClient；复用身份轮次和实时读权限，直接点击调用 Clipboard API。

**技术栈：** Vue 3、Vuetify 4、TanStack Vue Query、vue-i18n、Vitest、Playwright，无新增依赖。

**规格：** [设计](../specs/2026-11-15-v0.78.0-copy-page-links-design.md)、[范围](../product/scope-v0.78.0.md)。

## 全局约束

- 1–100 条、原顺序、URL 原样、LF 分行且无尾随换行；仅本页，不取 targetUrl 或跨页。
- 仅读权限，不借 CSV export 权限；无新 API／SQLC／迁移／权限／依赖。
- 所有同步与异步身份／授权／列表／锁守卫均真实验证，已接受的系统剪贴板不可撤销。
- 活动 4 GiB、双临时根 12 GiB、Docker 可回收缓存 6 GiB；不全局 prune、不安装依赖，不查 CI，不发布部署。

## 审查重点（Review Focus）

1. 旧渲染按钮被排队点击，当前缓存已失效或权限已撤销：不能复制。
2. 同 tick 撤权恢复／列表来回切换：旧结果不能提示成功或清新 pending。
3. noteQuery 私密筛选和 pageSize 初始化未完成：不能复制旧页，也不泄露关键词。
4. Clipboard API 的用户激活窗口：调用前不能 await；失败或不支持有反馈。
5. 本页复制与 CSV 全匹配导出的权限、页数及字段不同，不混用目标 URL。
