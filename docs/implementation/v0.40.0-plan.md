## 审查重点（Review Focus）

1. 文件读完前换号／撤权、关闭重开，旧输入或错误不得进入新上下文（Task1 FileOwnership）。
2. 第二文件、手工编辑与旧finally交叉，必须保留最新用户意图且不错误解除新loading（Task1 FileOrdering）。
3. 旧多列导出、畸形引号、空记录／超限不能被静默截断成部分创建（Task1 StrictCsv）。
4. 读取失败和未知提交不能导致换key、自动写或丢原草稿（Task1 ExactRetry，Task2 BrowserImport）。
5. 大文件在读取前拒绝，非法UTF-8无替换字符修复，手机与键盘可关闭和确认（Task1 FileBudget，Task2 BrowserImport）。
