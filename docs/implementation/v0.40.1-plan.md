## 审查重点（Review Focus）

1. TemplateBytes：屏幕／下载同源、BOM／CRLF精确且可被真实parser读回，没有私人内容。
2. StateIsolation：下载不改草稿、reading、导入错误、身份轮次或写请求；读取中下载仍保留原读取结果。
3. StageVisibility：预览／pending／unknown不显示帮助或下载，关闭重开局部反馈重置。
4. DownloadFailure：真实下载器失败反馈与手动重试，资源按原finally回收，无异常泄露或虚假保存承诺。
5. BrowserHelp：中英桌面／手机浅深色、键盘展开和下载、真实文件字节及重新导入预览，无隐式创建。
