# v0.9.0 系统设置与站点品牌基础闭环实施计划

状态：功能实现与当前环境可执行的本地门禁完成；完整目标运行时和生产环境验收仍待证据。

## 目标和边界

交付站点名称、默认语言、默认主题、简单页脚和安全本地登录开关，并把现有 OIDC Provider 管理纳入统一的系统设置权限与页面。产品边界见 [v0.9.0 范围](../product/scope-v0.9.0.md)，事务、安全和前端规则见 [详细设计](../superpowers/specs/2026-10-09-v0.9.0-system-settings-design.md)。

本版本不实现媒体上传、任意 HTML/CSS、主题编辑器、OIDC 模板、审计日志或部署环境变量在线修改。

## 架构决策

- 继续使用 `system_setting`，以 `site.settings_revision.updated_at` 作为统一乐观并发版本。
- 新增 `internal/loginpolicy`，集中读取并锁定 `auth.local_login_enabled`，使用注入的 OIDC 运行时校验函数检查最终 Provider 集合。
- 设置更新、Provider 更新和 Provider 删除统一先锁登录策略行，避免并发移除全部登录入口。
- 系统设置 API 位于 `internal/system`；本地登录 Service 和 OIDC Provider Service 只依赖最小策略接口。
- 前端公开配置使用 TanStack Query；偏好仍保存在浏览器，服务端默认值只填充没有本地选择的状态。
- `/admin/setting` 由新的设置容器页面承载，现有 OIDC 页面作为身份认证区域复用。

## 实施阶段

1. **数据与权限：** 新增 migration、`system:manage`、设置查询和生成文件，验证迁移往返与权限目录。
2. **设置与登录策略：** 建立设置模型、事务服务、公开与管理 Handler、共享登录策略锁和启动校验。
3. **认证协同：** 本地登录在昂贵操作前拒绝；OIDC Methods 返回真实开关；Provider 更新和删除保护最后入口。
4. **前端公开体验：** 严格解析公开配置，接入默认偏好、站点名称、页面标题和纯文本页脚。
5. **管理页面：** 实现常规设置草稿、冲突和错误状态，统一系统设置与身份认证页面及权限守卫。
6. **集成验收：** 补充 E2E、部署与技术基线、覆盖率目标和完整门禁证据。

执行步骤和每个原子提交见 [详细实现计划](v0.9.0-detailed-plan.md)，进度见 [任务清单](v0.9.0-tasks.md)，实际证据见 [验收清单](v0.9.0-acceptance.md)。
