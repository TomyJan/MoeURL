# v0.64.0 账号每日创建配额实施计划

> **面向 AI 代理的工作者：** 使用 executing-plans 内联逐任务实现；不派 builder／实现者。末段唯一 fresh 最强整分支独立终审，不派复审。用户已授权自主设计和交付，普通设计决定记账后继续。

**目标：** 可选统一每账号每日上限，成功计数、失败回滚、批量重放不重复扣减。

**架构：** 独立系统策略和 shared／exclusive gate，每账号一条真实数据库计量行，与创建／审计／回执共用事务。管理卡片和草稿独立于旧 strict settings。

**技术栈：** 既有 Go／pgx／SQLC 1.30／Goose／PostgreSQL、Vue／Vuetify／TanStack Query／zod／i18n，不新增依赖。

**规格：** [范围](../product/scope-v0.64.0.md)、[设计](../specs/2026-11-12-v0.64.0-account-daily-create-quota-design.md)。基线 master `b98bd1cbdbecaed7f30fd91bab7b5324d4463801`，分支 `feat/v0.64.0-account-daily-create-quota`。

## 审查重点（Review Focus）

1. 最后额度并发、批量全有或全无、随机冲突重试与 audit 失败不能超用或误扣；Task1 真实 PG 验证。
2. 行锁等待后取数据库日、未来行安全失败，关闭／调小／删除／转移／改组不能重置；Task1 计量和 tracer 验证。
3. 成功回执在当前授权之后、配额之前恢复；unknown 不能被后续耗尽解除；Task1 服务与 Task2 受控状态验证。
4. 配额保存／创建统一锁序和当前身份；撤权、双 CAS、Down 当日用量安全拒绝；Task1 真实锁队列及迁移验证。
5. 身份轮次与编辑后迟到 load/save 的全部 continuation 不能泄漏或覆写；Task2 具名受控竞态、Task3 手机键盘和真实失败反馈验证。
