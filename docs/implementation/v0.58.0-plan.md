## 审查重点

1. SVG 和 PNG 使用同一当前等级、颜色及完整 URL，没有一格式保留 M。
2. 等级切换清旧下载，PNG 和 SVG 的旧 success／failure／finally 均不能污染新轮次。
3. 颜色和等级交互保留另一选择，身份变化才同步恢复 classic／M。
4. 高等级编码失败不截断或偷偷降级，用户能明确主动恢复，SVG失败不破坏PNG。
5. 手机新增选择器不压掉动作；可访问状态、键盘顺序和实际下载与显示一致。
