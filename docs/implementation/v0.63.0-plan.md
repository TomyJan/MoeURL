# v0.63.0 可选目标主机白名单实施计划

> 使用 executing-plans 原生内联，不派 builder 或实现者；末段唯一 fresh 最强整分支独立终审，不派复审。用户长期授权自主设计、实现及正常交付。

**目标：** 默认关闭的精确 DNS 白名单限制新目标写入，保留黑名单优先、旧访问和已提交回执。

**架构与技术栈：** 复用 targetpolicy 的规范化和 shared／exclusive gate，独立管理资源；既有 Go／pgx／SQLC／Goose／PG，Vue／Vuetify／TanStack Query／zod／i18n，无新依赖。

**规格：** [范围](../product/scope-v0.63.0.md)、[设计](../specs/2026-11-12-v0.63.0-target-host-allowlist-design.md)。分支 feat/v0.63.0-target-host-allowlist；当前仅在 PR311 已核 master8a9bc9ec准备设计，PR312 完整交付并正常集成本地设计后才允许 start Task1，实际启动基线以私有证据为准。

## 审查重点（Review Focus）

1. 默认off不改变旧URL语法或黑名单，启用时IP空host不得漏放行；Task1规范化及真实七协议测试负责。
2. deny优先且两类保存与目标写入共享gate，提交后后继写必须看到新策略；Task1真实PG队列、取消/撤权和双CAS负责。
3. 已提交回执先于策略，unknown不能由后续确定拒绝解除；Task1回执/原子性及Task2受控状态测试负责。
4. 旧目标同字节配置编辑、公开访问保持原行为；Task1双编辑边界及Task3真实旧入口负责。
5. 身份/同号重登录/撤权/卸载/编辑中读取的每个success/error/finally不能泄漏或覆写草稿；Task2具名受控竞态及Task3手机键盘负责。
