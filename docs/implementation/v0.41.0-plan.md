## 审查重点（Review Focus）

1. PrivacySnapshot：入口授权后撤权、禁用、改组、删除和归属转移，不能由旧actor快照读到其他账号标签。
2. AccurateBounds：重复元素不重复计数；本人全部未删资源，50／51边界、频率和C排序，hasMore不装作完整目录。
3. LiteralSearch：Unicode32／33、原始控制、非法UTF8、百分号下划线反斜杠、重复未知query，不变成SQL语法或500。
4. IdentityEpoch：A→B→A、同账号撤权恢复、关闭重开、后台失效、旧搜索晚到均不能复活旧标签。
5. IndependentFilters：点选只改tag；错误／搜索／读取不阻断列表或写入，不把全资源计数解释为当前筛选数。
