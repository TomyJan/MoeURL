## 审查重点

1. 标签空数组也必须 metadata 权限，且 replay 前查当前 DB；真实撤权拒绝且三类记录不变。
2. 三协议共享 UUID，不得跨端点重复创建；测试每一对两个方向，同一协议 raw tags／顺序变化也 conflict。
3. 标签 JSON 不能丢原文或有损 surrogate；UTF-8／surrogate／重复键／null／缺字段严格拒绝，合法 emoji 和反斜杠文本存储可核。
4. 导入不能替换旧草稿再发现完整请求超限；精确65536／65537 bytes，以及 quoted JSON 的文件／请求不同大小边界。
5. 身份／权限／文件代际和 unknown 不得改端点／数组；真实 composable payload 和网络丢确认后重试证明，不只 mock 调用次数。
