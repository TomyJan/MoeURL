# v0.80.0 单条操作权限计划

> **面向 AI 代理的工作者：** 使用 executing-plans 内联执行；最后仅一次 fresh 最强独立整分支审查，不派 builder。

**目标：** 隐藏无权单条写操作，并阻止旧事件在失权或失效列表上分发写入。

**架构：** 共享列表消费独立显示能力，两父页沿用现有访问能力和缓存进行即时检查；保存由父页包装，原后端与敏感输入边界不变。

**技术栈：** Vue 3、Vuetify 4、TanStack Query、Vitest、Playwright，无新增依赖。

**规格：** [范围](../product/scope-v0.80.0.md)、[设计](../specs/2026-11-15-v0.80.0-link-action-permissions-design.md)。

## 全局约束

- 从已交付 master 8c748f16 开始，沿用当前 linked worktree，不改 master 直接开发。
- 无 API／迁移／权限／依赖新增，后端完整输入相同才复用原执行；本版前端产品号 0.80.0。
- 不查询或等待 CI，不碰 PR240／266／267、18080 和日常数据库，不发布部署。
- 活动 4 GiB、双临时根 12 GiB、Docker 可回收缓存 6 GiB；大操作先预算，串行，精确清理。

## 审查重点（Review Focus）

1. update 和 delete 分开授权，read／select 不授予写权限；矩阵由真实父页测试钉住。
2. 同 tick 缓存撤权早于 DOM 重绘时，旧事件不能发 HTTP；保存旧事件同样验证。
3. 当前行已消失、缓存失效或读取中时不能按旧目标写；启停按当前状态产生 payload。
4. 身份轮次变化关闭旧编辑器，不误把前一账号草稿提交到后一账号。
5. 原只读复制／二维码／备注和合法写操作保留；原证据不倒填为新执行。
