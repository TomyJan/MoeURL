## 功能验收

- [ ] 管理员可以读取并更新全部 v0.9.0 设置，旧版本数据自动获得安全默认值。
- [ ] 公开配置不暴露本地登录策略、部署配置、Secret 或其他管理字段。
- [ ] 语言和主题本地选择优先于系统默认值。
- [ ] 本地登录只能在存在可用 OIDC Provider 时关闭，且并发操作不能移除最后登录入口。
- [ ] 本地登录关闭后现有 Session 继续有效，Setup、Me、Logout 和 OIDC 登录保持可用。
- [ ] 系统设置页面、登录页、站点品牌和页脚支持简体中文、英语、桌面和移动端。
