# v0.33.0 首页文案实现计划

> **面向 AI 代理的工作者：** 使用 executing-plans 内联执行，标准 task-start／task-done 与 owned 账本；不派实现者或 builder。已有自主授权覆盖常规设计取舍，唯一 fresh 整分支审查在 Task3。

**目标：** 管理员安全保存两段首页纯文本，留空回退本地化默认，独立版本及同事务审计。

**架构：** 新 system/home-content 资源保存在现有 system_setting 单键，独立服务／handler；新 Vue entity 与独立编辑器接入现有系统设置页，首页非阻塞读取。

**技术栈：** Go／Chi／SQLC 1.30／Goose／PostgreSQL，Vue 3／Vuetify 4／TanStack Query／vue-i18n；不增依赖。

**规格：** [范围](../product/scope-v0.33.0.md)、[设计](../specs/2026-10-29-v0.33.0-homepage-copy-design.md)。本页复选框是初始计划；实际状态见[任务](v0.33.0-tasks.md)及[验收](v0.33.0-acceptance.md)。
