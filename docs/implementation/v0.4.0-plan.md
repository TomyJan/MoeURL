# v0.4.0 实施计划

## 版本目标

v0.4.0 实现确认页访问闭环。范围和数据契约以 [产品范围](../product/scope-v0.4.0.md) 与 [功能设计](../specs/2026-08-13-v0.4.0-confirmation-page-access-design.md) 为准，工程执行细节见 [详细实现计划](v0.4.0-detailed-plan.md)。

## 实施顺序

1. 数据库约束、内置权限和 migration 验证。
2. 后端创建/更新模式权限与管理响应契约。
3. Open、Preview、Continue 确认页访问状态机与事件口径。
4. 前端模式选择、列表标签和公共确认页。
5. E2E、覆盖率、生产构建和验收记录。

## 原子边界

每个工程切片先写失败测试，再实现最小代码，验证通过后本地提交。提交是默认行为；`push`、合并、`pull`、创建或切换分支或 `worktree` 以及其他远程 Git 操作必须获得用户明确授权。

## 生产验收

生产构建遵循既有基线：禁止新增分块警告、扩大受影响分块范围或提高既有阈值。后端和前端业务覆盖率继续保持 100%，确认页 E2E 同时覆盖桌面和移动视口。
