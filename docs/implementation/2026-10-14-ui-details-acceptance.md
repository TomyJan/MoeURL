# 控制台导航、版本标识与界面细节本地验收

2026-10-14：本轮在 `master` 上实现，并在提交前工作树验证。范围见 [实施计划](2026-10-14-ui-details-plan.md)。本记录不替代目标 CI、Docker 构建或生产验收。

## 实现范围

- 访问分析内聚到具体短链，移除主导航、概览和个人页的通用入口。个人与全站统计分别使用自己的路由、API、缓存键和返回入口；父级导航保持高亮。旧 URL 兼容跳转。
- Go 补齐两条统计页面路由，直接打开、刷新及收藏不再返回 404；页面静态资源仍不解析登录 Session，数据访问由原 API 权限边界保护。
- 目标和短链地址单行省略，保留完整文本、悬停标题、编辑值和实际链接。
- 页脚 Powered by 固定可见，管理页移除开关。服务端读取旧 `false` 值及接收旧客户端写入时均规范为 `true`；不新增 migration，不改变 API 字段结构。
- 静态构建版本使用精确 `v数字.数字.数字` tag 或前端开发基线 `0.11.0` 加 7 位 commit。版本链接指向对应 tag 或完整 commit。无关 tag 回退到 commit；Docker 通过构建参数注入，不复制 `.git`。缺少完整提交信息时拒绝构建，Compose 配置和清理不依赖该参数。
- 分析页面统一标题、间距、轻表面卡片、移动布局与失败重试。图表坐标及网格跟随主题，访问量使用非负整数刻度。图表跟踪实际 canvas，销毁及重建与渲染同步，修复失败后以同一缓存数据重试时趋势图空白的问题。
