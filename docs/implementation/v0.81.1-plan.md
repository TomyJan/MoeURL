## 审查重点

1. 同时业务／清理失败：聚合错误第一项严格等于原业务对象，后续清理仍真实删除文件。
2. throw undefined等假值：依旧reject，不能被if(error)当作成功。
3. 同步与异步清理失败：两者按顺序保留，释放失败不阻断恢复尝试。
4. 无错误或仅一种错误：成功不添错、失败不吞错，body只执行一次，不自动重试写入。
5. 实际浏览器接线与外层生命周期保持：六场景完整payload／geometry及自有资源清理正常，产品复用不冒新编译。
