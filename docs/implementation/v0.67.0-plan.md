# v0.67.0 目标 DNS 后缀黑名单实现计划

> **面向 AI 代理的工作者：** 使用 executing-plans 内联逐任务实现，不派 builder；最终仅一次全新整分支独立终审。长期无人值守授权覆盖普通设计和集成决定。

**目标：** 让管理员限制某 DNS 主机及全部子域的新目标写入。
**架构：** 新独立 suffix 资源复用 targetpolicy 的规范化、身份、strict JSON 和事务 gate。七个目标写协议通过既有 CheckTargets 读取三个合法资源；管理卡片独立草稿，旧精确策略与公开访问不变。
**技术栈：** 既有 Go／PostgreSQL／SQLC 1.30、Vue／Vuetify／zod／Playwright，无安装或新增依赖。
**规格：** [scope](../product/scope-v0.67.0.md)、[design](../specs/2026-11-13-v0.67.0-target-host-suffix-denylist-design.md)。BASE `d8ebceb7865272b8d2163eb4c73a61694f53c09a`，branch `feat/v0.67.0-target-host-suffix-denylist`。
