## 审查重点

1. unknown 后收到拒绝仍不能声明整批未创建，UUID 和有序原文不变。
2. 旧三模式不能误报自定义短码问题，200120 仍显示冲突。
3. 确定拒绝保留草稿，只有主动修改后重新预览才换编号，不自动写入。
4. 身份／权限失效和迟到结果不能影响新账号或恢复旧草稿。
5. 中英长提示在手机完整可读，不泄漏后端正文，不扩大 CSV 或恢复能力。
