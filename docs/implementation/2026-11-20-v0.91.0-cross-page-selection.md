# v0.91.0 短链跨页手动选择实现计划

> **面向 AI 代理的工作者：** 必需子技能：executing-plans 逐任务实现此计划。步骤使用复选框跟踪进度。

**目标：** 在本人和全站短链列表中，保留用户在同一筛选结果里跨页手动勾选的最多 100 条记录。

**架构：** `useShortLinkBatch` 持有筛选上下文内的 ID 集合，额外接收页身份和成功读回信号；同页刷新只按该页前后 ID 差异收敛。列表表头继续根据当前页 ID 展示状态，并把当前页全选改为对选择集合的增量添加／移除。

**技术栈：** Vue 3、TypeScript、TanStack Query for Vue、Vitest、Vue Testing Library、vue-i18n；复用既有批量 API，不新增依赖。

**规格：** [v0.91.0 设计](../superpowers/specs/2026-11-20-v0.91.0-cross-page-selection-design.md)

## 全局约束

- 同一已应用筛选条件下最多保留 100 个不同 ID；不提供跨页全选或部分批量成功。
- 页头全选和半选状态只由当前页决定；全选只添加当前页，取消只移除当前页。
- 当前页成功刷新只剔除该页刷新前存在、刷新后缺失的所选 ID。
- 达到 100 条后可取消已有行；未选行保持禁用，调用层拒绝任何越限新增。
- 筛选、账号身份／登录轮次或权限集合变化时清空选择和确认快照。
- 不新增 API、数据库、权限、依赖，不改变 CSV 与服务端批量事务契约。
- 本地验证与 CI、生产发布严格区分；不查 CI、不发布部署。

## 审查重点（Review Focus）

- 跨页后当前页全选／半选必须忽略其他页的所选 ID，否则页面会误报当前页状态。
- 当前页成功刷新缺失项时，不能清除其他页的有效选择；同页读取 pending 或失败也不能被误当作空集合。
- 当前页全选超过 100 个唯一所选 ID 时必须整次拒绝并提示，不能截断或部分累加。
- 过滤、身份轮次、权限变化后的迟到批量响应不能反馈到新上下文。
- 当前页取消全选不得丢弃其他页所选 ID；删除确认仍必须使用打开时固定的 ID 快照。
