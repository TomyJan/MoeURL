## 审查重点（Review Focus）

1. HTTP500／invalid envelope／invalid成功data 不是明确未提交；Task1 unknown matrix 与 Task2 真提交丢响应证明屏障不被绕过。
2. 失败 reload 或被编辑淘汰的成功 reload 不应清掉未知提示或阻写；Task1 failed reload／retired revision 用受控 promise 验证。
3. 错认其他资源错误码为本卡片输入拒绝，会让未知结果重新可写；Task1 distinct rejection codes 精确核 900212／900210／900216，其他码均 unknown。
4. 切号、同号重登录、撤权、卸载的迟到 success／error／finally 不得污染当前身份；Task1 每资源当前身份矩阵，Task2 每资源一个真实同 SPA 退休请求。
5. 后缀拒绝 row.host／wire suffixes 差异或开关字段复制错误会改变真实策略；Task1 精确核请求 payload 和完整版本，Task2 独立 GET 核实际保存及恢复后版本。
