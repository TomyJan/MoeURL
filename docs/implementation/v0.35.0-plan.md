# v0.35.0 有界页脚链接实现计划

> **面向 AI 代理的工作者：** 必需使用 executing-plans 内联执行、标准 task-start／task-done 和本计划 owned 账本；不派 builder／逐任务实现者或审查者。长期自主授权覆盖常规设计取舍，仅 Task3 最终阶段一次 fresh 最强实际支持模型整分支终审。

**目标：** 管理员安全保存最多 5 个有序页脚文本链接，独立当前授权／完整 CAS／事务审计，公开安全展示且保留旧页脚文字和固定署名。

**架构：** system_setting 独立 site.footer_links 单键、三个新 API 与 FooterLinksService；Go／TS 共享 URL 语料和明确规范化合同。前端严格 entity、per-QueryClient 公共协调器、独立草稿编辑器与 SiteFooter nav，不扩旧 DTO、权限或个人偏好。

**技术栈：** Go／Chi／SQLC 1.30／Goose／PostgreSQL，Vue 3／Vuetify 4／zod／vee-validate／TanStack Query／vue-i18n；无新依赖。

**规格：** [范围](../product/scope-v0.35.0.md)、[正式设计](../specs/2026-10-30-v0.35.0-footer-links-design.md)及[20 项具名矩阵](v0.35.0-test-matrix.md)。本页保持初始计划，实际状态见[任务](v0.35.0-tasks.md)与[验收](v0.35.0-acceptance.md)。
