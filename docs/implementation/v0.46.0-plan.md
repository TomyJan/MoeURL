## 全局约束

- body 16384 bytes；noteQuery 先拒 Cc 后 Go trim 再最多 100 码点；四只读 POST 不接 querystring。整数词法及全部错误码按规格。
- 五秒只读授权 snapshot；Count／List 同快照；导出先筛选再 1000 条／8 MiB／17 列预算。空词也重查当前授权。
- 不返回备注／词、不写 URL／storage／文件名／应用日志；不改 schema、权限、依赖或备注 CAS。分页固定 20，key 关键词只追加9。
- 原始失败、cwd／显式环境／未全捕获继承、runtime、输入全集／hash／bytes、退出和准确资源清理分别记证。不重复成功且输入未变的操作。
- 每任务标准 start／brief／done；Task4 后才整体完成。沿用既有自主 commit／push／守卫合并授权，不碰 PR240、18080、日常 DB、未知资源，不发布部署。

## 审查重点（Review Focus）

1. 空搜索词或旧 actor 预检不得绕过数据库当前授权；撤权／转移／禁用后的列表和导出不泄露集合。
2. 非法 Unicode、边缘控制符、整数溢出和重复 JSON 不得被宽松解码修复；q／tag 旧语义不变。
3. %／_／反斜杠按字面匹配，Count／List／导出谓词相同，预算不得在筛选前截断。
4. 防抖未应用词、ABA、重挂载及迟到 success／error／finally 不得复活旧集合或导出旧账号数据。
5. queued 翻页／筛选／写入不得绕过编辑／提交互斥，备注写后集合收敛，未知写入不重放。
