# v0.26.0 个人默认域名实现计划

> **面向 AI 代理的工作者：** 使用 executing-plans 在当前会话逐任务内联实现。步骤使用复选框跟踪；只在全部任务后派一次最强 fresh 全分支审查，不派每任务实现者／审查者。

**目标：** 账号显式保存可用域名，所有创建面板采用安全的初始选择，保持旧创建 API 与语言主题偏好契约。

**架构：** 独立 `user_domain_preference` 表及本人 API，独立版本；保存使用当前数据库授权与域名共享锁，域名删除同事务清除偏好并推进版本。Vue 复用账号 epoch、TanStack Query 和现有域名候选；不修改后端创建语义。

**技术栈：** Go／Chi／SQLC 1.30.0／Goose／PostgreSQL，Vue／Vuetify／TanStack Query／vee-validate／zod。

**规格：** [设计](../specs/2026-10-27-v0.26.0-personal-default-domain-design.md)；[范围](../product/scope-v0.26.0.md)。

## 审查重点（Review Focus）

- 域名删除先清偏好版本再删除，失败必须整体回滚；并发保存不能重建悬空引用。任务1 `TestDomainPreferenceDeleteConcurrency` 与清理冲突场景覆盖。
- 账号主组及其权限在请求解析后变化，保存仍以当前数据库为准；清除本人偏好不能被创建权限撤销困住。任务1授权矩阵及受控锁竞争覆盖。
