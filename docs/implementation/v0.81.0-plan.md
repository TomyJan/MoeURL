# v0.81.0 CSV 标准列顺序计划

> **面向 AI 代理的工作者：** 必需子技能 executing-plans 内联执行，TDD；仅版末一次 fresh 最强独立整分支终审，不派 builder／实现代理或复审。

**目标：** 允许八种完整标准 CSV 格式调整列位置，保持字面内容、协议和权限。

**架构：** 现有严格 CSV 解析后统一验证表头集合并排列该行字段，复用原 schema／mode；hook／后端不改，帮助仅双语文字。

**技术栈：** Vue、TypeScript、Vitest、Playwright，现有依赖。

**规格：** [scope](../product/scope-v0.81.0.md)、[设计](../specs/2026-11-15-v0.81.0-csv-column-order-design.md)。

## 全局约束

- 基线 d03cbdcfa4845f92c3e314fca4ac8e9aa47e9ab3；分支 feat/v0.81.0-csv-column-order。
- 仅原标准序列前 N 项的完整集合，N=1–8；列位置任意，名称逐字不 trim，原值／数据行顺序不变。CSV 与 JSON 各最多65536字节、1–20行。
- 不改 API／DB／权限／新依赖，不查 CI、不触 PR240／266／267、18080／日常DB、不发布部署。产品实现后0.81.0。
- 活动4GiB／双根12GiB／Docker可回收6GiB，大操作先预算串行，独占资源及时精确清理。
- 保留前版15条裁决及两组Minor原文；M1不混入本版实现，文档量词在实际改动处维护。

## 审查重点

1. 交换字段时从原行整体取值，不能原地覆盖导致标题变URL；具名字面对象测试及真实HTTP。
2. 缺失／重复／未知列、非前缀子集和坏行宽不能被忽略或填默认；具名整体拒绝和保草稿。
3. 只调整列位置，不改变行序、原始空白／Unicode／引号、tags原数组或wire预算；字节边界与完整payload。
4. 重排八列不得走旧端点或漏权限epoch；真实File、撤权恢复、未知回执原UUID重试。
5. 帮助和模板不承诺任意映射／恢复，手机可读，产品来源、扫描和运行时不混借；模板hash和真实浏览器原图。
