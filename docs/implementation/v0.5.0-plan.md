# v0.5.0 实施计划

## 版本目标

v0.5.0 实现内置用户组权限管理与权限预设闭环：三个内置组均可查看，`user` 和 `admin` 可编辑，`guest` 保持只读。范围和数据契约以 [产品范围](../product/scope-v0.5.0.md) 与 [功能设计](../specs/2026-08-20-v0.5.0-user-group-permission-management-design.md) 为准，工程执行细节见 [详细实现计划](v0.5.0-detailed-plan.md)。

## 实施顺序

1. 权限目录、预设、保护规则和 SQLC 条件更新。
2. 用户组管理 Service、HTTP API、路由和生产装配。
3. 前端用户组页面、独立草稿、预设与冲突状态。
4. 动态撤权、并发保护、桌面/移动 E2E 和发布验收。

## 原子边界

每个工程切片先写失败测试，再实现最小代码，验证通过后本地提交。提交是默认行为；`push`、合并、`pull`、创建或切换分支或 worktree 以及其他远程 Git 操作必须获得用户明确授权。

## 生产验收

本版本不新增 migration，但 SQLC 生成结果必须零漂移。后端和前端业务覆盖率继续保持 100%，Docstring Coverage 不低于 80%。生产构建不得新增分块警告，Playwright E2E 必须覆盖真实管理员页面、运行时撤权和桌面/移动布局。
