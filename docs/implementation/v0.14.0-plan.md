# v0.14.0 统计日期范围实施计划

> 使用 subagent-driven-development 逐阶段实现，先规格审查，再代码质量审查；全部完成后独立审查整个分支。

目标：在已有短链分析上提供有界 UTC 日期选择，保持权限和匿名事件口径。

架构：源 SQL 传入 UTC 半开时间边界，Go 验证日期并返回实际范围；Vue 将应用后的日期范围纳入查询键。沿用 Go、SQLC、PostgreSQL、Vue、TanStack Query、Vuetify 与现有校验技术栈。

范围见 [产品范围](../product/scope-v0.14.0.md)，契约见 [设计](../specs/2026-10-15-v0.14.0-analytics-date-range-design.md)，状态见 [任务清单](v0.14.0-tasks.md)。
