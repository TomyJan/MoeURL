# v0.44.0 备注状态筛选实现计划

> **面向 AI 代理的工作者：** 使用 executing-plans 在当前隔离工作区逐任务实现；不派 builder 或各任务实现者，最后整分支一次 fresh 最强 supported 终审。

**目标：** 本人／全站列表及导出按备注有无整理，保持当前授权和私有正文边界。

**架构：** 三态参数映射到 SQLC 的同一空串谓词。非空列表筛选在五秒只读 repeatable-read 事务内核当前授权和 Count／List；导出沿用单 SELECT 授权快照。两页和导出共享状态类型，写入确认后刷新当前列表。

**技术栈：** Go 1.26.8+、SQLC1.30.0、PostgreSQL、Vue3、TypeScript、Vuetify4、TanStack Query，无新依赖。

**规格：** [设计](../specs/2026-11-03-v0.44.0-note-status-design.md)、[范围](../product/scope-v0.44.0.md)。
