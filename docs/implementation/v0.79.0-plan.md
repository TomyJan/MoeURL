# v0.79.0 复制所选短链实现计划

> **面向 AI 代理的工作者：** 使用 executing-plans 内联执行；不派 builder，最后仅一次 fresh 最强独立整分支终审。

**目标：** 安全复制当前页所选的 1–100 个公开地址，允许只读选择而不扩大写权限。

**架构：** 扩展原复制 hook 的可选 selection 和共享 owner lock，两父页复用按钮；无 selection 路径保持整页复制。

**技术栈：** Vue 3、Vuetify 4、TanStack Vue Query、vue-i18n、Vitest、Playwright，无新依赖。

**规格：** [范围](../product/scope-v0.79.0.md)、[设计](../specs/2026-11-15-v0.79.0-copy-selected-links-design.md)。

## 全局约束

- 当前页 1–100 个唯一且全部存在的所选 ID，按列表顺序复制公开 url，LF、无尾随换行；不静默取交集、不读其他页。
- 选择只依赖读权限；写按钮和 submit 仍独立检查原权限。无新 API／数据库／权限／依赖。
- 直接点击首个 await 前写 Clipboard；旧反馈退休，系统已接受写入无法撤销。
- 活动 4 GiB、双根 12 GiB、Docker 可回收缓存 6 GiB；先预算、串行、精确清理，不查 CI、不发布部署。

## 审查重点（Review Focus）

1. 只读用户能选择／复制，但不能通过新选择入口编辑、删除或提交批量写入。
2. ID 缺失、重复或未知时整体拒绝，勾选顺序不能改变页面顺序。
3. 选择或身份 A→B→A 同 tick 后旧结果仍退休，不能 toast 或清新 pending。
4. 两实例 lock 所有权独立，旧 finally 不释放另一实例，也无 computed 初始化互引或自退休。
5. 已渲染按钮被延迟点击时仍核缓存、实时权限及所有父级锁，不能复制过期集合。
