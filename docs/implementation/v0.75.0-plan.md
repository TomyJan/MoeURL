## 全局约束与文件职责

UTC 时间恰 `YYYY-MM-DDTHH:mm:ssZ`、年0001–9999或空；1–20行，文件／完整 JSON 各65536字节。先当前授权再回执；新批次锁后clock_timestamp，已成功回执过期仍可重放。四项基础能力与实际模式权限保持，只有实际非空时间要求 set_expiration。无新依赖／权限／迁移，不查CI、不发布部署。

- 新 `internal/shortlink/bulk_create_expiration_{service,handler}.go`：严格第六协议及日期语法；`bulk_create_{metadata_service,service}.go`：prepared 时间、option、当前授权、锁后时间判断与原子持久化。
- `queries/short_link_create_batch.sql`／生成物：nullable expires_at 参数，标准生成；`internal/http/router.go`／`internal/app/app.go`：生产接线。
- 新 `internal/{app,http,shortlink}/*bulk_create_expiration*_test.go`：真实端到端、严格解码、并发／原子／回执／权限／旧格式。
- `web/src/entities/short-link/bulk-create{,-csv}.ts`及新 expiration 测试：独立类型、schema、client、parser；`web/public` 第六模板。
- `web/src/features/bulk-create/{useBulkCreate.ts,BulkCreateDialog.vue,BulkCreateCsvHelp.vue}`、i18n及新测试：epoch、预览、错误和帮助。
