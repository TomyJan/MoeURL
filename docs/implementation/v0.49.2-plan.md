1. 零高度仍有 gap：Task1 实际首业务矩形对 border＋padding，容差 1 px。
2. 退出动画提前脱流：Task1 先观察退出节点仍存在，再等移除，保持原时长。
3. 空路径隐藏或重建 Toaster：Task1 节点身份和下一条消息真正可见，Task2 完整业务回归。
4. 末条关闭焦点落 BODY：Task1 键盘关闭实际 activeElement，Task2 不抢新焦点回归。
5. 页面或 nested 错用空 CSS：Task1 回父层／页面同节点，Task2 五长消息／短高／手机业务。
