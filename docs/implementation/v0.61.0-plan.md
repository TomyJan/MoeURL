## 审查重点（Review Focus）

1. policy 保存和创建／编辑／owner 撤权不能死锁或漏新策略；Task1 实际 PG 队列及取消验证。
2. ACE／Unicode、尾点、userinfo、端口不能绕过 host 或误连带子域；Task1 规范化及真实 API。
3. 锁内原目标字节不变不受新规则影响，历史访问不变；Task1 双编辑及 Task3 真实入口。
4. 已提交回执先于新策略，先 unknown 后确定拒绝不能误解锁；Task1 四协议回执与 Task2 状态测试。
