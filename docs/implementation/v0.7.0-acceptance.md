# v0.7.0 多提供商 OIDC 登录验收清单

状态：功能实现与本地可执行门禁已完成；目标 CI、race、外部 OIDC 互操作和生产发布验收待补。

## 产品范围

- [x] 登录页展示数据库中全部启用且未删除的 OIDC 提供商。
- [x] 管理员可以新增、编辑、启停和软删除多个 provider。
- [x] 本地登录保持可用，未配置 OIDC 的部署无行为回退。
- [x] 系统品牌、通用设置、禁用本地登录、账号绑定和 provider 模板未混入本版本。

## 安全

- [x] Authorization Code Flow 使用 PKCE S256、随机 state 和 nonce。
- [x] state 仅以摘要保存且单次消费，回调重放失败。
- [x] callback 使用按 state 隔离的短期浏览器关联 Cookie；缺失、错误和跨浏览器回调均关闭失败，成功或失败后均删除 Cookie。
- [x] ID Token 的签名、issuer、唯一 audience、可选 `azp`、时间和 nonce 全部校验。
- [x] Client Secret 与 verifier 使用 AES-256-GCM 加密保存。
- [x] Secret、Token、code、state、nonce、verifier、subject 和 email 不进入日志或响应。
- [x] 回调地址只由 `MOEURL_PUBLIC_BASE_URL` 生成，return path 不能形成开放重定向。

## 账号与权限

- [x] 首次身份要求 verified email 且匹配精确域名白名单。
- [x] 首次供应只创建 `user`，不自动授予管理员权限。
- [x] 不按邮箱自动连接既有账号。
- [x] 重复身份复用同一用户，并发首次登录不产生重复账号。
- [x] provider 或用户停用后不能建立新 Session。
- [x] 管理 API 在 Service 层校验 `admin:access`。

## 数据与回滚

- [x] migration Up、约束、清理索引、空数据 Down 和 reapply 通过。
- [x] 存在 external identity 时 Down 安全失败且不丢失绑定。
- [x] SQLC 连续两次生成结果一致。
- [x] provider 更新使用乐观并发，冲突不静默覆盖。
- [x] 应用启动时验证全部已启用 provider 的运行字段和 Client Secret 密文；错误部署密钥阻止启动。
- [x] 使用保留 Secret 重新启用 provider 前验证密文可解密。
- [x] 过期 attempt 每周期最多四个 500 行批次并支持取消。

## 前端与 E2E

- [x] 登录页覆盖无 provider、多个 provider、加载失败和回调错误。
- [x] 管理页覆盖加载、空状态、成功、失败、冲突、停用和删除。
- [x] Secret 提交后立即清理且不进入 Query 缓存或 Mutation variables。
- [x] 桌面和移动端布局无已知重叠、溢出或不可达操作。
- [x] 本地签名测试 IdP E2E 覆盖首次登录、重复登录、域名拒绝、停用和本地登录回归。
