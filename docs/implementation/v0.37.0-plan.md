## 审查重点（Review Focus）

1. 同分钟两个事件、纳秒小数与非零 offset：详情和 datetime 必须逐字符保留，不能经 Date 舍入（Task1 RawPrecision）。
2. 非法／HTML 风格文本、Intl 不可用：安全原文 fallback，无 HTML 执行或崩溃（Task1 LiteralFallback）。
3. locale／zone／账号或权限变化：只改 label、不重取业务、不保存旧账号详情（Task1 ReactiveBoundaries 与 AccessUnmount）。
4. CSV／cursor／UTC 范围／datetime-local：请求与原字符串不受展开影响（Task1 既有 DisplayBoundaries）。
5. 键盘、触屏、390px 长文案／错误提示：可展开关闭且焦点保留，无页面横溢、通知不隐藏（Task2 Geometry 与 Task3 BrowserDisclosure）。
