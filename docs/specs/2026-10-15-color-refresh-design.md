# 鸢尾蓝与薄荷青配色

## 目标与取舍

用户认可当前标准列表和布局，要求改善灰蓝配色过于死板的问题。本轮保留布局、密度、圆角、动画和业务流程，只调整主题与色彩层次。

对比继续加深雾蓝、采用大面积珊瑚主色及鸢尾蓝搭配薄荷青三种方向，选择最后一种：鸢尾蓝能清楚突出主操作，薄荷青提供冷暖变化，珊瑚仅作为小面积装饰。浅色保留长时间阅读舒适度，深色采用紫调墨色及淡鸢尾蓝。

本设计替代 2026-10-14 视觉规范中的配色取值；其布局、权限、状态与动效规范继续有效，v0.0.3 文档保留为历史版本记录。

## 色彩职责

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 主操作、链接、选中 | `#5c4dde` | `#b9adff` |
| 次级强调、辅助动作 | `#147d75` | `#7cd6cb` |
| 装饰强调 | `#b8503b` | `#f0ad91` |
| 页面底色 | `#faf9f7` | `#15151f` |
| 卡片、表格、菜单 | `#ffffff` | `#1d1e2c` |
| 柔和表面 | `#f5f3fa` | `#242537` |
| 正文 | `#292639` | `#f0edf8` |
| 辅助文字 | `#626174` | `#aeaabe` |

- 主色集中于创建入口、链接、焦点和选中态，避免整页高饱和填充。
- 侧栏为轻微鸢尾色调；表格主体保持干净，表头用柔和紫调白区分。
- 概览数字和细小顶部色条使用主色、青色和珊瑚色，保留文字含义，颜色不成为唯一信息来源。
- 首页与认证页使用低透明度、静态的鸢尾和青色环境光，不增加动画、插图或内容。
- 成功、警告、错误继续使用独立语义色；危险操作保持错误色。
- PWA 图标、启动背景和浏览器默认主题色同步主色。

## 验证边界

沿用 Vuetify 集中 token，复用现有对比度测试并补齐次级操作、语义文字与柔和表面的组合，正文及常规操作文字至少满足 4.5:1。检查表格、菜单、弹窗、Toast、图表及浅深色切换。执行前端 lint、类型检查、单元覆盖率和构建，并在实际预览验证双语、两主题、桌面与手机。无需改变 API、数据库、权限或真实预览数据。
