## 实现合同

沿用 Vue 3、Vuetify 4、vue-sonner 2.0.9 和现有 Teleport。执行者选择仅为空 modal wrapper 添加绝对定位和零尺寸 CSS：以现有 `hasMessages` 及 `data-toast-modal-region` 的实际 toast DOM 存在性为依据，页面路径保持原样。有退出节点时继续原布局，移除后才脱流；新节点出现恢复有界正常流。

保持一个 Toaster 和现存消息节点，不能卸载、克隆、重建，不使用 display:none、visibility:hidden、aria-hidden、inert，不提前 dismiss 或缩短持续时间，不改父 gap。沿用已有最高层选择、退出层排除、触摸 capture／mouseleave 和安全焦点恢复。没有新的网络、数据库、权限或生成物接口。

零高度仍产生 gap，display:contents 可能让子 ol 继续参加布局，隐藏／卸载会改变 live region 或队列，故不选这些方案。绝对定位只用于实际为空的 wrapper；非空恢复必须有真实新消息验证。

## 可验证行为

真实业务 Shell 的 `.console-shell__mobile-panel` 与 `.console-shell__dialog-panel`：首个业务 child.top 等于 panel.top＋borderTopWidth＋paddingTop，容差 1 px。不能只断言 toast 数为零或 CSS 字符串。分别保留 RED 日志、矩形及原图。

测试 fixture 可扩展为真实 flex／grid 容器，用相同几何覆盖初始空、键盘关闭末条实际移除、自然超时退出、退出节点仍存在、下一消息恢复；同一 Toaster DOM 始终相同。有新焦点不抢回，末条关闭仍回安全按钮。保留原九项通知布局回归及页面／nested、六秒、原生 touch cancel、五长消息、窄短视口、主题语言。
