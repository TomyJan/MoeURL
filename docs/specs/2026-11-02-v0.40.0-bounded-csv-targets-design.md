# v0.40.0 有界 CSV 网址导入设计

## 意图与方案

落实[范围](../product/scope-v0.40.0.md)的少量网址导入。比较完整清单恢复、服务器上传和本地网址录入：前两者扩大归属／历史／存储边界，本版选择浏览器读取一列 CSV，再复用已经交付的原子批量创建。沿用 Vue／Vuetify／zod，不新增依赖。产品与实现选择由 Agent 自主作出。

## 格式和解析

新增 `entities/short-link/bulk-create-csv.ts`，导出 `BULK_CSV_MAX_BYTES = 65536` 和 `parseBulkCreateCsv(text: string)`，返回 `{ success: true; data: string[] } | { success: false }`。最大输入长度先按 UTF-8 字节检查；只移除开头一个 BOM。有限状态扫描字段开头、未引用、引用内、引用关闭四态，允许标准双引号与双引号转义。仅 LF／CRLF 分记录，裸 CR 拒绝；引用内换行属于字段内容，最后由网址 schema 拒绝。逗号产生第二列即拒绝，不尝试猜分隔符。

固定第一个记录恰为 `target_url`，不得有前后空格。每条数据恰一个字段，不忽略空行，不接受多余记录；允许文件最后一个 LF／CRLF，不凭空追加空记录。第 22 个总记录出现时立即拒绝；全部解析后复用 `bulkCreateTargetsSchema` 检查数量、长度、ASCII、安全网址和精确重复。不给导出公式防护加反转语义；旧 17 列导出明确拒绝，不会丢弃额外字段。

合法示例：

```csv
target_url
https://example.com/one
"https://example.org/search?q=a,b"
```

## 本地读取和状态

`useBulkCreate` 新增 `reading` 和 `importFile(file: File | undefined)`。未选文件不修改状态。读取前重查当前身份／权限、打开且无快照／pending／unknown；先检查 `file.size`，超限不调用 arrayBuffer。读取后再核实际字节数，`TextDecoder('utf-8', { fatal: true })` 解码后交给解析器。所有异常归为友好读取错误，不上传或写浏览器存储。

读取捕获 operation generation、身份 scope、文件序号及 draft revision。对 draft 的同步 watch 在任何编辑时推进 revision；重置／卸载推进 operation generation，后选文件推进文件序号。success／catch／finally 都先核当前所有权，过时结果静默丢弃。输入变化会立即退休旧读取并解除 reading，以便手动预览；旧 finally 不得清掉新文件的 reading。成功导入只将网址用 LF 拼入 draft，随后清除导入错误；不生成 key、snapshot 或网络请求。

对话框用原生单文件 input 与可见 label，`accept=".csv,text/csv"` 仅作为选择提示，不凭扩展名／MIME 判安全。每次 change 先取得 File 再清空控件值，允许重选同一文件；不显示底层路径。预览按钮在 reading 期间禁用；关闭／输入继续可用。预览后文件控件隐藏；原 preview／submit／unknown 恢复语义不改。所有 URL 保持文本节点，不用 HTML。

## 错误与兼容

错误区分文件超限、读取／编码失败、CSV 格式或网址非法。保留原草稿，允许用户修改或重选；权限／身份退休沿用原 reset。原手工逐行解析的 ASCII trim／忽略空行行为保持原样，严格 CSV 不借用这一宽松步骤。服务端仍是最终权限和目标校验权威；仅扩本地录入，不改变 JSON 请求形状或批量政策。

## 验证和交付

先用真实 MyLinksPage 控件测试观察缺少文件入口的行为 RED，再实现与补齐解析器测试。覆盖 BOM、LF／CRLF、引号／逗号、1／20／21、65536 边界、非法 UTF-8、多列旧导出、空行、重复、超长、协议与原文保留；私网目标继续由既有服务端权威校验拒绝，不声称前端解析器完成网络安全判定。文件 Promise 受控验证后选优先、手工编辑、关闭重开、换号／撤权／卸载、success／error／finally 晚到；真实 POST 断言导入不自动写、预览有序、未知结果同 key。

完整前端测试／四100／types／lint／隔离构建和完整 Playwright，截图逐张实读及精确产品扫描。后端／SQLC 未变时核全集 hash／bytes 复用原验证，不重复成功 suite 或生成器；当前提交 CI 仍须独立九项。只在本地完整门禁后唯一 fresh 最强终审，全部有效问题闭环，最新 head 真实审查后 guarded squash，master 自身验证、标准任务与可恢复归档后才完成。
