# v0.40.1 CSV 格式帮助设计

## 决定与边界

补齐前版 M1，选择原入口的原生 `details`／`summary` 与独立帮助组件，避免占据默认手机空间或改写批量状态机。相比另建导入向导和多列恢复，静态示例与下载足以帮助用户准备文件。Agent 按自主授权确定本版范围、示例和下载细节；不需要再等待常规设计审批。

## 数据与组件

新增 `web/src/features/bulk-create/csvTemplate.ts`：导出屏幕示例及下载描述，内容仅为下列固定公开样例，表头不翻译。屏幕可用 LF 展示；下载从相同内容转换 CRLF 并前置 BOM，不附加第二个行终止符。

```csv
target_url
https://example.com/one
"https://example.org/search?q=a,b"
```

下载描述符合现有 `downloadCsv` 参数类型：文件名 `moeurl-target-urls-template.csv`、媒体类型 `text/csv;charset=utf-8`，精确 UTF-8 字节必须可被生产解析器读回两条原网址，逗号保持字面值。模块不消费 auth、草稿、站点、时间或随机值。

新增 `BulkCreateCsvHelp.vue`，使用原生可访问折叠控件、纯文本 `pre`／`code`、本地化说明与下载按钮。局部状态保存下载已发起／失败反馈；每次点击先清旧反馈，调用原下载器，异常只映射固定友好文本。既有下载器的 finally 负责 anchor／objectURL 回收，不修改该下载器。避免新联网资源、HTML 注入、持久状态或全局 toast。

`BulkCreateDialog.vue` 仅在原文件输入所在的无 snapshot 草稿块挂载帮助。帮助组件不接收 controller 或草稿引用，因此下载不更改 reading、errorKey、draft、requestId 或身份轮次。预览／pending／unknown 隐藏沿用原 snapshot 分支；关闭重开重新创建局部反馈，不保留旧错误。读取中仍可下载固定模板，原读取成功／错误／finally继续由原controller所有权守卫管理。

## 文案与布局

中英说明包含格式与预算、先替换示例、仅填草稿需继续预览确认。下载成功只说已发起，不声称已保存；失败不暴露异常正文。示例可选择复制，长示例在本组件内折行，手机不新增横向溢出。使用主题 token，保留原界面语言、主题、键盘焦点与原生展开状态语义。

## 验证

真实 `MyLinksPage`／`BulkCreate.test.ts` 先缺帮助与下载行为 RED，再最小实现。字节测试以手工推导字面量断言 BOM／CRLF、文件名、媒体类型及生产 parser 往返；测试不可从被测 builder 生成期望值。真实下载器只替换浏览器 objectURL 与点击边界，观察 Blob、anchor 和错误反馈，不 mock 整个帮助组件或下载器。

覆盖下载不改草稿／无 POST、异常后手动重试、关闭重开、预览／pending／unknown 隐藏，以及受控 arrayBuffer 读取过程中下载后原文件仍可完成。完整前端四100／types／lint／隔离build；完整nonweb集合核同后复用已有Go和生成物证据。真实浏览器从下载事件保存字节、核验后重新选入文件并预览，不访问示例目标；中英双视口浅深色、键盘与原图实读。完整浏览器、精确产品、唯一终审、各提交自身真实远端审查及候选／master九CI分开归属。
