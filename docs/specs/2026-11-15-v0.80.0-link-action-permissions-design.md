# v0.80.0 单条操作权限设计

## 行为

`ConsoleLinkList` 接收独立 `canUpdate` 和 `canDelete`，默认 false。配置／启停只在前者为真时存在，删除只在后者为真时存在；原 `writeDisabled` 继续表达临时锁。本人／管理员父页分别消费既有 `useShortLinkAccess`，不按组名推断能力。

两个父页以相同规则解析当前目标：读状态已成功、无读取中或缓存失效，当前权限允许目标动作，目标 ID 仍在当前列表，既有行写锁未锁定。配置与启停用 update，删除用 delete。启停使用重新找到的当前记录，不使用排队事件中的旧 status。重复点击仍受现有 mutation pending 状态限制，不自动重试。

父页包装配置保存入口：当前设置目标 ID、输入 ID 和当前授权行必须一致，且没有竞争写请求；身份轮次或更新能力变化同步关闭编辑器。关闭后旧事件不能再提交。原密码瞬态处理和服务端校验保持；不承诺取消已发出的请求或撤回服务端已接受写入，不将旧异步回调重构混入本版。

父页同时向真实表单提供同步保存就绪判定。列表读取中、失效、失败或目标缺失时禁用保存，并提示等待列表恢复或取消后重开。`save()` 在读取和清空原生密码输入之前再次检查；拒绝的提交不 emit、不清密码，恢复后才可提交。明文不进入响应式草稿，父页最终目标与权限守卫继续保留。

## 验证与边界

真实父页测试覆盖只读、更新独有、删除独有、完整权限；直接捕获旧子组件事件回调，在缓存同步撤权、当前列表失效、目标消失、身份切换后触发，观察实际 HTTP 零写入。测试不只检查传入 props 或 mock 调用次数。合法启停／删除精确检查实际请求路径和 payload；启停用当前行状态。配置真实表单或其既有边界验证保存，不能只检查 dialog mock 存在。

真实浏览器沿用 workers:1 和一次性 Compose，验证中英文、1280px／320px，本人只读菜单和正常管理员操作；最终恢复组权限、禁用测试账号并释放精确资源。前端完整覆盖率仍为四项 100%，不降低阈值；后端物理输入未变才复用原证据。用完的 HTML、产品副本与独占 Docker 资源主动清理，保留必要日志、结果和原图。
