# v0.87.0 手动 CSV 标签列映射设计

## 意图与选择

外部表格已能选择网址和标题，但标签仍需先改为标准表头。Agent 选择增加一个显式可选标签列，连接现有 metadata 协议；比猜别名更确定，比一次映射八个字段更容易验证。沿用 Vue、Vuetify 和既有 schema，无新增服务或依赖。它是有界导入，不是清单恢复。

## 解析契约

`parseBulkCreateMappedCsv(text, columns:{target:number|null;title:number|null;tags?:number|null})` 增加可选 tags。tags 省略或 null 时，原 targets／titles 的形状与字面值精确不变；选择标签时返回 `{success:true,mode:'metadata',data:BulkCreateMetadataItem[]}`，标题未选补 `''`。选择标题但不选择标签仍用 titles。标签全部为 `[]` 也不降协议。

所有已选索引必须是范围内整数且互异；拒绝负数、分数、NaN、Infinity、越界和与网址／标题重复。仍只投影明确选中的列，其他单元格不参与字段校验、不进入结果。标签单元格只经 JSON.parse 转为未知值，再整体交原 `bulkCreateMetadataInputSchema`。非法 JSON、标量、对象、null、非字符串数组及原标签规则拒绝均返回精确 `{success:false}`，不暴露内容。

原 schema 保留最多 10 项、每项 32 码点、Unicode、重复与空白语义；不转换为小写、不 trim 返回值、不分隔符猜测。CSV 扫描和 metadata 完整 wire JSON 分别限制 65536 字节；校验使用既有 36 字节 UUID。保留严格 UTF-8、单 BOM、1–8 列、1–20 行、真实宽度及引号和换行规则，不另建状态机。原标准入口、八模板及 scanner 不变。

## 草稿、权限和异步

hook 增加 `mappingTags:Ref<number|null>`，由原 `clearMapping` 在取消、清除、应用、新文件、reset 和卸载时一并清空。title 和 tags 任一非空都视为元数据意图：读取时捕获的既有 metadata epoch 必须仍然相同，当前权限也必须有效。已选任一元数据列的暂存遇撤权立即退休；尚未选元数据时可以继续 URL-only，但之后选择标签仍受原 epoch 约束，撤权再恢复不能复活。

应用时只调用有界 parser，成功才进入原 replaceDraft；失败保留草稿、选项和本地暂存，不发 HTTP。原 replaceDraft 深冻结每一项及 tags 数组，preview 生成一次 UUID。结果未知时重试同账号头、UUID 和完全相同 payload，不重新读文件、降级协议或再投影。账号、generation、draftRevision、File 序号、success／error／finally 的既有守卫保持。

## 界面和隐私

现有面板增加标签下拉框和“不导入标签”；无 metadata 权限时与标题一同禁用，继续原权限说明。标签说明明确必须为 JSON 字符串数组，例如 `["docs","工程"]`，`[]` 为空，空单元格拒绝。中英文入口、帮助、忽略提示和安全错误同步。

列名继续以列编号区分空名和重复名，控制类字符替换后最多 60 码点纯文本；不显示数据样本、完整 tooltip 或 HTML。应用后的列表和预览复用现有纯文本标签渲染。手机仍能滚动到三个选择、应用／取消、预览与提交，不新增布局系统。

用户能取消并取回旧草稿；相同无效操作再次发生时，现有安全错误仍聚焦。未选字段不能出现在预览或请求中。产品可见版本在实现后更新为 0.87.0，正式发布和部署不在本任务内。
