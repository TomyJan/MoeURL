# v0.81.0 CSV 标准列顺序设计

## 意图与边界

在当前 linked worktree 内联执行，沿用 Vue／TypeScript／现有 CSV parser、TanStack Query 和 i18n，不新增库。持续自主授权覆盖常规设计与实施决定；不派 builder 或逐任务审查，仅版末一次 fresh 最强整分支终审。范围见[scope](../product/scope-v0.81.0.md)。

表格可以调整列位置，但不能让系统猜含义。只接受现有八种完整标准列集合的排列：前 N 个标准字段恰好各出现一次，N 为 1–8。比如标题在 URL 之前可以；只给 URL 和过期时间、目录外字段或重复列仍拒绝。任意列映射与清单恢复保持后续方向。

## 解析与字面量

保持 `parseBulkCreateImportCsv(text: string): ImportResult` 和 `parseBulkCreateCsv(text: string): CsvResult` 的导出契约。先执行原始 UTF-8／65536 字节／CSV 状态机／21 条含表头记录／最多八字段限制，再读取表头。

以表头长度 N 取标准序列前 N 项，查找每个标准名的原始位置；任一缺失立即整体拒绝。由于原表头长度同为 N，且期望名称互异，完整命中已排除重复名和额外名。先拒绝任意行宽不一致，再按位置从未被修改的该行一次构造规范字段数组；不得边覆盖边读取而交换丢值。

后续只按 N 选原有 schema 和 mode，移除已由统一表头／行宽守卫证明的重复位置条件，避免不可达分支。原业务验证、完整 wire JSON 预算、tags JSON.parse、原 UUID 长度占位及非空／权限语义不变。数组仅重排列，数据行和字符串原文不变。CSV 无效时不替换草稿，不引入网络副作用。

## 消费与帮助

`useBulkCreate`、client 和后端协议保持原实现。通过真实 File 读取验证：重排八列仍进入 countdowns 原端点，payload 字段／值／顺序准确；未知响应只重发同 UUID 和内容。撤权再恢复不能复活迟到文件，非法重排文件不覆盖手工草稿。

`BulkCreateCsvHelp.vue` 增一段双语纯文本说明，翻译各自准确解释完整标准列集合，不增加模板或下载状态。原八份公开模板及示例逐字保持。帮助渲染／下载／导入状态继续隔离，不能为文案增强清掉草稿。
