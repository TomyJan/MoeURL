# v0.16.0 聚合统计 CSV 导出设计

## 1. 授权与 API

新增 `GET /api/v1/short-link/statistics/export` 和 `GET /api/v1/admin/short-link/statistics/export`，接受与 statistics 一致的 `id`、`days` 或 `startDate`／`endDate`，复用严格解析和有界 UTC 日期校验。成功 envelope 的 `data` 为 `{fileName, contentType, content}`，`contentType` 固定 `text/csv;charset=utf-8`。返回 no-store，错误沿用 `100001`／`120001`／`200103` 等现有统计契约，基础设施仍 HTTP 500／900000；不返回文件或静默降级。

新增独立 ExportPort／ExportHandler，复用现有 Service 的 Statistics／AdminStatistics 与格式化函数，不扩大既有 Port。下载重新从服务端读取，不把旧统计缓存直接序列化。除新的导出能力外，个人要求 read_own 和本人归属，管理员要求 admin:access 和 read_all；权限由既有数据库 Resolver 读取，不信任客户端声明。

新增 `short_link:export_statistics`，属于 short_link_basic 可配置目录；user／admin 默认、standard 预设包含，basic／restricted／guest 不包含。`00019_analytics_export_permission.sql` 只追加内置组缺失权限、更新时间和记录本次追加。沿用 00017 的 UPDATE 变更追踪；Down 仅撤销本次追加且之后未被独立修改的权限，不撤销迁移后新增组或重新授予的权限，不删除统计及短链数据。

## 2. 文件契约

文件名 `moeurl-statistics-{slug}-{startDate}-{endDate}.csv`，来自规范短码和实际范围。CSV 首行为固定字段 `section,key,value,visit_count`，UTF-8 BOM，CRLF 行结束，规范转义引号、逗号和换行。顺序固定：metadata、summary、trend、referrer、device、country。

| section | key | value | visit_count |
| --- | --- | --- | --- |
| metadata | short_link | 公开短链 URL | 空 |
| metadata | start_date／end_date／time_zone | 实际日期／UTC | 空 |
| summary | range_visit_count／lifetime_visit_count／today_visit_count | 空 | 对应数量 |
| summary | last_visited_at | UTC RFC3339Nano 或空 | 空 |
| trend | date | UTC YYYY-MM-DD | 当天数量 |
| referrer | host | 已归一化来源主机名或已有桶标识 | 数量 |
| device | type | 已有设备分类或桶标识 | 数量 |
| country | code | 已有国家代码或桶标识 | 数量 |

维度保持现有 top 10 与 other 聚合，不导出原始事件。标题、标签、完整目标地址、用户信息、密码及授权信息不进入文件。summary 的 today 与 lifetime 不属于所选区间，字段名明确区分。空维度不造行，连续零访问趋势保留零值。

动态文本单元格以单引号中和公式：开头为 `=`、`+`、`-`、`@`，或跳过 Unicode 前导空白后为这些符号，或以制表／回车／换行开头时加单引号；数量列保持十进制数字。防护不依赖 CSV 引号，测试用标准 CSV reader 检查真实单元格。

## 3. 前端与生命周期

分析页标题区提供导出 CSV 按钮与说明，沿用 Vuetify、Toast 和既有响应式样式。只在已确认非 guest 身份且有导出与对应读取权限时显示；无有效统计、查询加载／重取／失败、导出处理中禁用。未应用自定义日期草稿不影响导出，点击时固定当前响应的实际 startDate／endDate，再请求对应 export 端点，避免跨 UTC 午夜改变相对范围。

API 使用严格 Zod 校验固定 MIME、文件名与内容，拒绝无效 envelope 数据。通过 Blob 与 object URL 保存文件，最终释放资源和临时 anchor；失败友好提示并允许主动重试，无自动重复写入／请求。下载响应返回时同时核对短链 ID、own/admin 上下文、已应用范围、组件存活和当前用户 ID／登录轮次；变化后不下载也不 toast。成功提示只表示浏览器已发起保存，不声称写盘成功。下载不改变日期、图表或统计事件。

## 4. 验证

后端先失败后实现：CSV reader 检查 BOM／转义／注入／空值／顺序；真实数据库比较导出与 statistics、归属、动态权限、管理员额外权限、缺失短链、无访问与范围；HTTP 检查严格参数、envelope、错误、no-store 和独立 Port 接入。migration 往返覆盖原有授权保留、本次追加撤销、迁移后重授及新增组保留。权限 fixture 与 SQLC 均通过锁定生成入口验证零漂移。

前端验证严格 API、下载释放／异常、加载失败禁止下载、实际范围参数、重复操作、所有迟到隔离和中英文。真实浏览器在隔离数据库创建自己的账号和短链、生成访问，下载并读取 CSV，校对实际统计；覆盖个人／管理与移动布局，独立清理。最后完整本地门禁与整个分支独立审查，目标 CI／Docker／PostgreSQL 18／生产证据分别记录。
