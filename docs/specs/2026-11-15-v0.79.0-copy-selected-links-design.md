# v0.79.0 复制所选短链设计

## 交互与范围

沿用 Vue／Vuetify／TanStack Query 和当前页选择状态，在批量工具栏加入复制入口及说明：“仅当前页所选项，每行一个公开短链地址。”／“Selected items on this page only, one public short link per line.”。按钮文案“复制所选短链”／“Copy selected links”；成功反馈包含实际条数。原标题区整页复制、单条复制及 CSV 导出保持各自含义。工具栏换行，不增加手机横向溢出。

`useShortLinkAccess.canSelect` 改为 `canRead`。保留 canUpdate/canDelete/canTag 和所有提交时实时权限判断。只读本人可选择、复制而不能写入；管理员仍需 admin:access/read_all，真实浏览器不能通过移除受保护权限构造非法管理员。管理员只读 cache 边界用真实权限 hook 单元验证。

仅当前成功、idle、未 invalidated 的真实 query cache 可用。页本身 1–100 条，选择 1–100 个非空唯一 ID，全部且唯一存在于该页；缺失、重复和未知 ID 整体拒绝，不取交集。按页面顺序筛选被选中的公开 `url`，保持原地址，LF 分行无尾随换行；只校验并复制这些 URL，不读 targetUrl 或备注。选择不跨页；过滤／分页／身份守卫及父级写入／编辑／确认／导出／创建锁保持。

## 复用与并发

扩展现有 `PageLinksCopyOptions`：可选 `selection?: Readonly<Ref<readonly string[]>>`，无此参数仍复制整页；可选 `lock?: Ref<symbol | null>` 供同页两实例共享。返回值保持 visible/disabled/pending/copy。按钮加可选 `mode?: 'page' | 'selected'`，默认 page，使用独立 testid 与本地化键；工具栏增加 copy slot，两父页接入所选实例。

每实例有独立 owner symbol、generation 和 pending；lock 非空时禁用其他复制。开始复制先占有 lock，只有 owner 能释放；retire 递增 generation、清自己 pending 并释放自己持有的锁，不能释放另一实例持有的锁。选择使用 deep、sync watch，A→B→A 同 tick 也退休。已存在的 query/auth cache 订阅、context/key/identity/blocked 守卫沿用。父级不把自身 pending 回接 blocked；lock 不触发自身退休，避免自锁、自退休和互相引用未初始化实例。

Clipboard writeText 必须在直接点击栈、首个 await 前调用。回调再核 generation、存活、身份、实时授权、当前 key/data 与 lock 所有权；旧 success/error 不 toast，旧 finally 不清新 pending 或释放新 owner。不支持、同步抛错和受控 reject 使用同一失败文案，不泄露异常正文。浏览器已接受的数据不能撤销，不承诺撤回；不自动重试、不写 storage、不调用 execCommand。
