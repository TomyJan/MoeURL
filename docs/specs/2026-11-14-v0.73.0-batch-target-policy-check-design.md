# 有界批量目标规则检查设计

依据[范围](../product/scope-v0.73.0.md)。以下数值与接口由 Agent 在既有架构和无人值守授权下决定，不冒作用户逐项批准。

## 输入与输出

POST `/api/v1/admin/system/target-policy/check-batch`，application/json，禁止 query。顶层恰含大小写精确的 targetUrls 数组，拒绝重复／转义重复键、未知字段、null、非字符串元素、尾随值／垃圾和非对象。读取最多 262145 bytes，超过 262144 则拒绝。解码前验证 UTF-8 和既有 Unicode escape 配对；数组 1–20 项，每项复用单目标 validPolicyCheckInput 的 1–2048 UTF-8 bytes／无控制字符约束。原值不改写，重复项保留。

成功 data 为 `{"items":[{"index":1,"outcome":"allowed"}]}`，每项 index 恰为其 1 起始输入位置；outcome 三字面量与单目标相同。错误：HTTP200／900227／Invalid batch target policy check；授权 HTTP200／120001；基础设施 HTTP500／900000。全部 no-store，错误 data=null。只记录固定事件与 request ID，不记录目标、命中规则或原错误。

## 后端边界

shortlink 新独立 TargetPolicyBatchCheckPort，方法 `BatchCheckTargetPolicy(ctx, actor, TargetPolicyBatchCheckInput) (TargetPolicyBatchCheckResult, error)`；Input.TargetURLs，Result.Items，Item.Index/Outcome。保持旧 Port 和单目标 service/handler 接口不变。

五秒 ReadCommitted／ReadOnly 事务先 LockTargets，再 AuthorizeAdminCheck，随后基础 validateTargetURL 分类；授权前不产生结果。至少一项基础合法时，调用 targetpolicy.CheckTargetsIndividually(ctx, q, validTargets)。该函数一次加载七份已保存资源、全部严格验证，再复用原有匹配函数逐项返回 nil／ErrInvalidTarget／ErrTargetDenied；任何其他错误整批失败。原 CheckTargets 共用同一个私有 savedTargetPolicies 快照加载及 check 方法，保持四拒绝先于三允许并集，旧多目标全部通过语义不变。

同一 shared gate 在整个事务持有，七规则保存只能持 exclusive gate，因此七次读取和全部判定期间规则不会变化。ReadCommitted 在等待保存提交后重新读取，不能用开始等待前的旧 snapshot；授权仅代表查询时点，不声称阻止事务结束后撤权。全基础非法时不读七规则，与旧接口一致。结果全有或全无，不创建链接、审计、配额或回执，无 DNS/HTTP。无 migration／SQLC 输入／依赖变化。

## 前端边界

entities/target-policy-batch-check/api.ts 复用原单项 schema，strict 请求／响应。items.length 必须等于本请求数组长度，index 必须逐位为 i+1；任何多字段、漏项、乱序、重复序号或非法 outcome 均失败，不能显示允许。无 query cache／Pinia／URL／storage 持久化。

features/target-policy-batch-check 提供独立卡片和 useTargetPolicyBatchCheck。textarea 用 CRLF/LF 分行，保留原行空白，单独 CR 仍是非法控制字符；包括末尾空行在内都报错。输入上限 20 行，每行采用同一字节／Unicode 规则。按钮显式发送，不自动重试。每次编辑递增 revision、清结果及反馈，并允许新请求；generation、revision、sequence 三令牌及活跃标记保护所有异步分支。切号、同号重登、相关权限改变和卸载同步清私有草稿／结果／loading；无权不发送。当前授权错误才触发既有授权刷新，迟到错误不能刷新新身份。

中英说明仅使用已保存规则，不包含其他卡片草稿，不检查配额、短码或可达性。结果用行号和状态文字，无 URL 回显。手机 20 行时内容正常流动、结果换行，按钮能用键盘和触摸到达。保留旧单目标卡片，不增加公开路由。
