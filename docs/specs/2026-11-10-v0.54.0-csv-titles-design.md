# v0.54.0 CSV 标题导入设计

## 意图与选择

批量导入时保留每个网址对应的标题，免去逐条补填。沿用 Vue／Vuetify、TanStack Query、zod、Go／PostgreSQL／SQLC，不安装依赖。

ROOT 选择独立双列 API，而非放宽旧 strict DTO：旧客户端、旧摘要及既有回执均不变。两个 API 共享事务核心，避免复制锁序、审计和幂等代码。暂不做任意字段映射或导出恢复；CSV 标题原样预览，服务端按既有 metadata 规则归一化。

## CSV 与草稿

- 固定表头只接受 `target_url` 或 `target_url,title`，大小写及顺序精确；可有一个开头 BOM。所有数据行列数必须与表头一致。
- 保留 65536 bytes、1–20 条、LF／CRLF、引号及双引号转义规则。裸 CR、空记录、重复 URL、非法 UTF-8、额外列、缺少列、无记录均整体拒绝；末尾一个换行不是空记录。
- URL 沿用 printable ASCII、1–2048、HTTP(S) 校验。标题沿用 Go `TrimSpace` 后最多 120 Unicode 码点、禁止控制字符；空标题合法。双列无论标题是否为空都需要元数据权限。quoted 逗号、双引号及 Unicode 合法；含换行的标题按控制字符规则拒绝。
- 旧单列仍填入逐行输入框。双列导入进入只读结构化草稿，显示每个 URL 和标题，隐藏逐行输入框，防止 `join('\n')` 丢标题。允许换文件；“清除导入，改用逐行输入”明确清空整批后返回手工输入。预览显示同一有序列表，不解析 HTML。
- 文件读取前后使用原 generation、账号 epoch、fileSequence、draftRevision 守卫。失败或迟到读取不覆盖已有草稿。预览冻结 UUID、模式和全部字段。pending／unknown 期间禁止改草稿；unknown 只能以同账号、同端点、同 UUID、同内容显式重试，不自动写入。
- 双列文件在无元数据权限时整体拒绝并提示，不悄悄降级单列。导入／预览／提交和 auth cache 更新均复核；撤权时清空带标题的草稿及快照。

## 新协议与事务

`POST /api/v1/short-link/batch-create-with-titles`，strict JSON：

```json
{"requestId":"11111111-1111-4111-8111-111111111111","items":[{"targetUrl":"https://example.com","title":"示例"}]}
```

恰有 `requestId` 和 `items`；每项恰有字符串 `targetUrl` 和 `title`，拒绝重复键、未知键、null、缺字段、尾随 JSON。UTF-8 JSON body 最大 64 KiB。UUID、URL、20 项及 expected-user header 沿用旧规则。响应仍为 `{requestId,createdCount}`，业务码沿用既有 invalid request、invalid metadata、permission、conflict 等映射；基础设施或无法确认成功的响应仍为 unknown。

新摘要为 SHA-256(`moeurl:bulk-create:titles:v1:` + Go JSON 编码的原始有序 items)。摘要包含原始标题，空白变化也被视为不同内容；持久化时才按既有 metadata 规则 trim。旧摘要字节不变；两端点共享 actor/requestId 回执键，因此跨协议重用 UUID 必须 conflict，不创建第二批。

共享核心沿用 5 秒事务及 domain creation gate → actor row → actor group 锁序。从当前数据库读取 active／未删除、非 guest、create＋default-domain 权限；新模式额外核 `short_link:set_metadata` 并对每项调用既有 metadata normalizer，随后才读回执。包括 replay 在内，撤权均拒绝。命中同内容回执仍不重选已停用域名；未命中才选默认域名并创建全部链接、逐条既有审计和回执。任一失败回滚全部三类记录。

SQLC 只给现有批量 insert 增加 title 参数，旧模式传空字符串；tags 仍空，其他创建设置不变。通过锁定 SQLC 1.30.0 标准入口生成并核零漂移，不手改生成物，不需要迁移。
