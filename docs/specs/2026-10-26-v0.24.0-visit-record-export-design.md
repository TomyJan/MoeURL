# v0.24.0 匿名访问记录导出设计

## 1. 意图与取舍

在既有单短链分析的访问记录区域提供离线分析文件，补足原详细统计的导出规划。选择单链、有界、同步、服务端当前快照；浏览器拼接分页会产生漏行／重复与陈旧授权，后台无限导出需要额外任务和存储模型，因此不采用。沿用既有技术栈，无新依赖、采集、全局入口或外部服务。以下数值、格式和工程取舍由 Agent 自主决定，不写成用户逐项批准。

## 2. API 与授权

新增 `GET /api/v1/short-link/visits/export` 和 `GET /api/v1/admin/short-link/visits/export`。输入仅 `id`、`days` 或成对 `startDate`／`endDate`、可选 `deviceType`／`countryCode`；沿用访问记录的规范非零 UUID、默认 7 天、7／30／90 天预设、最多 90 个 UTC 日、设备枚举和两位大写国家代码／unknown。重复、未知、显式空值、非法转义、未来／反向／混合日期均拒绝。`cursor`、`pageSize` 及客户端指定的 limit、owner、字段选择一律拒绝。

新可配置权限为 `short_link:export_visits`，属于 `short_link_basic`。个人要求它与 `short_link:read_visits`、`short_link:read_own`，且链接当前属于自己；管理要求它与 `short_link:read_visits`、`admin:access`、`short_link:read_all`。复用 insights 的 `read` 与数据库 Resolver，在一个带 5 秒期限的只读 repeatable-read 事务中重读 active／未删除／非 guest 账号、当前组授权、数据库时间和未删除链接。权限与归属以该次一致快照为准，不锁住权限编辑或链接移交；在快照前已提交的撤权／移交必须生效，在快照开始后的变更不将一份文件拆成多个授权时刻。客户端权限只用于入口与迟到结果保护。

成功沿用 JSON 下载描述 `{fileName,contentType,content}` 和既有业务 envelope，MIME 固定 `text/csv;charset=utf-8`。文件名固定为 `moeurl-visits-{id}-{startDate}-{endDate}.csv`，日期取数据库实际解析范围，不拼用户提供的任意文本。错误为 `100001` 非法输入、`120001` 无权、`200104` 缺失／软删／个人归属不符、`200120` 导出容量超限；基础设施为 HTTP 500／`900000`。所有响应 no-store，日志不含 SQL、SQLSTATE、CSV、来源主机、完整查询或秘密，只记录 request_id、安全错误类别与类型。

## 3. 查询与资源边界

复用 `short_link_event` 和既有 `(short_link_id,event_type,created_at,id)` 查询路径；仅 `redirect_response_sent`，按 `(created_at DESC,id DESC)` 稳定排序，使用与访问记录相同的半开 UTC 时间和设备／国家过滤。不执行全量 count、offset、逐页浏览器请求或 N+1 查询。

单次最多 1000 行，候选最多扫描／保存 1001 条匹配记录的 ID、排序和文本长度元数据。原始 referrer_host、device_type、browser_family、os_family、country_code 的 `octet_length` 先转 bigint 再求和，累计超过 8 MiB 或行数超过 1000 时只返回 limit 哨兵，不将完整文本拉入 Go。候选 MATERIALIZED 且文本回读仅在预算通过后进行；授权／链接预检和查询都位于同一 repeatable-read 快照，按候选 ID 回读不会混入后写数据。已有索引足以支持单链有界范围，不新增事件表、字段或索引。

CSV 写入另有精确 UTF-8 8 MiB 上限，包含 BOM、表头、CRLF 和转义扩张；超限整份拒绝，禁止返回部分成功文件。读取预算与文件预算独立，不能因转义后变小而绕过读取预算。空结果返回只有 BOM 与表头的合法文件。数据库／事务／编码取消或失败不能返回已生成的部分内容，读取和文件生成不写访问量、授权、业务版本或操作审计。

## 4. CSV 契约与隐私

固定表头：

```text
short_link_id,start_date,end_date,time_zone,event_id,occurred_at,referrer_host,device_type,browser_family,os_family,country_code
```

每行重复单链 ID、实际起止日期、`UTC`，随后为已有匿名事件 ID、UTC `RFC3339Nano` 时间和五类已有维度。NULL／空维度输出空单元格，非空分类值保持原有机器值，不将本地化“未知”写入数据。CSV 不返回短链完整目标、标题／标签、owner、用户名、原始 IP、原始 UA、完整 Referer 或任何令牌，不新增持久访客标识；事件 ID 与当前访问记录接口一致，不是访客标识。

使用标准 `encoding/csv`，`UseCRLF=true` 和 UTF-8 BOM。每个文本单元格独立执行既有公式安全策略：原值以 tab／CR／LF 开头，或去除 Go Unicode 空白后的首字符为 `= + - @` 时，在原值前加单引号；标准 CSV quoting 不代替公式中和。保留普通逗号、双引号、Unicode 和完整时间精度。浏览器复用已有 `downloadCsv` 的 Blob／临时 anchor／object URL 清理，不创建服务器临时文件。

## 5. 权限迁移

`00023_visit_export_permission.sql` 只给内置 user／admin 追加缺失的导出权限，guest 不变；权限本来齐全时不改变 updated_at。跟踪本次迁移追加的组及该权限后续 UPDATE 修订，Down 只撤销本迁移追加且未独立编辑的授权。保留迁移前已有、迁移后新增用户组及迁移后移除再重新授予的权限；不跟踪 INSERT，也不删除访问事件。Down 的跟踪清理与撤销在同一 Goose 事务中完成。

更新 Go 常量、默认组、目录／standard 预设、两种语言与权限类型；权限 fixture 只能经 `go run ./scripts/permission-catalog-fixture.go` 生成，SQLC 固定 1.30.0 标准生成并验证二次零漂移。不得改历史 migration 来实现本次授权。

## 6. 控制台与异步边界

在 `VisitRecordsPanel` 标题区域增加标准 Vuetify“导出访问记录 CSV”按钮及 1000 条／8 MiB 边界说明，保留现有样式与手机布局。权限交集满足才展示。仅当当前记录查询成功且不在刷新、记录 ID／上下文和已应用日期／设备／国家一致、国家草稿已应用且无校验错误时可用；空结果也可导出。固定使用已加载记录响应的实际 startDate／endDate 和已应用筛选，永不发送游标或 pageSize，文件覆盖完整筛选结果而非当前页。

浏览器继续校验规范 ID、严格日历日期、顺序和包含首尾最多 90 天；是否未来日由服务端数据库 UTC 时间决定。浏览器时钟落后或跨 UTC 午夜不能否定服务器已成功返回的实际范围，真正无效的范围仍处理服务端 100001，不触发下载。

导出 pending 防止重复点击，不禁用正常筛选或分页；这些变化使原请求上下文失效。保存固定 ID、上下文、实际日期、过滤、挂载实例和账号轮次；切换后再返回、卸载重建、同账号退出再登录或同步撤权时，迟到结果不得下载、toast 或覆盖新页面状态。请求结束前后都检查当前 cache 授权，不能只依赖上次渲染。变更和回到相同字符串仍算不同轮次，父查询 pending／error／刷新变化也使旧下载失效。

普通网络／基础设施失败显示双语 Toast 并保留筛选；200120 明确要求缩小日期或过滤，不截断。当前身份收到 120001／401／403 时清除已被服务端否定的旧授权再重读 auth/me，旧身份迟到的拒绝不动新账号；200104 触发当前访问记录重读，禁止凭旧成功缓存重复下载已不可见资源。文件响应严格校验固定 filename、MIME、BOM／表头和实际 UTF-8 字节上限，非法响应不触发浏览器下载。下载准备或浏览器保存失败也应清理临时对象并显示可重试错误。

已确认属于当前身份的拒绝所触发的 auth/me 读取由身份轮次与 cache 写入代次管理；它可以在清空权限导致父分析页卸载按钮后恢复同身份仍有效的读取授权。授权 cache 的订阅持续到读取结束，较新同账号授权、相同空数组写入、cache 移除或身份切换均使旧读取失效，结束后释放订阅。此全局授权恢复与组件导出结果分开：旧导出请求的下载、Toast 和页面局部操作仍严格服从挂载与上下文生命周期，不因授权恢复而重新执行。

控制台 Shell 在这次仍有效的授权重读 pending 期间暂缓权限不足引发的自动跳转；页面仍真实显示拒绝、卸载记录区且不保留旧 grants。读取完成、失败、较新 cache 写入或身份失效后恢复正常路由拒绝处理；guest／登录错误不受此等待影响。用户已主动离开的路由不自动返回。授权回填先让查询观察者处理新 grants，再结束 pending，避免 Shell 以旧空授权抢先跳转。

## 7. 验证与交付边界

真实 PostgreSQL 覆盖两种作用域、缺少每项权限、guest／无效／停用／软删账号、越权／移交／删除、固定范围和 unknown 过滤、并列时间排序、分页之外的完整结果、0／1000／1001、读取与 CSV 字节边界、公式注入及文本转义、快照期间新增／撤权的一致语义、数据库故障／取消及无副作用。HTTP 覆盖严格参数、JSON／no-store、业务码及安全日志。migration 覆盖 Up／Down／再 Up、先有授权不变、迁移后独立授予保留和默认权限一致。

前端先写行为测试，覆盖严格请求／响应、实际应用范围、非第一页仍导出全范围、未应用草稿、空结果、pending、scope 往返与迟到／同步 cache 撤权、所有错误类别和对象 URL 清理。真实 Compose E2E 使用独立 fixture，通过公开跳转生成成功事件，从个人／管理分析记录区实际下载并核对 CSV、过滤、隐私、权限和手机不溢出；不 mock 产品 API，不依赖跨测试顺序。

保持原业务／前端 100% 门禁，不扩大排除、不写镜像实现的无意义测试。最终执行完整 Go、前端覆盖／静态／隔离构建、SQLC 和权限 fixture 零漂移、完整 Playwright、Linux race／govulncheck、production smoke 与精确镜像扫描；按实际源输入、构建注入、提交、运行时和清理分别留证。实现、本地验证、目标 CI、主分支合并和正式发布分开记录。审计导出、全站访问合并、无限导出、XLSX、后台任务、跨时区和超过 90 天不在本版。
