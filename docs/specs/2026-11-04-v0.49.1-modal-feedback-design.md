# v0.49.1 弹窗通知布局设计

## 意图与现状

v0.49.0 的 M1 原图显示，成功通知在快速重开确认框时遮住标题。共享 AppToasts 将 Toaster 移入弹窗，但 vue-sonner 2.0.9 的 fixed／absolute 定位不为内容留空间。原通知归属测试没有真实几何断言。本版只修共享通知布局，范围见[scope](../product/scope-v0.49.1.md)。

## 选择与约束

执行者依据无人值守授权选择正常流通知区，沿用 Vue 3／Vuetify 4／vue-sonner，不安装依赖。动态标题 offset 无法保证不遮正文和按钮；另起全局区域会越出弹窗的可访问性与焦点边界，因此不采用。

保留一个 Teleport、一个 Toaster、一个 live region。页面使用原 top-right 定位；弹窗内让通知区与 card 共同参与有界 flex 布局，通知列表及各消息占实际空间。只在消息存在时占空间；最长区域初选 30dvh，溢出内部滚动。若真实短视口不能保留标题和安全动作，必须调整布局并更新设计，不能降低验收。

保留业务 dialog 的标题、警告文案、计数和 actions；唯一业务布局修正是 BatchNoteClearDialog 使用 grid-auto-rows:max-content，防止短高视口压缩警告行，不改变业务操作。保留六秒默认持续时间、五条可见通知、单独关闭、安全文本与中英主题。移动归属不重建消息、不清队列、不延长持续时间、不重播通知；退出后不保留通知内容高度。F1 自定义 flex/grid 空 wrapper 仍贡献 14／16px 结构 gap，明确延期，不宣称所有容器零空白。

## 活动层与焦点

只选已连接、活动且未隐藏的弹窗，排除 moe-overlay-leave-active 退出层；比较实际外层 overlay 的有效 z-index，同层才按 DOM 顺序。不把 DOM 最后一个误当最高层。nested 关闭回仍活动父层，最后一层关闭回 body。监听必要的节点／class／style／隐藏状态变更，避免自身搬移形成循环；卸载时断开 observer。

Toaster 始终位于当前 modal 的 focus／可访问边界内。迁移不主动聚焦、不挤走安全取消的初始焦点。通知关闭按钮可通过键盘到达；节点真正退出后，若焦点仍在 BODY，恢复当前 modal 安全旧控件，必要时回 modal 本身；用户已移焦则不抢回。消息队列和退出的身份以真实节点／ID 验证。

modal 中的原生 touch pointerdown 在 capture 阶段阻止 Sonner swipe 处理，保留原生滚动，不 preventDefault、不合成 pointerup；同时向原 Toaster DOM 报告 mouseleave，恢复鼠标发布后迁移遗留的 hover 暂停。真实触摸产生 pointercancel 后仍按剩余时长自然退出，不重置六秒。

## 测试与判定

单元层使用真实 Toaster 验证最高活动层、隐藏／断开层排除、nested 回退、同一消息节点与逐条关闭、语言主题、安全文本和空区域。测试替换过慢或外部依赖时必须保持消息生命周期真实；jsdom 不承担几何证明。

浏览器从现有真实业务入口产生成功通知并立即重新打开批量备注确认框：原实现桌面／手机的标题与通知矩形相交，作为真实 RED。修复后每条可见通知与 title、warning、summary、confirm／cancel 不相交，实际控件中心 elementFromPoint 命中。短视口、320px、横屏、200% 缩放、深浅色、reduced-motion、五条中英长消息以及关闭／快速重开覆盖不同布局分支。测试辅助只放测试文件，不新增产品测试路由。独占账号／链接／数据必须 finally 清理并核验。

本地完整前端四项 100%、types／lint／隔离 build，clean 提交完整浏览器、逐张原图、精确产品和一次最强 supported 独立终审；最新候选及 master 各自九 CI／完整日志与真实审查覆盖分别验收。不把旧成功、空 review、ack、skipped 或上传 artifact 冒新证明。200% 仅为 DPR2 与半 CSS 视口的布局等效验证，不声称操作浏览器缩放设置。页面 top-right 通知可能遮住页面鼠标入口的既有边界保留，真实键盘入口用于进入待验 modal，不声称本版解决页面浮层布局。

## 风险与回滚

主要风险是短高度挤压、第三方退出样式与嵌套归属。通过真实几何、点击和焦点测试决定是否成立，不用任意 offset 遮掩。回滚只撤共享通知及相关测试／文档，无数据库、权限或业务写入回滚。
