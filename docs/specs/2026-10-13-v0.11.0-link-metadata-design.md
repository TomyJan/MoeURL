# v0.11.0 短链标题与标签设计

## 数据与校验

`short_link` 新增 `title text not null default ''` 和 `tags text[] not null default '{}'`。标签保留输入顺序，区分大小写；前后 Unicode 空白被裁剪，裁剪后空标签、重复标签、控制字符和超长值拒绝。标题前后 Unicode 空白被裁剪，允许空字符串清除，最多 120 个字符，拒绝控制字符。标签最多 10 个，每个最多 32 个字符。不主动转换大小写、Unicode 规范形式或标点。

数据库对标题长度、标签数量和空元素提供约束；业务校验承担 Unicode 空白、控制字符和重复判断。精确标签过滤使用数组包含运算，增加 GIN 索引。旧数据不扫描公开访问链路、不改变 URL、状态、额度或统计。

## API 与权限

复用既有创建、个人更新和管理员更新端点，新增可选 `metadata: {title: string, tags: string[]}`。省略或 `null` 保留当前元数据，创建时默认为空；传入对象会整体替换，`tags` 必须为数组，空标题与空数组显式清除。先检查既有创建或更新权限，再检查 `short_link:set_metadata`，省略时不要求新权限。管理员全站操作仍须 `admin:access` 和对应全站权限。

管理 ShortLink 响应增加顶层 `title` 和 `tags`，空标签始终序列化为 `[]`；列表、创建、更新、统计中的管理短链结构一致。公开 Preview 和跳转模型不包含这些字段。

个人与管理员列表复用 `q` 并新增 `tag` 查询参数。`q` 是最多 200 个字符的文字子串，匹配短码、目标地址、标题和标签，管理员同时保留现有用户匹配；不把 `%`、`_` 当作通配符。`tag` 裁剪后按大小写敏感的完整标签匹配，最多 32 个字符。关键词、标签、状态取交集；分页列表与计数谓词一致，软删除数据仍排除，个人查询始终限定 owner。

## 事务和回滚

元数据随已有创建或更新在同一语句和事务中写入，拒绝无权限或非法输入时不能发生局部更新。更新省略元数据不得覆盖并发保存的元数据；不增加第二次更新语句。现有短链更新沿用最后写入的语义，不在本版引入新的并发协议。

`00016` 添加字段、索引及默认权限。权限回滚复用 `00015` 的迁移归属与 UPDATE 修订追踪，只撤销本次迁移实际追加且未独立修改的授权，迁移后新授予权限保留。Down 删除标题及标签，属于明确的数据丢失边界；回滚前备份，重新 Up 后字段为空，不伪造恢复数据。

## 前端行为

创建高级选项与设置对话框按权限显示标题和标签字段；标签使用一行一个标签的输入，支持中文与带空格的标签。使用共享 zod 校验和国际化错误文本。设置对话框记录打开时的元数据快照，只有修改时提交对象；后台刷新不覆盖草稿。没有新权限时仍能维护原有访问配置。

个人与全站列表展示纯文本标题及标签，长文本换行或省略，不能产生 HTML。两页提供关键词和标签输入，防抖后更新查询键；失败、空列表、加载状态沿用现有组件。公开页面没有标签入口。

## 验证与交付

- 数据库：新建、约束、筛选与计数一致、权限 Down/Up、迁移后独立授权保留。
- 后端：Unicode 边界、去空白、重复和非法值、权限撤回、跨用户读写、对象省略与清空、公开数据边界、数据库错误路径。
- 前端：创建和保存有效载荷、未修改时省略、撤权、非法输入、列表展示和查询参数；只添加行为测试，不添加源码字符串快照。
- 浏览器：同一独立场景完成创建、编辑、标签筛选及清空；验证个人与管理员列表，并覆盖移动端溢出。
- 运行现有完整 Go、前端覆盖率、静态检查、构建和生成零漂移门禁；缺失环境证据单独记录，不替代 CI 和发布验收。
