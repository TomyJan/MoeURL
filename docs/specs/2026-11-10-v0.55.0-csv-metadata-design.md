# v0.55.0 CSV 标题与标签导入设计

正式基线为 PR291 交付后独立核准的 master `f1431100332587058e8e6f248a4d2cdaa8830185`，分支 `feat/v0.55.0-csv-tags`。ROOT 根据既定无人值守授权自主收敛范围；不把选择记成用户逐项批准。沿用 Go／SQLC／PostgreSQL 和 Vue／Vuetify／zod，无新依赖、权限或迁移。独立准备的原始执行身份保持不变，准确转移合同核验后才用于正式任务。

## 现状与选择

已有单列 target_url、双列 target_url,title 导入，20 条原子创建、权限复核和持久回执。标签仍须创建后逐条或批量设置。路线图尚有多列导入；本增量只增加固定三列，不实现任意映射或完整导出恢复。

选择 target_url,title,tags；tags 单元格使用 JSON 字符串数组，与既有清单导出的 tags 表示一致，避免用逗号／分号／竖线切分导致合法标签内容歧义。JSON [] 表示无标签，空单元格／null／非字符串项整体拒绝。CSV 层正常双引号转义，例如：

```csv
target_url,title,tags
https://example.com,示例,"[""工具"",""a,b""]"
```

允许单／双／三列三种明确模式；保持旧单列 parser 的返回合同。其他表头、顺序或多余列拒绝。不接收导出的 17 列清单，不还原 slug、身份、访问条件、统计、历史或私密备注。

## 输入和权限

沿用 UTF-8、一个开头 BOM、LF／CRLF、严格引号、65536-byte 文件及完整 JSON、1–20 行、唯一 URL、URL 1–2048 printable ASCII。标题按既有 trim 后 120 码点；标签按既有有序且区分大小写、0–10 项，每项 trim 后 1–32 码点，禁止控制字符和归一化后重复。原始标题／标签不提前 trim，预览原文、持久化时才归一化；原始空白及标签顺序必须影响摘要。JSON 不成对 surrogate 在有损解码前拒绝，合法代理对、字面 U+FFFD 及反斜杠文本保留。

三列无论 title 或 tags 是否为空都需要 short_link:set_metadata；单列仍可在没有元数据权限时使用。新协议必须在读取已有回执前重新检查当前数据库权限，包括 replay。身份、权限、迟到文件读取、pending／unknown 守卫沿用既有机制；标签数组及 item 深度冻结，避免 preview 后数组被改。unknown 只允许同账号、同端点、同 UUID、同原文的显式重试。

## 后端合同

新独立 POST /api/v1/short-link/batch-create-with-metadata，strict JSON：恰有 requestId 和 items；每项恰有 targetUrl、title、tags，tags 必须为非 null 字符串数组。旧 titles DTO 和摘要完全不改；旧单列、双列继续拒绝新 tags 字段。

定义 BatchCreateMetadataItem{TargetURL string, Title string, Tags []string} 和 BatchCreateWithMetadataInput{RequestID string, Items []BatchCreateMetadataItem}。摘要 SHA-256("moeurl:bulk-create:metadata:v1:" + Go JSON 原始有序 items)。三个协议共用 actor/requestId 回执键，任意跨协议同 UUID 均 conflict，不创建第二批；旧两种摘要字节不变。

共享同一事务核心，保留 creation gate → actor → group 锁序、5 秒预算、当前权限、默认域名、全部 link／audit／receipt 原子性。核心使用内部 prepared item 的 raw title／tags，显式标记 metadata 是否必需；旧协议依然传空 metadata，不通过放宽旧 wire DTO 复用。SQLC 批量 insert 增加 tags 参数，旧两个入口传非 null 空数组；仅改 queries，通过锁定 SQLC1.30.0 标准生成并两次零漂移，禁止手改生成物。

## 前端用户流程

保持现有双列结构化只读草稿；三列增加逐项标签纯文本 chips／换行布局，无 HTML。导入前完整校验三列与未来请求 byte cap，失败保留现有手工或结构化草稿。三种模式显式区分，preview 冻结模式／端点／UUID／所有原文。换文件或清除导入只在允许编辑时发生，撤权立即清空元数据草稿与快照；迟到 success/error/finally 不影响新草稿。

帮助展示三种格式及标签 JSON 的准确 CSV 引号例子；下载三列模板，旧模板保留，使用同一原生文件下载机制。中英文明确固定格式、20 条、权限及不是导出恢复。无新页面或路由。
