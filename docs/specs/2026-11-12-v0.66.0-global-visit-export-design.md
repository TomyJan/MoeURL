# v0.66.0 全站访问记录导出设计

## 意图与取舍

补齐路线图的全站访问合并导出。沿已有仪表盘的 UTC 日期下载一次服务端快照，比浏览器遍历每条短链或分页合并更易保持权限、排序和容量一致。仅扩展现有 Go／SQLC／Vue／Vuetify 和 CSV 工具，不引入依赖或新页面。以下边界为 Agent 按现有契约作出的决定，不写成用户逐项批准。

## API、授权和迁移

新增 `GET /api/v1/admin/dashboard/visits/export`，仅 `days` 或成对 `startDate`／`endDate`。默认 7 天、预设 7／30／90、最多首尾合计 90 个 UTC 日；未来日以数据库 UTC 为准。重复、空值、未知参数、无效转义、混合日期及反向／不存在日期拒绝。ID、owner、cursor、pageSize、deviceType、countryCode 一律拒绝。

采用独立 `GlobalVisitExportPort` 和 Handler，`Service.ExportGlobalVisits(context.Context, auth.CurrentUser, RangeInput) (VisitExport,error)`，不扩展旧单链端口。复用 `Service.read` 的 5 秒只读 repeatable-read，重查 active、未删、非 guest 账号和数据库权限；要求 `admin:access`、`statistics:read_all`、`statistics:export_visits`、`short_link:read_all`、`short_link:read_visits` 全部存在。客户端组名、权限缓存和传入 owner 不提供授权。快照前提交的撤权必须生效；快照后撤权不把一份文件拆为不同授权时刻。

`statistics:export_visits` 位于 administration，沿 `audit:export` 的受保护 admin 专属模式；默认 admin 新增，user／guest 和三种可配置预设不新增。`00042_global_visit_export_permission.sql` 仅向 builtin admin 追加缺失项、精确推进 updated_at；跟踪迁移追加及权限成员资格后续 UPDATE。Down 只撤回本次追加且未独立改动的授权，保留原有、后新增组及移除后重授予；不清历史事件。权限 fixture 通过现有 Go 生成入口更新，不手改。

所有响应 no-store。成功 `{fileName,contentType,content}`，固定 `moeurl-site-visits-{startDate}-{endDate}.csv` 和 `text/csv;charset=utf-8`。非法输入100001，无权120001，容量200120，基础设施HTTP500／900000；返回稳定安全错误，不记录查询／CSV／来源／秘密，不新增读取审计。

## 查询、格式与资源

`queries/global_visit_export.sql` 中 `ExportGlobalInsightVisits` 使用现有 `short_link_event_success_time_id_idx` 和时间半开区间，只取 `redirect_response_sent`，按 `(created_at DESC,id DESC)` 稳定排序。无需连接当前未删短链，因此已删／转移链接的历史与仪表盘一致；不包含 owner 或目标。

候选 MATERIALIZED，最多 1001 个事件 ID、short_link_id、时间和文本长度元数据。五类可变维度 `octet_length` 先转 bigint 再累计，行数 >1000 或原文 >8388608 字节返回唯一限额哨兵，不回读文本。预算通过才按候选 ID 回读正文，保持同快照；不执行 count 全表、offset、N+1 或浏览器分页。不新建索引；查询期限和取消仍生效。

最终文件使用现有 `csvExportBuffer` 的独立 8388608 字节上限。固定表头：

```text
short_link_id,start_date,end_date,time_zone,event_id,occurred_at,referrer_host,device_type,browser_family,os_family,country_code
```

逐行使用事件真实短链 ID，不复用某个请求 ID。日期为数据库解析的实际范围，time_zone为UTC，时间RFC3339Nano；维度空值为空。标准 encoding/csv、UseCRLF、UTF-8 BOM、逐格 `csvExportText` 公式中和。超限或取消整份丢弃；不返回目标、标题／标签、账号、原始IP／UA／完整Referer或令牌，不写服务器临时文件。

## 仪表盘与异步边界

扩展现有 `VisitExportButton`／严格 entity 的上下文为 `site`，内部明确 site 标识且不发 ID；own／admin 的规范 UUID、筛选和文件名原规则不变。site 使用上述五权限交集和专用双语按钮／描述。只向全站 endpoint 发送当前 dashboard 成功响应的实际日期，不发缓存汇总或 topLinks。

按钮在标题区，桌面与手机保持既有布局和正常换行；说明最多1000条／8MiB、包括已删链接历史。dashboard query pending／fetching／error／denied或无实际range时阻止下载。日期选择的同步 readRevision、实际range、blocked、权限cache及账号identity纳入现有失效轮次；变更后又回原值仍失效。pending防重复，但允许改变日期；卸载、同账号重登录、换人、同步撤权／再授予后的旧成功或失败都不得下载、toast或影响新页面。当前拒绝复用 `useAuthorizationRefresh` 的cache代次与Shell协调；下载仍走既有Blob／anchor／URL清理。
