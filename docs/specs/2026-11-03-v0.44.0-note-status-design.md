# v0.44.0 备注状态筛选设计

## 意图与选择

在已有私有备注之上提供不接收敏感搜索词的有界整理能力。继续 Go／Chi／SQLC／PostgreSQL 与 Vue／Vuetify／TanStack Query；无新依赖。三态、只读权限、现有布局和不扩展 CSV 的取舍由执行者决定，不冒作用户逐项批准。范围见 [scope](../product/scope-v0.44.0.md)。

## HTTP 与存储语义

本人和全站的现有 GET 列表及 GET 清单导出接受可选 `noteStatus`。精确值为 `'' | present | absent`；省略或空串不限制，present 为 `note <> ''`，absent 为 `note = ''`。数据库列非空，不重新归一化；BOM 为合法非空。大小写、空白、未知值、重复新键、缺等号和坏编码返回 HTTP200／100001。合法旧参数和分页语义保留，导出继续拒绝未知键。

Count／List／Export 同一谓词，与 status／q／tag 取交集。软删排除，排序不变，total 在分页前计算；导出先过滤，再检查原 1000 条及 8 MiB 总预算，超限整份拒绝。默认旧客户端结果及原 17 列不变。q 不匹配备注正文；不增加备注正文、版本、布尔标记到主列表、CSV、统计或公开响应，不记录正文和新敏感日志。

## 当前授权和一致性

本人使用当前有效账号、当前组 read_own 与 owner；全站使用当前 admin:access＋read_all；导出另需 export。仅备注写权限缺失不妨碍筛选。匿名、guest、禁用或失去读取权限的账号不得借旧 actor.GroupKey 获取状态。

非空筛选路径在最多五秒的只读 repeatable-read 事务内，先用 SQLC 查询数据库当前有效账号和组权限，再在同一 snapshot 计算 Count／List。此路径不能只信任 resolver 的旧组快照；未筛选路径保留现有语义。授权查询只回布尔值，不取正文。取消／DB 失败都结束并回滚只读事务，不写审计。导出已有单 SELECT grant_snapshot，只加相同 WHERE 条件。

SQLC 只通过仓库锁定 1.30.0 标准生成，两次全集零漂移；不手改生成物，不改 schema、索引、备注 CAS 或旧 metadata 的响应和版本。

## 前端状态

两页增加“备注状态／全部／有备注／无备注”和“Note status／All／With note／Without note”。类型为 `ShortLinkNoteStatus = '' | 'present' | 'absent'`，默认不发送该参数。

在原 query key 末尾追加状态，保留既有账号和 epoch 索引；状态进入 batch filters、备注退休监听和 export 捕获。有效切换清选择，不显示上一筛选缓存。保存或其他互斥操作期间禁用选择器；update 事件同时重查实时互斥条件，拒绝 queued 事件。

导出请求只捕获已应用 status／debounced q／tag／noteStatus；切换后旧下载、错误和 finally 不恢复新状态。账号、权限、资源和操作代际守卫保留。确认当前 save／clear 后失效当前列表；未知保存不重试写入，显式 reload 核实后刷新匹配集合。只读账号可筛选和查看，无编辑假入口。
