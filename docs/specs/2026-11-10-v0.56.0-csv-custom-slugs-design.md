# v0.56.0 四列 CSV 自定义短码设计

ROOT 根据持续无人值守授权自行选择此增量，不写成用户逐项批准。PR293 已完整交付，正式基线 master `cc7d03760b1d7ca78943593fe754f68ad056fad5`，分支 `feat/v0.56.0-csv-custom-slugs`。原独立准备基于 2800df63，与 PR293 squash 同树；实际运行仍归属于其准备输入，不冒正式提交重跑。

## 目标与取舍

已有单列网址、双列标题和三列 JSON 标签导入；自定义短码目前只能单条创建。路线图列有多列导入，本增量只增加固定四列 target_url,title,tags,custom_slug，让有权限的用户批量创建可读地址。备选任意字段映射及17列导出恢复需要更多访问条件、身份和历史语义，继续排除；只补模板则不能解决批量指定地址需求。

## 协议与权限

- 保留原三种严格协议、摘要和客户端合同。新增独立 POST /api/v1/short-link/batch-create-with-custom-slugs；外层恰为 requestId/items，每项恰为 targetUrl/title/tags/customSlug，四个字段必需，customSlug 为字符串，空字符串代表随机。
- 固定 UTF-8 四列，原 BOM/LF/CRLF/严格引号，1–20唯一网址、文件与完整请求各65536bytes。title/tags沿用原始文本与归一化规则。customSlug 非空按原v0.12的ASCII3–32字符后小写，不trim；禁保留字、归一化重复短码，[]标签合法。CSV表头不改变现有返回模式，新增custom-slugs模式。
- 整个四列协议明确要求 short_link:create、domain:use_default、short_link:set_metadata 和 short_link:custom_slug，即使某行或全部customSlug为空；不具自定义权限者仍可使用原三列。事务内重查账号/组/全部权限，先于回执重放，撤权或换账号不得续用旧快照。
- 摘要SHA256("moeurl:bulk-create:custom-slugs:v1:"+Go JSON原始有序items)。大小写、原始title/tags和行序变化均改变摘要，四协议共享actor/requestId回执键，跨协议重用编号始终冲突。

## 事务与错误

复用creation gate→actor→group锁序和5秒预算、默认域名、全部links/audits/receipt同事务。SQLC既有CreateBulkShortLink已经有Slug参数，无query/schema/生成物变化。内部prepared item新增归一化后CustomSlug，旧协议传空；显式协议模式用于追加权限，不能靠非空字符串推断是否需要该权限。

指定短码只尝试一次，SQLC无行表示全局唯一冲突，返回200101，不回退随机或泄漏占用者；软删除继续占用。预先拒绝批内归一化重复短码；格式错100001、保留字200102、无权120001、回执冲突200120。批内随机行跳过本批全部指定短码，避免顺序相关的随机抢占；真实数据库唯一约束裁决并发。
