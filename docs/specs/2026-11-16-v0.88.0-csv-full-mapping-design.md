# v0.88.0 自定义 CSV 完整字段映射设计

## 目的与取舍

自定义 CSV 当前只允许选网址、标题和标签。用户从其他表格导入短链设置时，仍须手工调整短码、方式、过期、访问上限或倒计时列。本版在现有显式映射流程中补齐这五个字段，复用原 parser schema、八种 API、权限校验和冻结重试；不猜别名，不新建服务或依赖。

## 输入和解析

沿用 `inspectBulkCreateCsvMapping` 与 `parseBulkCreateMappedCsv`。映射参数为 `target` 必选以及 `title`、`tags`、`customSlug`、`redirectMode`、`expiresAt`、`maxVisits`、`intermediateDelaySeconds` 可选列索引。所有非空索引必须为合法整数、范围内且互异；只接受真实 1–8 列、1–20 条数据行和矩形表。scanner 的 UTF-8、单 BOM、CSV 65536 字节和引号规则不变。

按字段等级 `target_url,title,tags,custom_slug,redirect_mode,expires_at,max_visits,intermediate_delay_seconds` 的最高映射决定现有协议。缺失的前置字段用原缺省补齐（标签 `[]`，其他空字符串）；字段被选中后其空或非法值仍交原 schema，不回退到较低协议。保留原行宽校验和逐字值，不做 trim、别名识别或重新序列化 CSV。

映射入口投影成标准记录后直接交共享的“已扫描记录解析”路径，避免第二套八协议分发、重新编码原 CSV 或重复维护 schema。标准入口继续用原 scanner 和诊断顺序。最终完整 wire JSON（真实请求 UUID 长度、键名、转义均计入）不得超过 65536 字节，且在替换草稿前完成校验。

## 权限、身份和失败

协议为 `titles` 或更高时，仍要求 `short_link:set_metadata`，即便所选标题／标签值为空；协议为 `custom-slugs` 或更高时仍要求 `short_link:custom_slug`，即便短码为空。跳转方式仅按非空实际值检查 `short_link:use_intermediate` 或 `short_link:use_confirmation`；非空过期和访问上限分别检查现有 `short_link:set_expiration` 与 `short_link:set_max_visits`。非空倒计时必须配有明确的 `intermediate` 方式。现有后端仍为最终授权方。

复用原 `File` 读取序号、身份 generation、草稿 revision 和各权限 epoch。映射暂存捕获本次文件的全部相关 epoch；选择、应用及迟到 success/error/finally 均须匹配当前身份和读取轮次。撤权后再恢复不得复活旧映射；未选值字段不应因无关权限变化而清除 direct-only 数据。失败或取消不替换已有草稿、不发请求。成功应用只替换一次并沿用结构化数据深冻结；结果未知时只允许原账号头、原 UUID、原 payload 的既有重试。

## 界面和隐私

保留网址、标题、标签三个已有映射选择；高级区域新增短码、跳转方式、过期时间、最大访问次数和中间页倒计时。每项均可不选，字段标签和选择器复用既有 Vuetify 与 i18n 模式；不自动匹配相似名称。无基础创建权限时保持原行为；结构化高级选项不可用时提供对应权限说明。方式、过期、上限和倒计时的值权限按实际选中数据意图在应用前校验，避免要求无关值权限。

列名称仅作纯文本显示，不显示单元格样例、未选数据、完整原始文件或 HTML。错误使用既有安全通用文案；同一无效操作再次发生时仍聚焦错误区域。中英帮助明确所有字段均显式选择、未选字段被忽略而不是迁移、权限与缺省规则；补充标签 JSON 字符串数组的英文提示。390px 手机上高级字段、展开/收起、应用、取消和错误区均可达。

## 验收设计

先增加真实行为 RED：传入一个新增合法映射索引时，旧 parser 不能返回预期协议。再实现共享记录解析及最小映射扩展。测试覆盖八种协议、128 个标准字段子集、重复/分数/非数值/越界索引、重复空表头、矩形行宽、未选秘密字段、非法已选值、UTF-8／BOM、CSV 与完整 wire 字节边界、所有缺省和原返回值回归。

hook 测试覆盖实际 File→parser→现有 HTTP、结构权限和非空值权限、所有相关撤权／恢复、换号／新文件／取消、迟到异步、保留旧草稿以及未知结果完全相同请求重试。组件测试覆盖双语、权限提示、字段选择、错误重复聚焦及无泄漏。准确新产品做 smoke／所选扫描及中英桌面、390px 手机浏览器和持久化读回；后端、数据库、权限、依赖、模板输入保持原 hash。
