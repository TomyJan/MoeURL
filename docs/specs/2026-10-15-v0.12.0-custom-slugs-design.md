# v0.12.0 自定义短码设计

## 契约与边界

仅扩展 `POST /api/v1/short-link/create` 的可选 `customSlug`，不增加路由或修改更新请求。省略／null 为随机模式，提供字符串为自定义模式。格式为 `[A-Za-z0-9]{3,32}`，校验原始 ASCII 后转换为小写；空白、控制字符、Unicode 相似字、百分编码和路径分隔符均拒绝。返回沿用既有 `slug` 与 `url`。

示例：`{"targetUrl":"https://example.com/docs","customSlug":"TeamDocs2026"}` 保存为 `teamdocs2026`。`customSlug:""` 返回 `100001`，`customSlug:"LOGIN"` 返回 `200102`，已被占用的 `teamdocs2026` 返回 `200101`，所有业务失败沿用 HTTP 200。错误不透露占用者、目标地址、状态或域名。

## 授权与一致性

`short_link:custom_slug` 属于 `short_link_basic` 可配置权限，user／admin 默认拥有，guest 不开放，standard 包含。省略字段不要求此权限；任何显式自定义值都先检查权限。管理员也必须走能力校验。

创建前进行低成本校验；创建事务继续获取域名创建协调锁，通过 SQLC 的域名／组查询一起复核创建、域名及自定义权限并持有共享行锁到插入完成。权限被撤销时不得凭旧快照写入。数据库全局唯一约束是最终冲突裁决，不执行创建前可用性查询，避免时序漏洞和额外查询。

入口缺少自定义权限返回 `120001`；入口已通过但事务内权限或域名授权发生变化时，沿用既有创建查询的统一不可用错误 `200114`，不写入短链。前端提示刷新可用域名与权限，不自动重试指定地址。

自定义模式只尝试指定值一次，遇 slug 唯一约束返回 `ErrSlugConflict`。随机模式保留随机数生成及至多 8 次重试。不能将其他唯一约束或基础设施错误误报成用户短码冲突。

## 保留路径

继续使用共享保留集合：`api`、`assets`、`icons`、`setup`、`login`、`profile`、`console`、`link`、`links`、`analytics`、`admin`、`go`。部分条目短于自定义最小长度，仍保留在通用路由保护集合中。`sw.js` 和 `manifest.webmanifest` 因格式含点自然不合法。新增固定路由时同步更新保留集合并以真实 Router 行为验证冲突边界。

## 数据库与回滚

复用既有 `short_link.slug text unique`，不改变短码主表或历史值；Goose `00017_custom_slug_permission.sql` 仅添加权限及迁移授权追踪。复用已有权限 migration 的 UPDATE 编辑追踪语义，不追踪迁移后的 INSERT 授权。Down 仅移除本迁移添加且未被后续编辑的授权，不删除短链；旧版读取与访问仍接受这些小写字母数字短码。

SQLC 源查询在创建授权查询中增加自定义权限条件，由标准生成入口更新生成文件。权限 fixture 仍由 `go run ./scripts/permission-catalog-fixture.go` 生成。两者连续生成须零漂移。

## 前端

沿用当前主题与创建面板。高级设置中的可选“自定义短码”输入只对有权限的用户展示；留空省略字段，填写后显示规范化公开 URL，明确地址创建后不能修改。浏览器校验与服务端一致，但后端拥有最终裁决权；前端不复制完整保留字集合，保留路径错误由服务器反馈。

冲突、保留字与无权限错误使用中英友好 Toast；错误后保留目标、域名及其他草稿，仍可修改短码或清空改用随机模式。提交校验失败时自动展开高级设置；权限变化后隐藏输入且省略旧值，不让缓存草稿绕过授权。创建成功后继续创建清空自定义值。

## 验证策略

先增加行为测试并观察失败，再实现。后端使用真实数据库验证并发、跨域名冲突、软删除占用、事务内权限复核及迁移回滚；handler 测试验证稳定错误码。前端测试验证输入规则、规范化、请求省略、冲突保留、重置和权限变化，避免对源码字符串或组件注册清单做镜像断言。

浏览器在独立数据库完成初始化、登录和自定义短码流程，保留本地日常预览数据。运行 Go／前端门禁、生成检查和可执行的 Compose 检查；Docker、目标 CI、外部服务及发布证据分别如实记录，不以本地回退替代。
