# v0.21.0 短链清单导出设计

## 1. 意图与取舍

让个人和管理员可以把已有短链清单带到表格中整理，补足原有导出规划。由 Agent 决定使用同步、有界的服务端导出，复用 Vue／Go、CSV 下载描述和既有列表筛选；不引入依赖、队列、文件存储或新页面。1000 条适合轻量自托管，不将同步请求演变为无限量备份。

## 2. 权限与一致性

新增 `short_link:export`，类别 `short_link_basic`，可配置；user／admin 默认与 standard 预设包含，guest／basic／restricted 不包含。个人还须 `short_link:read_own`；全站还须 `admin:access` 与 `short_link:read_all`。不能用统计导出权限代替清单导出权限。

入口沿用数据库 Resolver 初步授权。SQLC 的一条 SELECT 同时查询授权和数据：授权子查询按当前 actor UUID 关联 app_user／user_group，检查 active、未删除、组非 guest 和所需权限；仅在授权通过时匹配候选。未授权保留一个 allowed=false 的哨兵行，无匹配短链保留 allowed=true、limit_exceeded=false 的空记录行，从而区分拒绝与合法空文件。个人按当前 owner_id 过滤；管理员才允许全站。客户端不能指定 owner_id、权限、limit 或 admin 参数。

一条语句的快照保证授权、归属与数据一致，不逐页读取或分语句 count 后 list，不锁短链或改变版本。查询开始前已完成的撤权、禁用、删除和转移生效；已授权的在途读取不追溯撤销。Service 使用调用方派生的 5 秒超时。SQL 先将最多 1001 条候选的 ID、排序及原始文本字节数元数据放入 MATERIALIZED CTE，不物化目标 URL 等大文本；同一语句内检查条数及累计 8 MiB 读取预算，只有通过后才读取完整字段。原始文本预算按每条记录的 domain.host、slug、target_url、title、每个 tag 元素、status、redirect_mode 和 owner.username 的 UTF-8 字节数累计，求和前转换 bigint。超过 1000 条或读取预算时只返回 allowed=true、limit_exceeded=true 且 ID／文本／tags 均为空的一个哨兵；Service 整体返回 `200118`，不输出部分内容，也不把超限大文本累积进 SQLC 切片。

## 3. API 与文件

新增 `GET /api/v1/short-link/export` 和 `GET /api/v1/admin/short-link/export`。只接受可选 `status`、`q`、`tag`，复用列表的参数名和状态、关键词及标签规范化规则；拒绝未知、重复参数和无等号参数，不接受 page／pageSize。严格参数解析失败返回 `100001`；无权 `120001`；超限 `200118`；基础设施失败 HTTP 500／`900000`，日志只用既有安全分类。

关键词搜索与对应列表一致：个人匹配短码、目标地址、标题和标签；管理员额外匹配所属用户名和昵称。管理员按账号筛出的列表不得在导出时丢失这些结果，个人不增加账号搜索范围。

成功沿用 no-store JSON envelope，data 为 `{fileName, contentType, content}`。文件名分别固定 `moeurl-links-own.csv`、`moeurl-links-all.csv`；MIME `text/csv;charset=utf-8`。空结果输出 BOM 与表头；按 `created_at DESC, id DESC` 排序，包含启用和停用、未删除的短链及其原 domain_id 对应公开地址，不受当前默认域名替换。

固定表头顺序：

```text
id,short_url,slug,target_url,title,tags,status,redirect_mode,intermediate_delay_seconds,expires_at,password_enabled,max_visits,visits_used,created_at,updated_at,owner_id,owner_username
```

tags 是 JSON 数组字符串，空数组为 `[]`；布尔为 `true`／`false`；无过期和无限额度分别输出空 expires_at／max_visits；数值为十进制；时间为 UTC RFC3339Nano。owner 字段只对应可读清单中的所属账号。password_enabled 只有布尔值，绝不输出密码／哈希／授权信息；也不包含访问事件、统计维度或其他用户资料。

UTF-8 BOM、CRLF、标准库 CSV 转义；动态文本复用 `csvText` 的 Unicode 前导空白、公式与控制字符防护，不能只靠 CSV 引号。读取预算之外，服务端仍独立限制最终 CSV 的精确 UTF-8 字节长度最多 8 MiB，计入表头、BOM、重复字段、JSON／CSV 转义及公式中和的增长，超限同样整体返回 `200118`；不截断单元格。两项预算均允许恰好 8 MiB；少数原始内容经规范化后会缩小的集合可能先被读取预算拒绝，这是同步导出的明确成本边界，不改变既有 URL 写入限制。JSON 下载描述沿用现有兼容路径，不直接返回附件或落盘。

## 4. 迁移与生成

`00022_short_link_export_permission.sql` 只给内置 user／admin 添加缺失的权限，并追踪本次追加与后续该权限成员关系的 UPDATE。Down 只移除本迁移追加且之后未被独立更改的权限；原有、迁移后新建组、撤销再重授及其他权限编辑须保留。没有 INSERT 追踪，不修改短链或审计数据。复用 00019 的安全回滚模式。

权限目录及前端 fixture 使用现有标准生成入口；源 SQL 用锁定版本 SQLC 生成，均检查零漂移。新业务文件进入 Go 100% 门禁；错误路径通过可控查询读者或真实数据库故障验证，不排除可测试逻辑。

## 5. 前端与生命周期

个人／全站列表标题区增加可复用 `ShortLinkListExportButton`，只对当前身份有对应权限时显示。说明明确「导出筛选结果，最多 1000 条」，不暗示当前页。筛选应用中、输入防抖未完成、列表初始加载／重取／失败、其他列表写入进行中或导出中禁用，零条结果可导出表头。

防抖未完成以现有 schema 规范化后的有效草稿与已应用筛选比较；只增加 Go 空白规范允许的首尾空白不应让按钮永久禁用，非法草稿继续由既有错误状态阻止导出。

点击固定当前已应用 status／q／tag 和 own／admin 上下文；不提交分页、选中项或未应用草稿。请求无自动重试。请求失败和超限分别友好 Toast，可主动重试；成功只提示已发起保存。下载复用 Blob／object URL 工具并释放资源。

严格 Zod 校验文件名、固定 MIME、内容前缀与最大长度。身份 epoch、权限、上下文、筛选或组件存活状态变化后，旧响应不能保存或 toast；在 await 后同步核对最新身份缓存并等待父状态渲染。导出不改列表、分页、选择、URL、短链事件或账号偏好。不跨标签页广播文件内容。

## 6. 验证与完成标准

- CSV reader 验证固定字段、BOM、CRLF、逗号／引号／换行、Unicode 公式、空值、tags JSON 与 8 MiB 限制；不只匹配源码文本。
- 真实 PostgreSQL 覆盖 owner／admin 隔离、全部权限交集、当前禁用／删除／改组／撤权、归属转移、默认域名更换、筛选与顺序、0／1000／1001 条；可控查询故障验证标准错误。
- HTTP 覆盖严格参数、成功与错误、no-store 及真实路由接入；迁移 Up／Down／Up、既有与后授权限保留；权限和 SQLC 零漂移。
- 前端 API、下载、超限、重复操作、筛选快照、无权、列表失败与所有迟到隔离，中英文及手机布局。
- 隔离 Compose 的真实浏览器创建独立账号和短链，读取下载文件，校对筛选／所属账号及注入文本，覆盖个人与管理员、桌面与移动，最后清理。
- 全仓 Go、100% 业务覆盖率、vet、前端完整测试／100% 覆盖率、lint／类型／构建、完整浏览器及独立整分支审查。目标 CI、合并和发布分别记录。
