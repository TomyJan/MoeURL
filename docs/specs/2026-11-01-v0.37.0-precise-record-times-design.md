# v0.37.0 精确记录时间设计

## 意图

v0.36.0 的本地短格式精确到分钟。同分钟发生的审计与访问事件需要辨别，同时不能让整张表永久变成长时间串。Agent 选择原生 details／summary；仅 title 对键盘不够友好，全局改成秒又会扩大旧约定，均不采用。

## 组件与接入

新增 web/src/shared/ui/InstantDetails.vue。唯一公开 props 为 instant: string 与 label: string。父级继续用 useDateTimeDisplay.format 生成 label，返回 null 时 label 回退 instant；子组件不获取偏好、不解析 instant、不构造 Date、不请求数据。summary 内保留 time 元素及原 datetime；短标签旁有本地化“精确时间”提示。展开正文直接输出 instant 文本节点，不使用 v-html、链接或自定义浮层。

中英文键为 insights.preciseTime，值分别为“精确时间”和“Exact time”。原生 disclosure marker、focus-visible 样式和自然 Tab 顺序保留；Enter／Space、鼠标与触屏由浏览器处理，不手写键盘状态机。默认折叠，展开只增加本行高度；正文有界宽度、可换行。不要给 summary 再嵌套按钮、链接或 tabindex。组件随记录卸载，不引入跨记录展开状态。

仅 AdminAuditPage 和 VisitRecordsPanel 的 occurredAt 单元格接入。原业务对象、查询 key、分页、筛选与排序完全不动。当前接口 schema 仅接受 Z，父组件测试沿用此契约，不因展示功能扩大接收范围。纯展示组件对传入的 Z／非零 offset 和小数精度逐字符输出；两个同一分钟的事件分别拥有自己的详情。非法字面量仅在纯组件验证安全显示，不能绕过父层解析；Intl 不可用时沿用原文 fallback，不强行解释输入。

## 身份与响应式边界

偏好或语言变化只改 summary 的显示标签；原始详情、datetime、CSV、cursor 和 UTC 范围不变，不引发业务重取。旧账号／无权／读取失败时由既有父层守卫卸载记录，详情不得把旧时间保存在额外共享状态。新组件不新增 auth 或 QueryClient 依赖。

## 提示排版

ConsoleShell 的时区状态提示保持原位置和状态语义。使用与 workspace 一致的响应式水平留白；设备／当前 zone／unsupported／unavailable 文案均可换行。390px 中英环境正文不贴边、没有文档级横溢，不修改侧栏、overlay 的焦点陷阱或业务主区滚动。精确像素取现有 CSS 设计变量，不另起主题系统。

## 文档与兼容

旧 v0.36.0 计划中的 Go pointer 签名加 inline code，仅清理 Markdown；原外置合同、裁决、日志、dispatch、ZIP 与截图一律冻结。记录 v0.36.0 的实际交付状态，不抹去旧阶段失败。版本元数据为 0.37.0，manifest 除 version、lock、workspace 与既有验证依赖匹配；禁止安装本机依赖。

## 验证

- 先在现有真实两表组件上证明缺少精确详情的行为 RED，不用 missing import 当产品失败；随后最小 GREEN。
- 同分钟两个时间、纳秒小数、Z／offset、原 datetime、原数据对象及文本转义；真实 Intl 失败 fallback 保留。
- 语言／偏好变化无业务重取；CSV／cursor／UTC range／datetime-local 边界不变；权限撤销后旧详情卸载。
- 真实浏览器的 summary 键盘开关与焦点、鼠标／触屏、390px 中英及提示错误状态；原图逐张 ROOT 查看，不隐藏通知。
- 新输入自身完整前端四项 100%、类型／lint／隔离构建，必要完整 E2E／精确产品扫描；审查与候选、master 九 CI 分别归属真实 SHA。
