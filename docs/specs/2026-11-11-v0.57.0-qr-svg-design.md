# v0.57.0 二维码 SVG 下载设计

## 现状与选择

已有共享弹窗覆盖创建结果、个人列表和管理列表，支持三个固定深色预设、白底 PNG、当前 generation 结果与本地下载。v0.32.0 明确把 SVG 留给后续版本。相比账号默认外观，本轮直接增加本地矢量制品，不引入本人资源、CAS、迁移或持久身份状态；不扩展成模板系统。

## 输出与界面

沿用既有 `qrcode`，调用 `toString(url, {type:'svg', width:320, margin:4, errorCorrectionLevel:'M', color:{dark,light:'#FFFFFF'}})`。dark 只来自现有目录，不收用户 XML 或动态颜色。对完整 SVG 字符串做 `encodeURIComponent`，仅作为带 download 属性的链接，不使用 `v-html`。文件名沿用已知短码，扩展为 `.svg`；PNG 链接和预览保留原契约。

SVG 准备有独立的本地化 status，失败提供持久错误，明确 PNG 可用及切换外观重试。弹窗动作区 `flex-wrap`，第三个动作不压出手机。无新增保存、权限或服务器请求。

## 异步边界

继续用同一 generationId。每次身份或预设变化先递增并清空两类旧制品、错误及加载状态。PNG 成功且当前时发布 PNG，并以 `void generateSvg(...)` 启动 SVG；该 helper 自己 try/catch/finally，三个出口均核同一 generation，PNG finally 不等待它。SVG 失败只改 SVG 状态。卸载递增 generation，使已启动的两类结果失效；不增加后台服务或持久资源。

Vue 原有调度合并 identity 同步恢复 classic 与编码 watcher，避免同一轮为旧颜色重复编码。关闭、空 URL 不生成；slug-only、URL-only、重开都清旧下载并恢复 classic。

## 验证与风险

组件测试先在原组件确认新链接、独立准备和错误状态缺失，随后最小实现。真实 qrcode 证明三色 SVG、白底、4 模块静区、完整长 URL 与安全 XML；只有在可控异步和错误测试中替换 SVG encoder，PNG 保持真实。旧 success／error／finally 不得覆盖新状态；保留既有 PNG 17 项回归。

浏览器双语和双视口验证三个入口、真实键盘 SVG 下载字节及文件名，解析 SVG 的安全节点和颜色，实际解码 SVG／PNG 后逐模块中心比较图案与白静区。该结果不冒实体扫码、纸张或设备认证。旧长 URL 键盘测试补入新 SVG 动作，不能仍假定 PNG 后直接关闭。12 张原图逐张检查。

API、后端、生成物及依赖保持全集 hash／bytes 不变，复用原执行归属。准备阶段产品版本和 head 不改，正式转移后独立构建 0.57.0 并核准确产品；本地门禁、真实审查、合并事实与发布状态分开记录。
