# v0.33.1 首页文案反馈设计

## 1. 目的与约束

修复 v0.33.0 三项已披露延期 Minor，选择最小的界面状态修复及文档更正。沿用 Vue 3、Vuetify 4、TanStack Query 和现有 HTTP 资源；不改变服务器、持久数据、权限、完整版本 CAS 或 public DTO。本设计取舍由 Agent 在既有自主多轮授权内作出。

## 2. 编辑反馈

`useHomeContentDraft.edit(field, value)` 仍只更新对应草稿并递增 edited；当且仅当反馈为 `saved` 时清空该反馈。两字段均适用，编辑不改变服务器 version、不发起保存。`conflict`、`saveFailed`、`invalid` 及 `loadFailed` 保留各自诊断语义；成功保存、重载和身份切换继续按原规则更新。保存期间输入禁用，不增加第二套 dirty 状态或新文案。

组件测试从真实 HomeContentEditor 的输入、保存按钮及反馈节点观察结果。先保存成功，再分别编辑标题或简介，应保留新输入、移除成功提示；再次保存应使用上次服务器返回的完整 revision。另测冲突后编辑仍显示冲突并保留草稿。网络边界可受控，draft、组件与 QueryClient 都保持真实。

## 3. 首页挂载与后台读取

首页显示自定义文案的条件变为当前 observer 已在本次挂载之后完成读取，并且当前 query 状态成功。使用 TanStack Query 的 `isFetchedAfterMount` 联合 `isSuccess`，不依赖全局 `isFetching`：已有本次成功时后台 pending 保留成功数据；新 success 替换；error 切回默认。没有成功的首次读取／首次失败后的重试 pending、重新挂载已有缓存时均不显示旧自定义内容。

仍 `retry:false`、`refetchOnMount:'always'`、`gcTime:0`，不改缓存 key、全局策略或 HTTP no-store。空字段仍逐字段回退当前语言，切换语言不翻译管理员文本，字面 HTML 形状文本不执行。后台等待期间创建入口保持可用。

真实 HomePage＋QueryClient 测试受控 HTTP promise：成功后 invalidation 开始时旧内容仍在；成功换新；后台失败后默认，下一次 pending 不恢复旧内容；初始／重挂载 pending 隐藏预填缓存。使用 query 状态／显式 deferred 同步，不用固定 sleep 或 mock useQuery。

## 4. 真实浏览器与隔离

扩展原首页文案 E2E 的真实管理保存流程，在英文桌面及中文手机保存后编辑草稿，确认上次成功反馈消失且刷新后的服务器值仍是上次保存值；随后显式重载。后台场景先在独立管理员页实际保存新值，再在已挂载的访客首页通过浏览器 offline→online 触发 reconnect，受控 HTTP 路由只延迟而不伪造成功数据；等待新响应后再确认新内容。组件测试另行覆盖 invalidation；跨页保存不假定具有实时通知。覆盖一次失败到默认、重挂载缓存抑制；原配置最终 fresh CAS 恢复并实核，不遗留短链。截图保留真实 toast，不遮掩信息。

## 6. 风险与方案比较

保留全局 isFetching 门槛会继续闪回，取消所有门槛会让重挂载暴露旧缓存；按本次 observer 读取状态划分，能用明确回归覆盖两者。自行维护最后成功文案会引入额外生命周期状态，因此不采用。编辑时清空全部反馈会隐藏冲突，故只清 `saved`。如果 observer 语义与预期不同，以真实组件测试为准，先记录根因，最小调整设计，不削弱旧缓存隔离。
