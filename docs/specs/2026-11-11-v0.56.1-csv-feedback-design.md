# v0.56.1 四列 CSV 导入提示设计

ROOT 依据长期无人值守授权自主选择前版两项延期提示为下一小增量。沿用 Vue、Vuetify、vue-i18n 和现有错误模型；复用已有 linked worktree，从 PR294 合并结果 `35b5b2bd703a87492c1185061c81fa526cfe94f4` 开始 `feat/v0.56.1-csv-feedback`。比较仅修摘要、同时修摘要与拒绝提示、扩大导入功能三案，选择第二案，解决用户不知道如何纠正短码的问题，保持范围最小。

## 现状与边界

四列解析、严格第四协议、全部权限、原子事务和幂等回执已交付；常驻摘要和无效文件提示仍只列三种格式，确定短码拒绝只显示通用失败。本版只修这些提示，不改协议、权限、后端、数据库或依赖。任意字段映射、导出恢复及其他访问设置仍不纳入。

## 行为

`csvHelp` 和 `csvInvalid` 的中英文均列四种格式，说明第四列 `custom_slug` 为空时随机；继续说明 UTF-8、1–20 条、文件与完整请求各 64 KiB、非导出恢复和拒绝后保留草稿。

在 `useBulkCreate.submit` 的现有 unknown 判断之后，仅当本次快照模式为 `custom-slugs`、错误确为 `ApiClientError` 且代码为 200101 或 200102 时，选择独立提示键 `customSlugTaken` 或 `customSlugReserved`。200120 保留回执冲突，其他错误保留通用分类。不能用后续拒绝证明此前未知写入已回滚，也不能泄漏后端错误正文或占用者信息。

确定拒绝保留原有序原文和 UUID，无自动重发。用户主动修改、重新预览才产生新批次。unknown 保持原账号、原接口、原 UUID 和原内容，禁止改稿；身份与权限失效及迟到结果继续走原有守卫。
