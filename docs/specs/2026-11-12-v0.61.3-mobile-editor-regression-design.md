# v0.61.3 手机编辑器回归补测设计

## 现状与取舍

现有 `web/e2e/v0.61.1-mobile-settings-layout.spec.ts` 已捕获 `geometry.group`，但只检查按钮相对 card/body/viewport 的横向范围、文字相对按钮的四边。取消 intermediate 后已有重开 UI 检查；取消 direct 后只有服务端状态和写请求检查。本版只补这两个观察缺口。

选择扩展原八场景，不复制整套测试或新增 fixture。模拟几何的单元测试不能证明浏览器实际裁剪，重复完整产品构建不能证明新增断言；因此采用既有产品镜像上的真实浏览器补验。这是 Agent 根据无人值守授权作出的实现选择。

## 断言与场景

- 继续英文 320×568、英文 390×900、中文深色 390×900、英文 1280×900，各自 own/admin 两入口。
- 对三个按钮的 `box` 和 `textBox` 分别检查 left/top 不小于 group 对应边减 1，right/bottom 不大于 group 对应边加 1。保留原 card/body/viewport、最小 44px、文字相对按钮及键盘可见性断言，不放宽容差。
- direct 取消、dialog 隐藏后，从真实列表再次打开；confirmation 的 `aria-pressed` 仍为 true，direct 为 false，不存在倒计时 slider。再次通过真实取消关闭，随后保留服务端 confirmation 和仅一次完整保存 payload 校验。
- 不插入 CSS、不改变产品行为、不依赖固定休眠；沿用真实账号／短链和 finally 聚合清理错误。

## 验证与身份

浏览器 driver 固定 Windows Node 26.3.0／Playwright 1.65.0；静态验证复用精确镜像中的 Linux Node 26.5.1／pnpm 11.5.0，分别记录运行身份。针对修改的 E2E 做 TypeScript／ESLint，再运行原八场景及必要 setup。全部产品物理输入必须与原 0.61.1 产品证明相同，新增测试输入归本版。新断言首次通过属于补验，不声称实现前 RED。

保留命令、cwd、显式环境、继承环境未全捕获边界、完整输入 hash/bytes、真实退出码、原日志和八份几何附件。仅保留必要选定图，成功 trace 不留；运行结束核准确 Compose 项目容器／卷／网络为空。无需重 Go、Vitest、产品 build、smoke 或扫描，除非后续实际产品输入发生变化。
