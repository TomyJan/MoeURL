# 统计与事件

v0.18.0 已合并全站统计、匿名访问记录和事务审计；v0.24.0 已合并单链匿名记录 CSV，v0.25.0 独立分支实现操作审计 CSV。各版本验证与发布状态分别见对应验收，本页早期非目标只描述当时边界。

## 统计能力分层

统计能力分为 3 层：

- 基础统计：访问总量、今日访问量、最近访问时间等核心指标。
- 基础维度统计：来源、设备、地区等低成本聚合维度。
- 完整详细统计：最近访问明细、事件明细、复杂筛选、导出等高级能力。

v0.0.1 不要求实现统计展示、统计聚合或访问明细查询，但应预留统计事件类型、统一事件记录接口和访问流程调用点。v0.0.1 的事件预留不要求创建事件表，不要求事件后台任务，不要求统计查询 API，不要求统计 UI。

v0.0.4 已完成基础统计前置：系统持久化已成功写出跳转响应的短链事件，并在我的短链和全站短链列表展示总访问量、今日访问量和最近访问时间。v0.1.0 在此基础上实现按短链的统计分析详情页、近 7 天趋势及来源、设备、地区聚合；该页从对应短链进入并返回所属列表，不提供独立的全局分析导航入口。v0.14.0 增加近 7／30／90 天及最多 90 天的自定义 UTC 日期范围，当前阶段见 [验收记录](../implementation/v0.14.0-acceptance.md)。v0.16.0 推进单短链匿名聚合 CSV 导出；访问明细、原始数据导出和任意时区不纳入。

## 基础统计

基础统计用于满足日常管理需求。

包括：

- 总访问量。
- 今日访问量。
- 最近访问时间。

近 7 天访问趋势属于 v0.1.0 统计页能力，不属于 v0.0.4 必须实现范围；v0.14.0 扩展为近 7／30／90 天和自定义日期，空日期访问量补零。趋势、来源、设备、国家和区间访问量按同一 UTC 日期范围计算；总访问量、今日访问量和最近访问时间保留全生命周期含义。日期与兼容约定见 [日期范围设计](2026-10-15-v0.14.0-analytics-date-range-design.md)。

## 维度统计与详细统计

维度统计和详细统计用于分析访问来源。

v0.1.0 实现来源、设备、地区等基础维度统计。来源只保存 Referer 主机名，设备只保存归类结果，地区只保存来自部署者配置请求头的国家代码；该请求头必须由可信反向代理覆盖或先清除客户端同名请求头后写入，不得将客户端直接提供的值视为可信数据。不得保存原始 IP、完整 User-Agent 或完整 Referer。v0.18.0 在成功访问事件上追加可空的浏览器／操作系统类别，去除版本和任意 UA 文本；旧记录不回填虚构类别。

包括：

- 来源页面。
- 浏览器。
- 操作系统。
- 设备类型。
- 地区。
- 最近访问记录。

详细统计展示由权限控制。

### v0.18.0 匿名访问记录与全站统计

个人与管理访问记录接口分别为 `GET /api/v1/short-link/visits`、`GET /api/v1/admin/short-link/visits`。读取要求 `short_link:read_visits`，再叠加本人读取与归属，或管理入口与全站读取权限。日期最多 90 个 UTC 日；`pageSize` 默认 25、范围 1–100，按 `(created_at DESC,id DESC)` 游标读取下一页，不做深 offset 或全量 count。设备筛选支持 desktop／mobile／tablet／bot／other／unknown，国家支持两位大写代码或 unknown；未知类别返回 null。每次请求重查授权，错误不渲染为空结果。

全站接口 `GET /api/v1/admin/dashboard` 要求 `admin:access` 和 `statistics:read_all`，返回有效用户／短链规模、保存的启用状态数量、UTC 今日新增／访问量、区间访问量、连续日趋势、热门短链及生成时间。同一只读 repeatable-read 快照中执行有界查询；已删除链接的成功历史仍计访问量，热门记录显示删除状态并取消详情入口。启用状态不等于公开可访问；不提供虚构 UV、在线人数或机器健康指标。完整 DTO 和日期契约见 [v0.18.0 设计](2026-10-22-v0.18.0-analytics-audit-design.md)。

原访问事件及全生命周期聚合继续长期保留，v0.18.0 只限制单次读取范围，不自动删除历史访问事件。该版本未提供记录导出；v0.24.0 已合并单链匿名记录 CSV，v0.25.0 独立分支实现审计 CSV，分别见下文。全站访问合并导出、任意时区和事件归档仍未实现。

### v0.24.0 单链匿名记录导出

个人与管理接口分别为 `GET /api/v1/short-link/visits/export` 和 `GET /api/v1/admin/short-link/visits/export`。只接受规范非零 UUID 的 `id`、默认 7 天／7、30、90 天 `days` 或成对 `startDate`／`endDate`，可选设备／国家；最多 90 个 UTC 日。拒绝游标、pageSize、重复、未知和显式空参数。同一 5 秒只读 repeatable-read 快照重读有效账号、数据库组权限和未删除链接；独立 `short_link:export_visits` 必须叠加 `short_link:read_visits` 及本人读取／归属，或后台入口／全站读取。

只导出 `redirect_response_sent`，按 `(created_at DESC,id DESC)` 排序。候选至多 1001 条元数据，最多 1000 行，原始可变长文本与最终 UTF-8 CSV 分别限制 8 MiB，超限整体拒绝且不回读超预算文本。成功 JSON 为 `{fileName,contentType,content}`，MIME `text/csv;charset=utf-8`；文件名 `moeurl-visits-{id}-{startDate}-{endDate}.csv`。固定字段为 `short_link_id,start_date,end_date,time_zone,event_id,occurred_at,referrer_host,device_type,browser_family,os_family,country_code`，时间为 UTC RFC3339Nano，空值保持空单元格，包含 BOM／CRLF、标准 quoting 和逐文本公式中和。空结果允许仅表头文件。

按钮只在记录成功加载且范围／已应用筛选一致时可用，第二页仍导出整个筛选范围，未应用国家草稿和刷新中的旧范围不可导出。换号、同账号重登录、路由／过滤往返、撤权及卸载后的迟到结果均失效，浏览器释放 Blob URL 与临时节点。非法输入／无权／不可见／容量分别为 100001／120001／200104／200120，基础设施 HTTP 500／900000；所有响应 no-store。文件不含目标地址、标题／标签、owner、用户名、原始 IP／UA／完整 Referer 或令牌，也不新增采集、事件、审计或业务写入。完整契约和实际验证见[设计](2026-10-26-v0.24.0-visit-record-export-design.md)与[验收](../implementation/v0.24.0-acceptance.md)。

## 聚合统计导出

v0.16.0 在现有统计基础上增加 CSV 下载，个人与管理接口分别为 `GET /api/v1/short-link/statistics/export` 和 `GET /api/v1/admin/short-link/statistics/export`。每次请求重新检查 `short_link:export_statistics`、对应读取权限与归属，不直接导出浏览器缓存；日期规则与统计一致，前端固定当前已加载的实际 UTC 范围。

文件只含公开短链 URL、日期、UTC、概览、连续日趋势和现有来源／设备／国家聚合，使用固定机器字段、UTF-8 BOM、CRLF 与公式注入保护。它不包含完整目标地址、管理元数据、用户身份或原始访问记录；下载不计访问量。文件字段、错误与生命周期边界见 [导出设计](2026-10-16-v0.16.0-analytics-export-design.md)，实际状态见 [验收](../implementation/v0.16.0-acceptance.md)。

## 统计事件口径

短链访问流程应在工程设计上提前定义统计事件类型，避免后续新增密码页、确认页、中间页、风控审核时造成统计口径混乱。

v0.0.1 必须预留以下事件类型：

| 事件 | 触发时机 |
| --- | --- |
| `short_link_opened` | 访问者打开短链 URL，并成功识别域名和短码。 |
| `access_condition_checked` | 系统完成访问条件检查，例如不存在、软删除、禁用等。 |
| `redirect_initiated` | 系统准备跳转到目标链接。 |
| `redirect_response_sent` | 系统已成功写出跳转响应。 |
| `redirect_blocked` | 短链因不存在、软删除、禁用或访问条件被阻止。 |

以下扩展事件不属于 v0.0.1 必须预留范围，其启用状态随对应能力演进：

| 事件 | 状态或对应能力 |
| --- | --- |
| `password_verified` | 后续访问密码事件。 |
| `confirmation_clicked` | v0.4.0 已启用；确认页主动继续时发出，但数据库 Recorder 不持久化。 |

`redirect_response_sent` 只表示 MoeURL 已成功写出自身可确认的跳转响应，不代表访问者浏览器一定完成跳转，也不代表目标页面实际加载成功。

v0.4.0 在确认页主动继续时发出 `confirmation_clicked` 非统计事件，但数据库 Recorder 继续只持久化 `redirect_response_sent`。确认页进入、预览和点击都不增加访问量，最终目标响应沿用既有计量口径。

后台处理流程应允许不同事件分别入库或聚合。v0.0.1 只要求定义事件类型常量、统一事件记录接口，并在短链访问流程中调用该接口；具体实现可以是 no-op 实现或结构化日志。v0.0.4 先展示访问量和最近访问时间；v0.1.0 再展示来源、设备和地区聚合；浏览器、操作系统、事件类型和最近访问记录仍属于后续详细统计。

v0.0.4 的访问量口径只统计 `redirect_response_sent` 事件。短链不存在、软删除、禁用或被访问条件拦截时，不计入访问量。`redirect_response_sent` 仍只代表 MoeURL 已成功写出跳转响应，不代表访问者浏览器完成跳转或目标页面加载成功。

## 操作记录

v0.18.0 使用 `audit_log` 记录关键成功操作，提供 `GET /api/v1/admin/audit/list` 与只读 `/admin/audit`，要求 `admin:access` 和 `audit:read`。按日期、操作者 UUID、资源类型、动作筛选，递增 bigint ID 以十进制字符串返回，时间保留原 UTC 精度。系统供应的 actor 为 null，用户删除不级联丢失审计。

应用显式绑定事务局部 actor 上下文，由白名单触发器只记录标识、动作和变化字段名；不记录秘密、完整 URL、请求体或配置值。审计插入失败使原业务一起回滚，业务失败／实际 no-op 不产生成功日志。自助错误密码仍按原协议提交失败计数；成功改密、会话撤销及凭据审计同事务。域名授权按集合差量修改，相同集合不产生伪记录。数据库管理员直接 SQL 与历史 migration 不在应用操作审计保证范围内。

新审计滚动在线保留 180 天，读取始终应用截止时间；每小时有界清理，最多 4 批、每批 500 条，周期总时限 10 秒并响应退出取消。该在线保留不替代独立受保护备份。`00021 Down` 在存在审计时安全拒绝；支持的旧应用回退保留兼容 schema，不通过在线清空日志绕过保护。

本版覆盖：

- 创建短链。
- 编辑短链。
- 删除短链。
- 禁用短链。
- 修改权限。
- 修改用户组。
- 修改域名配置。
- 修改系统设置。

## 操作审计 CSV

v0.25.0 的 `GET /api/v1/admin/audit/export` 只读导出现有审计元数据，不采集新事件或字段值，不改变 180 天在线保留和清理规则。三权限交集、当前账号、UTC 范围与保留时刻在同一 5 秒只读 repeatable-read 快照内确认；按已应用 actor／resource／action 过滤后取完整结果，最多 1000 条，原文与编码后 UTF-8 各 8 MiB，超限整体拒绝，不返回部分文件。

固定 11 列为日期、UTC、完整十进制 audit ID、UTC RFC3339Nano 时间、actor ID／当前用户名、资源类型／ID、动作和变更字段 JSON 数组。空 actor 与账号缺失有明确区别，文件使用 BOM／CRLF、标准 CSV 转义及公式中和；不含目标 URL、业务值、密码／哈希内容、Token、原始 IP／UA。`password_hash` 作为既有变更字段名可以出现，不能把字段名误当泄露。空结果仍是合法表头文件；不新增全站访问合并、归档或后台任务。完整契约与实际证据见[设计](2026-10-27-v0.25.0-audit-export-design.md)和[验收](../implementation/v0.25.0-acceptance.md)。

## 状态页面

短链访问过程中可能出现多种状态。系统应提供统一、可读、可自定义的状态页。

常见状态页：

- 短链不存在。
- 短链已禁用。
- 短链已过期。
- 访问次数已达上限。
- 需要访问密码。
- 密码错误。
- 无权访问。
- 目标链接不可用。
- 系统维护中。

状态页面应支持：

- 多语言。
- 自动深色模式。
- 响应式布局。
- 系统主题和页脚配置。
- 返回首页按钮。

## 风控与审核扩展入口

风控和滥用治理属于远期开发目标，v0.0.1 不要求完整实现，但工程设计应预留扩展入口。

本节风控主要针对目标链接和短链滥用治理，不替代登录安全、账号安全和系统访问策略。

后续可扩展能力包括：

- 目标域名黑名单和白名单。
- 自动审核规则。
- 接入 Google 安全浏览等外部安全数据源进行目标链接审核。
- 管理员手动复审。
- 用户举报入口。
- 可疑短链标记。
- 创建频率限制。
- 每日创建数量限制。
- 风险链接强制确认页。
- 审核状态和审核记录。

短链创建、编辑和访问流程中应预留审核状态字段和拦截点，便于后续在不重构主流程的情况下加入自动审核、白名单、外部安全数据源和人工复审。
