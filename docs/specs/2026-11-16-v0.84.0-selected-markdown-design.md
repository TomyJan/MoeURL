# v0.84.0 所选 Markdown 清单设计

## 交互与格式

在既有两列表选择工具栏并列增加“复制所选 Markdown”／“Copy selected Markdown”，说明“仅当前页所选项，包含标题和公开短链地址。”／“Selected items on this page only, with titles and public short links.”。成功文案“已复制 {count} 条 Markdown 短链”／“Copied {count} Markdown link(s)”。工具栏继续自然换行，保留纯网址、整页复制和独立管理清单 CSV 的含义。

只整理当前已授权读取的 `title` 与公开 `url`，不访问 `targetUrl`、备注、owner 或其他页。选择条件沿用 1–100 个唯一且全部存在的 ID，按列表顺序输出，形如 `- [说明](<https://sho.rt/abc>)`。空标题用公开地址作为标签；标签保原文字，用反斜杠转义 `\`、反引号、星号、下划线、花括号、方括号、圆括号、井号、加号、减号、点、叹号、竖线、尖括号和波浪号，`&` 编为 `&amp;`。目的地址中 `\`、`<`、`>` 和 ASCII 空格分别编为 `%5C`、`%3C`、`%3E`、`%20`；其余原地址字符保持。每行一个项目，LF 分隔，无表头和尾随换行。

只在 Markdown 模式校验标题必须为字符串，不含 Unicode Cc／Zl／Zp；任一项不满足则整个复制禁用，原纯网址复制不因不使用的标题而改变。URL 沿用原 HTTP(S) 和控制字符检查。Markdown 模式必须显式提供 selection，不能误接成整页复制。没有 HTML 预览或 Markdown 解析器，不引入依赖或宣称其他应用的完整渲染兼容性。

## 复用与隔离

`PageLinksCopyOptions` 增加可选 `format?: 'markdown'`，默认仍为原纯网址模式；选中实例传 `selection`。新组件模式为 `selected-markdown`，独立 testid `short-link-selected-markdown-copy` 和本地化键。两父页加 `selectedMarkdownCopy`，复用相同 `copyOptions`／`copyLock`，不把自身 pending 回接 blocked。

共享锁只互斥三个复制入口；筛选、分页或其他写入照原逻辑退休复制回调，不新增会改变原操作的全局锁。按原 owner symbol／generation／同步 cache 订阅判断当前结果，任一身份或选择变更都退休旧反馈；旧 finally 不释放新 owner。Clipboard 首个 await 前接收固定文本，失败显示原安全本地化错误，不输出异常正文，不使用 storage、execCommand 或自动重试。
