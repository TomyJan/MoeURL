# v0.89.0 确定性 CSV 表头别名设计

## 方案

保留现有手动映射作为唯一应用入口，在面板增加显式匹配按钮。与上传即匹配相比，主动点击保持列选择的明确意图；与模糊推断相比，有限集合可以完整测试且不会读取单元格。用户已授权自主选择合理增量，采用此最小方案直接实施。

## 有限别名

| 字段 | 接受的完整表头 |
| --- | --- |
| target | `target_url`、`url`、`网址`、`目标网址` |
| title | `title`、`标题` |
| tags | `tags`、`标签` |
| customSlug | `custom_slug`、`slug`、`自定义短码`、`短码` |
| redirectMode | `redirect_mode`、`跳转方式` |
| expiration | `expires_at`、`过期时间` |
| visitLimit | `max_visits`、`最大访问次数` |
| countdown | `intermediate_delay_seconds`、`倒计时`、`中间页倒计时` |

仅移除两端 U+0020／U+0009，ASCII A–Z 转小写；不移除换行、不折叠内部空白、不折叠 Unicode。重复同名和不同别名均算多候选，即使其中一列已占用也不消除歧义。

## 接口与行为

新增纯函数 `matchCsvHeaderAliases(headers, selected, permissions, excluded = [])`，返回本次可填的部分字段→索引；不改变输入、不接收行数据。字段名与映射面板 props 一致，`permissions` 包含 `title`、`tags`、`advanced`，`excluded` 保存本文件已明确不导入的字段。target 可匹配；metadata 字段分别受 title／tags 开关约束；其余五字段共用现有 advanced 开关。

先从全部已选择索引构造占用集合，再按上表顺序处理空字段。该字段仅有一个候选、该索引未占用且权限允许时返回；否则保持空选。手选即使占用语义不同的列也不重解释。所有现有解析与最终授权校验照常执行。

用户显式选择“不导入”或清空网址选项与尚未触碰的空值分开记录；再次匹配不得覆盖显式空值。此排除集合只属于当前文件，换文件或卸载时丢弃；重新手选具体列即取消对应排除。真实下拉框选择当前已为空的选项也表达排除意图，不能只依赖值变化事件。

组件通过已有八个 update 事件填空，不新增父级 hook 状态。反馈只含数量或通用无匹配说明，不含单元格、表头详情或日志。新 headers 引用到达时清除反馈，取消／换号／撤权由现有父级生命周期处理。按钮和反馈在 390px 下可读可达；双语文案说明仍需检查并应用。

## 验证

真实对话框测试先证明旧组件不能通过匹配完成安全列投影，再实现。纯函数覆盖全部别名、ASCII 边界、歧义、占用、权限、幂等及不变性；组件覆盖反馈、换文件、已有手选和实际 HTTP payload。完整前端门禁保持四项 100%；准确候选产品覆盖中英桌面／手机真实浏览器及未选秘密列持久化隐私。最终只做一次 Sol high 独立终审，并取得本 head 真实 CodeRabbit 后正常守卫合并。
