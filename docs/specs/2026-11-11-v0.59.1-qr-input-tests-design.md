## 连续键盘

真实创建自有短链、通过按钮或菜单打开二维码。等待 SVG 就绪及焦点在弹窗内；Vuetify 可以聚焦外层 dialog 或内层 overlay 容器，此时只发一次 Tab。否则从实际首控件检查。接下来只发连续 Tab，每次断言明确控件 focus 和完整可见，不能逐项 locator.focus。三色、M／Q／H、尺寸、PNG、SVG、关闭共十项；下载只核可达，原版真实下载和菜单选择继续用原执行合同。

## 滚轮和布局

到关闭按钮后记录 scrollTop、clientHeight、scrollHeight。有溢出必须 top>0、标题非完整可见；无溢出必须 top=0、标题完整可见。指针移到卡片内部的视口有效坐标，先确认位置没有变化，再发送 `mouse.wheel(0,-1200)`。有溢出时必须观察 `{top:0,height:原值,content:原值}`，再核标题完整可见；无溢出保持 top=0。每语言至少一次实际溢出。顶部和底部各拍原图，不冒整卡同时可见；页面无横向溢出，通知不隐藏。

隔离诊断已发现旧“偏移减少”断言会假通过：创建通知约 5.5 秒后退出，卡片高度由 548 变 593、偏移 45 自行归零，关闭焦点不变。因此同时核几何，不能用固定等待、隐藏通知或程序滚动掩盖。正常 run 的四个实际滚回分别为 45、109、44、44→0；中文个人／全站卡片 593 高完整容纳，无需滚动。这些数值是本次证据，稳定规格只要求真实溢出、归零与几何不变。

## 有效性和清理

私有变体跳过第二控件必须在连续 Tab 处失败；取消 wheel（实证 cancelable=true／prevented=true）或完全省略 wheel 都必须在几何守卫处失败。不改正常产品，首次正常通过只是补验，不伪造产品 RED。保留旧假通过和测试自身的初始焦点／无溢出假设错误。

每测试独立 context／自有短链。真实登录与删除检查统一业务 envelope；catch／finally 聚合原场景、删除和 context 关闭错误。suite 后仅检查自有 compose 容器、卷和网络为空，不触未知资源。
