# v0.86.2 文档状态维护设计

## 当前能力与历史边界

总览的当前能力应描述已交付的标准 CSV 字段子集：必须有唯一 `target_url`，其余七个标准字段可选、可调整列顺序，仍按原协议执行缺省与授权。它不是任意未知字段、字段别名或历史清单恢复。路线图当前基础和剩余能力必须采用同一边界；早期版本的历史范围不据此改写。

总览不再硬编码过时的“当前最新产品”。当前产品和本地、候选审查、正常合并及发布的状态，以[开发进度](../product/development-status.md)及对应验收为准。原 v0.76.0、v0.48.0 等验收保留为各自历史证据，不转移到新提交。

## 文档职责

v0.86.1 设计保留用户可见说明、缺省语义、实际视口和操作区可达性条件。实现工具、门禁次序、审查与合并要求、资源预算由其实施计划承载，已发生的验证结果由验收承载；用链接连接这些文档，不重复维护执行流程。

语言维护只改善已核实的 14 条可读性建议。“补记／补验／补齐”继续表示追加记录、验证或缺省；判断句和准确构建页脚 `V0.86.1-30a47bb` 保持原义，不能按词典建议改成其他内容。
