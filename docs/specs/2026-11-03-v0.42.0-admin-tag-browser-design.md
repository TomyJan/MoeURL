# v0.42.0 管理员全站标签查找设计

## 意图与取舍

全站列表已有精确标签筛选，但管理员不知道其他账号使用了哪些标签。本版提供只读发现入口，点击继续使用原列表过滤，不建立第二套列表或标签管理器。

本设计由 Agent 按用户持续自主开发授权决定：优先全站目录，而非涉及大规模写入的重命名／合并。保留本人契约，新增独立管理端口与 SQL；前端提取小型共享面板及两个固定上下文包装组件，避免复制已修复的代际守卫。没有用户逐项批准设计的表述。

## API 与数据库

`GET /api/v1/admin/short-link/tags?q=`。成功仍为 HTTP200／code0，data 为严格 `{items:[{tag:string,linkCount:integer}],hasMore:boolean}`，items 非 null，最多 50 项，计数正整数。无 owner、URL、cursor、limit、scope 或总数。NoStore 与真实身份中间件沿用业务 API。

新增独立 `AdminTagCatalogPort.ListAdminTags(context.Context, auth.CurrentUser, TagCatalogInput) (TagCatalogResult,error)`、`AdminTagCatalogHandler`，以及 `Service.ListAdminTags`。当前 `TagCatalogPort.ListTags` 语义不变。允许复用严格 query 解析和结果投影，但不能传布尔值关闭个人 owner 约束。

管理授权预检沿用 authorizeAdmin(read_all)，其不要求硬编码 admin 组名。独立 SQLC `ListAdminTagCatalog` 使用同一 SELECT 的 grant_snapshot 检查真实账号存在／active、当前组非 guest、两项权限，再对所有未软删除短链标签 unnest、count(distinct id)。有效非内置自定义组拥有两项权限时同样可读。使用 left join sentinel 区分无权限与空目录，不将空集误判成功授权。

统计忽略当前列表 status、关键词、tag 与当前页，只描述全站未删除管理资源。已停用、过期、耗尽、停用域名不减数；软删或标签移除减数，转移不影响全站数但影响个人数。一次 SELECT 保证授权与结果快照一致，不追溯撤销已获授权的在途结果。

查询固定 LIMIT51，按 link_count DESC、tag COLLATE "C" ASC；应用截为50并设置 hasMore，不返回完整总数。ctx 五秒期限；不锁短链，不增加索引或 schema。SQLC1.30 标准生成两次，完整输入／生成集合零漂移，不手改生成物。

## 输入与错误

唯一可选 query 为 q，允许无 query 或 q=。拒绝未知／重复 key、无等号片段、空分隔片段和坏编码。对原始 q 先拒绝非法 UTF-8 与控制字符，再 Go TrimSpace，裁剪后 0–32 Unicode 码点。BOM 保持 Go 语义。大小写敏感 strpos 字面子串，%／_／反斜杠均普通文字，不执行 SQL 通配或正则。

非法请求 HTTP200／100001，无权 HTTP200／120001。本端点沿用 CurrentUser 中间件：已过期、已撤销或不存在的 Session 回退为 guest，随后管理授权返回 HTTP200／120001；身份解析的基础设施错误仍为 HTTP500／900000。存储失败同为 HTTP500／900000，仅记录中性操作标识和安全请求元数据，不输出 q、标签、URL、owner 或原数据库错误。空目录 items=[]、hasMore=false。

## 前端接口与布局

全站列表原工具栏后、数据面板前独立整行放默认折叠“全站标签”。局部 grid 保证筛选控件不被批量工具挤压；不改共享主题 CSS。描述明确“来自全站全部未删除短链，不随当前筛选变化”，显示纯文本标签及引用数。标签按钮可用键盘，长 Unicode 文字可换行，phone 不横溢。

严格实体新增 `listAdminTags(query:string)` 固定管理端点，复用同一严格响应 schema；个人 `listPersonalTags` 路径不变，不接收客户端 URL 或 owner。

提取 `TagCatalogBrowser.vue` 负责现有生命周期，`PersonalTagBrowser.vue`／`AdminTagBrowser.vue` 是固定 own／admin 包装，不能由页面任意指定 endpoint。保留个人原行为与测试。共享面板接收父 access 与可选 blocked，复用父身份观察，不新增 auth observer。只读展开不阻止列表和写入；blocked 禁止选择按钮并在排队回调再次检查，父层选择 handler 同样使用既有互斥条件。

own key 为 ['short-link','tag-catalog',userId,epoch,generation,search]；admin key 为 ['admin-short-link','tag-catalog',userId,epoch,generation,search]。家庭失效消费现有写后 invalidateQueries，不改变共享 Query 默认值。retry=false、staleTime0、gcTime0；搜索250ms防抖，非法草稿不发请求。

读取与可见数据同时要求父 canRead、当前 auth success 且非 invalidated、access.allows('read')；响应代际／search 与当前一致、查询成功且非 fetching／invalidated。关闭、身份轮次或撤权同步退休 generation。精确目录 query invalidate 时退休旧 generation，cancel/remove旧 query，首次无数据 pending 也不能复用旧 promise；连续失效同样成立。旧 success／failure／click、A→B→A、同账号撤权恢复和离线重连不得复活旧内容。

失败重试只作用当前读取；关闭清本地搜索而不改列表筛选。点选只改原 tagFilter，保留 status/q，失效旧读取不触发选择。空／无匹配／更多提示分开，中英全部接入 i18n。
