## 目标

管理员后台用于系统级管理。

v0.0.1 只要求提供管理员查看和管理全站短链的最小入口，以及首次初始化流程。完整后台能力按后续版本逐步实现。

## 后台导航结构

完整目标形态建议按二级分组组织：

```text
系统仪表盘

域名与链接
  链接管理
  域名管理

用户与权限
  用户管理
  用户组管理

系统维护
  系统设置
  主题设置
  审计日志 / 操作记录
```

权限不建议作为独立的常规菜单长期存在。权限配置应主要内聚在用户组编辑页面中，便于管理员理解「用户组 → 权限」的关系。

管理后台可以与用户中心共用同一套界面，只在菜单中展示管理入口。

## 系统仪表盘

v0.18.0 在 `/admin/dashboard` 提供真实全站快照，要求 `admin:access` 和 `statistics:read_all`，导航位于管理区首项。展示用户／短链总数和启用数、UTC 今日新增短链／成功访问量、已应用区间访问量、连续日趋势和热门短链。启用只表示保存的状态，不代表已通过过期、密码、额度和域名条件；不展示 UV、在线人数或机器健康等未采集指标。

日期使用近 7／30／90 天或最长 90 天的自定义 UTC 区间。已软删短链的历史访问仍计数，热门记录明确标注已删除并取消无效分析入口。数量排除软删用户／链接，用户数也排除 guest。当前阶段证据见 [v0.18.0 验收](../implementation/v0.18.0-acceptance.md)，合并不视为正式发布。

## 域名与链接

链接管理用于管理全站短链。

管理员可以：

- 查看全部短链。
- 搜索全部短链。
- 按用户、域名、状态筛选。
- 禁用短链。
- 删除短链。
- 修改短链所属用户。
- 查看短链统计。

v0.0.1 要求提供管理员查看和管理全站短链的最小入口。该入口至少支持查看全站短链列表、识别所属用户、启用或禁用短链、软删除短链。搜索和多维筛选可以作为增强项，不作为 v0.0.1 阻塞验收。

v0.20.0 的单条归属转移使用全站列表的「更多 → 转移归属」，要求 `admin:access` 与 `short_link:update_all`。管理员输入接收账号的准确用户名，并确认将管理权及全部既有匿名统计一起移交；接收人须启用、未删除且属于 user／admin。旧所有者失去后续个人管理及统计访问，公开地址、域名、访问密码、额度与事件不变。完整精度版本冲突需重新打开确认；同 owner 不写入或审计。接口为 `POST /api/v1/admin/short-link/transfer`，本版不提供普通用户赠送或批量转移，详见 [设计](2026-10-23-v0.20.0-link-ownership-design.md)。

v0.22.0 扩展为全站当前列表最多 100 条的批量转移，沿用上述权限、准确用户名、完整版本及保留语义。确认框固定选择快照，任一缺失／陈旧版本／故障使整批零写入，真实变化逐条同事务审计；同 owner 计为未变化。接口为 `POST /api/v1/admin/short-link/batch-transfer`，无跨页选择或普通用户赠送；界面冲突必须刷新后重新确认，身份变化隔离迟到结果。范围与实施状态见[设计](2026-10-25-v0.22.0-batch-ownership-design.md)和[验收](../implementation/v0.22.0-acceptance.md)。

v0.23.0 已合并个人与全站当前列表“整理标签”：添加、移除、替换及空数组清空，最多 100 条。后台需 `admin:access`、`short_link:read_all`、`short_link:update_all`、`short_link:set_metadata`；个人以 own 读写权限及当前归属替代后台权限。摘要冻结 URL、原标签及完整版本，可纵向滚动；一行一个标签，显式确认，清空前显示警示。与设置、启停、删除、转移、其他批量及导出互斥；普通失败保留草稿，冲突关闭旧确认并等待成功刷新，身份或权限变化撤销旧确认。仅实际标签变化与版本同事务审计，不改标题、归属、地址、访问配置或历史。集中标签库、跨页全选及导入仍未实现；契约和状态见[设计](2026-10-26-v0.23.0-batch-tags-design.md)与[验收](../implementation/v0.23.0-acceptance.md)。

v0.21.0 设计在全站清单标题区增加导出筛选结果的 CSV，要求 `short_link:export`、`admin:access` 和 `short_link:read_all`。包含匹配短链及其所属账号标识、目标和配置，不输出秘密或原始访问事件；最多 1000 条／8 MiB，超限需缩小筛选。个人入口只输出本人当前归属记录，完整边界见 [清单导出设计](2026-10-24-v0.21.0-link-list-export-design.md)。

v0.24.0 在管理单链分析的访问记录标题区增加“导出访问记录 CSV”，要求 `short_link:export_visits`、`short_link:read_visits`、`admin:access`、`short_link:read_all`。它按已加载的实际 UTC 日期和已应用设备／国家下载完整结果，当前页码不限制文件；未应用国家草稿、查询刷新或失败时不可下载。最多 1000 条／8 MiB，超限缩小筛选；无权隐藏入口，服务端在同一快照重新授权。个人入口仅本人归属，不提供全站访问合并、审计导出或后台任务。文件只含已有匿名事件，不含目标地址或账号资料；权限迁移、错误与生命周期见[设计](2026-10-26-v0.24.0-visit-record-export-design.md)及[验收](../implementation/v0.24.0-acceptance.md)。

域名管理用于管理系统可用域名。

管理员可以：

- 添加域名。
- 编辑域名。
- 禁用域名。
- 删除域名。
- 设置全局默认域名。
- 配置域名可用用户组。
- 配置域名默认跳转方式和默认跳转页模板。
- 配置域名排序。

完整域名管理页面不属于 v0.0.1 范围。

## 用户与权限

v0.19.0 在用户列表的账号操作中增加单账号主用户组调整，只允许其他非内置账号在 user／admin 间切换。完整精度版本检测冲突，改组与撤销所有旧会话、group_id 审计同事务提交；相同组无变化。确认对话框明确提权／降权与重新登录，保护当前操作者和 builtin，不支持自定义组／多组／批量迁移。实现与验证状态见 [范围](../product/scope-v0.19.0.md) 和 [验收](../implementation/v0.19.0-acceptance.md)。

用户管理用于维护本地用户资料和账号状态。

管理员可以：

- 查看用户列表。
- 搜索用户。
- 查看用户详情。
- 启用或禁用用户。
- 调整用户组。
- 查看用户短链数量。
- 查看用户访问量。

用户组管理用于配置权限。

以下列表描述完整用户组管理的远期能力模型，并非 v0.5.0 当前页面范围。v0.5.0 不提供创建用户组、域名与模板配置或用户组成员查看能力。

管理员可以：

- 查看用户组。
- 创建用户组。
- 编辑用户组。
- 配置用户组权限。
- 配置用户组可用域名。
- 配置用户组可用跳转方式和模板。
- 配置用户组默认域名。
- 查看用户组成员。

内置用户组不可删除，但可以修改部分权限。

v0.5.0 已交付内置用户组权限管理的第一阶段：

- 查看 `guest`、`user`、`admin` 三个内置用户组及其真实数据库权限；`guest` 保持只读。
- 按短链基础能力、访问增强能力、域名能力和管理能力分类编辑 `user`、`admin` 权限。
- 套用 `restricted`、`basic`、`standard` 预设后继续逐项调整，并在确认保存前保持为本地草稿。
- 固定保护 `admin` 的后台入口和全站短链管理权限，禁止把这些权限授予其他内置组。
- 使用更新时间做乐观并发，冲突时重新加载最新权限，不执行最后写入者覆盖。

v0.5.0 不创建自定义用户组，不修改用户所属组，也不实现访客短链归属、用户组成员、域名授权、配额或审计日志。

完整用户与权限管理页面不属于 v0.0.1 范围。

v0.0.1 不实现完整用户管理页面，但管理员必须具备创建普通用户的最小入口。该入口仅支持设置用户名、密码、昵称、用户组和启用状态，用于满足普通用户登录和创建短链的闭环。用户列表、用户详情、用户删除、批量导入、多用户组和权限可视化配置均属于后续能力。

以下权限树描述用户组编辑能力的远期方向，并非 v0.5.0 当前页面范围。v0.5.0 只展示并编辑产品范围定义的 13 项既有权限。

用户组编辑页建议按能力分组展示，避免权限项平铺导致难以理解：

  自定义短码

  设置有效期

  中间页跳转
  确认页跳转
  可用跳转页模板
  可编辑模板元数据

统计权限
  基础统计
  维度统计
  详细统计

  用户组管理
  全站短链管理

  系统设置
  主题设置

## 系统维护

系统维护用于管理全局配置、主题和审计记录。

系统设置建议包含：

- 默认语言。
- 默认主题。
- 默认短码长度。
- 默认跳转方式。
- 默认中间页倒计时。
- 默认短链有效期。
- 默认用户组。
- 本地登录开关（需存在可用外部登录方式时才允许关闭）。
- 外部接口鉴权扩展入口，用于后续支持程序化创建短链、查询短链和获取统计数据。
- OIDC 提供商管理。
- OIDC 提供商预置模板。

主题设置建议包含：

- 站点名称。
- Logo。
- Favicon。
- 主题色。
- 首页文案。
- 页脚内容。
- 默认跳转页模板。

v0.18.0 的 `/admin/audit` 位于系统维护分组，要求 `admin:access` 和 `audit:read`。只读查询最近 180 天的关键应用变更，按 UTC 日期、操作者 UUID、资源类型和动作筛选，提供有界游标前后翻页。显示系统／当前用户名与稳定 UUID、资源标识、动作、实际变化字段名和精确时间；不提供修改／删除按钮，不显示字段前后值。退出、换号、撤权或请求失败后不显示旧身份记录。权限与事务、no-op、故障回滚及回退保护见 [本版设计](2026-10-22-v0.18.0-analytics-audit-design.md)。

v0.25.0 在审计页标题动作区提供“导出操作审计 CSV”，叠加受保护的 `audit:export`，仍须 `admin:access` 与 `audit:read`。只导出当前已加载的实际 UTC 日期及已应用操作者／资源／动作组合，当前页码不限制结果；空结果可下载，任一种未应用草稿、查询刷新或失败时禁用。最多 1000 条，原文与最终 CSV 各 8 MiB，超限整体拒绝。文件只含现有审计元数据，bigint ID、UTC 微秒及变更字段 JSON 数组保持完整，不含字段值、目标地址或秘密。改组撤销会话后旧页面请求拒绝且无下载；账号／权限／筛选／分页／卸载轮次隔离迟到结果，原生 Blob URL 和节点始终释放。服务端授权、快照、迁移及交付状态见[设计](2026-10-27-v0.25.0-audit-export-design.md)与[验收](../implementation/v0.25.0-acceptance.md)。

具体功能是否可用，仍应由权限系统最终决定。

## 首次初始化流程

首次初始化流程属于 v0.0.1 必须实现能力。

初始化内容至少包括：

- 注册第一个用户，该用户加入内置 `admin` 用户组。
- 设置站点名称。
- 配置默认系统访问域名或确认当前访问域名。
- 配置默认短链访问域名。
- 选择默认语言。
- 写入固定内置权限模型。

初始化完成前，普通登录、短链创建和管理后台应不可用。初始化完成后，系统应写入固定内置权限模型，并禁止重复执行初始化流程，除非管理员通过明确的维护机制重置系统状态。
