# 二维码导出尺寸设计

范围见 [v0.59.0](../product/scope-v0.59.0.md)。本设计在原共享弹窗内增加固定尺寸，不改服务端协议。

## 状态与编码

`export-sizes.ts` 导出固定三档及联合类型。组件持有 `selectedSize` 和菜单开关；身份同步重置时恢复 320 并关闭菜单。

编码 watcher 将 URL、颜色、纠错等级和尺寸一并快照。PNG 和后续独立 SVG 只消费该快照，不能在 await 后读取可变选择。每轮先清旧制品、错误和 loading；所有异步完成路径继续核对 generation。失败显示原有错误，不截断 URL、不暗降参数。

## 交互

动作区在 PNG 之前放 Vuetify 尺寸菜单，按钮展示当前值，选项使用单选状态和双语可访问名称。保留 PNG→SVG→关闭相邻 Tab 次序，预览仍以固定 320 属性和现有响应式 CSS 显示。尺寸只改变下载制品，不撑大页面。

内容区采用紧凑留白，去掉继承的额外上下 padding；原短屏滚动卡片保留 8 px 的焦点滚动边距，避免聚焦按钮时出现亚像素裁切。不缩小预览或点击区域。390 px、桌面及长公开 URL 保留完整可见检查；375 px 沿用正常聚焦／滚动可达要求。

## 验证与回滚

组件测试用字面量选项独立生成预期，核真实 PNG IHDR、SVG 及字节；覆盖 27 种尺寸／等级／颜色组合、相互保留、身份重置、迟到成功／失败及 finally。真实异步编码使用有上限的条件等待，不使用固定 sleep。

浏览器覆盖中英 × 桌面／390／375 三视口、全部三个入口、实际下载字节与完整 URL 模块、无新增 API、键盘和布局。原断言和失败原件保留。无数据库迁移，回滚为前版组件与文案即可，不改变已存业务数据。

准备阶段与正式转移、产品、审查和合并分别固定准确输入、SHA 和制品身份；全部门槛满足前不声明交付。
