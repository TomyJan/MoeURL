# v0.53.2 创建身份读取恢复设计

## 行为

`ShortLinkCreatePanel` 的 `currentUserQuery` 失败时展示 `role="alert"` 和“重试”按钮，调用既有 `refetch()`。重试挂起期间按 `isFetching` 禁用按钮，首次重试的 pending 状态允许隐藏错误提示。失败可再次重试。

中文固定提示“身份信息读取失败，请重试。”，英文“Could not load your account. Please retry.”；按钮为“重试”／“Retry”。不显示原始错误正文，不全页刷新，不自动创建。

## 状态与边界

复用已有 Query、身份代际、取消、权限及 mutation 守卫，不手动写身份缓存或建立第二套状态机。只有最新有效身份及权限允许时才能创建；返回 guest、撤权或登出后的迟到成功不得恢复权限。失败／重试保留目标草稿、域名手选及其他草稿。无 API、数据库、权限、依赖或全局 Query 策略变化。

## 验证

真实组件、QueryClient 和 HTTP 边界覆盖七项：首次失败恢复后主动创建、后台失败保草稿与手选、重复失败不泄漏正文、返回撤权、挂起禁用、返回 guest、真实登出交错。先正式 RED 再最小实现 GREEN。

准确新产品镜像的浏览器覆盖首次／后台失败各桌面 1280 和手机 390，失败只拦 `auth/me`，恢复放行真实服务器；键盘重试、挂起禁用、无自动创建、保草稿及真实提交一次，保存原图。完整前端四项 100%、静态检查、构建及完整浏览器门禁另留准确执行身份。旧预备实验和历史失败不借给新 SHA。

唯一独立整分支终审、最新真实 CodeRabbit、全部有效意见处置后正常精确 head 合并、独立对象核验和可恢复归档。详见[范围](../product/scope-v0.53.2.md)。
