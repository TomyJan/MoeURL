# 管理员目标规则检查设计

依据[范围](../product/scope-v0.72.0.md)。检查现有规则如何对一个目标作出准入判断，替代管理员为了排查设置而创建短链的操作。复用七规则的真实实现，不增加第八份策略或外部探测。

## API 与载荷

POST `/api/v1/admin/system/target-policy/check`，Content-Type `application/json`，禁止任何 query。对象恰含一个大小写精确的 `targetUrl` 字符串，拒绝重复、未知、缺失、null、错误类型、尾随 JSON／垃圾和非对象。解码前拒绝非法 UTF-8，最大 body 16 KiB（足以承载 2048 bytes 全部 JSON 转义）；解码后的原目标 1–2048 UTF-8 bytes，不 trim、不规范改写，拒绝 Unicode 控制字符。错误返回 HTTP200／900226，消息固定。该限制专属于本检查接口，不能宣称旧单条创建已有相同上限。

成功 data 恰为 `{"outcome":"allowed"}`、`{"outcome":"invalid_target"}` 或 `{"outcome":"restricted"}`，统一 code/message/meta 外壳。权限错误 HTTP200／120001；存储、超时和数据库失败 HTTP500／900000。全部 no-store。日志仅固定事件和 request ID，不记录输入、原错误或命中规则；浏览器只在当前组件草稿中短暂保存输入，不放 query cache／Pinia／URL／storage。

## 包与事务边界

新增 `shortlink.TargetPolicyCheckPort`、`TargetPolicyCheckInput{TargetURL string}`、`TargetPolicyCheckResult{Outcome string}` 和独立 handler；`shortlink.Service.CheckTargetPolicy(ctx, actor, input)` 实现该 Port。不扩大旧 `shortlink.Port`，不搬迁基础 validator，不复制校验逻辑。

`targetpolicy.AuthorizeAdminCheck(ctx, q, actor) error` 是明确的授权桥接：复用本包 actorID、既有 `GetTargetPolicyAdmin` 和 authorizeAdmin，不接受任意 callback，不反向 import shortlink。非法 actor 不进入 SQL。方法先校验输入结构，五秒 ReadCommitted／ReadOnly 事务：LockTargets → 当前授权 → validateTargetURL → CheckTargets。ErrInvalidTargetURL／targetpolicy.ErrInvalidTarget 映射 invalid_target，targetpolicy.ErrTargetDenied 映射 restricted；其他错误原样交 handler 隐藏。基础非法必须先通过授权，但无需读取策略。shared gate 在任何查询之前，等待独占保存提交后下一条语句读取新规则；所有规则更新共用独占 gate，七次读取期间不能改变。读取权限代表该语句时点授权，不声称阻止事务结束后的撤权。

不增加 migration／SQLC 输入／依赖。只有查询及事务 advisory gate，无业务写入、审计上下文、DNS／HTTP。现有创建／编辑／回执／访问流程不变。

## 前端

新增 `entities/target-policy-check/api.ts`：严格请求和恰单字段／三字面量响应；未知或多字段响应按错误，不把 malformed 响应显示为允许。不缓存结果，不自动重试。

新增 `features/target-policy-check/useTargetPolicyCheck.ts` 与 `TargetPolicyCheck.vue`，独立卡片接入 AdminSettingsPage，复用现有当前身份 generation 守卫。每次输入改变增加 revision 并清除结果；请求捕获 generation／revision／请求序号，所有 success、error、finally 仅当三者仍当前且组件活跃才更新。切号、同号重登、撤权、卸载退休整个请求；编辑后可发新请求，旧 finally 不得停止新 loading。重复点击当前 loading 时不再发送。失败保稿、显示可理解错误，无自动重试；结果用状态文字，不显示原 URL。

卡片明确“使用已保存规则，不包含其他卡片草稿”“只检查此时目标规则，不检查配额、短码或可达性”。中英、键盘、触摸、长目标换行和移动按钮可达。无需新路由／固定 slug。
