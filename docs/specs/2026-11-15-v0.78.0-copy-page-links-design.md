# v0.78.0 复制本页短链设计

## 行为与界面

在本人／管理员列表标题动作区放一个可复用按钮和短说明：“仅当前页，每行一个公开短链地址。”／“This page only, one public short link per line.”。有读权限才显示，空页禁用；不要求写或导出权限。只取当前真实 query cache 的 items[].url，以 LF 拼接，顺序和地址原样保留，无尾随换行；不触及 targetUrl、备注、所属账号等字段，不发额外数据请求。保留停用或耗尽记录的公开地址，不承诺复制后一定可跳转。

新增 `features/short-link-page-copy/usePageLinksCopy.ts` 与 `ShortLinkPageCopyButton.vue`。hook 接收现有 access、响应式 listQueryKey、blocked 和即时筛选／分页 context，返回 visible、disabled、pending、copy。两个父页复用原 exportBlocked，再补 exportPending、QR、私密确认和本人 bulkCreateOpen 等已有互斥锁；不将自身 pending 接回 blocked，避免自我退休。不阻断用户换页或换账号，只退休反馈。

## 同步与异步守卫

hook 使用 useQueryClient，不增加 auth 或列表查询。每次点击从当前 key 读取 state，须 success、idle、未 invalidated、当前 access.canRead 与 access.allows('read')，全部父级锁允许，items 数量 1–100。返回时再次核相同 key、数据对象、身份和授权。context 含未防抖的 status/keyword/tag/noteStatus/noteQuery/page/pageSize，避免旧页资料被新筛选操作复制。订阅相关 query cache 的 updated/removed 及 auth/me 变化，连同同步 watch 递增 generation，处理同 tick 撤权再恢复、失效再恢复及筛选来回切换；卸载解除订阅。

copy 在直接点击栈内捕获仅 URL 的文本并调用 navigator.clipboard.writeText；不先 await。无 Clipboard API、抛错、reject 使用统一本地化失败反馈，不输出异常正文或数据。await 之后先 nextTick，让父级状态更新，再检查 generation、当前身份、实时授权与锁；成功显示“已复制 {count} 条本页短链”／“Copied {count} links from this page”。旧 finally 只清理自己的 generation，不能覆盖新复制的 pending。浏览器已接收的复制没有撤销 API，本功能只隔离后续界面反馈，不虚构保密保证。不写 storage、不广播、不自动重试、不调用过时的 execCommand。
