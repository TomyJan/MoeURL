# 全站前端视觉与交互更新

2026-10-14 用户确认交互原型后进入实施。原型用于确定视觉方向，示例数据不进入产品。

## 范围与边界

保留 Vue、Vuetify、既有路由、API、权限和全部已实现业务功能。采用雾蓝石墨配色，统一公共页面、控制台、管理表单、访问页、弹窗和通知。此次不新增业务版本或后端能力。

## 视觉规范

- 浅色：主色 `#3d648f`、背景 `#f5f7fa`、正文 `#233246`、表面 `#ffffff`、次级文字 `#617184`。次级文字较原型略微加深，以满足小字与背景的对比度要求。
- 深色：主色 `#9abae0`、背景 `#111923`、表面 `#192431`、正文 `#e8eef5`、次级文字 `#9aabbe`。
- 铜橙仅用于当前导航位置和提醒；成功、错误各使用独立语义色。
- 页面、面板、卡片圆角统一为 20–24 px，常规控件 10–12 px。降低阴影、字重和装饰性渐变，保留轻量、圆润的风格。
- 桌面侧栏与主内容分离；“新建短链”保留在导航栏上部，账号入口保留底部。移动端沿用顶部入口和抽屉，创建操作使用底部面板。

## 布局、状态与动效

页脚纳入唯一应用框架。短页的内容区与页脚合计占满视口；长页随内容自然滚动。控制台页脚属于工作区，不覆盖侧栏或正文；允许页脚关闭、换行和长文本。

概览使用真实语言包补齐 `overview.*` 文案，包括加载、空数据、错误、重试与统计。所有页面维持中英文、浅深色和窄屏可用。

动效集中定义：交互反馈约 120 ms，页面和菜单约 180 ms，弹窗与抽屉约 220 ms；使用透明度与小幅 transform，避免布局动画、无意义循环和延迟操作。展开与折叠保持已有焦点、Escape、滚动锁和权限行为。`prefers-reduced-motion: reduce` 下关闭非必要位移与动画。
