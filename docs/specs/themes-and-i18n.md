## 多语言设计

当前支持：

- 简体中文。
- 英语。

语言切换器中可以显示为「简体中文 / English」。

后续可扩展：

- 繁体中文。
- 日语。

多语言覆盖范围：

- 首页。
- 登录页。
- 用户中心。
- 我的短链页。
- 统计页。
- 管理后台。
- 跳转页。
- 错误页。
- 系统提示。

浏览器语言选择优先级：

```text
用户手动选择
  ↓
浏览器中保存的个人偏好
  ↓
浏览器语言
  ↓
系统默认语言
```

v0.0.1 应实现多语言基础架构，至少支持简体中文和英语。

v0.15.0 在此基线上增加独立的账号语言／主题偏好，设计见 [账号偏好规格](2026-10-16-v0.15.0-account-preferences-design.md)。个人设置页显式保存到账号，未设置的字段继续使用浏览器／站点基线。登录及完整刷新时加载账号值，每次成功登录（含同账号直接重新登录）开启新的身份轮次；当前身份进入后主动使用切换器的选择优先于迟到的自动加载。账号值只保存在内存覆盖层，不写入访客的本地偏好；退出或更换账号时清除覆盖层，旧轮次响应不能重新应用。顶栏切换器仍只保存浏览器选择，不自动同步账号。

## 操作反馈

成功、失败、冲突及表单校验摘要统一使用应用级可堆叠 Toast，支持单独关闭和自动消失，并跟随当前语言和主题。通知只渲染文本与受控组件，不插入 HTML，不直接展示 Zod issues、网络异常或后端原始错误。

字段校验信息保留在对应输入项旁；页面加载失败、重试入口和影响操作的持久状态保留在页面中，避免通知消失后失去恢复入口。初始化完成页提供登录和首页入口。密码在初始化、登录及重置过程中原样传递，不做 HTML 转义、裁剪或 Unicode 归一化；JSON 编解码必须保持其原值。

## 主题模式

当前默认配色采用 [鸢尾蓝与薄荷青](2026-10-15-color-refresh-design.md)，分别提供暖白浅色与紫调墨色深色；布局、标准组件和下述主题偏好机制保持不变。

系统支持 3 种主题模式：

- 跟随系统。
- 浅色模式。
- 深色模式。

未保存本地偏好时采用管理员配置的默认主题；安全默认值为跟随系统。

用户可以通过主题切换器保存浏览器本地偏好，已有选择不被系统默认值覆盖。v0.15.0 个人设置页另有账号保存入口；账号的 `system` 在当前设备上跟随操作系统，未设置则沿用浏览器基线。

v0.0.1 应实现主题模式基础架构，至少支持跟随系统、浅色模式和深色模式。

v0.0.1 前端初始化时即应接入 MoeURL 自定义主题。默认主题采用 Material Design 3 风格，可以先写死在前端配置中，不要求提供后台主题编辑能力。

## 响应式布局

2026-10-14 视觉更新以 Vuetify 主题 token 统一公共页面、控制台和对话框，布局与交互见 [视觉与交互规范](2026-10-14-ui-refresh-design.md)。该轮雾蓝石墨配色已由 [2026-10-15 配色规范](2026-10-15-color-refresh-design.md) 替代，当前采用鸢尾蓝主色、薄荷青辅助色及暖白／紫调墨色表面。

桌面端“新建短链”保留在侧栏上部，移动端保留顶部和抽屉入口。页脚参与同一弹性页面框架，短页的内容和页脚合计填满视口，长页自然滚动。概览的统计、加载、失败重试与空数据文案必须同时覆盖中英文。

动画集中使用短时透明度和小幅位移，页面约 180 ms、弹窗和抽屉约 220 ms、操作反馈约 120 ms；保留键盘焦点恢复和 Escape 行为。系统要求减少动态效果时取消非必要动画和位移，统计图表不执行入场动画。

所有核心页面都应适配：

- 手机。
- 平板。
- 桌面。

短链访问页尤其需要优先保证移动端体验。

v0.0.1 应实现响应式基础布局。

## 页脚配置

页脚是系统主题配置的一部分，只允许管理员配置。

当前支持管理员配置纯文本页脚。Powered by 固定展示，内容为 `Powered by MoeURL V<构建版本>`，仅 `V` 开头的版本文字带链接；精确 tag 构建链接到 tag，否则附短 commit hash 并链接到 commit。旧 `showPoweredBy` 字段只保留兼容并规范为 `true`，不提供关闭入口。

以下为尚未实现的结构化页脚配置目标：

- 版权信息。
- 备案号。
- 自定义链接。

页脚配置应用于首页、系统页面、跳转页和错误页。具体页面是否展示某些页脚内容，可以由主题策略控制。

系统设置的基础页脚配置已由 v0.9.0 实现；结构化字段和链接列表仍不在当前交付范围。

## 跳转页模板外观

当前已实现固定外观的中间页、确认页和访问状态页。以下模板选择、元数据表单及模板管理属于待开发目标。

系统可以内置多种跳转页模板：

- 默认中间页。
- 极简确认页。
- 图片背景页。
- 错误提示页。

每个模板可以声明自己的元数据字段。用户选择某种模板后，创建短链表单会出现该模板对应的填写项。

示例：

| 模板 | 可填写元数据 |
| --- | --- |
| 默认中间页 | 提示文案、倒计时、按钮文案。 |
| 图片背景页 | 背景图、主标题、副标题、按钮文案。 |
| 极简确认页 | 风险提示、确认按钮文案、返回按钮文案。 |

模板元数据设计原则：

- 由模板定义字段，不允许用户随意注入任意页面结构。
- 字段应有类型、默认值、校验规则和权限控制。
- 管理员可以配置模板默认值和适用用户组。
- 普通用户只能在创建或编辑指定短链时填写自己可用的字段。

跳转页模板和模板元数据结构在 v0.0.1 只要求预留，不要求实现完整管理界面。
