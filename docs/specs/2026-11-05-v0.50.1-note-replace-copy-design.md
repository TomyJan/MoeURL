# v0.50.1 批量备注文案维护设计

由执行者依据无人值守授权选择：先兑现前版延期意见，再扩大功能。见[范围](../product/scope-v0.50.1.md)与[计划](../implementation/v0.50.1-plan.md)。

## 确定变更

英文 `batchNoteReplace.saved` 改为 `Notes replaced: {changed}; already matched: {unchanged}.`。0、1、100 使用同一句式，两个计数仍来自真实保存结果；只改此键，不改中文、保存请求、刷新或通知时长。

v0.50.0 设计明确列出本人及管理员各自预览／写入的四条 POST URL，对照当前 `internal/http/router.go` 和 `web/src/entities/short-link/batch-note-replace.ts` 的实际路径核验。四个交付入口及前版 scope、plan、acceptance 据 PR270 与外置完成回执同步，保留历史失败和运行时边界，不把合并当发布。

`web/package.json` 仅版本变更，不改依赖、lock 或 workspace。PR269 的量词已由前版解决，只记录承接。

## 验证比例

这是可逆的低风险文案维护，不新增复述字符串常量的测试，也不制造行为 RED。复用真实页面保存流程与现有 i18n 测试；用实际 i18n 运行核验 0／1／100 计数。运行受影响的完整前端 coverage、types、lint、隔离构建，保持四项 100%。后端与 SQLC 输入全集核等后复用原证据，不重跑生成器或 Go。

新版本仍独立运行标准完整浏览器与精确产品验证；英文手机保存提示的原图及真实保存流程单独核对。最后一次独立整分支审查；候选与 master 各自 CI、真实最新提交审查及完整讨论闭环，守卫合并后可恢复归档。
