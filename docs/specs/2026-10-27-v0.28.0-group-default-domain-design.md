# v0.28.0 用户组默认短链域名设计

## 1. 意图、兼容与方案

补齐domains的个人→组→全局→排序层级，用于创建面板初始选择。明确手动选择仍优先于所有配置；组默认不是授权，不改变公开访问和已保存短链。保留v0.8、v0.26的后端创建契约：选项当前为全局默认时省略domainId，其他选项传UUID；提交时后端仍检查当前全局／显式角色及当前授权。管理配置在提交期间变化可导致原200114，刷新后用户重选，不自动回退重发。

比较三个方案：浏览器保存无法跨设备且不能按组统一；给旧权限请求／严格DTO追加字段会破坏旧z.strictObject客户端并可能被旧完整保存清除；单独新表虽可隔离版本，却增加组配置的多版本同步、删除和审计映射。采用user_group可空列＋已有组版本，新增独立端点，旧HTTP DTO／请求不变。共享版本意味着权限与默认配置的并发编辑会冲突，这是同一组资源的显式选择，不是独立版本承诺。

沿用Go／Chi／PostgreSQL／Goose／SQLC和Vue／Vuetify／TanStack Query／zod，不增加依赖、权限或通用策略框架。guest仍无创建能力，自定义组与默认跳转另行规划。

## 2. 数据和迁移

Goose00027为user_group增加可空default_domain_id，引用domain(id)的默认NO ACTION外键；非null值必须非零UUID且当前行builtin、key为user或admin。旧记录均null，不修改旧组updated_at／权限，不回填个人值。为非null域名引用建立小型部分索引，供清理及外键检查。

新增专属AFTER UPDATE触发器／函数，只在default_domain_id实际变化且事务启用审计时插入user_group、资源组UUID、action=update、changed_fields=[default_domain_id]；只记标识和字段名，不记域名或配置值。原user_group_audit继续只对权限集合变动记permissions_change，不修改共享record_business_audit，不双记。

所有原完整user_group SQL投影按标准SQLC生成适配新列，以继续返回完整生成模型；手写旧UserGroup HTTP映射故意不暴露新字段，保持现有严格响应。新专属DTO读取新字段。旧权限UPDATE不赋值default_domain_id；新默认UPDATE不赋值permissions。

Down先drop新触发器和专属函数，再drop索引、约束和列；原权限trigger、账号、权限、域名、个人偏好、组updated_at、短链及全部历史审计保持。配置值会丢失，正式Down前需备份确认。旧镜像可保留列并忽略默认；它不会清理新FK引用，可能拒绝删除被组默认引用的域名，不能称策略／删除完全兼容。

## 3. API 与读取投影

新接口均在/api/v1，业务失败HTTP200、统一数字code，no-store；基础设施500／900000，日志不含配置正文或数据库错误内容。

| 路由 | 输入 | 成功data |
| --- | --- | --- |
| GET /admin/user-group/domain-default | 必须且仅一个groupKey，guest/user/admin；拒绝未知、重复、空参数 | setting={groupKey,domainId可null,updatedAt完整字符串,editable}及candidates数组 |
| POST /admin/user-group/set-domain-default | 严格JSON三个必填字段groupKey、domainId可null、expectedUpdatedAt非null | 与上述管理读取相同的setting及candidates |
| GET /domain/group-default | 不接受查询参数；当前Cookie账号，不收userId或groupKey | selection={domainId可null,status=available/not_set/unavailable} |

管理GET的guest仅返回editable=false、domainId=null和空候选，展示只读边界；POST guest返回300203。未知groupKey或格式错误100001；所需builtin目标组不存在300201；完整组版本不匹配300202；操作者无权或指定域名当前对目标组不可用统一120001，含未知／停用／非short_link／无授权。清除不要求目标组仍具备创建能力，但操作者仍须双管理权限。

写入要求application/json（合法媒体参数允许）、恰好一个JSON对象，拒绝未知／缺失字段、尾随文档、错误类型。groupKey写只支持user/admin；domainId非null必须规范小写非零UUID；版本必须完整非零RFC3339Nano。保留完整纳秒，不能因PG微秒编码截断变成匹配。

管理GET使用最多5秒只读repeatable-read事务：先从actor.ID重新读取当前active／未删除账号及其builtin admin组和当前权限，再读目标组及候选，形成一个一致快照。要求admin:access和domain:manage；不信actor.GroupKey／Permissions。目标原始权限必须通过DecodeSnapshot校验，损坏数据返回基础设施失败，不能伪装为空候选。候选只含目标组有创建和对应domain:use_default／domain:use_assigned权限、已授权、启用short_link域名，按v0.27顺序返回id／host／displayName／isDefault。保存值不在候选中时管理员能看见原UUID及不可用状态并清除，不补入无权候选。

本人GET以单条SQL快照读取当前有效非guest账号、builtin主组、组保存值及当前域名／授权；服务端校验真实组权限。只有交集可用时返回UUID，未配置为not_set，已配置但不可用为unavailable且domainId=null。无名称、地址、保存的不可用UUID、目标组权限或其他账号信息。无创建权限也可读取不含元数据的不可用状态；无效账号／guest返回120001。损坏权限或数据库错误不伪造not_set。

## 4. 写事务与锁序

所有新增默认设置在5秒WithAuditTx内，先规范actor非零UUID，再domain advisory共享锁（复用LockShortLinkCreation）→当前app_user FOR SHARE→当前builtin admin组FOR UPDATE→目标builtin组FOR UPDATE。操作者组始终先取排他锁，即使目标是admin也不先共享再升级；目标admin复用已持锁行，user随后锁定。重查active／未删除／当前组及admin:access、domain:manage，再检查目标与完整版本。

指定UUID时在持锁后按目标组当前权限和grant核实启用short_link。domain共享锁使该判断与域名配置写／删除互斥，目标组排他锁使权限并发更新无法穿过校验。先比较版本再比较值；当前同值直接返回当前表示，不UPDATE／不推进版本／不审计。实际变化仅更新default_domain_id与greatest(clock_timestamp(),updated_at+1微秒)，同事务审计；事务内读回、模型校验或审计失败全回滚。HTTP响应在提交后编码；其失败返回基础设施错误，不能撤销已提交写入，客户端必须重新读取再操作，不能自动重试写入。

旧UpdatePermissions保持入口快速授权、请求／旧DTO、受保护权限规则和同集合仍推进版本的旧行为，但生产事务也采用相同domain共享→当前user共享→当前admin组排他→目标组排他前缀，最终只需其原admin:access。排队期间账号禁用／删除／改组、admin不再builtin或权限撤回均不能写。完整版本在持锁行上先用Go时间比较，再执行原条件SQL，避免纳秒被编码截断。显式actor传入手写事务store，不从审计GUC倒推身份、不扩公开API；隔离fake保持测试边界，安全结论必须由真实DB／HTTP门闩回归证明。该旧写边界随本轮共享组版本一起补强，不借机改旧列表或其他模块。

成员迁移先锁用户再锁组，不请求domain锁；新旧组配置写都在domain锁后取user，再按admin→user顺序取组。domain旧写从domain排他开始，互斥发生在持组锁之前，不能引入组→domain倒序。scope不新增任意组锁框架。

## 5. 删除与资格变化

域名删除保留原版本、全局默认和任意短链引用检查。成功删除前，在原审计事务／domain排他锁内清该域名的个人偏好，并清user_group.default_domain_id、单调推进每个受影响组版本，再删除域名；任何清理或审计故障全回滚。组清理SQL先通过明确的MATERIALIZED数据依赖锁builtin admin行FOR UPDATE，再按admin优先和UUID锁引用组并更新，不能先锁user组再升级先前共享的admin组。避免与成员迁移的admin→user共享组读取形成环。此新增清理及删除事务使用5秒期限；外键保留NO ACTION作为最后防线。

停用、移除grant、撤销目标组创建或default/assigned权限、切换全局默认不清保存值或版本。本人使用时再次判断角色与交集，失效通用提示后回退；恢复资格后可再次选中。真正删除清空并推进版本，旧编辑器必须冲突，不能重建引用。既有短链、个人选择和域名排序不改写。

## 6. 管理界面

在AdminUserGroupsPage中为当前组增加独立默认域名区域，单一下拉、清除／保存、说明仅影响创建初始选择。guest只读；没有双管理权限时新区域不开放。候选来自专属管理查询，不凭当前操作者自己的available列表替目标组决定。加载、空候选、读取错误／重试、已保存但不可用、保存、冲突及显式重新加载均有双语状态。

权限和域名默认各保留每组草稿；共享组版本有清晰说明。当前组任一草稿脏时禁用另一区域的编辑／保存，取消本区恢复另一区域。切Tab保留各组草稿，不自动放弃；任一写入pending期间阻止重复写及Tab切换。提交边界再次核当前身份、目标组、数据有效性与pending，不只依赖按钮disabled。

刷新不得覆盖脏草稿；共享组版本后台改变时标记陈旧并保留原快照，显式重载成功才采用新版本／放弃对应草稿。旧权限API的300202处理仍可按旧契约明确告知后重载该权限草稿；不得因新默认区域的普通后台refetch静默丢弃权限草稿。保存返回setting后等待必要组列表、默认配置及当前选择查询刷新，刷新失败显示重试并禁止后续写入，不以局部响应冒完整配置已就绪。

本页查询按userId＋login epoch分区，保留原userGroupQueryKey前缀失效；旧权限和新默认mutation都捕获scope与groupKey，成功／失败／刷新前核仍为当前身份。退出、换账号、同ID新epoch、卸载及迟到读取不能写新账号cache或反馈。当前权限同步失效即停写，恢复使用当前me验证后再刷新，不使用可能先污染身份的旧refetch结果。两个表单不嵌套。

## 7. 创建面板

useDomainPreference及available原身份隔离保留，增加本人组默认query，key包含userId＋epoch且支持统一前缀失效；不把另一身份placeholder当当前结果，不保存到localStorage。管理员设置／清除成功、权限保存成功及域名管理成功均失效相关管理、本人组默认和available前缀；其他浏览器通过已有焦点／online／显式重试读取最新配置，不宣称推送即时同步。

没有明确手动选择且个人偏好未成功读取时仍沿用原加载屏障；个人偏好已成功且有当前可用值时无需等待组默认。否则采用组默认前须其查询成功，或用户明确选择／点击使用系统选择。组默认加载／失败不伪造未配置；失败提供重试与明确系统兜底，即使只一候选也可恢复。明确使用系统选择是当前表单的手动fallback，采用当前可用全局默认／有序首项，不能被迟到组默认覆盖，不清任何持久配置。

有效手动／个人优先，随后与available交集匹配的有效组默认，再原全局／有序首项。组默认unavailable提供不含域名信息的通用回退提示；不把其未知UUID补进选项。个人、手动或组层变化均不自动提交。预览依据当前选择；真实创建成功URL以响应为准；200114刷新身份、available及组默认并保留表单，用户重新确认，不自动重发。成功创建／重置清临时选择，再用最新已加载优先级。
