# v0.46.0 备注关键词筛选设计

## 请求与隐私

新增四个只读 POST：`/api/v1/short-link/note/search`、`/api/v1/admin/short-link/note/search`，及两者各自的 `/export`。搜索词不进入旧 GET／q，不返回备注正文或版本，不进入 CSV、公开响应、统计或应用日志。

列表 JSON 恰七字段：`page`、`pageSize` 为整数，`status`、`q`、`tag`、`noteStatus`、`noteQuery` 为非 null 字符串。导出恰五个字符串筛选，不接受分页。原始 body 最多 16384 bytes；拒绝非 JSON 媒体、任何 query string、重复／未知／缺字段、尾随文档、非法 UTF-8／孤立 surrogate、错误标量。分页整数词法拒绝 1.0、1e0、-0、字符串或越界；page>=1，pageSize=1–100，offset<=2147483647。

noteQuery 先核有效 Unicode 并拒绝全部 Cc（包括边缘 TAB、换行、NEL），再按 Go TrimSpace 裁剪，最后限制 100 码点。BOM 保留，无 NFC；纯空白裁剪为空可接受，但仍受 body 预算。q／tag 各守原规则。noteStatus 沿用空串／present／absent。空 noteQuery 无内容条件，官方清空后走旧 GET；API 空词仍必须走新授权快照。

复用 noteActor 的可选 expected-user header：官方发送捕获账号 ID；缺省仍核 Cookie actor，若提供必须单值规范 UUID 且等于 actor，绝不授予权限。输入 100001、权限 120001、status 沿旧错误、导出超限 200118；基础设施 HTTP500／900000。所有响应 no-store，不回显词或原 SQL 错误。

## 服务与数据库

独立 `NoteSearchPort`、handler 和 `NoteSearchInput`（包含 `ListInput` 与 `NoteQuery`）。`SearchOwnNotes`／`SearchAdminNotes` 返回既有列表；`ExportOwnNoteSearch`／`ExportAdminNoteSearch` 返回既有 ListExport。旧 List／AdminList／ListExportInput 不增加公开搜索词，最小复用私有组装与 CSV 编码。

新列表总在最多五秒的只读 repeatable-read 事务中核数据库当前账号 active／非 guest、当前用户组、本人或全站读取权限；Count／List 同快照，不能因空 noteStatus／noteQuery 跳过。本人集合限定 snapshot 当前 owner，软删始终排除；转移后旧 owner 不得读。导出沿用单 SELECT grant_snapshot，另核 export 权限，在原 1000 条／8 MiB／17 列预算前应用所有筛选。

SQLC 条件为 `strpos(lower(note), lower(arg)) > 0`，空词跳过；%／_／反斜杠均字面。大小写由数据库决定，不宣称 locale 无关 Unicode casefold。原 Count／List／Export caller 显式空词保持旧集合；源变化才用锁定 SQLC 1.30 标准生成两次并全集核零漂移。无迁移、依赖或权限新增，不把原数据库错误写入日志。

## 前端与并发

新增 `entities/short-link/note-search.ts`：固定 POST、完整 body、捕获 expectedUserId，复用严格 items 与独立 response.meta 验证。两页用独立关键词输入，原 500ms debounce；先 Cc 后裁剪／码点验证与服务端一致。无效或未应用词期间隐藏旧总数，禁止写、导出、翻页；读取失败可重试。应用有效词回第一页、清选择、推进共享 listRevision。

查询族首项保持既有失效通知；key 的 userId4、epoch5、listRevision6、noteStatus7、page8 不变，noteQuery 仅追加9。queryFn 只消费捕获 key；身份、授权、筛选 A→B→A 和重挂载均退休旧结果。搜索 query gcTime=0，最后 observer 卸载即不留关键词缓存。不得用旧集合占位新筛选。

导出捕获完整已应用筛选和账号；非空词走 POST，空词走旧 GET，固定 own／all 文件名、17 列 header 和 8 MiB UTF-8 校验。关键词纳入同步代际 watch；迟到 success／error 不下载、不 toast，旧 finally 不清新请求。第 2 页仍导出全部匹配，未带 page／pageSize。备注保存／清空后重新确认集合，未知写入显式 reload，不自动重放。所有 queued 事件重查实时授权、草稿与进行中操作互斥。
