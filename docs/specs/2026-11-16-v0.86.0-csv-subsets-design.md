# v0.86.0 CSV 标准字段子集设计

## 输入与分发

表头字段按以下顺序定义等级：`target_url,title,tags,custom_slug,redirect_mode,expires_at,max_visits,intermediate_delay_seconds`。`target_url` 必须且唯一，其他各最多一次，顺序任意；不 trim、不识别别名，不忽略未知字段。保留原 scanner 的严格 UTF-8、单个开头 BOM、引号／CRLF、最多八列、含表头 21 条及 65536 字节限制。

先检查原始表头和各真实数据行宽度相等，再按最高出现字段选择现有协议；不按实际列数或空单元格降级。依次对应 targets、titles、metadata、custom-slugs、redirect-modes、expirations、visit-limits、countdowns。重排只读原行，不原位交换。

只补该协议需要而表头缺失的先行字段：title／customSlug／redirectMode／expiresAt／maxVisits／intermediateDelaySeconds 为 `''`，tags 为 `[]`。CSV 内部可用 `[]` 文本进入原 JSON/schema。已提供的空 tags、非法 JSON 或其他无效单元格继续拒绝，不能当成缺列。字面值与行序保持，不 trim、规范 URL、修日期、重编码标签或反公式中和。

缺 redirect_mode 保留空值，由原后端解释 direct，不读取账号／域名偏好；缺 expires_at／max_visits 分别无固定过期／不限，空秒数沿用原 5 秒。非空秒数必须显式提供 intermediate。`target_url,intermediate_delay_seconds` 的 `3` 不能推断成中间页。

补齐后的完整未来 wire JSON（含 36 字节 UUID、键名和 JSON 转义）也必须不超过 65536 字节；独立于 CSV 本体预算，在替换草稿前执行原 schema 校验。

## 授权、身份与失败

省列仅简化录入，不修改权限：所有结构化协议即使空标题／标签也需要 `short_link:set_metadata`；第四至第八协议即使短码为空也需要 `short_link:custom_slug`。方式、过期、上限额外权限继续按非空实际意图检查，服务端仍是最终持锁授权方。

复用 File 读取序号、身份 generation、全部权限 epoch、草稿版本、冻结快照与提交守卫。迟到读取、撤权再恢复、换号不复活旧文件。失败不覆盖旧草稿、不发 HTTP；预览／提交中／未知结果不导入替换。未知结果只重试同协议、UUID、payload 和捕获账号头，不能重新补默认或换端点。

旧 `parseBulkCreateCsv` 只接受 targets；详细与非详细结果形状保持。手动映射仍仅选 URL 和可选标题，其他列由用户显式忽略；不能和标准字段识别隐式混用。原八份模板／示例字节保持。

## 界面与兼容

帮助更新格式概述、默认和权限两段纯文本，中英都说明必需 URL／可选七列、缺值规则、非空倒计时条件及结构化原权限。metadataRequired／customSlugRequired 不再使用列数或“含标题／标签”推断。

保持现有 Vuetify 布局、移动端换行和预览确认流程。本轮不重构 hook、client 或后端，不新增依赖；仅 parser、i18n、帮助与版本号为产品代码变化。

## 证据与收口

真实行为 RED 必须是旧 parser 拒绝合法子集，不能是缺模块／类型错误。显式八模式期望对象、128 子集正反序、坏行宽／表头、已提供非法值、Unicode／BOM 和两个精确字节边界保护协议；hook 覆盖实际 HTTP payload／端点、权限／身份竞态、原请求重试；浏览器验证真实持久化和低权限失败。

后端、API、权限、DB、锁文件和模板全输入 hash 守恒，复用准确前版证据，不重跑无变化后端／生成器。单轮完整前端四项 100%、类型／lint、相关 E2E strict／build；单轮准确产品 smoke／扫描与桌面手机浏览器。所有首次失败保留原身份。

沿用活动 4 GiB、双 .tmp 12 GiB、Docker 可回收 6 GiB，大操作先预算；仅清自有资源，必要证据压缩提取逐 hash，准确 owned leaf 可恢复迁出。真实 CodeRabbit、正常 match-head 合并及独立 SHA／tree／唯一父核验后完成交付；不查 CI、不发布部署。
