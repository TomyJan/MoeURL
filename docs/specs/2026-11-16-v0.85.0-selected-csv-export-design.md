# v0.85.0 所选 CSV 设计

## 目标与方案选择

补齐已有单页选择与服务端 CSV 之间的缺口：下载当前页所选管理清单，始终以导出时的完整授权集合为准。复用 Go／SQLC／Vue／Vuetify 和原下载工具，无依赖或权限新增。浏览器拼 CSV 无法保证最新授权与完整数据；逐条请求会混合快照并产生部分成功；把 ID 集合塞入原 GET 查询串会扩大旧协议。采用独立、有界、只读 POST，旧端点不变。

## HTTP 契约

`POST /api/v1/short-link/export/selected` 和 `POST /api/v1/admin/short-link/export/selected`，请求恰为 `{"ids":["规范UUID"]}`。`ids` 必填且为 1–100 个规范小写、非零、不重复 UUID；不 trim、转小写、去重或取交集。公开 Service 方法同样验证，不只信任 handler。

Content-Type 必须为 `application/json`，可带合法 MIME 参数；拒绝所有 query 和裸问号、未知／重复／缺失键、null、错误类型、非法 UTF-8、JSON 非配对代理项／替代字符、第二个 JSON 值和尾随垃圾。请求体先限量读取，最多 16 KiB；按 token 校验唯一键后才解码，不能依靠默认 Decoder 忽略重复键。错误为 HTTP200／`100001`，响应 `no-store`。

官方客户端始终发送 `X-MoeURL-Expected-User-ID`。服务端复用 `noteActor` 的可选绑定头：缺失仍按真实 Cookie 身份；存在则须单值、规范非零 ID 且等于当前身份。头不授予任何权限。本人端要求 `short_link:export`＋`short_link:read_own`，管理员端要求 `short_link:export`＋`admin:access`＋`short_link:read_all`，不扩大普通列表或选择权限。

## 单快照及有界读取

保留 `ExportShortLinkList` 查询和 reader 接口，内部新增 `selection_mode`、`selected_ids` 两参数及 `selection_unavailable` 哨兵列。旧调用默认 false／nil，所有筛选条件、1000／1001 行界保持。新调用先经 Service 规范校验，明确进入选择模式，不能把空切片当全量。

同一 SELECT 完成账号 active／未删／非 guest、实际组权限和 owner 校验。选择模式的 SQL 再防御 null／空／超过100／重复／零 ID 数组；候选只物化 ID、排序和文本字节数，按请求 ID 筛选。可读候选数量必须等于请求唯一数量；任何缺失、已软删或转移后不可读项都置 `selection_unavailable`，返回整份 `120001`，没有内容、缺失 ID 或已知数量。管理员可按原授权选择其他账号记录。

完整性与原始文本 8 MiB 预算都在 payload lateral 读取前检查；拒绝时仅返回空哨兵，不能先返回可读子集或大文本再由 Go 丢弃。成功按 `created_at DESC, id DESC` 取最新字段。CSV writer 继续限制最终文件 8 MiB；总操作 5 秒。超限 HTTP200／`200118`，基础设施 HTTP500／`900000`，安全分类日志不记录 body、ID 集合或 SQL 原始异常。无写入、锁、审计或访问事件；已授权读取不承诺追溯撤销。

## 文件协议

复用现有 `ListExport` JSON 描述和全部 17 列：`id,short_url,slug,target_url,title,tags,status,redirect_mode,intermediate_delay_seconds,expires_at,password_enabled,max_visits,visits_used,created_at,updated_at,owner_id,owner_username`。保持 BOM、CRLF、JSON tags、UTC 精度及 CSV／公式防护；不含备注正文、密码／hash／token。MIME 固定 `text/csv;charset=utf-8`，本人文件名 `moeurl-links-own-selected.csv`，全站文件名 `moeurl-links-all-selected.csv`。旧响应仍只接受旧文件名，前端只抽两个消费者真正共享的内容 schema，不宽化旧协议。

## 前端与异步边界

新增独立 selected-list-export entity、hook 和按钮，位于选择工具栏 export slot；仅完整导出权限可见，文案“导出所选 CSV”／“Export selected CSV”，说明“仅当前页 1–100 条，使用当前服务端数据”。不读取跨页缓存或额外请求列表。

只认当前准确 queryKey 的 success、idle、未 invalidated 缓存；所有选项唯一且全部存在于当前页，按页序提交 ID。空、重复、未知或缺失选择整体禁用。身份 epoch、权限撤销恢复、context、筛选／分页、选择、cache 替换／失效／fetch／error或卸载都退休旧请求，包含同 tick A→B→A；await 后同步重查缓存再等待 nextTick，迟到成功／错误／finally 不下载、不覆盖新反馈、不清新请求。无自动重试；显式重试，成功仅提示发起保存，下载工具释放 object URL。

两个父页拆分 `listExportPending` 与 `selectedExportPending`，computed 聚合成原 `exportPending` 总锁。原全量按钮只额外受 selected pending 阻止；所选 hook 外部 blocked 只额外受 list pending 阻止，不能回喂自己的 pending 或已含总锁的 `batch.unavailable`，避免合法请求自取消。旧行操作、复制、选择、筛选与分页继续使用总锁；canStart 在占锁前核当前身份与上下文。
