## 目的与范围

同一账号跨设备查看控制台时，可显式保存时间显示时区；保持既有 Cookie Session、权限和服务端时间权威。仅解决真实 instant 的显示，不重新解释日历日期，不改统计语义。

纳入：个人设置独立时区面板、本人偏好 API、独立 CAS、登录轮次隔离、共享时间格式器、已登录控制台列表／概览／最近访问／组版本说明的显示接入。旧日期样式尽量保持，日期时间保留明确时区说明。

不纳入：任意时区分析、90 天以上范围、导出时区、到期时间输入语义、公开跳转页、站点默认时区、管理员代改、浏览器本地时区持久化、头像、任意时区字符串、用户上传时区数据、新依赖。

## 有界预设

null 表示跟随当前设备；合法持久化值固定为 UTC、Asia/Shanghai、Asia/Singapore、Asia/Tokyo、Europe/London、Europe/Paris、America/New_York、America/Los_Angeles、Australia/Sydney。中英文名称与 IANA 标识并列，不以固定 UTC 偏移替代 DST 规则。

取舍：完整 IANA 目录引入目录来源、别名规范化与浏览器／Go tzdata 漂移；仅固定偏移会错误处理夏令时。有限 IANA 枚举沿用现有有界预设产品策略。后端只验证枚举并保存，格式化交给浏览器 Intl，因此不新增容器 tzdata 依赖。Host Node26.3 的只读可行性计算已确认九预设、南北半球 DST 及跨日；这不替代产品或浏览器测试。

## 存储与严格 API

独立 user_time_zone_preference：user_id 为 app_user 的主键外键、删除账号级联；time_zone 可空且 CHECK 固定枚举；updated_at 为非空 timestamptz。无旧账号回填，不碰 app_user.updated_at 或语言／主题／域名偏好版本。Down 只删新表，不删除账号或其他偏好；回退会丢失本偏好，验收说明备份边界。

GET /api/v1/user/time-zone-preference 返回 data.preference={timeZone:null,updatedAt:null} 表示该有效账号未保存；已存在返回完整 RFC3339Nano 版本。POST /api/v1/user/time-zone-preference/update 只接受 timeZone 和 expectedUpdatedAt 两个必需字段，各可为 null；拒绝未知／重复／缺失字段、非对象、错误类型、枚举大小写或空白变体、多余 JSON 与无效版本。本人 ID 仅来自 Cookie，接口 no-store，不返回其他账号或元数据。

guest、builtin guest、禁用／删除账号以及失去基础访问资格者拒绝；当前账号有效性须由数据库核查，不能只相信请求中缓存身份。写入用既有有界事务，锁账号并按已有锁序核当前组；无需域名或 short-link creation 锁。首次 expectedUpdatedAt=null 只创建缺失记录，其余版本精确 CAS；并发只一个成功，成功版本严格递增，纳秒不可表示值不舍入成可写版本。事务失败无部分写。

错误沿用 100001 输入无效、120001 无权、300104 偏好冲突、500/900000 基础设施错误。具体认证状态仍遵守现有 middleware 的 401／403 与业务错误区分，不自行改通用响应规则。不记录偏好正文，不增加不必要权限或审计事件。

## 前端和身份隔离

TanStack Query 按本人 userId+epoch 独立 key；只在共享 auth/me 确认非 guest 时启用，无自动写入或轮询。偏好只在当前身份内存生效，不写访客 localStorage，不长期存入 Pinia。退出、换账号、同账号新登录轮次均立即回设备基线，旧轮次迟到结果不能应用到界面或缓存。现有 createIdentity 会同步推进 scope，并按旧 userId 清相关查询；新偏好加入同一清理链。显示层还须核响应附带的本地 scope 标记，避免 query key 切换到 Vue watch 刷新间短暂暴露旧账号值；该标记不发给后端。

独立编辑器：加载前禁保存；后台重取不覆盖脏草稿；保存携带开始编辑时的完整版本。成功后应用服务器返回值，失败保留草稿；冲突提供显式重载，重载成功才放弃草稿，不自动写重试。身份、挂载状态与编辑 revision 同步守卫所有读取／写入 success、error、finally 以及 cache 更新，不能仅在最后赋值时检查一次。

共享格式器接受真实 instant、显示样式与所选 zone；有效 instant 才格式化，旧非法值保留各调用点已有友好 fallback。Intl 不支持时区时不得造成渲染崩溃或隐式改账号值：暂退设备并明确告知用户；该路径真实测试。日期时间显示需能区分选中时区，布局不溢出，语言切换只改文案／格式，不写账号偏好。

统计 range 的 YYYY-MM-DD、图表 UTC day、CSV、cursor、CAS token、服务端到期判断和表单 datetime-local 保持原值；不对这些纯日期／协议字符串套用 instant 格式器。到期输入须明确标为设备本地时间，避免列表按账号时区显示而编辑时无提示。公开 RedirectPage 继续原设备时区，不因账号登录状态变更公开展示。

已核 AdminAuditPage 和 features/visit-records/VisitRecordsPanel 当前可见 occurredAt 原文；本版改的是可见文本，不改 time 的 datetime 属性、原 API 对象、排序键、cursor 或 CSV。时间日期模板不能因为当前偏好选择而发起重新统计或重新导出。

## 验证与审查重点

1. 真实 PG：本人隔离、未保存／保存／清除、全部枚举、非法严格 DTO、首次及陈旧 CAS 竞争、完整版本、禁用／删除／基础权限变更、数据库故障与 Up/Down/Up；旧三类偏好与 app_user 版本不变。
2. SQLC：只通过标准1.30入口生成，完整 source/generated 集合与零漂移证据；生成输入改变才运行。
3. 前端行为先真实 RED 再最小 GREEN：当前真实页面缺时区入口或显示不随已保存值变化，不拿 missing import 当 RED。覆盖编辑 revision、失效身份、同账号重登、迟到 error/finally、冲突显式重载和设备 fallback。
4. 时间边界：UTC 午夜前后、正负偏移、London/New York 与 Sydney 不同季节 DST、语言切换、非法 instant。明确证明统计 UTC 分桶、CSV、CAS 和到期输入不受影响。
5. 完整本地受影响门禁与100%覆盖、Linux race／扫描、真实浏览器桌面／移动／中英文、独立账号跨浏览器重新登录；测试资源 finally 清理，截图保持原通知，实际输入／SHA／runtime／退出码分别留证。
6. 本地完成后唯一独立整分支终审；有效意见真实核查及必要 REDGREEN，不依靠作者自审。候选与 master 各自九项 CI、完整原文、最新真实审查覆盖和有效问题闭环，再按 match-head 守卫合并、独立 SHA/tree/父核和全新可恢复归档。
