# v0.45.0 短链列表分页设计

## 意图与取舍

用户需要找到第 21 条以后的短链。当前两个列表页面不传 page，现有客户端默认 page=1、pageSize=20，服务端已有稳定分页及 total。本版复用该协议；固定每页 20 条的前后按钮是执行者依据现有界面选择的最小增量，不增加后端、依赖或多资源写语义。

## 查询与集合身份

本人及全站页面各自 page 从 1 开始，在既有 query key 末尾追加页码，保留旧身份索引。queryFn 从捕获的 queryKey 读取请求参数，不读取后来改变的 refs。每次切页及有效筛选、身份轮次或读权限变化推进共享单调 listRevision；后者还重置 page=1。A→B→A 和重挂载不恢复旧集合或接受迟到结果。无 placeholder 旧页；换页加载、读取失败及撤权时隐藏旧记录和旧总数。同一页后台刷新沿用既有行为：保留当前表格和勾选，禁用基于列表的写入／导出并隐藏未确认总数；成功读取后按真实 ID 收敛选择，避免普通刷新丢失用户勾选。

筛选仍按原规则校验和 debounce；未应用／无效草稿期间禁止翻页，不发无效参数。page 也加入 batch.filters 和 note.reset 上下文；切页清当前勾选，不支持跨页写入或全选。

## 展示与翻页

`ShortLinkPagination.vue` 只展示与发事件，props 为 page:number、total?:number、pending:boolean、blocked:boolean、failed:boolean，emits 为 change:number、retry。固定每页 20 条，成功且非 fetching 的当前结果才显示总数和总页数；零条为第 1 页。前后按钮有翻译和可访问名称，窄屏可换行，不引入页面横向溢出。

页面处理函数只接受相邻合法整数，实时检查读权限、草稿与操作锁；下一页还须当前成功 meta 证明存在。失败时提供重试当前页与上一页，不能把不存在的 meta 当成 total=0。查询成功且结束后，若 total 缩小导致 page 超界，转到最后有效页并重读；零条转第 1 页。失败／pending 不收敛，不无限回跳。

## 操作互斥与导出

配置、二维码、转移、备注打开或加载／草稿／保存、批量创建草稿、批量确认／提交、行写入和导出期间禁翻；事件处理函数重查 live 状态，不能仅靠 disabled。批量创建组件通过同步 open 事件报告当前打开状态，不改变其草稿和提交协议。访问记录位于独立路由，不增加虚构弹窗锁。授权撤回仍按既有动作守卫执行。

CSV 继续使用已应用筛选而不是页码或当前勾选；第 2 页也导出全部匹配结果，请求不含 page／pageSize。翻页改变列表代际，因此迟到下载不可落盘，原下载预算、列和隐私边界不改。
