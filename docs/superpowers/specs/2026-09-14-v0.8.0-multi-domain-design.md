# v0.8.0 多域名管理设计

## 1. 背景与范围

MoeURL 已将 `domain_id` 写入短链，并保证短码全局唯一，但初始化后只能使用一个全局默认域名。创建流程总是读取该默认域名；部分更新响应也用当前默认域名重新拼接已有短链 URL。管理员还不能管理域名，用户不能选择域名。

本版本交付可实际使用的多域名闭环：管理员管理短链域名、指定内置用户组可用范围和全局默认值；有权用户创建时选择域名；公开访问按短链原有域名及其启用状态校验。现有短链不迁移域名，默认域名改变不改写已发布 URL。只支持受控的单机 Compose + 外部 TLS 反向代理拓扑，不自动配置 DNS 或证书。

本设计不实现系统访问域名管理、个人及用户组默认域名、自定义用户组、用户自带域名、按域名复用短码、域名所有权证明、自动 DNS/TLS、跳转模板和旧链接迁移。这些能力需要独立设计。

## 2. 方案比较与决策

1. 仅管理域名和全局默认值：改动小，但用户仍无法选域名，不能构成多域名产品闭环。
2. 管理域名、组授权、创建选择及公开域名校验：利用现有 `domain_id`，可以独立交付且安全语义明确。
3. 同时实现个人/用户组默认值、域名证明和自动 TLS：跨越用户偏好、权限、外部基础设施，扩大升级和运维风险。

采用方案 2。域名使用权限由用户组权限与域名授权关系共同决定，不为管理员或某个组硬编码放行。

## 3. 数据模型与兼容

现有 `domain` 保存 `id`、`host`、`display_name`、`purpose`、`enabled`、`is_default` 和时间戳；`short_link.domain_id` 已是非空外键。既有 `host` 常为裸主机名或带端口的 authority，`buildShortLinkURL` 对裸值默认使用 HTTPS，也支持已带协议的值。新增管理 API 接受完整根 Origin，production 仅允许 HTTPS，development 仅对回环地址允许 HTTP；拒绝用户信息、路径、查询、片段、空主机名、控制字符和不合法端口。读旧值时沿用既有 URL 构造规则，并提取规范化 authority 用于请求匹配；migration 不批量改写 `host` 或短链 URL。

新增 `domain_user_group` 关系表，以 `(domain_id, user_group_id)` 为主键并分别引用现有表。升级时把既有默认短链域名授权给内置 `user`、`admin`；`guest` 保持不可创建。服务端仅接受现有内置且可登录的 `user`、`admin` 组作为域名授权目标。组授权影响新的短链创建，不追溯撤销已创建短链。

`domain.host` 继续保持唯一；服务端在同一域名写事务中串行化规范化 authority 冲突检查，拒绝大小写、默认端口、裸主机名与完整 Origin 等同义地址的重复注册。已有不符合新输入规则的值保留、可展示但不得据此创建同义域名；管理员需要在不破坏已发布短链地址的前提下修正部署配置。新数据不引入第二套 URL 字段或隐式域名别名。

系统中始终保留一个启用的全局默认短链域名。切换默认值在一个事务内先清除旧标记、设置新标记，并更新既有 `system_setting.site.default_short_link_domain` 镜像；`domain.is_default` 是业务读取的权威来源。不能停用或删除当前默认域名，必须先选择替代值。删除只允许非默认且从未被任何短链引用的域名；有引用时引导停用，不删除历史外键。已被任何短链引用的域名禁止修改 `host`，仍可改显示名称、授权组或启用状态。

所有写入比较 `expectedUpdatedAt`，成功写入使 `updated_at` 严格递增；旧时间戳返回冲突，不做最后写入者覆盖。组授权更新、状态修改和默认切换在事务内完成，避免出现部分成功。无效值、重复规范化 authority、并发冲突、仍被引用及默认域名保护分别使用稳定业务错误。

## 4. 权限与创建流程

保留 `domain:use_default`：省略 `domainId` 创建时，必须拥有该权限，且当前内置组获默认域名授权。新增可配置 `domain:use_assigned`：显式选择域名时必须拥有该权限，且组获该域名授权。新增受保护的 `domain:manage`：只固定授予 `admin`，管理 Service 还需逐项校验 `admin:access`。默认预设中，`basic` 保持只含默认域名使用权，`standard` 包含显式选择权；既有 `user`、`admin` 仅在升级时已有 `domain:use_default` 的情况下得到显式选择权，撤过权的用户组不能因为升级自动获得新能力。

旧 `POST /api/v1/short-link/create` 请求不传 `domainId`，行为保持默认域名。可选 `domainId` 为 UUID；服务端在写入短链的同一事务中再次确认目标域名启用、用途为 `short_link`、组授权和权限，避免前端过期列表绕过规则。已保存短链的 `domain_id` 不通过短链更新 API 修改；如需新域名，创建一条新短链。所有创建、更新、列表和统计响应的公开 URL 都由该短链关联的域名生成，不再用当前默认域名重建已有链接。

`GET /api/v1/domain/available` 返回当前登录用户可选的启用域名及默认标记；没有显式选择权限时，只返回可用的默认域名。无权限或无可用域名时返回空数组，创建请求仍由服务端最终拒绝。前端只在具有多个可用选项时展开域名选择，默认情况下继续发送不含 `domainId` 的请求。

## 5. 管理 API 与前端

管理 API 使用现有 `/api/v1`、GET/POST、数字业务码和 `Cache-Control: no-store` 约定：

```text
GET  /api/v1/admin/domain/list
POST /api/v1/admin/domain/create
POST /api/v1/admin/domain/update
POST /api/v1/admin/domain/set-default
POST /api/v1/admin/domain/delete
```

列表返回 `id`、`host`、`displayName`、`purpose`、`enabled`、`isDefault`、`allowedGroups`、`updatedAt` 和是否存在短链引用。创建输入是 `host`、`displayName`、`allowedGroups` 和 `enabled`，用途固定为短链域名；更新传 `id`、可编辑字段及 `expectedUpdatedAt`；设默认和删除传 `id` 与 `expectedUpdatedAt`。服务端不相信列表中的 `referenced` 提示，写入时重查约束。敏感基础设施错误只记录安全分类，不将 SQL 或部署信息返回客户端。

新增 `/admin/domain`，并在控制台管理导航中展示域名管理入口。页面提供列表、创建、编辑、停用/启用、设默认、删除确认、加载/失败/空状态及并发冲突恢复；冲突不自动覆盖脏草稿。域名地址不可编辑时显示原因。短链创建面板展示获授权的域名，默认选择不会改变既有请求；管理列表、二维码和复制继续使用响应中的完整公开 URL。两种语言、桌面与移动端均需覆盖。

## 6. 公开访问与安全边界

`/{slug}`、公开预览、`/go/{slug}/preview`、`/go/{slug}/unlock` 和 `/go/{slug}/continue` 都以请求的真实 `Host` authority 与短链所存域名的规范化 authority 比较，并在每一步重新检查域名 `enabled`。不信任客户端提供的 `X-Forwarded-Host` 或 `X-Forwarded-Proto`。错误域名或已停用域名按短链不存在处理，不泄露目标 URL；原域名重新启用后已发布链接恢复。内部跳转保持同源相对路径，访问密码 Cookie 的既有 Path、Secure 和授权失效语义不变。

现有初始域名通常是裸 authority，生产 TLS 仍由代理终止；上线检查必须确认代理保留正确 `Host` 和端口，并为每个公开域名配置 DNS、HTTPS 证书及到同一 App 的路由。旧部署若使用与已登记域名不同的别名访问短链，新版本会拒绝该别名；升级前应列出并验证实际公开地址。Compose smoke 与 Playwright 初始化数据应使用能与其请求 authority 匹配的域名，不能通过放宽生产校验掩盖配置错误。未验证的公网域名不得在文档中宣称可访问。

## 7. 测试与验收

- migration：Up、旧数据授权回填、约束、Down、再次 Up；回滚不得删除现有域名或短链，新增权限仅在未被管理员改变时撤回。
- 领域与数据库：Origin 规范化、同义冲突、权限交集、默认切换及并发、组授权更新、不可变地址、引用删除保护、创建和停用竞争。
- 路由：正确 Host、错误 Host、停用/重启、带端口及裸旧 host、密码/中间页/确认页各公开路径均执行域名约束，登录和 OIDC 固定路由不回退。
- 前端：严格响应 schema、选择器默认兼容、保存和冲突、删除确认、权限变更、双语、双视口；不依赖请求顺序或固定等待。
- E2E：管理员创建第二域名并授权 `user`，用户选该域名创建真实短链，从该 Host 访问并计数；改变全局默认不改已有 URL；错误 Host 与停用拒绝，重新启用恢复；清理隔离测试资源。
- 门禁：Go 全量、vet、目标业务覆盖率、SQLC 零漂移、前端测试/覆盖率/lint/typecheck/build、Playwright 全量及 Compose smoke。目标 CI、race、安全扫描和真实 DNS/TLS 的验收证据与本地结果分开记录。
