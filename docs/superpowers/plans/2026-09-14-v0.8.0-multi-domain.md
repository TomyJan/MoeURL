# v0.8.0 多域名管理实现计划

> **面向 AI 代理的工作者：** 按 `superpowers:executing-plans` 内联执行，每项使用复选框跟踪；测试先红后绿，完成一个独立切片即本地提交。

**目标：** 让管理员管理并授权多个短链域名，用户创建时选择可用域名，公开访问只在短链所属的启用域名生效。

**架构：** `internal/domain` 负责 Origin 校验、域名管理和授权查询；SQLC 管理 `domain_user_group` 与原有 `domain`。`internal/shortlink` 从创建到公开访问使用保存的 `domain_id`，Router 将真实请求 `Host` 传入公开 Service。前端以 TanStack Query 管理域名列表与表单草稿。

**技术栈：** Go 1.26.8、Chi、SQLC 1.30.0、Goose、PostgreSQL、Vue 3、Vuetify 4、TanStack Query、Vitest、Playwright。

## 文件职责

- `migrations/00013_multi_domain.sql`：用户组授权关系、权限回填和可逆性跟踪。
- `queries/domain.sql`、`queries/short_link.sql`：域名管理、选择、权限及公开路径的 SQLC 查询；`internal/db/sqlc/` 由生成器负责。
- `internal/domain/model.go`、`validation.go`、`service.go`、`handler.go`：域名输入输出、规范化、业务事务和 HTTP 契约；各自有同名 `_test.go`。
- `internal/permission/permission.go`、`catalog.go`：两项新权限和预设；权限测试及前端目录快照同步。
- `internal/system/service.go`：首次初始化时给 `user`、`admin` 授权新建的默认域名；对应初始化事务测试。
- `internal/shortlink/model.go`、`service.go`、`redirect_service.go`、`redirect_handler.go`：创建选择、旧 URL 保持和 Host 校验；对应测试覆盖每条公开路径。
- `internal/app/app.go`、`internal/http/router.go`：装配 Domain Service 与固定 API、静态页面路由。
- `web/src/entities/domain/api.ts`、`web/src/pages/AdminDomainsPage.vue`：严格 Schema、域名管理 UI；对应 API 和页面测试。
- `web/src/entities/short-link/model.ts`、`web/src/features/short-link-create/ShortLinkCreatePanel.vue`：可选 `domainId` 与创建选择；对应前端测试。
- `web/src/app/router.ts`、`i18n.ts`、`web/src/widgets/console-shell/ConsoleShell.vue`：管理员入口、双语和导航测试。
- `web/e2e/v0.8.0-multi-domain.spec.ts`、`scripts/compose-smoke.sh`：真实双 Host、默认切换和公开访问回归。
- `docs/product/scope-v0.8.0.md`、`docs/specs/domains.md`、`docs/implementation/v0.8.0-{plan,tasks,acceptance}.md`、部署手册、技术基线、索引与 README：版本边界、升级检查及实证记录。
