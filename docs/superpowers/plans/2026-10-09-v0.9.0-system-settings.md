# v0.9.0 系统设置与站点品牌基础闭环实现计划

> **面向 AI 代理的工作者：** 按 `superpowers:executing-plans` 内联执行；每个行为变更先写测试并确认红灯，再实现最小代码、运行定向验证并原子提交。

**目标：** 交付可并发安全更新的站点品牌、默认语言和主题、简单页脚与本地登录开关，并把 OIDC Provider 管理纳入统一的系统设置权限和页面。

**架构：** `system_setting` 保存设置，以 `site.settings_revision.updated_at` 提供统一乐观并发。`internal/loginpolicy` 负责登录入口不变量和共享锁序；`internal/system` 负责公开配置与管理设置 API；Auth 和 OIDC Service 只依赖最小策略接口。前端用 TanStack Query 管理服务端设置，本地语言和主题选择继续保存在浏览器。

**技术栈：** Go 1.26.8、Chi、SQLC 1.30.0、Goose、PostgreSQL、Vue 3、Vuetify 4、TanStack Query、Vitest、Playwright。
