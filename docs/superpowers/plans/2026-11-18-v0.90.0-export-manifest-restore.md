# v0.90.0 导出清单恢复实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 executing-plans 逐任务实施本计划。步骤使用复选框（`- [ ]`）语法跟踪进度。

**目标：** 从固定 MoeURL 短链管理清单安全、原子地重建最多 100 条当前账号所有的短链和可重建配置。

**架构：** 浏览器用单独的严格 17 列 CSV parser 在本地解析并显示损失边界；用户确认后通过新的严格 JSON POST 提交。Go Service 在一个 5 秒 `WithAuditTx` 内重新验证当前账号、字段权限、目标安全策略、每日创建配额、domain origin 授权和短码唯一性，随后原子写入记录、审计和已有创建回执。

**技术栈：** Go 1.26.8+、Chi、PostgreSQL、SQLC 1.30.0、Vue 3、TypeScript、Vuetify 4、Vitest、Playwright；不新增依赖。依据 100 行用例的真实失败裁决增加 migration 00048，仅扩展既有回执数量约束。

**规格：** [产品范围](../../product/scope-v0.90.0.md)；[设计](../../specs/2026-11-18-v0.90.0-export-manifest-restore-design.md)。实现前必须同时阅读两份。

## 执行约束修正（2026-11-19）

用户澄清允许自行安装／更新必要依赖；原“不安装依赖”和缓存 runtime 无效的规则由 Agent 误写，现修正。新增恢复生产文件必须纳入业务覆盖率目标；先补可测试边界及真实读写故障，再依技术基线精确记录八个基础设施／模型不可达排除，不能通过遗漏新文件伪造 100%。真实 E2E 在实现后补跑，无实现前浏览器行为 RED 证据；保留该历史顺序，不把 setup 失败冒充 RED，原 parser／hook／组件及回执容量的真实 RED→GREEN 仍有效。

## 全局约束

- 17 列固定顺序、源 CSV ≤ 8 MiB、每文件 1–100 行；JSON 请求 ≤ 1 MiB。
- 新路径仅 `POST /api/v1/short-link/manifest/restore`；JSON 成功／业务失败遵守统一 code envelope 与 `no-store`。
- 服务端 Cookie actor 是唯一权限权威；`X-MoeURL-Expected-User-ID` 只绑定浏览器已捕获身份。
- 只创建当前 actor 的新记录；复用现有 `short_link:create_own`、字段权限、域名权限、创建配额、目标策略、审计及回执表。
- 所有行均成功才提交；任何权限、domain、quota、target-policy、验证或 slug 冲突均零写入；软删除短码不可复用。
- `id`、原 owner、时间戳、访问事件、`visits_used`、密码不恢复；新 ID／时间／当前 owner，访问用量为 0，密码启用行整批拒绝。
- 不改既有导出和 CSV 网址导入行为，不引入依赖；migration 00048 的回执容量扩展不改变旧协议的 20 条上限。避免非必要安装，必要依赖／工具可自行安装或更新；不查询 CI、不发布／部署，不碰 PR #240／#266／#267。
- 保持 Go 业务覆盖率与前端四项覆盖率 100%；排除严格遵守技术基线的最小不可稳定触发／数据模型不可达语句块，不排除可测试行为；SQLC 使用 `sqlc.yaml` 锁定配置并零漂移。
- 大型验证前按仓库临时预算脚本盘点全部受控 `.tmp` 根及 Docker 可回收缓存；只清理本任务自有资源。

## 审查重点（Review Focus）

1. **任意行的 slug/domain 冲突：** 活动或软删除 slug、任一行不获当前 origin 授权、任一行冲突或后半批写入失败，都必须让 100 行内整批零写入；真实 PostgreSQL 测试核对短链、审计、配额与回执。
2. **短链生成与访问权限分离：** 默认 origin 使用默认域名权限，非默认 origin 使用分配域名权限并校验 group grant；任何缺字段权限、disabled 行缺 `update_own` 或账号禁用均拒绝，真实 actor 测试覆盖撤权／改组。
3. **目标安全和 quota：** 恢复仍执行现存目标 deny／allow policy 和每日创建上限；真实数据库回归确保拒绝不消耗 quota、不留下部分链接。
4. **秘密／历史误回填：** 任意 `password_enabled=true` 行使文件整体拒绝；`visits_used`、旧 owner、ID、时间戳和事件从不进入创建请求或写入。
5. **CSV 与安全字符串边界：** 恶意／错列／公式中和文本不能自动反转、跳行、造成公式或泄露到错误/日志；精确 CSV 和 JSON 预算边界有自动测试。
