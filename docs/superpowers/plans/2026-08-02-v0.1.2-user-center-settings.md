# v0.1.2 个人设置基础闭环实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 在既有控制台 Shell、登录态和前端偏好系统之上，补齐个人设置页与当前用户昵称自助修改，让登录用户可以查看账号信息并编辑自己的基础资料。

**架构：** `auth/me` 继续作为当前账号读取入口，`internal/user` 新增一条自助昵称更新查询和服务方法，Go HTTP 层暴露个人资料更新接口。Vue 侧新增 `/profile` 页面，复用现有 `PreferenceSwitcher`、账号查询和控制台导航，让昵称保存、语言/主题偏好和快捷入口保持一致。

**技术栈：** Go 1.25、Chi、SQLC、PostgreSQL、Vue 3、TypeScript、Vuetify 4、TanStack Query、vee-validate、zod、vue-i18n、Vitest。

- [ ] **步骤 3：实现最小 SQLC 查询**

在 `queries/user.sql` 中新增只更新当前用户昵称的查询：

```sql
-- name: UpdateOwnAppUserNickname :one
update app_user
set nickname = $2,
	updated_at = now()
where id = $1 and deleted_at is null and builtin = false
returning id, username, password_hash, nickname, group_id, status, builtin, created_at, updated_at, deleted_at;
```

生成后在 `internal/user/service.go` 中新增自助更新方法，直接复用现有用户摘要映射。
