# v0.61.0 目标主机精确黑名单

状态：设计已收敛，尚未实现或验收。基线 master `1cad579cabcd6253095eff5556adafc636662b88`，分支 `feat/v0.61.0-target-host-denylist`。前版 v0.60.1／PR306 已完整交付；本版单独验证、审查和交付，不借前版结果。

## 目标与盘点

落实路线图中目标域名黑白名单的第一个有界增量：管理员可限制今后保存到指定 DNS 主机的新目标。默认空列表保持原行为。

| 能力与来源 | 当前状态与本版取舍 | 影响、验证与风险 |
| --- | --- | --- |
| roadmap 目标域名黑白名单 | 未实现；纳入精确主机黑名单 | 后端全部目标写入、前端管理卡片、新设置与审计；真实 PG 及浏览器；并发风险高 |
| 白名单、后缀、通配符、IP／CIDR | 未实现；不纳入 | 避免优先级与误封语义，不建接口或占位 UI |

| 历史公开访问与配置编辑 | 已实现；保留 | 不改变 open／preview／unlock／continue；原目标字节不变时允许其他编辑 |
| 外部信誉、DNS 检测、举报或自动审核 | 远期能力；不纳入 | 不增加请求、依赖或服务，不宣称完整反滥用或 SSRF 防护 |

## 必须实现

- 当前有效管理员维护独立 `security.target_host_denylist`，0–100 个完全相同的 DNS／有效 ACE 主机。`example.com` 不包含 `sub.example.com`；端口、scheme、路径、查询和片段不影响匹配。
- 管理员输入只接受 ASCII host，先拒控制字符再 trim，小写、可移除一个终止点；每项 1–253 字节、标签 1–63 字节，规范重复整体拒绝，成功按 ASCII 排序。禁止 URL、端口、userinfo、Unicode 原文、空标签、通配符、IP 和数字式尾标签。
- 新建单条及四种批量创建、本人／管理员实际改变目标都受限，无管理员绕过。省略目标或与锁内原目标字节相同不触发新策略；改路径或查询也算新目标。
- 批量一项受限整批拒绝，无链接、成功审计或回执残留。当前身份授权之后，相同内容的已提交回执优先恢复，异内容仍冲突。
- 独立 GET／POST 管理 API、严格完整 JSON、完整精度 CAS、五秒事务、仅键名审计、坏存储与缺行失败关闭。不扩旧设置 DTO 或公开配置。
- 事务共享／排他 gate 最先取锁，保存后才进入的目标写入必须看到新策略。真实 PG 验证队列、撤权、取消、审计回滚和双 CAS。
- 独立管理卡片、身份隔离草稿、冲突保留与显式重载。所有受限写入显示明确双语错误且保留输入；旧 unknown 批次不能因后来的确定拒绝清除不确定性。

## 非目标与交付

不更改历史访问，不做白名单、通配符、IP 规则、DNS 解析、服务端抓取、配额或权限新增。本版不新增依赖；已有依赖按锁更新已获授权。旧应用回退不执行新写入策略，不能声称跨旧应用仍生效。

本地验证、唯一独立整分支终审、最终 head 真实 CodeRabbit、正常合并独立核验、标准任务和可恢复归档分别完成后才验收。不查或等待 CI，不发布部署，不碰 PR240／266／267、18080、日常数据库或未知资源。
