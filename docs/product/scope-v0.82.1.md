- 保留初始化或场景原错，以及逐个删除、禁用和关闭的所有错误；某步失败不得跳过后续清理。不重试业务写入，不把失败转换为成功。
- 测试专用模块承载实际 fixture 生命周期，原 spec 直接消费。用真实资源状态及受控外部失败证明 context 初始化失败、清理同时失败、假值拒绝、无账号和正常路径；不检查源码字符串冒充行为验证。
