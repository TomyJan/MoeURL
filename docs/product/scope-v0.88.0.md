# v0.88.0 自定义 CSV 完整字段映射

## 当前阶段

本版实施中。基线为 PR378 合并提交 `5b9017da3ab62194fa4834e55d0505f8b768f893`，产品仍为 0.87.0；准确实现、验证、审查和交付状态见[计划](../implementation/v0.88.0-plan.md)及[验收](../implementation/v0.88.0-acceptance.md)。

## 目的

自定义表格已经能手动选网址、标题和标签列。本版让用户也能明确映射其余五种既有标准字段，避免为导入而重命名列，同时保留显式选择、不猜列名和原有授权边界。

## 必须实现

- 网址必选；标题、标签、自定义短码、跳转方式、过期时间、最大访问次数和中间页倒计时均可选。一个源列最多映射一个字段，选择必须是有效且互异的整数索引。
- 只投影明确选择的列。未选择列的表头和数据不做值校验、不展示样例、不进入预览、日志、请求或错误信息；真实数据行宽仍严格等于表头宽度。
- 按最高已选标准字段复用现有八种创建协议。缺失的前序字段补既有缺省；已选字段即使为空也不降低协议或结构权限。非法的已选值拒绝整批，不静默纠正。
- 保持严格 UTF-8、单个开头 BOM、1–8 列、1–20 条数据行、CSV 本体 65536 字节和完整请求 JSON 65536 字节上限。
- 逐字保留 URL、标题、短码及设置值；沿用标签 JSON 字符串数组、现有日期／整数／倒计时 schema 和原八个 API。非空倒计时必须显式映射为 `intermediate`，不得从倒计时推断跳转方式。
- 复用现有身份、文件序号、草稿版本、权限轮次、失败保留、不可变请求及未知结果重试保护。文件读取、映射、应用或提交期间发生撤权／换号／新文件时，迟到结果不得恢复旧授权或覆盖新状态。
- 保留当前三个映射控件，新增其余字段的高级区域；默认不选、不猜别名。桌面与窄屏上均可操作，文案和安全错误提供中英文版本。补齐 v0.87.0 延期的英文标签格式提示。

## 非目标

不改后端、API、数据库、权限目录、依赖、标准 CSV、八份模板或现有协议；不做表头别名、未知列自动忽略、Excel、文件上传、历史恢复、部分成功、自动重试或通用映射框架。

## 影响与风险

| 领域 | 变化 | 主要验证 |
| --- | --- | --- |
| CSV 解析 | 映射其余五个字段并复用已有分发 | 八协议显式结果、全部字段子集、非法索引与真实宽度 |
| 授权 | 前端按结构协议及非空值意图复核现有权限 | 读中／暂存后撤权、恢复与换号，direct-only 不受无关权限影响 |
| 隐私与重试 | 仅保留选择投影，维持深冻结和同请求重试 | 未选敏感列不外传；完整 JSON 边界；同 UUID／payload／账号头 |
| 界面 | 五个高级选项和延期文案 | 双语组件及真实桌面、390px 手机操作可达性 |

版本不包含远程 CI、正式发布或部署验收。
