# v0.84.0 复制所选 Markdown 清单

状态：设计已收敛，尚未实现；基线为 PR369 的 master `e2dd5b0fef23133a16ab1afbc845b5eff9d447e9`，已交付产品为 0.83.1。各阶段见[验收](../implementation/v0.84.0-acceptance.md)，不查询 CI，不发布部署。

## 盘点与取舍

| 能力／来源 | 当前状态 | 本版决定 | 后端／数据库 | 前端与测试 | 风险 |
| --- | --- | --- | --- | --- | --- |
| [所选公开地址复制](scope-v0.79.0.md) | 已交付，读权限、当前页 1–100 条 | 保持原行为 | 不变 | 回归原纯网址及整页复制 | 低 |
| [清单 CSV 导出](scope-v0.21.0.md) | 服务端重查导出权限和完整快照 | 保持，不从浏览器缓存拼 CSV | 不改独立导出授权 | 原入口保持 | 中，避免弱化导出权限 |
| 当前所选标题与公开地址组成 Markdown 清单 | 未实现 | 纳入，方便粘贴到文档／讨论 | 不新增读取 | 精确字符、选择、身份和真实剪贴板 | 中，格式注入或复制错集合 |
| 所选管理清单导出、恢复与跨页选择 | 未实现 | 本版不纳入，需要独立服务端范围 | 不扩接口 | 不假装本地复制是管理清单导出 | 高，授权和恢复语义 |

Agent 根据持续自主授权选择此更小的交换增量。与新增所选 CSV 接口相比，它只整理已授权读到的标题和公开地址，不复制目标网址、备注、所有者或其他管理字段，不绕过 `short_link:export`。

## 必须实现

- 本人／全站列表的选择工具栏增加“复制所选 Markdown”／“Copy selected Markdown”，保留现有纯网址复制、整页复制和 CSV 导出。
- 仅当前成功、空闲、未失效页面的 1–100 个非空唯一 ID，全部存在才可复制；按列表顺序，每条为 `- [标题](<公开地址>)`，空标题回退公开地址，LF 分行且无尾随换行。
- 标题的 Markdown 标点和 HTML 边界转义，`&` 保持字面含义；目标仅为公开 `url`，对目的地址中的反斜杠、尖括号和空格作百分号编码。标题的控制字符或 Unicode 行／段分隔符、非法 URL 或不完整选择整体拒绝，不静默丢弃。
- 沿用当前读权限与实时身份／缓存／筛选／选择／卸载守卫；新旧三个复制入口共用所有权锁。Clipboard 在直接点击栈调用，迟到反馈和旧 finally 不影响新操作；已接受的系统复制无法撤销，不自动重试。
- 中英文、键盘、1280px 桌面和 320px 手机可达，无横向溢出。真实原生剪贴板成功和受控拒绝分别验证。
- 无 API、权限、数据库、SQLC 或依赖变化。现有准确后端证据保持原归属，新前端执行完整本地门禁、准确产品与浏览器验证；最终真实 CodeRabbit、正常合并独立核验和可恢复归档分别实证。

设计见[规格](../specs/2026-11-16-v0.84.0-selected-markdown-design.md)，执行见[计划](../implementation/v0.84.0-plan.md)。资源上限和用户模型成本要求继续有效。
