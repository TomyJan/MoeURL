## 目标与版本选择

补齐[管理规格](../specs/admin.md)已经提出的内部备注，用于记录短链用途和交接信息。既有标题、标签、本人和全站标签查找已交付；本版选择单链接备注这个有界增量，不扩大集中标签治理或批量导入。

## 必须实现

- 既有短链的内部纯文本备注，最多 1000 个 Unicode 码点；允许换行与 TAB，空串清空。打开独立入口后读取，支持只读查看、编辑、保存及明确冲突恢复。
- 本人读取需 `short_link:read_own` 和当前归属，写入还需 `short_link:update_own`、`short_link:set_metadata`。全站读取需 `admin:access`、`short_link:read_all`，写入再需 `short_link:update_all`、`short_link:set_metadata`。按能力支持自定义组，不新增权限或授权。
- 官方客户端固定身份请求、独立备注版本、事务内当前授权、同值 no-op 和原子审计；没有自动写重试。读取／保存所有异步结果受账号、权限、资源与打开轮次保护。
- 备注随资源转移；UI 明示“备注会随短链转移，请勿填写密码”。软删保留存储，但管理端点拒绝读写。旧设置不改备注，备注不改旧 `updated_at`。
- 中英、桌面／手机、长文换行、键盘可用，真实浏览器及精确产品验证；迁移 Up／Down／再 Up、安全拒绝有内容回退。

## 非目标与交付边界

不在创建、主列表 DTO、公开 Preview／跳转、CSV、统计、标签目录或日志中加入备注；不增加备注搜索、批量编辑、Markdown、HTML、附件、历史、加密保险箱、依赖或公开路由。不承诺撤销已经合法完成的读取，也不增加跨会话实时广播。

沿用既有分层、Cookie Session、Goose／SQLC 与 Vuetify。每阶段实际门禁、最终候选真实审查、候选及 master 各自九 CI、完整原始证据和可恢复归档分别判定。见[设计](../specs/2026-11-03-v0.43.0-internal-link-notes-design.md)、[计划](../implementation/v0.43.0-plan.md)与[验收](../implementation/v0.43.0-acceptance.md)。
