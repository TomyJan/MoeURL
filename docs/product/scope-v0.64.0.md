## 必须实现

- 管理员设置统一的每账号每日上限：`null` 表示无限额，整数 `0`–`1000000` 表示上限；`0` 禁止新的创建。所有可创建账号包括管理员适用同一规则，既有权限仍独立判断。这是 Agent 为缩小首版边界所作的决定，不代表用户指定了分组方案。
- 单条与四种批量创建统一计量，成功创建、审计、用量及批量回执同事务；失败不扣，整批不部分成功。
- 按原创建账号记账；软删除、转移、禁用、改组或临时关闭上限均不退款、不重置。无限额期间也记录用量，重新启用立即使用当天真实累计值。
- 取数据库 UTC 日；每账号最多一条计量行，先锁行再取日期，正常换日重置，数据库日期倒退安全拒绝。既有链接的访问及两种目标编辑完全不扣创建配额。
- 独立完整版本、CAS、当前身份双权限、键名审计、no-store、严格 JSON；独立卡片、中英文反馈和异步身份隔离。
- 本地完整必要门禁、准确产品与真实桌面／手机浏览器、唯一独立终审、最终提交真实 CodeRabbit、正常合并独立核验及可恢复归档。

## 非目标与兼容

不新增依赖、权限、公开配置字段或固定前端路由，不扩旧 strict DTO，不追溯迁移前、旧应用或混合版本运行期间的创建。该配额是应用级账号约束，不承诺阻止绕过应用直接写数据库。回退旧应用不执行新配额，必须明确维护窗口；本版不发布或部署。
