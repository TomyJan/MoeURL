## 必须实现

审查发现的卸载重建、范围往返旧缓存和跨 UTC 午夜日期偏移已统一修复，并补齐父聚合身份隔离。原完整门禁候选 `721206c` 的前端、68 项 E2E、production smoke、镜像扫描和证据 ZIP 保持历史归属；当前实现候选 `e476f87d` 包含权限集合审计修复，修复后后端门禁与定向复审通过，前端、完整浏览器及镜像门禁尚未重跑，详见 [验收记录](../implementation/v0.18.0-acceptance.md)。本页定义的安全范围保持不变。

- 管理员全站仪表盘：有效用户／短链数量、启用数量、UTC 今日新增短链／访问量、所选区间访问量、连续日趋势及热门短链。
- 单短链访问明细：个人只能查询自己的未删除短链，管理员按管理权限查询；展示成功跳转事件的时间、来源主机、设备、浏览器／系统类别和可选国家代码。
- 所有日期查询沿用近 7／30／90 天或最长 90 天的自定义 UTC 日期范围。明细及审计使用有界游标分页，拒绝无效、重复及相互矛盾的参数。
- 新权限 `statistics:read_all`、`audit:read` 固定保护在 admin；`short_link:read_visits` 可配置，user／admin 默认拥有，standard 预设包含。仍叠加既有个人／管理读取权限，不按组名绕过检查。
- 审计覆盖短链创建、编辑、启停、软删除和批量变更，用户创建／资料／状态／凭据变更，内置组权限修改，域名及授权／默认变更，系统设置和 OIDC Provider 管理。记录操作者、资源、动作、UTC 时间与变化字段，成功变更和日志在同一事务提交。
- 管理员审计页按 UTC 日期、操作者 UUID、资源类型和动作筛选，提供下一页／返回前页、加载、空、失败重试及无权限状态。
- 中英双语、桌面与移动布局、直接打开／刷新、退出／换号／撤权时的私有数据隔离；完整有效测试、覆盖率、SQLC 及浏览器验证。

## 隐私、保留与安全

不采集原始 IP、完整 User-Agent、完整 Referer、目标 URL 查询、访客账号或持久访客标识。浏览器／系统仅从当前请求归类为有界名称，不保留版本；旧事件无新字段时显示未知。既有成功访问事件及聚合口径不变，不为了增加明细删除历史事件或降低全生命周期统计。事件仍尽力异步写入，丢弃或失败不阻断跳转，页面明确其不等于唯一访客数或目标加载成功。

审计不得包含密码／哈希、会话／授权 Cookie、OIDC Token／Secret／subject／email、请求体、完整目标地址或配置值。以资源 ID 和变更字段追溯，不保存敏感前后值。新审计保留 180 天，读取时排除过期记录，后台定期有界清理；不提供审计编辑／删除 API，不声称抵抗数据库管理员篡改。

## 不纳入

原始访客数据、跨站追踪、唯一访客统计、实时流、任意时区／超过 90 天区间、访问明细及审计导出、外部 SIEM、分布式监控、审计密码学签名、自动风险审查，以及登录失败／会话刷新等独立安全事件中心。低风险语言／主题偏好与后台清理不计入关键业务变更审计。
