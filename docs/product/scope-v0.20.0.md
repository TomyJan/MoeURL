# v0.20.0 短链归属转移

## 目标与状态

基于主分支 `c08b67b2`（PR #211 已合并的 v0.19.0），补齐原管理后台规划中的「修改短链所属用户」。本版处于设计和开发阶段，未合并或发布；实际验证见 [验收](../implementation/v0.20.0-acceptance.md)。

## 必须实现

- 管理员从全站短链列表将单条未删除短链转移给指定的有效 user／admin 账号，按准确用户名指定接收人。
- 沿用 `admin:access` 与 `short_link:update_all` 权限交集；事务内重查当前操作者、接收人和权限，不信任旧身份快照。
- 使用列表返回的完整精度 `updatedAt` 乐观并发；冲突拒绝覆盖，同一所有者无变化。
- 只改变 owner_id 和版本；原地址、目标、状态、访问配置、密码授权、额度和匿名历史事件保持不变。历史统计归当前所有者查看，原所有者立即失去后续个人管理访问。
- 转移与既有 owner_id 白名单审计同事务；审计失败不能留下部分转移。
- 中英双语确认对话框、失败保留输入、冲突重新选择，身份切换与迟到响应隔离，桌面和手机真实流程。

## 非目标

不实现用户主动赠送、接收审批、批量转移、域名迁移、跨页选择或新的用户组／权限模型。接收人没有域名创建权限不影响接收现有短链，管理仍按其当前权限判断，不授予额外能力。

规格见 [设计](../specs/2026-10-23-v0.20.0-link-ownership-design.md)，执行见 [计划](../implementation/v0.20.0-plan.md)。
