# v0.56.1：四列 CSV 导入提示

状态：正式设计，尚未完成本版交付。基线为 PR294 已独立核准的 master `35b5b2bd703a87492c1185061c81fa526cfe94f4`。本版接续前版明确延期的两项提示问题，不倒填原 PR 的修复状态。

## 范围

- 中英文常驻帮助和无效 CSV 提示说明全部四种固定格式，包括 `target_url,title,tags,custom_slug`、空短码随机、文件与完整请求分别最多 64 KiB。
- 四列模式首次确定拒绝时，分别说明短码已占用（200101）或系统保留字（200102），提示原草稿保留、整批未创建，可修改后重新预览或留空随机。
- 未确认的旧写入优先于后续拒绝，继续显示未知结果并锁定原账号、接口、编号和内容；不能声称整批未创建。旧三种模式和回执冲突提示保持原有分类。

不改 CSV 语法、后端、权限、事务、数据库、生成物或依赖，不做导出清单恢复。不查或等待 CI，不发布部署。
