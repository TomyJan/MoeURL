# v0.80.1 访问配置操作可达性

Agent 在持续自主授权下选择此有界改进，基线为 PR360 已交付 master `533a3ce2485cfb2366ebb0ee26e153ee8419d61a`。Task1 已标准完成；真实几何 RED、最小布局、完整本地门禁、准确新产品7项GREEN及可恢复清理已核。真实审查交付尚待，已交付产品仍为 0.80.0。

v0.80.0 的真实图显示长配置表单的操作和提示可能在当前截图视口之外；此前 DOM 可见断言不等于进入可见裁切区域。本版先在准确基线产品上用浏览器几何断言取得失败证据，不把截图观察直接冒作产品故障或新验证通过。

## 必须实现

- 配置正文独立滚动，保存和取消位于固定操作区；长表单在中英文 320×500、390×800、1280×900 下均可操作，无横向溢出。
- 列表暂不可写的现有提示与操作区一同保持可见，正文滚动到顶／中／底都不得遮住提示或按钮。单行目标／密码等输入可以通过正文正常滚动访问。
- 只调整表单布局，不抢焦点、不清草稿或密码、不自动保存，不改变权限、同步提交守卫、pending、退出或服务端语义。列表恢复后保留原输入并能正常保存。
- 真实浏览器按 viewport 与祖先滚动裁切的交集验证按钮／提示矩形，不用 `toBeVisible` 或样式类名代替；同时验证键盘焦点与精确 HTTP payload。
- 接续 PR360 两组文档 Minor：验收文件／目标的量词，以及计划“前一个账号／后一个账号”；记录前版真实交付并保留原执行归属。

## 非目标与资源

不新增 API、权限、数据库、依赖、通用弹层框架或错误焦点管理；不扩大到所有表单，不承诺实体手机软键盘与其他浏览器。原只读菜单、复制／QR、密码瞬态和服务端最终授权保持。本地验证、真实 CodeRabbit、正常合并及可恢复归档分开判定，不查询 CI、不发布部署。

活动 4 GiB、双临时根 12 GiB、Docker 可回收缓存 6 GiB；所有大操作先预算、串行，精确清用完的容器／卷／网络／专用镜像和缓存，保留必要证据与恢复映射。不全局 prune，不碰 PR240／266／267、18080 或日常数据库。
