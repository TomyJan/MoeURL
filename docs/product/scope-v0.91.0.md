# v0.91.0 短链跨页手动选择

## 状态与目标

当前实施中。本人和全站短链列表已完成 hook 与页面切片；其定向 54 项测试通过。完整前端测试、覆盖率、类型检查、lint、生产构建、独立最终审查和标准交付仍未完成，不据此宣称版本验收或发布。

让用户在同一筛选结果中逐页检查时保留明确手动勾选的短链，并沿用既有批量操作。完整边界见[v0.91.0 设计](../superpowers/specs/2026-11-20-v0.91.0-cross-page-selection-design.md)及[实现计划](../superpowers/plans/2026-11-20-v0.91.0-cross-page-selection.md)。

## 必须实现

- 本人及全站分页列表保留用户跨页手动选择，最多 100 条。
- 页头全选和半选只反映当前页；全选添加当前页 ID，取消只移除当前页 ID。
- 同页成功刷新只剔除该页刷新前存在、刷新后缺失的选中 ID；换页读回不清除其他页所选项。
- 筛选、身份／登录轮次或权限集合变化清空选择及删除确认快照。
- 100 条后仍可取消已选行；未选行禁用，底层拒绝任何超限新增。
- 超限当前页全选整体不生效并显示本地化提示，不静默截断或部分选择。
- 复用当前动作授权、最多 100 条批量 API 与服务端原子语义；操作失败仍按既有规则处理。

## 不纳入

跨页全选、全选全部筛选结果、跨筛选保留、持久化选择、部分成功、API／数据库／权限／依赖改动，以及 CSV 或服务端批量事务变化。分页期间并发增删不形成跨请求快照。

本地验证不替代 CI、生产验收或发布；本轮不查 CI、不发布部署。
