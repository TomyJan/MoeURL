# v0.67.0 目标 DNS 后缀黑名单

状态：前后端实现与本地门禁通过，Task1 已标准完成，Task2 标准收口进行中；准确提交产品、真实浏览器、审查及交付待执行。基线为 PR320 已核准 master `d8ebceb7865272b8d2163eb4c73a61694f53c09a`；分支 `feat/v0.67.0-target-host-suffix-denylist`。源码版本为 0.67.0，准确提交产品尚待构建，未发布部署。

## 目标与选择

落实路线图中域名后缀规则的有界增量，让管理员一次限制某个 DNS 主机及其全部子域的新目标写入。该范围由 Agent 在长期自主开发授权内选择；复用现有 DNS 校验和事务边界，不增加外部服务或授权层。

| 当前能力或候选 | 本版取舍 | 影响与验证 |
| --- | --- | --- |
| 精确黑名单、可选精确白名单已交付 | 保持原语义，新增独立后缀拒绝资源 | 三资源优先级、坏存储及真实事务队列 |
| 后缀规则尚未实现 | 纳入 DNS 自身及各层子域匹配 | 标签边界、ACE／Unicode、批量原子性 |
| 历史访问和目标不变的配置编辑 | 原行为保持 | 旧链接公开入口及锁内原文字节比较 |
| 通配、正则、IP／CIDR、DNS 探测、SSRF、外部信誉 | 不纳入 | 不增加依赖、请求或安全认证承诺 |
| 头像、自定义组、媒体上传及导入恢复 | 独立后续方向 | 不与本次策略增量混合 |

## 必须实现

- 独立 `security.target_host_suffix_denylist`，默认 `{"suffixes":[]}`，0–100 项。`example.com` 拒绝自身、`a.example.com` 和更深子域，不拒绝 `badexample.com` 或 `example.com.evil.test`。
- 管理输入沿用既有 ASCII／有效 ACE 规范：控制字符先拒后 trim、小写、至多一个终止点、253 字节和 63 字节标签界限、规范重复整体拒绝、保存排序。父子重叠允许保留，不自动删项。不使用公共后缀表，宽范围规则由管理员明确配置。
- 空列表不新增目标语法限制；非空时复用当前目标 DNS 分类，错误不能当未命中放行。IP 不由后缀规则匹配，已有 URL 校验和启用白名单的 IP 拒绝保持；目标 URL 原文字节不重写。
- 精确和后缀黑名单都优先于精确白名单。单条、四种批量、本人／管理员实际改目标均受限，无管理员绕过；批量一项受限则零链接、成功审计或回执。当前授权后先恢复同内容已提交回执，后来策略不能破坏恢复；unknown 重试状态不被确定拒绝清除。
- 独立 GET／POST、严格完整 JSON、32768 B、完整微秒 CAS、五秒事务、当前有效管理员双权限、no-store、键名审计和坏存储失败关闭。不扩旧设置或公开 DTO，不加权限。
- 共用现有 policy shared／exclusive gate，先于所有业务行锁；提交后的策略对之后进入的新写入生效。三个资源无跨请求缓存，不承诺多个独立保存原子化。
- 独立中英卡片、身份隔离草稿、编辑中不排序、冲突保留并阻写、显式重载。load／save 的 success、error、finally 均防迟到身份结果；切号、同号重登录、撤权及卸载清理旧私有数据。
- 迁移默认空，Down 保留列表、版本及历史，再 Up 不覆盖。旧应用回退不执行新规则，明确披露；SQLC 标准生成核完整零漂移。
