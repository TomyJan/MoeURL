# v0.39.0 个人默认跳转方式

## 阶段与目标

v0.39.0 已完整交付：[PR246](https://github.com/TomyJan/MoeURL/pull/246) 最终候选 `647b013fa1b04f4eb874ceb32d8df97f375c072e` 的真实审查与全部有效意见闭环；[候选九 CI](https://github.com/TomyJan/MoeURL/actions/runs/41367196539) 和合并 master `7bf680b3a487e2ad364589b79d325de15cb9e1bd` 的[九 CI](https://github.com/TomyJan/MoeURL/actions/runs/41371662994) 均成功。master 原 8 项成功，运行器失联的 E2E 单独恢复后 149 项通过；完整成功日志为保留原件的可重建组合，内容核验至 EOF，未冒九项重跑。标准 Task1–4、30 条完整裁决报告、新 whole-owned ZIP／解压全集核与准确 leaf 可恢复迁出均完成，未发布或部署。下方旧阶段保留历史归属。

让经常使用确认页或中间页的账号保存自己的创建初选，减少重复选择。方案由 Agent 依据持续自主交付授权选定，沿用原生执行和最终一次独立审查，不要求用户逐项确认。

## 必须实现

- 独立本人资源保存 `null`、`direct`、`intermediate` 或 `confirmation`；`null` 表示跟随域名。不扩大旧语言主题、时区或域名偏好的严格 DTO 与并发版本。
- 个人设置页提供独立中英编辑器：加载、失败重试、保存、清除、冲突显式重载、后台版本变化与权限撤回提示。无当前增强权限时仍可读和清除旧值，保存增强模式必须持有对应权限。
- 单条创建优先级为手动选择 → 当前有权个人默认 → 当前实际域名有权默认 → direct。域名选择层级保持原意；默认不是强制策略或授权。自动 intermediate 为 5 秒。
- 自动初选读取未知或失败不能默默冒作成功，提供重试或显式本次模式；手动选择不受默认读取失败阻塞。后台刷新不覆盖已绑定草稿；重置、创建成功或身份轮次变化重新绑定。域名切换仅重算非手动草稿。
- 独立表和精确 CAS，两端点 no-store，只以本人 Cookie 身份为目标；五秒写事务等待后复核当前有效账号、当前 builtin 非 guest 组与模式权限，版本单调递增。不存在管理员代改、自动重试写入或跨账号缓存。
- 官方浏览器读写携带预期账号请求头，后端与 Cookie 本人不符即拒绝，不按请求头选目标。本页观察到的登录轮次切换使旧任务失效；别页同账号重登仍操作同一资源，其他保存造成的旧版本由 CAS 拒绝，不承诺全站 Session 广播。
- 真实 PG／HTTP、迁移 Up／Down／Up、SQLC 标准生成零漂移、组件／QueryClient 身份竞态、完整浏览器与精确产品验证。保持后端业务及前端语句／分支／函数／行 100% 原阈值，不增加无依据排除。

## 非目标与反目标

不改旧创建 API 省略模式仍 direct、不改批量创建固定 direct、不追改已有短链，不改公开访问／统计／密码／额度。不实现用户组默认模式、强制模式、个人倒计时、模板、头像、任意时区或新权限／依赖。不得把已保存值当当前授权，不持久化个人值到访客存储。不碰 PR240、正式发布或部署。

## 完成标准

账号跨登录保留个人模式，手动与权限边界准确，旧端点及既有短链保持原语义；当前输入与实际运行时门禁可追溯。唯一独立终审及有效问题闭环、最终 head 真实 CodeRabbit 覆盖和自身九 CI 后，才守卫合并；合并提交自身九 CI、标准任务、完整报告及可恢复归档分别完成。限额按 PR 评论更新时间＋明确等待时长，到点核无 running／当前 head 无已有请求后仅请求一次。
