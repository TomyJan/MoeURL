# v0.70.0 目标 CIDR 黑名单

状态：设计，尚未实现或验证。基线为 v0.69.1／PR332 已独立核验的 master `e51ac428fe3d98793cbe337529f62d05cc88b5cc`。这是 Agent 按路线图和无人值守授权选择的增量，不代表用户逐项批准了具体设计。

## 盘点与选择

| 能力 | 当前状态与选择 | 影响与风险 |
| --- | --- | --- |
| 精确 IP、精确与后缀 DNS 黑白名单 | 已交付，保留五资源及全部旧 DTO | 新增第六资源，与原 gate 同事务读取；风险高 |
| 直接 IP 的网段拒绝 | 纳入，独立 CIDR 列表，默认空，最多 100 项 | 新迁移、独立管理接口和卡片；风险高 |
| 新目标写入、批量回执与原子性 | 沿用七个写入口和原回执优先顺序 | 受限批次不产生部分写入，风险高 |
| 历史访问、同字节目标编辑 | 不增加策略读取或追溯限制 | 旧短链和无关编辑保持原行为 |
| DNS 解析、CIDR 白名单、通配、SSRF、外部信誉 | 不纳入 | 不发起网络探测，不作通用网络安全承诺 |

## 必须实现

独立 `security.target_cidr_denylist`，默认 `{"prefixes":[]}`。0–100 个 IPv4／原生 IPv6 CIDR；控制字符先拒后 trim；前缀长度使用无符号、无多余前导零的十进制，范围 IPv4 0–32／IPv6 0–128。必须含 `/`，拒绝 URL、zone、方括号、端口和数字别名。拒绝 mapped IPv6 CIDR，需用等价 IPv4 CIDR 表达。主机位清零、IPv6 小写压缩，按规范文本排序，规范重复整体拒绝；不同长度的包含或重叠网段允许且不合并。读取不修复非规范存储。

目标只按 URL 的实际字面 IP 匹配。mapped 目标先 `Unmap`，按 IPv4 网段判断；原生 IPv6（含兼容形式）按 IPv6 判断，IPv6 `::/0` 不替代 IPv4 `0.0.0.0/0`。非空列表复用既有数字歧义／非法 DNS 分类拒绝；空列表不扩大原语法限制。基础地址禁限、所有旧拒绝策略和启用的 DNS 允许集合均继续执行，新资源不能解除任何旧限制。不解析 DNS、不跟踪跳转。

在同一持 shared gate 事务先完整验证六份存储，再做任何拒绝或允许判断。新资源保存共用 exclusive gate，先于账号、组和业务锁。七个实际写入口全部接入，无管理员绕过；当前授权后先恢复同内容已提交回执，异内容仍冲突。锁内原目标未变或省略的编辑、旧 open／preview／unlock／continue 不读新限制。

独立 GET `/api/v1/admin/system/target-cidr-denylist` 和 POST `/api/v1/admin/system/target-cidr-denylist/update`，strict 完整 JSON、32768 B、no-store、完整微秒 CAS／先 CAS 后 no-op、五秒事务和仅键名审计。管理要求当前有效非 builtin 账号、builtin admin 组及 `admin:access`＋`system:manage`；不新增权限。输入／冲突使用 `900222`／`900223`，目标拒绝仍 `200121`，非法目标仍沿用原错误。

独立中英管理卡片与旧 general form 分离，一行一网段，支持添加、删除、清空、保存和显式重载。编辑不自动清主机位或排序，保存以服务端规范结果为准。说明 `/0` 会拒绝对应地址族全部新目标，mapped 使用 IPv4 规则；不假装预览 DNS 解析结果。冲突／未知结果保留草稿并阻写，只能由当前身份接受的显式重载成功解除；切号、同号重登录、撤权、卸载及所有迟到结果隔离。

迁移 `00046_target_cidr_denylist.sql` 默认空；Down 只卸本迁移审计定义，保留内容、精确版本及历史，重 Up 不覆盖。旧应用忽略新 key，回退后 CIDR 限制失效，不能称安全等价回退。依赖不变，产品版本在前端阶段更新为 0.70.0。SQLC 使用锁定 1.30.0 标准生成入口连续两次核零漂移。
