# v0.61.1 手机访问配置布局

状态：设计完成，正式实现和验证尚未开始。基线 master `99a1d62b5e1380c26448c5b0fef893eb24d796db`，分支 `feat/v0.61.1-mobile-settings-layout`，产品目标 0.61.1。前版 PR307 已交付，原门禁保留原执行身份。

## 目标与盘点

修复前版延期 M1：英文手机访问配置的三种跳转模式被卡片裁剪，320px 下还可能引起横向焦点滚动。本人和管理员入口共用同一组件，均纳入。

| 能力／来源 | 当前状态与取舍 | 影响、验证与风险 |
| --- | --- | --- |
| 手机设置编辑器 M1 | 已复现；纳入 | 仅组件 CSS；真实内部几何、短屏键盘；中风险 |
| 保存、取消、草稿与权限 | 已实现；保留 | 原组件测试及两入口真实持久化回归；防误写 |
| 创建面板、桌面样式、后端策略 | 已实现；不扩展 | 桌面对照；后端完整输入不变时复用原证据 |
| 白名单、通配符、IP 与外部风控 | 未实现；不纳入 | 无 API、迁移或依赖变化 |

## 必须实现

- 仅在原 `max-width: 480px` 媒体查询中让跳转模式按钮组换行、自适应高度且不超过可用宽度；手机按钮高度至少 44px。
- 不缩字号、不省略按钮文字、不隐藏溢出来掩盖裁剪。英文 320×568、390×900，中文深色 390×900，以及英文桌面 1280×900，分别检查本人与管理入口。
- 检查卡片、按钮组、每个按钮及完整文字的真实几何；保存和取消可滚动、可聚焦且在视口可见。保存确认模式只发一次既有完整 payload；取消中间页和直接模式不写入，重新打开保留服务端模式。
- 保持权限、pending、草稿重置和保存逻辑；后端、数据库、依赖与构建阈值不变。
