# v0.38.0 有界批量创建

## 定位与状态

基线为 v0.37.0／PR244 实际合并的 master `617c12cc8cb07c2ea3173b8d0cc65239aec4f49c`。v0.37.0 的候选和 master 各九 CI、真实审查、标准 Task1–4 和可恢复归档已完成；未正式发布。旧结果不能替代本版验证。

Agent 根据持续自主开发授权选择这个小阶段：在「我的短链」粘贴少量目标网址，预览后一次创建。它不是 CSV 清单恢复；字段、上限和整批语义是 Agent 的设计决定，不冒称用户逐项指定。当前为设计阶段，没有功能或测试完成声明。

## 必须实现

1. 已登录非 guest 用户有 `short_link:create` 与 `domain:use_default` 时，在个人列表使用批量创建。最多 20 条、每条 1–2048 字节的可打印 ASCII HTTP／HTTPS 网址；国际化域名和路径可使用 Punycode／百分号编码。后端仍执行现有目标地址安全校验，不访问目标 URL。
2. 每行一条；界面只裁去行首尾 ASCII 空格／制表符并忽略空行，支持 LF／CRLF。重复的规范化字符串拒绝；不做 URL 语义去重。预览以文本显示序号和完整目标，不执行 HTML。
3. 全部为本人所有、随机短码、active、全局默认域名、direct、延迟默认 5 秒；无到期、密码、访问限额、标题或标签。旧单条高级创建不变。
4. 整批短链、每条事务审计和幂等回执全部成功或全部回滚。当前账号／组／默认域名授权必须在数据库事务内重查，5 秒上下文限时；随机短码碰撞只做有界重试。
5. 客户端为一个明确批次生成一个 canonical 非零 UUID。相同账号／requestId／有序网址重复提交只返回原创建数量，不产生新短链或审计；同 key 不同内容拒绝。回执持久保存 requestId、actor、SHA-256、数量和时间，不保存目标 URL／密码／令牌。
6. 网络超时等未知结果保留原批次并提供同 key 的手动重试，不自动重试写入或自动换 key；关闭／离开后可能丢失草稿与 key 必须明确提示，不能宣称刷新页面后自动恢复。成功显示数量并刷新个人列表，不做跨账号结果缓存。
7. 中英、桌面／手机、键盘可用；加载、校验、提交中、成功、冲突、权限变化和未知结果都有真实反馈。身份或权限变化清除旧数据，晚到响应不改新身份。

## 非目标

不读 CSV／上传文件，不恢复旧短码、owner、历史、密码或访问事件，不代他人创建，不新增 guest 能力、权限、依赖、后台任务、API token、远端抓取或正式部署。不改变 18080、日常数据库、PR240 和其他计划；十分钟 ACTIVE 自动任务只兜底，不删停。
