# v0.79.0 复制所选短链

状态：所选复制已实现，完整本地前端验证通过；准确产品、真实浏览器、审查和交付尚待。基线为 PR358/master `a7c3200f85d1aaa15597e1831c8f1a3bc942e3cc`，已交付产品仍为 0.78.0。本版各阶段分别判定，不查询 CI，不发布部署。

## 必须实现

- 本人和全站列表增加“复制所选短链”。仅整理当前成功页面中勾选的 1–100 个公开 `url`，按列表顺序、LF 分行、无尾随换行。保留原整页复制、单条复制与独立 CSV 导出，不读取其他页、目标网址或备注。
- 读权限即可选择和复制；选择不授予修改、标签、转移或删除权限。点击仍同步检查当前身份、授权、缓存和父级锁。
- 空选择、未知或重复 ID、失效或不完整缓存整体禁用，不静默复制交集。筛选、分页、身份或选择变化退休旧反馈；两个复制入口互斥，旧 finally 不解锁新操作。
- 中英文、桌面与 320px 手机、键盘均可用。Clipboard 在直接点击栈内调用，不自动重试；成功和受控失败分开验证，已接受的系统复制无法撤销。
- 不增加 API、数据库、权限或依赖。复用现有前端架构及准确后端证据；实现后完整本地前端门禁、准确产品和真实浏览器、最终 head 真实 CodeRabbit、正常合并核验及可恢复归档。
