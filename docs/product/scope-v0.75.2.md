# v0.75.2 批量创建错误提示可达性范围

基线为 PR345 已独立核验的 master `78228e170f89ccd2a9f59c2d7dcfcabe00854457`，分支 `fix/v0.75.2-bulk-error-feedback`。前置诊断在相同生产投影上实际检查中英 390×800、320×500：真实 200108、零写入，但四个错误提示可见高度均为 0，焦点在 BODY。诊断是现状证据，不冒修复测试通过。

## 必须实现

- 当前打开的批量对话框出现新的错误时，在 DOM 更新后将焦点及滚动位置移到该错误；兼容文件解析失败、明确业务拒绝及未知结果重试。
- 只定位当前挂载、当前打开且仍有错误的对话框。不排队遗留异步 focus，不在关闭、卸载或身份退休后移动焦点。
- 定位不改变草稿、UUID、端点、payload、权限、pending、unknown、重试或放弃语义，不自动重试或提交。
- 中英手机 390／320、桌面与长预览真实浏览器核验提示正文可见、焦点可达及无横向溢出；未知结果同批重试和明确拒绝主动修改保持。
- 产品版本更新为 0.75.2，文档区分本地实现、实际验证、真实审查和正常合并。
