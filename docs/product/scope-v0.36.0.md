# v0.36.0 账号时区显示预设

状态：2026-11-01 Task1–2 实现与本地门禁已标准完成（90674e6／070627a）；Task3 在 clean 544a0706 的完整 128 项浏览器、5 张原图实读、标准产品与精确镜像正常更新扫描已通过，两次下载失败与官方镜像恢复分别留证；唯一终审、本地标准收尾与远端交付仍待。基线为已交付 PR242 的 master 08b990d70bf30dbe54f885d0b7a3bc9490eacb89；自主持续开发授权下选择此有界增量，不代表用户逐项指定预设。

## 必须实现

- 登录账号在个人中心独立保存时间显示时区，null 跟随设备；九个固定 IANA 预设，不以固定偏移伪造夏令时。
- 本人 Cookie API、独立偏好表、当前数据库有效身份和完整精度 CAS；不串改语言、主题、默认域名及 app_user 版本。
- userId＋登录 epoch 隔离全部读取、保存、反馈与缓存；退出或换身份立即回设备时区，旧响应不得泄漏。
- 共享 Intl 格式器接入控制台短链、概览、用户、统计最近访问、组版本、审计与访问记录七处真实时间显示；明确显示时区。不支持的预设安全回设备并提示，不改保存值。
- 显式保存、后台读取不覆盖脏草稿、冲突显式重载，不自动写重试；中英文、桌面和手机均可用。

## 不在本版

不改 UTC 统计分桶及 90 天范围、纯日期参数、CSV、游标、CAS token、服务端到期判断、datetime-local 输入或公开跳转页。不做站点默认时区、管理员代改、任意时区目录、新依赖、新权限、上传或部署。到期输入明确标注设备本地时间。
