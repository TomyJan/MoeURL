状态：后端与迁移已实现，真实事务边界、完整本地 Go／业务覆盖率 100%／vet／Linux race 与源扫描已验证；管理卡片、准确产品与浏览器、真实审查及合并交付仍待完成。基线是 PR326 已独立核准的 master `fe36797f3133fe963a14e05bf320c230c7f2708c`，沿用现有隔离工作区；当前产品版本仍为 `0.67.0`。

## 目标与盘点

管理员可明确允许某 DNS 主机及其所有子域的新目标写入，减少逐项维护精确主机的成本。该增量由 Agent 在长期无人值守授权内选择，所有取舍是 Agent 的决定，不冒称用户逐项批准。

| 现状或方向 | 本版选择 | 影响与风险 |
| --- | --- | --- |
| 精确拒绝、精确允许、后缀拒绝已交付 | 保持旧 DTO，新增独立默认关闭的后缀允许资源 | 后端、迁移、管理卡片、四策略事务；风险高 |
| 精确允许不含子域 | 启用的两允许集合取并集，任何拒绝仍优先 | 必须分别证明仅命中精确项和仅命中后缀项可成功 |
| 七种目标写协议及回执恢复已实现 | 接入统一新目标检查，保留恢复顺序与批量原子性 | 锁、撤权、unknown 重试风险高 |
| 既有链接访问与原目标字节未变的编辑 | 保持原行为 | 不做访问阶段追溯封禁 |
| 通配、正则、IP/CIDR、DNS 查询、SSRF、外部信誉 | 不纳入 | 不新增依赖、外部请求或安全认证承诺 |
| 媒体上传、自定义组、导出恢复 | 后续独立方向 | 不混入本版 |

## 必须实现

- 独立 `security.target_host_suffix_allowlist`，默认 `{"enabled":false,"suffixes":[]}`。0–100 项，启用要求 1–100 项；关闭保留配置，清空不暗中关闭，关闭项不参与授权。
- 两种允许策略都关闭时不增加 URL 语法限制；有任一种启用时，目标必须为有效 DNS，命中启用的精确 hosts 或后缀 suffixes 任一集合。IP 目标拒绝。精确和后缀黑名单始终优先，无管理员绕过。
- 后缀匹配自身及 `.` 标签边界的任意深度子域，不匹配 badexample.com 或 example.com.evil.test。沿用 ASCII／有效 ACE、控制字符先拒后 trim、小写、单终止点、253/63 字节、规范重复拒绝和排序存储；父子重叠可保留。不引入公共后缀表，`com` 等宽规则须明确提示。
- 四份存储均先验证合法，包括关闭的允许策略；缺行、坏值、非法版本失败关闭，不用短路放行。目标 IDNA 分类错误不能使用部分结果，保存的 URL 原文字节不重写。
- 新独立 GET／POST、strict 完整 JSON、32768 B、完整微秒 CAS、先 CAS 后 no-op、五秒事务、no-store 和仅键名审计。当前有效非 builtin 账号、builtin admin 组、admin:access＋system:manage；旧设置和公开 DTO 不扩展，不新增权限。
- 单条、四种批量、本人／管理员实际改目标均应用规则；任一受限整批零链接、成功审计和回执。当前授权后先恢复同内容已提交回执；异内容仍冲突，unknown 重试不能被后继确定拒绝清掉。
- 四资源保存共用 exclusive policy gate，目标写共用 shared gate，先于所有身份和业务行锁；同一事务读取四资源，无跨请求缓存，不承诺多个独立保存跨提交原子化。
- 独立中英卡片，说明允许集合取并集、拒绝优先、宽规则及仅今后目标；旧精确允许卡片同步并集说明。关闭保留草稿，空启用阻写；编辑不排序、冲突保草稿并阻写、显式重载。所有异步 success/error/finally 防身份迟到，切号、同号重登录、撤权和卸载清理私有状态。
- `00044_target_host_suffix_allowlist.sql` 默认关闭，Down 只卸新审计 trigger/function，保留设置、精确版本与历史，再 Up 不覆盖。旧应用回退不执行新后缀允许规则，必须披露。SQLC 按锁定 1.30.0 标准入口生成两次核完整零漂移。
