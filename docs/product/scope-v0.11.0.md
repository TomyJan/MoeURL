# v0.11.0 短链标题与标签范围

状态：设计与实施阶段，尚未完成门禁或发布验收。

## 目标

补齐路线图中的标签和短链管理基本信息，让用户可以辨认、分类和查找已有链接。本版聚焦每条短链的轻量元数据，不建立独立标签库，不改变公开访问和统计口径。

## 必须实现

- 创建和编辑短链时维护可选标题及标签，旧数据默认为空。
- 标题最多 120 个 Unicode 字符；最多 10 个标签，每个最多 32 个 Unicode 字符。
- 使用独立 `short_link:set_metadata` 权限，内置 `user`、`admin` 默认拥有，`guest` 不拥有；`standard` 预设包含，`basic`、`restricted` 不包含。
- 我的短链和全站短链展示标题、标签，支持关键词搜索和单标签精确筛选。
- 元数据只在有权读取的管理响应中返回，不加入公开预览、跳转响应或访问事件。
- 创建、编辑、清空、撤权、跨用户隔离、筛选及 migration 往返有真实测试证据。

## 非目标

不实现全局标签库、标签重命名、标签颜色、层级、批量操作、独立备注、Open Graph、全文检索服务或访客创建能力。管理员使用现有全站读写权限，无新管理入口。

## 取舍

独立标签实体便于集中管理，但需要额外的归属、授权、删除和合并语义；自由备注只能搜索，不能精确分类。本版采用短链内的有界 `text[]` 标签和纯文本标题，在既有 SQLC 查询内完成过滤，不增加外部依赖。
