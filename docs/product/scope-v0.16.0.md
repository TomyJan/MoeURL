# v0.16.0 短链聚合统计导出

## 目标与状态

将既有统计分析提供为可下载的 CSV，服务于离线整理和表格分析。当前处于设计与实施，分支为 `feat/v0.16.0-analytics-export`，基线为 `2ec7eaa4`（PR #190 已合并 v0.15.0）。[验收记录](../implementation/v0.16.0-acceptance.md) 单独记录本地门禁、目标 CI 与发布状态。

## 必须实现

- 个人与管理分析页可导出单条短链当前已应用 UTC 日期范围的聚合统计；默认 7 天，范围仍为 1–90 天。
- 导出包含公开短链 URL、实际日期范围、UTC、区间访问量、全生命周期访问量、今日访问量、最近访问时间、每日趋势及来源／设备／国家聚合。
- 新增可配置权限 `short_link:export_statistics`，叠加既有读取与归属检查；内置 user／admin 默认拥有，standard 包含，basic／restricted／guest 不包含。
- 服务端每次生成重新授权，沿用数字业务错误、JSON envelope 与 no-store；导出不使用前端旧统计缓存。
- UTF-8 BOM、CRLF、规范 CSV 转义、公式注入防护和固定机器字段；缺失值为空，零访问仍可导出。
- 下载中的失败提示、重复操作保护、路由／登录轮次变化及组件销毁后的迟到结果隔离，桌面与移动布局和双语提示。
- 权限 migration、生成目录、真实数据库与浏览器验证、100% 业务／前端覆盖率和独立审查。

## 不纳入

访问明细、原始 IP／User-Agent／Referer、全站合并导出、批量导出、任意时区、超过 90 天、后台导出任务、XLSX／PDF、统计采集扩展和操作审计不进入本版。

## 方案取舍

直接导出浏览器缓存最简单，但无法在下载时重新检查授权；独立后台作业适合大数据但超出有界聚合需要。本版采用同步服务端 JSON 下载描述，复用现有统计服务，浏览器仅保存文件，不引入存储、队列或第三方 CSV 依赖。
