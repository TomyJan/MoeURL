# v0.67.2 Go 安全补丁维护范围

状态：实施中。隔离补丁运行时、构建配置、文档及完整后端组合验证完成；新产品兼容性与交付尚待。产品版本保持 0.67.0。

## 目标与现状

PR324／v0.67.1 已交付，主分支为 `1989e85d99ce2cdbb4ad32c4916be5316f7ea3db`；三个标准任务、最终候选真实 CodeRabbit、正常合并独立核验及 11 份文件恢复归档均完成。原 20 条裁决、16 条文案误报和两组延期 Minor 保留在原报告，不倒填历史。

本版起点 Docker 构建为 Go 1.27.3，主机后端门禁为 Go 1.26.10。官方 [GO-2026-6859](https://pkg.go.dev/vuln/GO-2026-6859) 指出 HTTP/1 的 MaxBytesReader 请求体读取与响应头并发写入可能导致崩溃；修复下限分别为 1.26.11／1.27.4。原同步调用链条件评估不等于已升级运行时，也不等于没有公告；本轮源扫描已核补丁效果，新产品另待验证。

## 边界与安全

只更新既有 Go 运行时补丁，使用官方归档与 SHA-256，隔离路径与进程环境；不改变全局工具链、系统 PATH 或旧工具链。不新增依赖、不更改 go.mod／go.sum、Node、SQLC、Goose 版本或数据规则。不补偿性修改业务代码。

Linux 实测发现 Docker 时钟倒退导致既有密码授权测试的时间前提失效；仅将该测试的初始密码修订固定为过去、撤销修订设为授权创建后 1 微秒，保留全部业务断言与生产守卫。原失败和同输入诊断保留，受影响包重新验证；不把测试修复称为业务安全逻辑变更。

不查询或等待 CI，不触碰 PR240／266／267，不发布部署。单活动 4 GiB／两临时根合计 12 GiB／Docker 可回收缓存 6 GiB；所有大型生成前预留容量，串行盘点、生成与清理，原失败、合同和必要恢复源保留。

回滚只恢复 Docker 构建版本配置和文档，不改变数据库。若新工具链不兼容，保留失败并停止签发该维护的完成结论；不得降阈值或隐瞒旧风险。
