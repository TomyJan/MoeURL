# v0.55.0：CSV 标题与标签导入

状态：从 PR291 独立核准 master `f1431100332587058e8e6f248a4d2cdaa8830185` 开始正式实施。主要实现与本地门禁已独立准备，须准确转移并逐项完成标准任务；产品构建、实际浏览器、终审和交付尚未完成。

## 目标

让已拥有元数据权限的用户一次导入网址、标题和标签，保留已有单列网址、双列标题协议。固定格式解决当前批量创建后的逐条补标签操作，不扩展为完整清单恢复。

## 必须实现

- 固定 UTF-8 三列 `target_url,title,tags`；tags 是 JSON 字符串数组，`[]` 表示无标签。正确处理 CSV 引号、JSON 转义、逗号和 Unicode。
- 1–20 条唯一网址、文件及完整请求各最多 65536 字节。标题沿用 120 码点；标签最多 10 个，每个归一化后 1–32 码点，无控制字符或重复值。
- 独立严格 `POST /api/v1/short-link/batch-create-with-metadata`，权限、原子审计和幂等回执全部沿用既有事务。旧两种 DTO 与摘要不变；三个协议共享批次编号冲突边界。
- 三列即使标题和标签都空，也要求 `short_link:set_metadata`，重放前检查当前数据库权限。
- 导入草稿与预览按普通文字展示原始标题和标签。深冻标签快照；结果未知时仅显式重试原账号、原接口、原编号和原内容。
- 迟到文件读取、账号切换和撤权不得覆盖或泄漏旧草稿；拒绝文件不丢失现有草稿。
- 三列公开下载模板、中英帮助、桌面和移动端真实浏览器验证。

## 不在范围

不做任意字段映射、17 列清单恢复、短码／身份／权限／访问条件／统计／历史／私密备注恢复；不加依赖、权限、迁移、页面或路由；不发布或部署。
