# v0.32.0 二维码外观预设范围

状态：已通过 [PR #230](https://github.com/TomyJan/MoeURL/pull/230) 合并为 `99f877094119585c4cdd510bfb046f8ade56d47d`，最终候选 `28214ef` 与合并 master 各自九 CI 成功，真实最新审查及全部有效意见闭环，标准 Task1–4 和最终完整归档均完成。未正式发布。原单元、各候选浏览器／七图／精确产品保持[验收](../implementation/v0.32.0-acceptance.md)原执行身份；不以合并结果重标本地运行。

## 目标

在创建结果、我的短链与全站短链共用的二维码对话框中，提供黑白、鸢尾蓝、森林绿三个本地外观预设。使用者可为打印或分享选择可辨识的深色二维码，预览与下载始终对应当前公开短链和当前选择。

## 必须实现

- 默认黑白；黑色 `#000000`、鸢尾蓝 `#312E81`、森林绿 `#14532D`，背景始终不透明白色 `#FFFFFF`。
- 保持 PNG、320 像素、M 纠错；所有预设使用 4 个模块的白色静区，不裁边、不加 Logo、渐变或圆点。
- 有本地化名称与选择状态，鼠标和键盘均可操作，颜色不是唯一提示。
- 选择变化立即清旧预览与下载，等待当前编码；迟到成功、失败、finally 均不得覆盖新结果。
- 关闭再打开、切换 slug 或完整 URL 均恢复黑白；不保存到账号、浏览器存储、链接或服务器。
- 编码失败提供持久错误，不能下载旧图；切换其他预设可重新编码。
- 只编码完整公开短链 URL，沿用既有 PNG 文件名。三个原入口与权限边界保持，外观变化不发产品 API、不改变链接数据和访问统计。
- 中英双语、1280×720 和 390×800，真实浏览器验证三个入口、PNG 下载与预览字节一致，逐张读取六张当前预设原图。

## 非目标

任意颜色输入、透明背景、Logo、尺寸编辑、SVG、批量下载、服务端图片存储、持久模板、二维码专属权限及移动设备扫码兼容承诺均不纳入本版。Go、SQLC、migration、DTO、依赖与公开访问路由不变。正式发布和生产部署不执行。
