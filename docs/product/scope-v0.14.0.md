# v0.14.0 范围

## 目标与状态

从主分支 `a52733cc`（PR #186，v0.13.0）推进原有统计规划，补齐按日期范围查看单条短链分析。功能已通过 PR #187 合并为 `c864ce3a`，尚未据此声明正式发布；原分支本地验证与目标环境缺口分别见 [验收记录](../implementation/v0.14.0-acceptance.md)。

## 必须实现

- 个人与管理员短链分析支持近 7、30、90 天及自定义连续日期区间。
- 日期为 UTC 日历日期，包含起止两天，自定义区间为 1–90 天且结束日不晚于今天。
- 趋势连续补零，来源、设备、国家聚合与区间访问量使用同一范围。
- 保留总访问量、今日访问量和最近访问时间的全生命周期含义。
- 保留既有权限、所属用户检查、成功跳转计量及匿名数据边界。
- 默认仍展示近 7 天；支持错误重试、字段校验、查询隔离、双语和移动端。

## 不纳入

访问明细、原始 IP、完整 User-Agent／Referer、导出、全站仪表盘、任意时区、跨设备偏好、用户组或认证变更均不进入本版。不新增 migration、权限或环境变量。

## 方案选择

| 方案 | 决策 |
| --- | --- |
| 只增加固定 30 天趋势 | 改动小，但仍不能分析某次活动的具体日期。 |
| 有界日期范围及固定快捷选项 | 采用；覆盖日常分析，限制查询区间与返回点数。 |
| 完整明细、导出和聚合仓库 | 涉及数据保留和运维策略，拆为后续版本。 |

自定义用户组、OIDC 模板和个人偏好同步仍属于原有待开发清单；本版优先完成统计模块已有数据上的实用闭环。
