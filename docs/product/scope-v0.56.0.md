# v0.56.0：CSV 自定义短码导入

状态：正式设计与实施中。前版 [PR293](https://github.com/TomyJan/MoeURL/pull/293) 已完成真实审查、正常合并、独立对象核验和可恢复归档；基线 master `cc7d03760b1d7ca78943593fe754f68ad056fad5`。准备副本验证保持原执行身份，不冒正式任务或整版已交付。

## 目标

让有权限的用户批量指定可读短码，保留单列网址、双列标题和三列标签格式。固定四列解决当前逐条指定短码的重复操作。

## 必须实现

- UTF-8 固定四列 `target_url,title,tags,custom_slug`，1–20 条唯一网址；文件和完整 JSON 请求分别最多 65536 字节。标题、标签沿用既有边界。
- 空短码表示随机；非空为 3–32 个 ASCII 字母数字，按小写保存，不 trim。保留字、归一化重复、占用或软删除短码不得退化为随机创建。
- 独立严格 `POST /api/v1/short-link/batch-create-with-custom-slugs`，每项恰有四个字段；原三个协议及其摘要不变，四协议共享账号／批次编号冲突边界。
- 整个四列协议要求创建、默认域名、元数据和自定义短码四项当前权限，即使全部短码为空。事务内检查权限先于回执重放。
- 全部短链、审计和回执原子提交；随机行预先避开本批所有指定短码，避免行顺序影响结果。
- 原文有序快照、纯文本预览小写短码或随机标记；未知结果只能按原账号、接口、编号和完整内容显式重试。撤权及迟到异步保持现有隔离。
- 第四个公开模板、中英帮助、桌面／手机真实浏览器验收。

## 不在范围

不实现任意字段映射、导出清单恢复、其他访问条件或私密备注导入；不加依赖、权限、迁移或 SQLC 查询，不发布部署。不查询或等待 GitHub CI。
