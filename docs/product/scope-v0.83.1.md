## 必须完成

- 纯网址的完整紧凑 JSON `{requestId,targetUrls}` 最多 65536 字节，含固定 36 字节合法 UUID；恰好上限接受，多一字节整体拒绝。网址仍是 ASCII HTTP(S)、每条至多 2048 字节、1–20 条且唯一；字面值、顺序和手工 ASCII trim 不变。
- 共同 schema 约束数组、手工解析、标准单列 CSV 和 API；API 在不合格时返回原本地校验错误，不发 HTTP。预览失败不生成 UUID 或快照，标准导入失败保留原草稿和模式。
- 唯一扫描器仍接受合法 65536 字节文件、拒绝 65537 字节文件；保留严格 UTF-8、CSV 语法、结构诊断和原八份模板。原高层“文件恰好上限则成功”断言须拆分，明确不同预算。
- 真实 RED→GREEN、必要完整前端四项 100%、types／lint／受影响 E2E strict／build；准确新产品 smoke／所选扫描及中英 1280／390／320 浏览器，验证超额拒绝、草稿保留、零 HTTP 和普通真实写入。
- 文档维护接续 CR-M1 九项计划复选框和 CR-L2 有效量词／并列建议。原 IR-M1、IR-M2 测试工具 Minor 保留延期，原冻结报告不回写。
