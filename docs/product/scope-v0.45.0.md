# v0.45.0 短链列表分页

## 状态与目标

本人及全站列表分页已实现，本地完整 3011 项前端测试、四项 100%、181 项浏览器、34 张相关原图与精确产品验证通过，唯一独立终审的有效问题均已修复。标准任务收尾和远端交付继续按合同推进，候选真实审查、候选／master 各自九 CI、合并与最终归档尚待，不代表正式发布。上一版 v0.44.0 已通过 PR257 完整交付，未发布部署。

## 能力盘点与范围

| 能力及来源 | 当前状态 | 本版决定 | 影响及验证 | 风险 |
| --- | --- | --- | --- | --- |
| 两页列表；现有列表 API 和客户端 | API 已有 page／pageSize／total，界面无分页 | 固定每页 20 条，上一页／下一页与成功确认的总数 | 仅前端，真实 HTTP 页面与浏览器 | 中：缓存、授权和并发操作 |
| 现有筛选、单页批量选择和内部备注 | 已交付 | 保持行为，切页清选择，筛选／身份／权限变化回首页 | 页面竞态与完整回归 | 中：旧集合写入 |
| CSV 清单导出 | 已交付 | 仍导出全部已应用筛选，页码不进请求 | 第二页导出，原 17 列与上限不变 | 中：误导出单页 |
| 备注全文搜索／批量备注 | 路线图候选 | 不纳入，不扩敏感搜索及多资源 CAS | 无后端、数据库或权限影响 | 不增加新授权面 |

支持中文／英文、桌面／手机、加载／失败／空集合及只读账号。翻页不可跨页保留勾选；页面管理弹窗、备注读取／草稿／写入、批量创建打开、批量确认／提交、转移及导出期间禁止翻页，同 tick 事件也重查互斥。Shell 单条创建沿用覆盖层，不注册分页锁。无跳页输入、页大小选择或跨页全选。

同页后台刷新保留表格和选择，批量、备注及导出沿用当前读取守卫；既有单行配置、启停、删除未统一增加读取中锁。offset 分页不承诺并发增删期间的跨请求快照。

## 边界

不新增 API、路由、Go、SQLC、schema、权限或依赖。备注正文和版本不进列表、公开响应或 CSV；不改变 CSV 的 1000 条／8 MiB／17 列合同。沿用当前授权与服务端校验，不将前端分页当安全边界。不触 PR240、日常环境，不发布部署。
