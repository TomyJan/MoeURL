# v0.28.0 用户组默认短链域名

## 目标与阶段

本轮从 PR225 的合并提交 `8c024b5035226285ea76571c8b6a50ceb2d19440` 起步，独立分支 `feat/v0.28.0-group-default-domain`。前轮最终 64751e5 的 PR CI40486914108 及合并 8c024b5 的 CI40493457478 各九成功，实际最终 CodeRabbit 已覆盖最新且有效意见闭环；这些证据只证明基线，不替代本轮。当前处于设计阶段，未实现、未执行本版门禁、未创建 PR，未正式发布。

补齐 roadmap 及 domains 规格中的组默认层：管理员为内置 user、admin 分别保存一个默认短链域名，作为没有有效个人偏好时的创建面板初始选择。所有选择仍受当前账号、主组权限、域名启用和授权交集约束。保持后端省略 domainId 仅表示提交时全局默认，不在本轮改变旧 API 客户端语义。

## 本轮必须实现

- 在用户组管理页为 user、admin 提供独立组默认编辑器；guest 明确只读、不开放创建。选项只包含该目标组当前真正可用的域名，支持清除。配置不授予任何权限。
- 创建面板顺序：仍可用的明确手动选择 → 有效个人偏好 → 有效组默认 → 可用全局默认 → v0.27 有序首项。高优先项失效时通用提示并回退，手动选择全局默认与未选择有别；不返回无权域名的名称、地址或 UUID。
- 使用 user_group 新增可空 default_domain_id 及现有 updated_at 作为同一组资源版本。独立动作只更新默认字段，旧权限动作只更新权限；共享 CAS 防止并发组配置静默覆盖，不给旧严格 DTO 追加字段。无个人偏好表变更，无新权限或依赖。
- 新管理读取／设置接口及本人当前组有效默认读取均 no-store；Cookie 身份、当前数据库有效账号与 builtin admin 组、双管理权限是新管理操作最终边界。目标组非 guest 且 builtin，指定值须有创建、对应 default/assigned 权限及域名授权。
- 新写入和旧权限更新共享 domain advisory 共享锁 → 当前账号共享锁 → 当前 admin 组排他锁 → 目标组排他锁的前缀；避免锁升级和组间反序，当前身份在等待后重查。旧权限更新请求与正常业务语义保留，并新增排队撤权回归。
- 组默认同值且版本当前时 no-op，陈旧同值仍冲突；变化单调推进组版本并与仅字段名 default_domain_id 的审计同事务。域名删除原事务同时清受影响组默认／推进组版本，保留个人偏好清理及既有默认、短链引用保护；任何失败全回滚。
- 停用、改授权、撤权限和切全局默认不主动改保存配置，使用时复核并回退；恢复资格后可再次生效。真正删除清配置，旧版本不能重放。组默认清除不影响个人偏好、排序或已有短链。
- 独立草稿、共享组版本冲突、明确重载、两个组的草稿保留、写入 pending 与刷新失败屏障、当前身份／登录 epoch 隔离、迟到读写抑制以及双语／双视口形成完整闭环。
- Goose Up／Down／再 Up、标准 SQLC 生成零漂移、真实 DB／HTTP／锁等待／授权／版本／审计故障、真实 QueryClient 与完整浏览器及制品门禁独立留证，原 100 阈值和原排除不下降、不扩大。

## 不纳入

服务端按组或个人重解释省略 domainId、默认跳转方式、默认模板、访客创建、自定义组、多用户组、批量重排／默认配置、自助绑定、DNS／TLS、已有短链域名迁移、账号代改个人偏好、新权限／依赖和正式生产部署。
