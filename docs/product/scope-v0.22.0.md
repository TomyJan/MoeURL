## 必须实现

- 管理员对当前返回列表的 1–100 条不同短链指定同一接收账号，每条使用打开确认框时的完整精度版本。
- 复用 `admin:access` 与 `short_link:update_all`，无新增权限、schema 或依赖；准确用户名不裁剪或折叠大小写。
- 5 秒事务预算、有序行锁、数据库当前授权、全量版本预检、整批原子提交及审计。任一不存在／软删／冲突／故障均整批零写入。
- 同 owner 仍校验版本，但不写版本或审计；实际变更仅归属与更新时间，原 URL、域名、配置、密码授权、用量、元数据和历史事件不变。
- 中英双语与桌面／移动确认；未保存输入、冲突刷新、重复提交与身份轮次隔离。
- 真实 PostgreSQL 并发／回滚、严格 HTTP、完整前端 100%、真实浏览器和独立审查。
