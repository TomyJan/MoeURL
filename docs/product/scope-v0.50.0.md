# v0.50.0 批量替换内部备注范围

状态：设计完成，尚未实现。基线为 PR269 已交付 master `4b5d4dc4db6d14a430cdc3cdf7238f3d9516da77`，分支 `feat/v0.50.0-batch-note-replace`。见[设计](../specs/2026-11-05-v0.50.0-batch-note-replace-design.md)、[计划](../implementation/v0.50.0-plan.md)与[验收](../implementation/v0.50.0-acceptance.md)。

## 目标与必须实现

- 本人／全站列表当前页选择 1–100 条，输入同一非空内部备注，实际预览变化数量后显式覆盖。
- 沿用 1000 Unicode 码点、CRLF 规范化、控制字符校验及 Go 空白语义；不显示或返回目标旧正文。
- 四个独立 POST 端点，完整主版本与备注版本双 CAS；全量校验后原子修改，仅变化项推进备注版本并写字段名审计。
- 草稿任意编辑退休旧预览；未知写结果必须重新实际预览并再次确认，不自动重试。
- 所有身份／权限／页面代际隔离与既有操作双向互斥，中英、手机、键盘及焦点完整验证。
- 当前代码真实 RED→GREEN、完整本地门禁、唯一独立终审、最新远端真实覆盖、候选及 master 各九 CI、可恢复归档。

## 非目标与选择理由

批量清空已经交付，统一替换能减少逐条编辑，且比追加更容易让用户明确最终内容。空内容使用现有清空入口。不做追加、历史、撤销、跨页全选、后台任务、迁移、新依赖或权限；不改变公开访问、列表／CSV 字段或单条备注协议。不发布、部署或触碰 PR240。

## 现状盘点

| 能力 | 来源与现状 | 本版 | 影响与风险 |
| --- | --- | --- | --- |
| 单条内部备注 | v0.43.0，已交付 | 复用规范化与权限 | 不扩 DTO，测试回归 |
| 备注筛选及分页 | v0.44.0–v0.48.0，已交付 | 保持筛选与页大小 | 保存后列表变化需真实刷新 |
| 批量清空 | v0.49.0，已交付 | 保留独立入口 | 双向互斥与并发回归 |
| 统一替换 | roadmap 批量编辑，未实现 | 纳入 | 后端四 API／SQLC，无 schema；前端独立流程；中风险，原子性与私密隔离 |
| 备注历史／追加 | roadmap 远期，未实现 | 不纳入 | 留存策略及组合语义需另版 |
| 正式发布 | 各版部署验收独立 | 不纳入 | CI 不替代生产验收 |
