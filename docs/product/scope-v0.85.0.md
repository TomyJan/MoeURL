## 意图与范围

在“我的短链”和“全站短链”已有当前页选择工具栏增加“导出所选 CSV”。用户勾选 1–100 条，服务端按导出时最新授权和数据返回管理清单；原“导出 CSV”继续导出全部筛选结果，两者含义分开。选择功能不授予写权限或导出权限。

## 必须满足

- JSON 仅 `ids`；1–100 个规范小写、非零、不重复 UUID；16 KiB 请求体。官方客户端携带当前账号绑定头，权限仍由 Cookie 和数据库判定。
- 本人要求 `short_link:export` 与 `short_link:read_own`；全站要求 `short_link:export`、`admin:access` 与 `short_link:read_all`。同一 SQL 快照重查当前有效账号、实际组权限、归属和未删除状态；任何请求项不可读，整体返回 `120001`，不返回部分结果或缺失 ID。
- 按服务端 `created_at DESC, id DESC` 排序，读取最新数据，不承诺保持勾选时字段。原始文本与最终 CSV 各不超过 8 MiB，总超时 5 秒；超限沿用 `200118`。
- 沿用 17 列、BOM、CRLF、公式防护及私密数据排除；文件名区分为 `moeurl-links-own-selected.csv` 和 `moeurl-links-all-selected.csv`。全部筛选及私密备注搜索导出保持。
- 无新增依赖、权限、migration、写入、审计、访问事件、页面或后台任务。不存储选择和下载内容，不发送私密备注筛选词。
