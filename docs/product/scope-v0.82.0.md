## 必须完成

- 详细解析入口可返回受信 `header`／`syntax`／`width` 和 1–21 的逻辑记录号；表头为 1，引号内换行不另计。所有失败仍整体拒绝，不显示输入原值。
- 两个旧解析入口维持精确旧失败 `{success:false}` 和全部成功对象；详细入口与旧入口只共享一套状态机。非结构失败仍用原通用提示。
- 原 alert 内追加中英诊断，说明逻辑记录计数；保持重复选择焦点、当前草稿、读取／身份／权限守卫及原 UUID／payload 重试。
- 真实行为 RED→GREEN，完整前端四项 100%、types／lint／相关 E2E strict／build；新准确 web 配守恒后端，实际 smoke／所选扫描和中英桌面／手机浏览器，必要原图及资源清理分别实证。
