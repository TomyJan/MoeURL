# v0.74.0 CSV 跳转方式导入范围

基线为已独立核验的 PR341 master `3def603c33406dd04b67d6dcaaf3179e9ff149b5`，分支 `feat/v0.74.0-csv-redirect-modes`。范围由 Agent 依持续无人值守授权选择，不写成用户逐项批准。当前为设计／实施阶段，不代表功能已交付。

## 目标与取舍

现有四列 CSV 可批量指定网址、标题、标签和短码，但所有批量创建固定 direct。增加固定第五列，减少批量创建中间页／确认页后逐条修改；这是路线图“多列导入”的有界增量。备选全量导出恢复涉及归属、历史与多项访问条件，范围过大；默认统计区间是另一独立偏好，不在本版。

## 必须实现

- 新增严格 UTF-8 五列 `target_url,title,tags,custom_slug,redirect_mode`，1–20 条唯一网址；文件与完整 JSON 各最多 65536 字节。原四种格式、端点及摘要保持不变。
- 第五列只接受 `direct`、`intermediate`、`confirmation` 或空字符串；空表示 direct，不读取个人／用户组／域名初选。中间页固定 5 秒，不提供倒计时列。
- 新增独立 `POST /api/v1/short-link/batch-create-with-redirect-modes`，每项恰有五个字段。五列协议始终要求创建、默认域名、元数据和自定义短码四项当前权限；含 intermediate／confirmation 行时分别要求对应模式权限，即使是原回执重试也先重新授权。
- 同一事务内全部短链、审计、配额与回执原子提交；所有格式共用 actor/requestId 冲突边界，新模式原文和行序参与独立版本摘要。保留七项目标规则、当前账号与组锁、默认域名授权及随机／指定短码互不抢占。
- 新第五个公开模板、中英帮助和纯文本预览；明确空模式 direct、中间页 5 秒及模式权限。不可未知降级、自动转为其他格式或静默丢弃第五列。
- 文件读取、预览、提交与未知结果重试绑定当前身份／权限／草稿轮次；撤权使使用该权限的草稿和快照同步退休，撤回后恢复也不能复活旧异步读取。
- 完成本地门禁、准确产品与受影响真实浏览器、原图、唯一独立终审、最新候选真实 CodeRabbit、正常合并核验及可恢复归档。

## 不在范围

不增加密码、过期时间、最大次数、备注、任意字段映射、跨页选择或清单恢复；不新增依赖／权限／迁移，不改变公开访问和统计语义。不查 CI，不发布部署。
