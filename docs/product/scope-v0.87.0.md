## 必须完成

- 独立自定义 CSV 入口增加“标签列（可不导入）”。网址必选，标题与标签可分别省略；所有选中索引必须是范围内且互不相同的整数，每个新文件重新选择。
- 标签单元格仅接受 JSON 字符串数组，复用现有最多 10 项、每项 32 个 Unicode 码点、控制字符、重复值和空白规则。空单元格拒绝，`[]` 明确为空标签；不按逗号拆分。
- 未选标签时保持原 targets／titles 精确结果；选中标签时使用 metadata，未选标题补空字符串。保留原文字、行序和完整请求 65536 字节上限。
- CSV 保持严格 UTF-8、至多一个开头 BOM、65536 字节、1–8 列、表头及 1–20 条等宽数据、严格引号与换行。标签不是额外第九列。
- 仅成功应用才替换旧草稿。取消、无效列或 JSON、字段拒绝保留旧手工／结构化草稿；不上传文件、表头、未选内容或数据样本。
- 标题或标签任一选择都要求现有 metadata 权限和读取时的权限轮次；撤权／恢复不能复活旧暂存。换号、关闭、新文件、卸载和迟到异步继续既有守卫；冻结标签与未知结果同请求重试保持。
- 中英文界面明确“仅导入所选网址、标题和标签，其他列忽略”，说明 JSON 数组和非历史恢复；无权禁用标题与标签控件，错误不暴露原数据。
