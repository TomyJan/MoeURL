## 必须实现

- 个人设置独立显式保存沿用默认（20）、20、50、100，跨登录和设备保留，Cookie 本人资源与独立 CAS。
- 本人和全站短链列表首次进入采用该值。优先当前登录轮次缓存，否则最多等 3 秒，失败或超时本实例使用 20；准备期间不发列表请求。
- 当前列表主动选择立即生效，迟到读取、后台保存和聚焦不覆盖本实例；列表切换不自动保存。身份或权限退休同步清理并重新初始化。
- 严格输入、真实 PostgreSQL／HTTP 和锁队列验证；旧偏好协议与权限边界保持。
- 本地完整门禁、真实浏览器、原图与准确产品、独立终审、CodeRabbit 最新真实覆盖、正常合并与可恢复归档。
