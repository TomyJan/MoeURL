基线为 PR354 已独立核验的实际 master `7ff56260b53839049cf0a07916ebac00bd1f8994`，分支 `feat/v0.77.0-csv-countdowns`。本版由 Agent 按持续自主授权选择，后端和前端本地门禁、准确新产品及 33 项真实浏览器验证完成，19 张原图已查看，产品副本、镜像和缓存已可恢复清理；审查和交付尚待，不发布部署。

选择这一增量可让批量中间页短链无需再逐条调整秒数；相较完整恢复或上传系统，能复用现有权限和事务边界。这是 Agent 的产品决策，不表示用户逐字段指定。

## 必须实现

- 精确第八表头 `target_url,title,tags,custom_slug,redirect_mode,expires_at,max_visits,intermediate_delay_seconds`，1–20 个唯一目标；UTF-8 CSV 和完整 JSON 各最多 65536 字节。旧七种格式、模板、DTO、端点及摘要保持。
- 新字段空值默认 5；非空只接受规范 ASCII 字符串 `3`、`4`、`5`、`6`、`7`、`8`、`9`、`10`，且 `redirect_mode` 必须明确为 `intermediate`。空模式、`direct`、`confirmation` 只允许空秒数。不 trim，不接受前导零、符号、小数、指数、空白或全角数字。
- 新增独立 `POST /api/v1/short-link/batch-create-with-countdowns`：外层恰有 `requestId/items`，每项恰有 `targetUrl/title/tags/customSlug/redirectMode/expiresAt/maxVisits/intermediateDelaySeconds`。八个字段显式存在，tags 是非 null 字符串数组，其余是字符串；数字、null、重复／未知键、尾随 JSON、无效 Unicode 均拒绝为 100001。
- 复用当前创建、默认域名、元数据、自定义短码基础授权；按实际行检查中间页／确认页、非空过期／上限权限。倒计时没有新权限。持锁重读当前账号／组授权，必须先授权再查回执。
- 原文及顺序进入独立摘要；八协议共用 actor/requestId 冲突边界。精确重放只回原回执，不重建或修改旧链接，不重置已改倒计时、已耗用量、日期、配额或审计。原链接过期或耗尽后仍可在当前授权下重放。
- SQLC 批量查询的原固定 5 改为校验后的参数；旧七路径显式写 5。保持全部链接／审计／每日配额／回执原子事务，不新增 migration、权限、依赖或审计动作。
- 第八公开模板、双语帮助和纯文本预览显示实际秒数或默认 5。接入全部既有 metadata/custom/mode/expiration/cap 权限 epoch、身份／草稿／File 轮次；撤权后恢复不能复活迟到文件，未知结果只原 UUID／payload 重试。
- 本地完整门禁、准确新产品和真实浏览器、原图查看、唯一 fresh 最强独立终审、最终 head 真实 CodeRabbit、正常守卫集成和可恢复归档分别留证。
