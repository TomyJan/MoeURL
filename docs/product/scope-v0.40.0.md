# v0.40.0 有界 CSV 网址导入

## 定位与状态

基线为已完整交付的 v0.39.0／PR246，master `7bf680b3a487e2ad364589b79d325de15cb9e1bd`。本版处于设计阶段，尚未实现或验证。Agent 按持续自主开发授权，从路线图的导入方向选择这个小增量；文件格式和上限是 Agent 的设计决定。

在现有「我的短链 → 批量创建」中，从本地 CSV 读取少量目标网址，继续原有预览、确认和原子创建流程。它只帮助录入网址，不恢复旧短链。

## 必须实现

1. 已有批量创建对话框保留手工逐行输入，增加带可访问名称的本地 CSV 文件选择。读取完全在浏览器完成，不新增上传、API、依赖、权限或数据库变更。
2. 文件最多 65536 字节，严格 UTF-8，可有一个开头 BOM。固定一列表头 `target_url`，随后 1–20 条网址，顺序保留。可用 LF／CRLF；末尾允许一个行终止符，不忽略空记录，不接受裸 CR。
3. 支持标准 CSV 双引号包围与 `""` 转义；分隔符仅逗号。任何多列、引号帧错误、缺表头、空记录或额外空行均整体拒绝。网址沿用现有 1–2048 字节、可打印 ASCII HTTP(S)、精确重复拒绝的批量 schema，不隐式 trim、URL 规范化或公式反中和。合法带逗号／双引号网址可通过正确 CSV 引号表示。
4. 成功读取只替换尚未预览的输入；用户仍须显式预览、确认。失败保留原草稿并显示友好本地化错误，不显示底层异常。没有部分导入、自动截断或读取即发写请求。
5. 文件读取期间显示进度状态；允许关闭或继续编辑草稿。后选文件、手工编辑、关闭、换号、撤权、认证失败或卸载使旧读取失效。旧 success／error／finally 不得覆盖新输入或清掉新读取状态。
6. 预览后／提交中／未知结果期间不允许读入文件；未知结果保留原 payload／requestId 的手动重试，不能借导入更换 key。导入失败或晚到读取也不能破坏该快照。
7. 中英、桌面 1280×720／手机 390×800、浅深色及键盘可用；文件控件不造成横向溢出，完整网址以文本预览。提示格式示例和「仅录入网址，使用全局默认域名／direct；不恢复旧配置」。

## 非目标

不读取多列旧导出清单、不识别 Excel、不恢复 slug／owner／历史／元数据、不自动访问目标网址、不改变个人默认方式或批量端点语义。不引入后台作业、持久草稿、远程文件或新依赖；不碰 PR240／日常数据库／正式部署。
