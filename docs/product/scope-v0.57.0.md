## 目标

为已有单条短链二维码增加本地 SVG 下载，方便打印和设计排版；PNG 预览、下载与三个现有入口继续可用。

## 必须实现

- 创建结果、我的短链和全站短链共用当前二维码弹窗，增加中英双语 SVG 下载链接；文件名 `moeurl-${slug}.svg`。
- SVG 和 PNG 使用同一完整公开短链 URL、当前三色预设、320 像素、M 纠错、4 模块静区、不透明白底。
- PNG 成功后独立准备 SVG。SVG 未完成或失败不能阻塞、清除或误报 PNG；失败持久说明 PNG 仍可用，切换外观可重试。
- 每次 open、slug、URL 或预设变化清旧 SVG、错误和加载状态；迟到 success、error、finally 不影响新一轮，卸载后结果失效。
- 下载编码后的 `data:image/svg+xml;charset=utf-8` 数据，不向页面注入 SVG，不拼用户 XML，不访问外站或新增产品 API，不改变短链数据、权限和统计。
- 保留键盘操作，中英桌面 1280 像素及手机 390 像素动作可见且无横向溢出；操作区允许换行。
- 根据原交付证据同步 v0.56.1 验收两项清单 Minor，不倒填为 PR299 已修。
