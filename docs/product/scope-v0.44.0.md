# v0.44.0 备注状态筛选

状态：设计已确定，正在实施。功能、本地门禁、远端审查、候选 CI、master CI 和正式发布分别判定；尚未完成本版验收。

## 目标

让本人和全站短链按“全部／有备注／无备注”整理，并把相同条件用于清单导出。沿用 v0.43.0 的私有备注与 v0.43.1 的独立版本边界，选择这一增量是执行者按持续无人值守授权作出的决定。

## 必须实现

- 两个已有列表和清单导出支持可选 `noteStatus`：省略／空字符串为全部，`present` 为数据库备注非空，`absent` 为空。只判断原始存储是否等于空串，不再 trim，BOM 为非空。
- 与 status／q／tag 取交集；总数在分页前计算，导出先筛选再应用原 1000 条／8 MiB 上限。q 不搜索备注。
- 只读账号可筛选。本人需要当前 read_own 和 owner；全站需要当前 admin:access 和 read_all；导出另需 export。禁用、撤权、改组和转移不能借旧身份快照推知备注状态。
- 两页三项有 label 的 Vuetify 选择器，切换清理旧选择并隔离迟到列表、导出和备注操作；保存期间的排队切换事件也必须拒绝。
- 当前备注保存／清空成功后，或未知写入显式重新加载核实后，刷新当前列表，不自动重放写入。
- 列表、CSV、公开响应和日志不新增备注正文、独立版本或派生字段；不把正文放入地址栏。

## 非目标

不做全文或正则备注搜索、批量编辑、备注历史、CSV 备注列、分页 UI、自定义权限、迁移或索引调整；不发布部署，不碰 PR240、18080、日常数据库和未知 Docker。
