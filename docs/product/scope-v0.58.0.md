# v0.58.0 二维码纠错等级范围

状态：本地功能、准确产品／浏览器和唯一独立终审已核准；候选提交时标准 Task2 收尾及真实远程审查、合并与归档待完成。前版 PR300 已完整交付；本版从已独立核验的 master `97fa899c477e1918898ec7e3f0c182272d6c5ea4` 建立 `feat/v0.58.0-qr-correction`，准备、正式验证和后继交付分别记录。

## 目标

在共享二维码弹窗选择标准 M、增强 Q、高 H 三个固定纠错等级，供下载时按用途取舍；保留默认 M、现有三色和 PNG／SVG，不承诺实体扫码成功率。

## 必须实现

- 创建结果、我的短链和全站短链共用一个本地选择器，三选项分别为 M、Q、H，默认 M。
- PNG 和 SVG 使用相同当前等级、完整公开 URL、当前三色、320 像素、不透明白底和四模块静区；尺寸和文件名保持既有契约。
- 选择等级保留当前颜色，选择颜色保留当前等级；open／slug／URL 身份变化重置 classic／M。无持久偏好或新请求。
- 等级变化立即使旧制品与加载／错误失效；迟到的 PNG 和 SVG success／catch／finally、关闭或卸载均不干扰新一轮。
- PNG 成功后才独立准备 SVG。SVG 等待或失败不阻塞 PNG；较高等级无法编码时显示错误，不截断 URL、不默降等级，允许主动回选 M 恢复。
- 双语可访问名称、pressed 状态与键盘操作；手机不溢出，完整当前 URL 和三个动作仍可见。帮助文案解释等级是编码选项，不承诺具体设备、纸张或遮挡条件。

## 非目标
