## 目标与选择

从[路线图](roadmap.md)的可配置主题色方向收敛一个有界增量：管理员为整个站点选择鸢尾蓝、海洋蓝或森林绿强调色。当前鸢尾蓝保持默认；浅色、深色与跟随系统仍由既有浏览器和账号偏好决定。

这是执行者在长期自主迭代授权下作出的范围选择，不记为用户逐项批准。使用固定且可验证的配套色值，先交付可恢复的基础品牌配置，不引入任意色值或完整主题编辑器。

## 必须实现

- 系统设置页提供独立“站点强调色”表单，选择 `iris`、`ocean`、`forest`，明确保存后应用；未保存草稿不改变全站颜色。
- 强调色只改变主操作、链接、选中态及配套主色文字、环境光与焦点环；背景、辅助色、危险／成功等语义色和布局保持现有设计。
- 管理读写要求当前数据库有效账号、内置 admin 组及 `admin:access`、`system:manage` 两权限。独立完整精度版本防止旧草稿覆盖；冲突保留草稿，由用户显式重新加载。
- 公开读取只返回预设标识；全站安全默认、首次加载及读取失败使用鸢尾蓝，不阻断创建或访问。管理保存成功立即应用服务端已提交结果；其他客户端不承诺实时推送。
- 独立资源、存储键和版本，不扩展旧严格设置、首页文案或账号偏好 DTO。旧完整保存、账号切换与深浅色切换不得清除站点预设。
- 迁移默认保留已有值，Down／再次 Up 不丢失管理员选择和审计历史；实际变化与仅键名审计同事务，无变化不制造版本或审计。
- 中英双语、桌面和手机、键盘操作、加载／错误／保存／冲突／身份失效状态完整。三个预设在两种模式下的正文／主操作文字对比度至少 4.5:1。

## 非目标

任意十六进制色值、颜色选择器、自定义 CSS／HTML、Logo／Favicon 上传、PWA 图标与安装元数据动态生成、个人强调色、预览全站未保存草稿、主题模板库及跨客户端推送均不纳入。本版不增加依赖、权限或部署配置，不改变短链公开访问与统计语义。
