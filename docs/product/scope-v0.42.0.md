## 目标与盘点

管理员目前只能手工输入已知标签，无法发现其他账号已使用的标签。本版把路线图中的集中标签能力继续拆为只读全站查找；不引入集中写入。

| 能力与来源 | 当前状态 | 本版选择及影响 | 验证与风险 |
| --- | --- | --- | --- |
| 本人目录，v0.41.0 | 已交付，仅本人 | 保持独立端点、缓存与授权；复用面板实现。 | 全量本人回归，防止跨域缓存泄露。 |
| 全站目录，路线图与 admin 规格 | 未实现 | 纳入独立管理 GET、SQLC 查询和全站页折叠面板，无 schema。 | 当前权限快照、计数、边界；中等隐私风险。 |
| 标签写入，v0.11.0／v0.23.0 | 已有单条与批量整理 | 不改写入协议或权限，复用写后缓存失效。 | 初次 pending 失效、连续失效与迟到读取。 |
| 标签实体、重命名、合并、颜色 | 尚未实现 | 不纳入，需要另行设计批量版本与审计。 | 避免扩大只读阶段。 |
| 头像、自定义用户组、API 鉴权等 | 远期路线图 | 不纳入，与本版目标独立。 | 无新依赖、存储或部署变化。 |

## 必须实现

- 全站短链原筛选与批量工具下方独立整行“全站标签”，默认折叠；展开读取标签与引用短链数。点击只设置原精确 tag 筛选，保留关键词和状态，并遵守原页面批量、导出、设置互斥。
- 独立 `GET /api/v1/admin/short-link/tags?q=`，要求当前有效非 guest 身份、`admin:access` 和 `short_link:read_all`。不以组名代替权限；本人端点仍仅本人。
- 同一 SELECT 快照重新检查数据库账号、状态、组和两项权限后聚合全部未软删除短链，包含停用、过期、耗尽及停用域名资源；每条短链的同一标签只计一次。
- 原始输入拒绝非法 UTF-8 和控制字符；Go TrimSpace 后最多 32 码点，大小写敏感字面子串，百分号、下划线、反斜杠无语法意义。未知、重复、无等号或坏编码 query 拒绝。
- 固定最多 50 项，读取 51 项判 hasMore；引用数降序、同数按 PostgreSQL C 排序。五秒超时、no-store、安全错误。无所有者、URL 或完整标签总数返回。
- 中英、键盘、手机长标签、加载、空／无匹配、失败重试、身份与权限变化、关闭重开、首次和连续读取失效都可验证。own/admin 缓存严格隔离，旧响应和排队点击不能恢复旧数据。
- 无 migration、新权限、依赖、新前端路由、公开字段、独立标签实体、写入或发布部署。
