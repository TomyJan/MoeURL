# v0.1.2 范围

## 目标

v0.1.2 完成个人设置基础闭环：在既有控制台 Shell、`auth/me` 数据和前端偏好系统之上，补齐一个可进入、可编辑、可返回的个人设置页，让登录用户能够查看自己的账号信息、修改昵称，并在统一页面中管理语言和主题偏好。

主线为：

```text
当前账号信息 → 个人设置页 → 昵称自助修改 → 前端偏好入口 → 自动化验收
```

## 必须实现

- 新增 `POST /api/v1/user/profile/update`，仅允许当前登录用户修改自己的昵称。
- `/profile` 页面展示当前账号信息，并提供昵称编辑、语言切换和主题切换入口。
- 首页账号入口和控制台账号入口都可以进入个人设置页。
- 个人设置页复用既有 `PreferenceSwitcher` 和 `auth/me` 数据，不重复造一套偏好系统。
- 页面覆盖加载、局部错误、保存成功、移动端布局和空状态。
- 个人设置页文案、路由和导航都使用稳定的中英文翻译键。

## 数据与权限边界

- 只允许已登录的非 `guest` 用户修改自己的昵称。
- 不能通过该接口修改用户名、用户组、账号状态、密码、头像、权限或其他用户资料。
- 语言和主题偏好继续由前端本地存储保存，不在本版本引入服务端偏好模型。
- 不新增数据库表，不新增 migration。
- 不涉及系统设置、管理员仪表盘、OIDC、会话管理或域名配置。

## 暂不实现

- 头像上传。
- 密码修改。
- 默认域名、默认跳转方式、时区、时间格式的服务端持久化。
- 服务器侧语言和主题同步。
- 系统设置页面的真实表单。
- 管理员用户中心或全站个人概览。

## 完成标准

- 自助昵称更新、个人设置页、路由、导航、翻译和前后端契约均有自动化测试。
- `/profile` 可以稳定展示当前账号信息并保存昵称修改。
- 首页和控制台都能进入个人设置页。
- `go test ./...`、`go vet ./...`、前端 lint、类型检查、测试、覆盖率和构建全部通过。
