# v0.19.0 用户组成员迁移

## 目标与状态

基于主分支 `5a1d9761`（含 PR #208 的 v0.18.0）补齐原规划中的账号改组。当前为设计阶段，不代表实现、门禁或发布完成。

## 必须实现

- 管理员从用户列表为非内置、非自己的账号切换主用户组，仅允许内置 `user` 与 `admin`。
- 提交前明确确认提权／降权及全部旧会话撤销；账号需重新登录，OIDC 绑定和短链归属保持不变。
- 后端事务内重查操作者账号与当前 `admin:access`，校验目标保护状态及完整精度版本，不能信任请求入口的旧组。
- 并发冲突拒绝覆盖；相同组不更新时间、不撤销会话、不产生审计。
- 改组、撤销旧 Session 和既有 `group_id` 白名单审计同事务提交，任一步失败全部回滚。
- 中英双语、加载／错误／成功／冲突反馈，桌面与移动端真实流程。

## 非目标

不创建自定义组、多用户组、批量迁移、OIDC 组映射或新授权层；不允许 guest、内置账号改组及自我提权／降权。不修改密码或既有短链访问条件。

设计见 [用户改组设计](../specs/2026-10-23-v0.19.0-user-group-membership-design.md)，执行与证据见 [实施计划](../implementation/v0.19.0-plan.md) 和 [验收](../implementation/v0.19.0-acceptance.md)。
