- 保留默认焦点在安全的“保留”按钮；返回后原私密草稿、双版本和 requestId 不变，只能手动重试同一请求。

## 非目标及现状

v0.52.0 两项 Minor 分别是手机确认说明首屏可见性与计划测试名称，原版已真实审查并合并；本版独立处理，不倒填原审查结论。比较增加滚动回调、固定外部警示与独立确认正文，选择第三项以避免滚动时序与短视口挤压。只改 Vue／Vuetify 呈现，不改 controller、API、数据库、权限、依赖、文案含义或回执协议，不提供跨刷新恢复、撤销、历史及跨页选择。不等待或冒称 GitHub CI，不发布部署，不碰 PR240／266／267、日常数据库或其他资源。
