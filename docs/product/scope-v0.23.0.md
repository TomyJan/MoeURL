## 必须实现

- 添加和移除保留现有标签顺序；替换使用输入顺序，空数组用于清除；沿用大小写敏感、Unicode 去空白、10 个／每个 32 字符限制。
- 复用个人／全站更新权限，额外要求 `short_link:set_metadata`，后台额外要求 `admin:access`；数据库事务内重查授权和归属。
- 每条固定完整 `updated_at` 版本；任何缺失、软删、归属不符、版本冲突或结果超量整批零写入。
- 只实际变化的标签和版本写入并同事务审计，无变化不推进版本、不写审计。
- 明确确认、双语、手机布局、操作互斥、冲突后重新加载与身份轮次隔离；覆盖率阈值保持 100%。
