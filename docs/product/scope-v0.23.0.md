# v0.23.0 批量短链标签整理

状态：2026-10-26 从 PR #217 合并提交 `ba2073cf18f395900ea3c1a6575c6405d3d87593` 开始设计和实施，分支 `feat/v0.23.0-batch-link-tags`。尚未实现、验收、推送或发布；过程证据见[验收](../implementation/v0.23.0-acceptance.md)。

## 目标与盘点

| 能力 | 来源／当前状态 | 本版范围与影响 | 验证与风险 |
| --- | --- | --- | --- |
| 单条标题与标签 | v0.11.0 已有内联 text[]、校验、搜索与精确筛选。 | 复用规范化和权限；新操作只改变标签。 | 保留标题、访问配置及历史；中等并发风险。 |
| 批量整理 | roadmap 与 admin 规格已规划，尚无闭环。 | 个人／全站当前列表 1–100 条，添加、移除、替换标签；无新 schema／权限。 | 真实 PostgreSQL 原子性、撤权、越权、版本、no-op、故障回滚；前端与真实浏览器。 |
| 集中标签库和导入 | 尚未实现，标签归属及导入安全需独立设计。 | 不纳入，不新增实体、全站重命名、跨页选择或后台任务。 | 避免范围扩大和共享标签授权歧义。 |

## 必须实现

- 添加和移除保留现有标签顺序；替换使用输入顺序，空数组用于清除；沿用大小写敏感、Unicode 去空白、10 个／每个 32 字符限制。
- 复用个人／全站更新权限，额外要求 `short_link:set_metadata`，后台额外要求 `admin:access`；数据库事务内重查授权和归属。
- 每条固定完整 `updated_at` 版本；任何缺失、软删、归属不符、版本冲突或结果超量整批零写入。
- 只实际变化的标签和版本写入并同事务审计，无变化不推进版本、不写审计。
- 明确确认、双语、手机布局、操作互斥、冲突后重新加载与身份轮次隔离；覆盖率阈值保持 100%。

具体契约见[设计](../specs/2026-10-26-v0.23.0-batch-tags-design.md)与[计划](../implementation/v0.23.0-plan.md)。
