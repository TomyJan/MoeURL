## 目标与盘点

管理员可选择仅允许今后保存到指定 DNS 主机的新目标，默认关闭兼容当前行为。该范围由 Agent 在持续自主授权内选择，补齐路线图中黑白名单的第二个有界增量。

| 方向／现状 | 本版选择 | 影响、验证和风险 |
| --- | --- | --- |
| v0.61.0 精确黑名单已交付 | 保留且优先于白名单 | 同一事务 gate 和明确交集；竞态风险高 |
| 白名单未实现 | 纳入独立可选精确 DNS 白名单 | 后端、管理卡片、新设置与审计；真实 PG／浏览器验证 |
| 七个目标写协议及已提交回执 | 统一应用新目标限制，保留恢复顺序 | 批量原子性、身份、unknown 重试风险高 |
| 历史访问、目标不变的配置编辑 | 保留原行为 | 真实旧链接入口及原文字节边界验证 |
| 后缀、通配、IP／CIDR、DNS 解析、外部信誉 | 不纳入 | 避免把精确清单扩成复杂安全规则或 SSRF 防护 |
| 上传品牌媒体、导出恢复、持久模板 | 独立后续方向 | 不与本增量混合 |

## 必须实现

- 独立 `security.target_host_allowlist`，默认 `{"enabled":false,"hosts":[]}`。关闭时不增加新匹配或 URL 语法限制，原黑名单仍执行；可保留 0–100 个预配置主机。启用时要求 1–100 个主机，空列表启用整体拒绝。
- 主机输入沿用黑名单的 ASCII／有效 ACE、控制字符先拒后 trim、小写、至多一个终止点、canonical 排序和规范重复拒绝。只精确 DNS 主机，不含子域；URL／port／userinfo／Unicode 原文／通配符／IP 和数字尾标签不能作为管理项。
- 启用时新目标必须为有效 DNS 且精确命中；IP 目标明确受限。DNS 分类错误按原非法目标处理，不能误放行；完整目标 URL 原文字节不重写。黑名单命中始终拒绝，无管理员绕过。
- 独立管理员 GET／POST、严格完整 JSON、32768 B 请求上限、完整精度 CAS、五秒事务、no-store 和键名审计。当前有效非 builtin 账号、builtin admin 组及 `admin:access`／`system:manage` 双权限；不扩旧 DTO 或公开配置。
- 单条、四种批量、本人／管理员实际改变目标都受限；一项拒绝整批零链接／成功审计／回执。当前授权后已提交同内容回执先恢复，异内容仍冲突；原目标字节不变的编辑及公开访问不读新限制。
- 两类策略保存共用既有 exclusive gate，目标写入共用 shared gate，先于业务行锁；保存提交后才进入的写入必须看到新策略。两个资源坏存储／缺行都失败关闭，无进程缓存。
- 独立中英管理卡片，关闭开关不清除草稿列表；开启空表不得保存，清空不暗中关闭。冲突保草稿，显式重载；身份／权限／登录轮次和每个异步 continuation 都受守卫。现有 `200121` 受限反馈及 unknown 重试语义保持。
- 迁移默认关闭，Down 保留设置／版本／审计，重 Up 不覆盖定制内容。旧应用回退不会执行新白名单，必须披露；不新增依赖、权限或外部请求。
