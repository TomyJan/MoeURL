# v0.93.0 自定义组批量成员迁移

## 阶段与目标

本版处于设计和实施阶段，尚未通过本地验收或集成。基线为 PR #423 合并后的 `1863adae`。沿用 v0.30 的当前列表批量迁组，将 v0.92 已支持的自定义主组纳入同一个原子操作；不改变产品显示版本或声明发布。

## 必须实现

- 原 `POST /api/v1/admin/user/batch-change-group` 接受内置 user／admin 或当前存在且可分配的自定义组；请求／返回结构、1–100 个唯一规范 UUID、完整账号版本和五秒事务保持。
- 当前列表中的自定义组成员可被选中，与 user／admin 成员混合迁移。guest、自身、builtin 账号、缺失或删除账号仍拒绝；禁用账号允许迁组且保持禁用。
- 事务按 UUID 顺序锁 actor 和全部目标账号，再锁 builtin admin 重查身份及 `admin:access`。源组逐项验证可分配；目标组用现有组管理排他锁固定，与并发删除串行。不得把批量操作拆成单账号多个事务。
- 所有保护与完整精度版本检查完成后才写。陈旧同组也冲突，当前同组 no-op；真实变化才更新账号版本、撤销全部旧会话和产生原 user/update/group_id 审计。任一失败整批回滚，返回零计数。
- 前端按当前身份／登录 epoch 加载真实组目录；读取失败、尚未加载或后台刷新时禁用新增选择和提交，提供显式重读。确认对话框冻结账号、版本及可选组名称和 key，异步刷新不悄然改换目标；组不再存在由服务端拒绝，清空确认并读回最新目录与账号后重新选择。
- 支持中英、桌面与手机；自定义名称作为文本显示，旧 admin 提权提醒保留，非 admin 目标明确显示组名及重新登录提醒，不把 custom 误显示为 User。

## 非目标

多主组、OIDC 映射、批量创建／删除组、自动重试写、跨页用户选择、用户分页／搜索、组权限／域名编辑、迁移短链或个人偏好、新依赖、新 API 路由、migration 和发布部署均不纳入。

## 盘点与风险

| 能力／来源 | 当前基础与本版决定 | 影响与验证 | 风险 |
| --- | --- | --- | --- |
| v0.30 批量迁组 | builtin-only，扩至可分配 custom 源／目标 | Service 真实 PG 原子性、故障、并发；API 形状保持 | 高：部分撤销或陈旧版本覆盖 |
| v0.92 单账号及组管理 | custom 已可分配，复用 helper 和目标排他锁 | 删除竞态、guest 和保留 key 拒绝 | 高：孤立引用或误授管理员 |
| 当前列表批量确认 | 既有冻结快照及身份轮次守卫，增加目录状态 | UI 目录失败／恢复／迟到响应，原 builtin 回归 | 高：旧身份或失效目录误写 |
| 多主组等路线图扩展 | 未实现，继续排除 | 无新授权模型或 schema | 高：不混入本版 |

详细设计见[设计](../superpowers/specs/2026-11-25-v0.93.0-custom-group-batch-design.md)，验证事实见[验收](../implementation/v0.93.0-acceptance.md)。v0.30／v0.92 的非目标继续只描述其原版本。
