# v0.12.0 自定义短码范围

状态：设计与实施中，尚未完成验证或发布。开发基线为 `master` 的 `a64e978d`，功能分支为 `feat/v0.12.0-custom-slugs`。

## 目标与取舍

补齐既有短链规划中的自定义短码，让有权限的用户在创建时指定易读地址。相较个人设置增强，本项直接改善核心发布流程；相较批量导入，它不引入任务队列、文件格式或批量失败语义。采用创建时指定、创建后不可修改的方案，保持已发布 URL 稳定。

## 必须实现

- 创建请求支持可选 `customSlug`；省略或 `null` 继续随机生成 6 位短码，显式空字符串不合法。
- 自定义值为 3–32 个 ASCII 字母或数字，先拒绝非 ASCII 与其他字符，再将大写字母归一化为小写。不裁剪空白，不接受连字符、下划线、斜杠或百分号。
- 新增 `short_link:custom_slug` 权限，内置 user／admin 默认拥有，guest 不拥有；standard 预设包含，basic／restricted 不包含。创建事务内复核该能力。
- 固定路由保留字不可创建，包含现有系统入口和 `icons` 静态资源前缀；随机生成与自定义共用保留规则。
- 短码跨域名全局唯一，软删除继续占用。并发冲突由数据库唯一约束裁决，返回 `200101`，不随机替换或重试用户指定值；保留字返回 `200102`，格式错误返回 `100001`。
- 首页和控制台复用创建面板，在高级设置中展示权限控制输入、格式说明和规范化地址预览；无权限不提交该字段。错误使用现有友好 Toast，冲突后保留草稿。
- 更新权限目录、双语、测试、部署 smoke 和进度入口；已有链接、访问模式、密码、额度及统计口径不变。

## 非目标

不实现短码编辑、释放、复用、抢注预约、可用性查询接口、按域名重复短码、批量创建或访客开放。不增加服务、依赖或环境变量。

## 验收

覆盖格式边界、ASCII 大小写、保留路径、无权限及事务内撤权、跨域名／软删除冲突、并发唯一性和随机回退；真实浏览器验证创建、冲突草稿、权限变化及桌面／手机布局。migration 往返仅撤销本迁移添加且未被后续编辑的权限，保留创建的短码和后续显式授权。
