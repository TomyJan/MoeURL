# v0.89.0 自定义 CSV 表头匹配

## 状态与边界

PR #386 已将本范围正常合入 master（merge commit `f236951862f53e59cfedbe318e224d48fd1c902e`）。准确 head 的 CodeRabbit review 为 `reviewed`，source／covered SHA 一致且有效意见已闭环；合并 tree 与唯一父已由 API 和独立 fetch 核验。候选完整前端门禁、准确产品浏览器、whole-owned 恢复归档及此前失败记录见验收。本范围的本地交付与集成收尾已完成，但不等同目标 CI 或正式发布验收。本版不新增 API、数据库、权限或项目依赖，不查 CI、不发布部署。

## 必须实现

- 用户主动点击「按表头匹配空选项」，仅根据有限的中英文表头别名填充尚未选择且当前有权选择的字段。
- 同一字段匹配到多个表头时保持空选；手选索引及已占用列始终保留，不覆盖、不复用。
- 只忽略表头两端 ASCII 空格／tab 和 ASCII 字母大小写，不做模糊匹配、Unicode 相似字或数据内容推断。
- 展示填充数量或无可填选项反馈；更换文件清除反馈。匹配不应用草稿、不预览、不发送请求，用户仍须检查并点击「应用所选列」。
- 保持 v0.88.0 的八协议、权限 epoch、完整 wire 限额、失败保草稿和未知结果原请求重试。未选单元格不显示、不记录、不上传。
