## 必须实现

- 只接受 v0.21.0 固定 17 列管理 CSV；严格 UTF-8、BOM／CSV framing、精确表头和字段数量；输入最多 8 MiB、1–100 条。所有格式或业务校验采用全有或全无，不跳过行。
- 新增 `POST /api/v1/short-link/manifest/restore`，单请求最多 100 条、JSON 最多 1 MiB；原子检查当前账号、建链和字段权限、目标 URL 策略、每日创建配额、域名启用／授权和全局短码唯一性。全部在同一事务检查和创建，任何失败零写入。
- 使用当前短链及域名字段重建每行配置；短码与导出一致，`short_url` origin 对应当前启用且授权域名。记录 owner 为当前登录账号，状态按清单恢复。拒绝密码已启用记录和冲突短码，不自动改码、覆盖或复活软删除资源。
- 用量从 0 开始，最大访问次数配置保留；新记录的 ID 与时间戳为新值。不补写事件／审计历史、不冒称恢复事件、次数、旧归属或数据库。保留的 `max_visits` 可能允许再次使用完整额度，确认前必须显著告知。
- 复用现有创建幂等键／相同 payload 重试、安全审计、账号绑定请求头、权限解析和目标安全策略；当前身份或授权变化后不得提交迟到文件／请求。
- 预览仅报告浏览器可确定的文件结构、字段格式与一致性；不增加 dry-run API，不声称已确认服务端实时权限、短码可用性或每日剩余额度。最终权威检查在单次恢复 POST 中完成。
- 中英文、桌面和窄屏布局；成功／拒绝／未知结果、显式同 key 重试和草稿保留均可理解、可操作。旧 URL／CSV 导入协议和 v0.21 导出保持兼容。

## 非目标

不做数据库／实例备份或原 UUID、所有者、创建时间、统计事件、访问用量、密码恢复；不更新／删除／复活现有记录、不释放短码、不跨账号重建归属、不做域名自动映射、部分成功、自动改码、XLSX、异步任务、通用外部表格映射或导入历史追溯。
