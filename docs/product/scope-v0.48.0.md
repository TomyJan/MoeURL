# v0.48.0 短链列表每页条数

2026-11-04 设计启动，基线为已验 master `5ed2939c6de3f75e3cb46dac37fcb6ffa06ad74f`。尚未实施或验收，见[设计](../specs/2026-11-04-v0.48.0-list-page-size-design.md)、[计划](../implementation/v0.48.0-plan.md)及[验收](../implementation/v0.48.0-acceptance.md)。

## 必须实现

- 本人和全站列表独立的挂载内大小，只接受数字 20／50／100，默认 20；标签“每页条数”／“Rows per page”。
- 改大小回第一页、清选择并退休旧请求／备注上下文；筛选保留大小，身份或读授权变化恢复 20。
- pending 可以换大小；编辑、写入、导出、批量创建等原锁与实时权限守卫 queued 事件。
- GET 和私密 POST 仅使用捕获大小，严格响应 meta；当前成功响应证明页界，失败保持大小可重试。
- 双语桌面／手机可用，CSV 仍全匹配、1000 条／8 MiB／17 列。

## 非目标

不持久化 URL、账号或 storage；不增加任意大小、跳页、跨页全选、快照、API、schema、索引、权限或依赖。不发布、部署或打 tag。
