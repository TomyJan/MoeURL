# v0.78.0 复制本页短链

状态：设计完成，尚未实现或验证；基线为 PR356 合入的 master `64722b925560abc31248d4e227ff2e4a11186b76`。不查询 CI，不发布部署。

## 必须实现

- 本人和全站列表增加“复制本页短链”／“Copy links on this page”。仅复制当前成功读取页面的公开 `url`，保持列表顺序，每行一条，无表头、无尾随换行，1–100 条。不是目标网址、所选项、跨页或全部筛选结果。
- 复用本人 read_own、管理员 admin:access 与 read_all，无需 export 权限，不新增 API、数据库、权限或依赖。保留既有单条复制和全匹配 CSV 导出。
- 初始加载、重取、失败、已失效缓存、空页、筛选草稿未应用、其他列表写入／编辑／确认／导出／创建中均禁用。点击再次同步核当前身份、授权、真实 cache 和全部父级锁，不依赖旧渲染。
- 直接用户点击内调用 Clipboard API，不先 await 或自动重试。不支持、同步异常、异步拒绝有明确本地化失败反馈；成功反馈实际条数。
- 身份轮次、授权、筛选、分页、页大小、列表读取或组件存活变化后，旧异步结果不能 toast 或解除新操作的 pending。已经被操作系统接收的复制无法追溯撤销，不能宣称数据可收回。
- 中英文桌面和 320px 手机布局、键盘操作可用，不改变筛选、选择、分页、统计或用户偏好。

## 盘点与取舍

| 能力 | 当前状态 | 本版决定 | 风险和验证 |
| --- | --- | --- | --- |
| 单条复制、全匹配 CSV | 已实现，CSV 有独立 export 授权 | 保持；本页复制只整理已授权读取的数据 | 对照 URL、顺序、当前页及无 export 权限 |
| 一次复制当前页 | 未实现 | 纳入，纯前端有界操作 | 真实父页、同步 cache 守卫、异步身份隔离 |
| 跨页选择、导出恢复 | 尚未实现，涉及更广目标快照和数据语义 | 不纳入 | 不读额外页，不改 API 或 CSV 格式 |

此方案由 Agent 根据无人值守授权选择。与完整导出恢复、跨页选择相比影响面更小，不扩服务器数据读取。沿用 Vue／Vuetify／TanStack Query 和现有身份轮次。验收与交付见[计划](../implementation/v0.78.0-plan.md)及[验收](../implementation/v0.78.0-acceptance.md)。
