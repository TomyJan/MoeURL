# v0.60.0 可搜索账号显示时区

状态：后端 Task1 已标准完成；前端搜索及完整门禁通过，Task2 标准收尾中；浏览器、真实审查及交付尚未完成。基线为已完成 PR304 的 master `a371588c8c2a43ebeedab1e8d9b7a4064891e0c6`。实际验证与源扫描提示见[验收](../implementation/v0.60.0-acceptance.md)。

## 目标与取舍

让九个固定时区之外的用户也能保存账号显示时区。采用有版本的固定目录和可搜索选择器，沿用本人偏好与浏览器 Intl 显示，不把后端变成时区转换服务。

| 来源与现状 | 本版决定 | 影响与风险 |
| --- | --- | --- |
| 路线图中的时区目录；v0.36.0 固定九项 | 扩展为 419 项精确标识，可按标识及已有本地化名称搜索 | 后端校验、数据库 CHECK、前端选择同步；中风险 |
| 已有独立 CAS、身份轮次、Intl 回退 | 完整保留，不扩旧 DTO | 本人和异步边界需回归 |
| PR304 的 CR-M1 文档措辞 Minor | 本版整理受影响的摘要，记录原版延期 | 仅文档，不倒填已修 |
| 任意时区分析、导出和到期输入 | 不纳入 | 保留 UTC 业务及设备输入语义 |
| 别名自动转换、服务器 tzdata、上传、站点时区 | 不纳入 | 不引入依赖或新的运行配置 |

## 必须实现

- 固定目录为已有 Node v26.3.0／ICU 78.3／tzdata 2026b 返回的 418 个 Intl 标识加 UTC。九个旧值均保留，目录发布后不随客户端动态变化，不宣称覆盖全部 IANA 别名。
- null 仍表示跟随设备。仅精确目录成员可保存；不接受空白、大小写变体、路径、任意偏移或目录外别名，不静默规范化保存值。
- 个人设置提供可搜索、可键盘操作的受控选择；筛选词不是保存值。保留旧九项的中英名称，其余显示完整 IANA 标识；无匹配时有友好反馈。
- 复用本人 Cookie API、完整精度 CAS、当前数据库有效身份、五秒事务、账号后组的锁序及 userId＋epoch 隔离。未保存的搜索和草稿不影响显示；读取、保存和冲突恢复不泄漏旧身份。
- 通过新迁移扩大 CHECK，保留全部旧行与版本。存在旧九项以外的保存值时 Down 安全失败且不改数据；兼容旧九项／null 时允许 Down／再次 Up。
- 浏览器不支持所选目录值时明确提示并回设备显示，保留账号值。非整小时偏移、DST、跨日和双语窄屏实际验证。

## 非目标与交付

不改变统计 UTC 分桶、纯日期、CSV、游标、CAS token、到期输入、服务端时间判定或公开跳转页；无新权限、业务路由、依赖、账号代理编辑、站点默认时区或发布部署。

真实后端与前端 RED→GREEN、迁移安全边界、标准生成零漂移、受影响完整本地门禁、准确产品浏览器与原图、唯一独立终审、最终 head 真实 CodeRabbit、正常合并独立核验、标准任务和可恢复归档分别取证。不查询或等待 CI。
