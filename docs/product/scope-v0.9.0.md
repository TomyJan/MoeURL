# v0.9.0 系统设置与站点品牌基础闭环范围

状态：设计阶段，功能尚未实施。

## 目标

v0.9.0 在现有初始化设置、前端语言与主题偏好、多提供商 OIDC 和权限目录之上，交付可实际管理的系统设置闭环。管理员可以维护站点名称、系统默认语言、系统默认主题和简单页脚，并在至少保留一个可用 OIDC 登录入口的前提下关闭本地账号登录。

本版本只补齐已有产品设计中的基础设置，不把主题编辑器、媒体上传、身份治理或部署配置搬入数据库后台。

## 必须实现

### 系统设置

- 管理员可以读取和更新站点名称、系统默认语言、系统默认主题、页脚文本、Powered by 显示开关和本地登录开关。
- 站点名称为纯文本，去除首尾空白后长度为 1 至 64 个 Unicode 字符；页脚文本为纯文本，可为空，最多 200 个 Unicode 字符，不解释 HTML。
- 默认语言只允许 `zh-CN` 和 `en`；默认主题只允许 `system`、`light` 和 `dark`。
- 系统默认语言和默认主题只在浏览器不存在用户本地偏好时生效，不覆盖已经保存的个人选择。
- 系统访问域名继续由初始化和部署配置管理；默认短链域名继续由域名管理页管理。

### 权限与并发

- 新增受保护权限 `system:manage`，固定属于内置 `admin`，不得授予 `guest` 或 `user`，也不得从 `admin` 移除。
- 系统设置和 OIDC Provider 管理同时要求 `admin:access` 与 `system:manage`；前端路由、导航可见性和后端 Service 使用相同权限契约。
- 设置读取返回统一修订时间，更新请求携带 `expectedUpdatedAt`；服务端在单一事务中比较版本并更新全部设置，冲突不得静默覆盖。

### 本地登录安全边界

- 只有至少一个未删除、已启用且持久化运行配置可校验、Client Secret 可解密的 OIDC Provider 存在时，才允许关闭本地登录；不以身份提供商的瞬时网络可达性作为开关条件。
- 本地登录关闭后，不能停用、删除或修改最后一个可用 OIDC Provider 为不可用状态。设置更新和 Provider 更新、停用、删除共享事务锁边界，避免并发操作绕过该不变量。
- 本地登录接口在密码校验和登录事务开始前读取策略；关闭时返回稳定的登录方式不可用错误，不泄露用户是否存在。
- 关闭本地登录不删除本地用户、密码或现有 Session；已登录用户继续使用原 Session，初始化流程仍可创建首个本地管理员。
- 应用启动时若发现本地登录关闭且不存在可用 OIDC Provider，应拒绝启动，避免部署进入无登录入口状态。

### 公开配置与前端

- 新增最小公开配置读取接口，只返回站点名称、系统默认语言、系统默认主题、页脚文本和 Powered by 显示开关，不返回本地登录策略、部署配置或其他管理字段。
- 既有登录方式接口返回真实的本地登录启用状态；登录页关闭本地登录表单后仍展示所有可用 OIDC Provider。
- `/admin/setting` 升级为真实系统设置页面，包含“常规设置”和“身份认证”区域；复用现有 OIDC Provider 管理能力，不复制第二套管理逻辑。
- 站点名称接入首页、登录页、控制台和页面标题；共享页脚接入公共页面、控制台、跳转页和错误页。公开配置读取失败时使用安全默认值，不阻塞首屏。
- 页面覆盖加载、错误、重试、脏草稿、保存、冲突和权限变化状态，并支持简体中文、英语、桌面和移动端。

## 数据与接口影响

- Goose migration 为现有 `system_setting` 增加缺失的设置默认值和统一修订行，不新增重复的通用配置表；同时把 `system:manage` 加入 `admin` 权限。
- 新增 `GET /api/v1/system/public-config`、`GET /api/v1/admin/system/settings` 和 `POST /api/v1/admin/system/settings/update`。
- `GET /api/v1/auth/methods` 保持现有响应结构，但 `local.enabled` 改为读取持久化策略。
- Provider 更新和删除的事务存储扩展为与本地登录策略协同；现有 OIDC Provider、外部身份和 Session 数据不迁移。

## 暂不实现

- Logo、Favicon、图片上传、首页背景图、主题色编辑、自定义 CSS 和任意 HTML 页脚。
- 页脚链接列表、备案信息结构化字段、首页标语和跳转页模板编辑。
- OIDC Provider 预置模板、组映射、账号主动绑定、SAML、LDAP、SCIM 和 Passkey。
- 默认短码长度、默认跳转方式、默认短链有效期、默认用户组和个人偏好服务端同步。
- 操作审计、设置历史、回滚 UI、批量导入导出和外部密钥管理。
- 通过后台修改 `MOEURL_PUBLIC_BASE_URL`、OIDC 加密密钥、数据库地址、系统访问域名或 TLS/DNS 配置。

## 完成标准

- 新旧部署都能读取稳定的公开配置和管理设置，管理员可以通过乐观并发安全更新全部本版本设置。
- 没有本地偏好的浏览器采用系统默认语言和主题；已有本地偏好不被后台更新覆盖。
- 本地登录关闭前后、最后一个 OIDC Provider 的更新与删除竞争、应用重启和现有 Session 行为均符合安全不变量。
- 管理页面、登录页、公共品牌与页脚在双语和桌面、移动端下形成真实闭环，不展示未实现选项。
- migration Up、Down、再次 Up、SQLC 零漂移、后端测试与覆盖率、前端测试与覆盖率、lint、typecheck、build、Playwright 和 Compose smoke 通过。
- 目标 CI、race、安全扫描和生产 OIDC 登录切换的证据独立记录；缺失时不得声称版本已发布。
