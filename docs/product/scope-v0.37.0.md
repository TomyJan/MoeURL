# v0.37.0 精确记录时间与提示排版

## 定位与状态

这是在 v0.36.0 交付之后的小阶段，不是新后台功能或正式发布。Agent 根据持续自主开发授权选择：先解决已记录的分钟精度与手机提示贴边，再扩展其他产品能力。设计取舍由 Agent 作出，不声称用户逐项指定。当前仅完成范围设计，产品实现、各本地门禁和远端交付分别验收。

基线为 PR243 实际合并的 master 5dc1c8aa34bbc9ba66576efd1ec41d1ce2025e43。其自身九项 CI、真实审查、标准 Task1–4、完整归档和准确 owned leaf 可恢复迁出均有外置 receipt；本版不能借用这些结果证明新输入通过。

## 必须实现

1. 审计和访问表格保留当前账号时区的紧凑时间；每个发生时间可通过鼠标、键盘和触屏展开完整原始 RFC3339 字符串，秒、小数位与偏移逐字符不变。
2. 精确时间使用文本节点。无 HTML 执行，无 Date 重序列化，无新 HTTP、缓存或身份观察者。
3. ConsoleShell 提示与内容保持有界留白；中英、设备回退、保存值、不支持及读取失败文案在手机能换行，不把整个页面撑宽。
4. 保持两表权限、分页、筛选、顺序、CSV 与 UTC 范围；公开页、到期输入、其他五个时间入口不变。

## 非目标

不增加 API、SQLC、migration、权限、依赖、时区预设或全局秒格式；不改身份刷新、保存行为、公开访问、18080 或日常 DB。不触 PR240，不 tag、release 或 deploy。新版本自己的本地、PR 和 master 证据完成前不写验收通过。
