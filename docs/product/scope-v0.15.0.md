# v0.15.0 账号语言与主题偏好

## 目标与状态

补齐既有个人设置规划中的服务端偏好保存，让同一账号在其他浏览器登录后恢复语言与主题。当前处于设计与实施，功能分支为 `feat/v0.15.0-account-preferences`；执行证据见 [验收记录](../implementation/v0.15.0-acceptance.md)。

启动时远端 `master` 仍为 `a52733cc`，GitHub API 显示 PR #187 未合并。新分支暂依赖 v0.14.0 的 `2e560f9f`；不将用户报告的合并状态代替实际提交证据，交付时重新核对基线。

## 必须实现

- 已登录的普通用户、管理员及 OIDC 用户可以读取和保存自己的账号语言与主题。
- 语言允许 `zh-CN`、`en` 或未设置；主题允许 `system`、`light`、`dark` 或未设置。未设置字段沿用浏览器及站点默认值。
- 个人设置页明确提供保存到账号、加载失败重试和冲突恢复；未保存草稿不改变当前界面。
- 登录后加载账号偏好；顶部切换仍是即时的浏览器选择，不隐式写库。当前会话主动切换优先于迟到的自动加载。
- 账号值不写入访客的本地存储；退出或切换账号移除上一账号覆盖层。迟到的读写结果不得应用到其他账号。
- Cookie 身份限定资源归属，不接受客户端用户 ID；乐观并发防止覆盖其他设备的新设置。
- migration、SQLC、权限、异常、覆盖率、双语及真实浏览器跨上下文场景形成闭环。

## 不纳入

头像、时区、默认域名、默认跳转模式、服务端保存所有 UI 状态、推送同步、自定义用户组与管理员代改个人偏好均不进入本版。

## 方案取舍

纯浏览器保存无法跨设备；所有顶部切换立即写库会引入意外写入与复杂的并发恢复。本版采用个人页显式保存账号值、顶部保留浏览器即时选择，在登录及页面刷新时加载账号默认偏好。无持续轮询或推送。
